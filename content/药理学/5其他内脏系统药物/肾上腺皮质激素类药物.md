# 肾上腺皮质激素类药物

## 一、❤糖皮质激素 —— 体内过程

- 吸收：口服、注射、皮肤、眼结膜吸收。可的松和氢化可的松吸收快且完全，1~2 h 内达峰，一次用药持续 8~12 h。
- 分布：氢化可的松进入血液后，有 10% 游离（有生物活性），90% 与血浆蛋白结合（80% 与<font color="#ff0000">皮质激素运载蛋白 CBG</font> 结合，10% 与白蛋白结合）。
	- CBG 在<font color="#ff0000">肝</font>中合成，肝、肾疾病、恶病质 —— <font color="#ff0000">减少用量</font>。
	- 妊娠/使用雌激素时，血中 CBG ↑，使游离 CG ↓，但通过负反馈作用可使 CG 水平恢复正常，因此无明显影响。
- 代谢：主要在<font color="#ff0000">肝</font>中还原代谢。
	- 可的松、泼尼松（C 环 C11）需要在肝内转化为氢化可的松、泼尼松龙方有活性 —— 肝、肾功能不好、局部用药时，<font color="#ff0000">不用可的松、泼尼松</font>。
	- 合用苯巴比妥、苯妥英钠、利福平等 —— 加速分解，<font color="#ff0000">增加用量</font>。
	- 甲亢时 —— CBG ↑、酶活性 ↑，肝灭活加速，<font color="#ff0000">增加用量</font>。
- 排泄：90% 以上在 48 小时内出现于尿中，尿中代谢产物 17-羟皮质素、17-羟酮皮质素可反映肾上腺-垂体功能。
- 根据作用时间长短，CG 可分为：短效（< 12 h）、中效（12~36 h）、长效（> 36 h）。

## 二、❤糖皮质激素 —— 药理作用

作用广泛，与剂量密切相关：

- 生理剂量时 —— 影响物质代谢过程（糖、脂、蛋白质、核酸、水与电解质代谢），维持机体自身稳定。
- 超生理剂量时 —— 还有抗炎、免疫抑制、抗休克等作用。
- 缺乏 → 代谢失调 → 死亡；应激 → 大量分泌 → 适应环境变化产生的刺激。

### （一）❤对代谢的影响

1. <font color="#ff0000">糖代谢——升高血糖</font>：促进糖原异生，减少葡萄糖利用，减少葡萄糖分解。<font color="#ff0000">※可能会诱发、加重糖尿病</font>。
2. <font color="#ff0000">蛋白质代谢</font>：肌肉、骨等组织蛋白质分解 ↑ → 负氮平衡；蛋白质合成 ↓ → 肌萎缩，伤口难愈。※长期用药引起肌肉消瘦、骨质疏松、皮肤变薄、伤口愈合延缓、成长缓慢、淋巴组织萎缩等。
3. <font color="#ff0000">脂肪代谢</font>：激活四肢皮下脂酶 → 四肢皮下脂肪分解 ↑ → 游离脂肪酸 ↑、酮体 ↑、血浆胆固醇 ↑ → 脂肪重新分布 → <font color="#ff0000">向心性肥胖</font>（面圆、背厚、躯干部发胖而四肢消瘦）。机制补充：胰岛素分泌 ↑ → 促进脂肪堆积 → 四肢不敏感，面、背部敏感。
4. <font color="#ff0000">水、电解质代谢</font>：弱的盐皮质激素作用 → 保钠排钾；拮抗抗利尿激素 → 利尿作用；长期用药 → 排钙 ↑、排磷 ↑、肠道对钙的重吸收 ↓ → 骨质脱钙。
5. <font color="#ff0000">核酸代谢——影响三大物质代谢的基础</font>：诱导合成 mRNA 或其他多种 RNA，从而影响物质代谢。

### （二）❤「四抗」

#### 1.❤抗炎作用

特点：

- 抗炎作用强大；抗炎为非特异性的；对炎症的各个阶段均有抑制作用。
- 早期 —— <font color="#ff0000">增加血管紧张型、降低血管通透性；抑制白细胞浸润及吞噬反应，减少炎症因子释放</font> → 减轻红、肿、热、痛。
- 后期 —— <font color="#ff0000">抑制毛细血管和成纤维细胞增生</font> → 防止粘连及瘢痕形成。
- 注意：抗炎同时降低了机体的防御功能 → 防御功能 ↓、组织修复 ↓。
- 局部抗炎有效。

机制：<font color="#ff0000">与胞浆内的 GC 受体（GR）结合</font>后发挥作用。

基因组效应（基本机制）：

1. GCs 进入细胞，与胞浆内的 GC 受体（GR）结合。
2. 未活化的 <font color="#ff0000">GR-HSP90</font> 与 GCs 结合后，GRα 与 HSP90 分离而活化，随后 <font color="#ff0000">GCs-GR 复合体进入细胞核</font>。
3. GCs-GR 与<font color="#ff0000">靶基因启动子序列的糖皮质激素反应元件（GRE）</font>结合。
4. <font color="#ff0000">转录增加或减少</font>。
5. <font color="#ff0000">改变炎性介质和细胞因子水平而抗炎</font>。
	- 对炎症抑制蛋白及某些靶酶的影响：<font color="#ff0000">脂皮素-1 ↑</font>；抑制 PLA₂（PG、白三烯 ↓）；抑制 iNOS、COX-2 的表达。
	- 对细胞因子及黏附因子的影响：促炎因子 ↓（TNF-α ↓、IL-1 ↓、IL-6 ↓）；ICAM ↓。
	- 诱导炎症细胞凋亡。

其他机制：稳定溶酶体膜和肥大细胞膜；增强血管对儿茶酚胺的敏感性；抑制成纤维细胞 DNA 的合成。

#### 2.❤免疫抑制与抗过敏作用

免疫抑制的机制：

- 抑制巨噬细胞对抗原的吞噬和处理。
- 诱导淋巴细胞的 DNA 降解，影响淋巴细胞的物质代谢。
- 诱导淋巴细胞凋亡。
- 干扰补体参与免疫反应，抗体生成减少。
- 抑制核转录因子 NF-κB 活性，抑制某些与慢性炎症有关的细胞因子（IL-2、IL-6、TNF-α 等）的基因表达。

抗过敏的机制：GCs 抑制过敏介质的产生，从而缓解许多过敏性疾病的症状，能抑制器官移植的排异反应。

#### 3.❤抗毒作用

- 提高机体对细菌内毒素的耐受力（稳定溶酶体膜，减少内源性致热源的释放及抑制下丘脑体温调节中枢的反应性）。
- <font color="#ff0000">不能中和内毒素</font>；<font color="#ff0000">不能保护机体免受外毒素的损害</font>。

#### 4.❤抗休克作用（常用于严重休克，特别是<font color="#ff0000">中毒性休克</font>）

- 提高机体对内毒素的耐受力。
- 降低血管对某些血管活性物质的敏感性，扩张痉挛的血管，使微循环的血流动力学恢复正常。
- 稳定溶酶体膜，减少心肌抑制因子（MDF）的形成和其他水解酶的释放，增强心肌收缩力。
- 抑制某些炎症因子的产生，减轻全身炎症反应综合征及组织损伤。

### （三）😊其他作用

1. 允许作用：增强儿茶酚胺的缩血管作用、胰高血糖素的升血糖作用等。
2. 退热作用：用于严重的中毒性感染 —— 稳定溶酶体膜、减少内源性致热源的释放、抑制中枢对致热源的反应。
3. 血液与造血系统：红细胞和血红蛋白 ↑、血小板 ↑、中性粒细胞 ↑（功能 ↓），淋巴细胞 ↓ ——「三升一降」。
4. 中枢神经系统：提高中枢兴奋性 → 精神失常、癫痫、儿童惊厥。
5. <font color="#ff0000">骨骼——骨质疏松（停药指征）</font>：抑制成骨细胞活力，减少骨中胶原的合成，促进胶原和骨基质的分解，使骨质形成发生障碍。
6. 消化系统：胃酸、胃蛋白酶 ↑，胃黏液分泌 ↓ → 诱发溃疡。

## 三、❤糖皮质激素 —— 临床应用

1. <font color="#ff0000">替代疗法</font>：用于急、慢性肾上腺皮质功能不全者，肾上腺次全切除术后，垂体前叶功能减退者。
2. <font color="#ff0000">严重感染或炎症</font>
	- 严重急性细菌感染：适用于严重感染、症状凶险、组织破坏严重并伴有中毒或休克的危重患者，如中毒性菌痢、流脑、败血症等。意义：迅速缓解症状，减轻炎症；保护心、脑等重要器官，减少组织损害；帮助患者度过危险期。用法：<font color="#ff0000">大剂量冲击疗法（3~5 d）</font>，与<font color="#ff0000">足量有效的抗菌药</font>合用。
	- 病毒性感染：原则上不用（<font color="#ff0000">水痘、带状疱疹禁用</font>）；某些严重感染可用：SARS、乙型脑炎等。
	- 用于某些炎症的后遗症：脑膜炎、心包炎、风湿性心瓣膜炎、眼科疾病等重要脏器炎症，防止疤痕形成、组织粘连。
3. <font color="#ff0000">免疫相关疾病</font>：自身免疫性疾病（风湿性、类风湿性关节炎、系统性红斑狼疮、肾病综合征等，一般综合用药）；过敏性疾病（荨麻疹、支气管哮喘、过敏性休克等，一般用抗组胺药、肾上腺素受体激动药，必要时本类辅助）；器官移植的排斥反应。
4. <font color="#ff0000">抗休克</font>
	- 感染中毒性休克：与抗生素合用，<font color="#ff0000">大剂量、及早、短时间突击使用</font>（在抗生素之后开始使用，在撤去抗菌药物前停药）。
	- 过敏性休克：首选肾上腺素，必要时加用糖皮质激素。
	- 低血容量性休克：首先补充血容量和电解质，必要时用糖皮质激素。
5. <font color="#ff0000">血液病</font>：治疗儿童急性淋巴细胞性白血病，与其他化疗药物合用；治疗溶血性贫血、再生障碍性贫血、粒细胞减少症、血小板减少症、过敏性紫癜等。
6. 其他系统疾病：眼部疾病（前部炎症：结膜炎、虹膜炎 —— 局部用药；后部炎症：脉络膜炎、视网膜炎 —— 全身或球后给药）；皮肤疾病（湿疹、接触性皮炎、牛皮癣 —— 局部应用；剥脱性皮炎 —— 全身用药）；呼吸道（严重支气管哮喘等的辅助治疗）。

## 四、❤糖皮质激素 —— 不良反应

### （一）❤长期大剂量应用引起的不良反应

1. <font color="#ff0000">类肾上腺皮质功能亢进综合征（cushing syndrome）</font>：糖、蛋白质、脂肪、水盐代谢紊乱。一般不作特殊治疗，必要时加用抗高血压药、抗糖尿病药，采用低盐、低糖、高蛋白饮食，补钾。
2. <font color="#ff0000">诱发和加重感染</font>：抑制免疫功能 → 体内潜在感染灶扩散，静止病灶复燃。结核病人必须合用抗结核药；无有效药物控制的感染需慎用。
3. <font color="#ff0000">消化系统并发症</font>：诱发、加重溃疡病。<font color="#ff0000">※溃疡患者禁用</font>。
4. <font color="#ff0000">糖尿病</font>。
5. <font color="#ff0000">骨质疏松、肌肉萎缩、伤口愈合延迟</font>。
6. <font color="#ff0000">糖皮质激素性青光眼</font>：易感患者小梁网细胞 GR 的亲和力更高，小梁细胞功能活动异常，房水回流受阻，眼压升高。
7. 心血管系统并发症：高血压、动脉硬化。
8. <font color="#ff0000">对妊娠影响</font>：增加胎盘功能不全、新生儿体重减少或死胎发生率。
9. 其他：失眠、幻觉甚至精神失常、癫痫。

### （二）❤停药反应

1. <font color="#ff0000">药源性肾上腺皮质功能不全</font>：长期应用 GCs → <font color="#ff0000">反馈性抑制下丘脑-垂体-肾上腺皮质轴</font> → ACTH 分泌 ↓ → 肾上腺皮质功能 ↓。
	- 恢复与剂量、用药时间、个体差异有关：停用激素后，垂体分泌 ACTH 的功能需 3~5 个月恢复；肾上腺皮质对 ACTH 起反应需 6~9 个月。
	- 故<font color="#ff0000">不可骤然减药，需缓慢减量</font>；尽量采用隔日给药；停药数月后遇应急情况，要给予足量的 GC。
2. <font color="#ff0000">反跳现象</font>：突然停药或减量过快时<font color="#ff0000">原有疾病</font>复发或恶化。原因：病人对激素产生了<font color="#ff0000">依赖</font>，且<font color="#ff0000">病情尚未完全控制</font>。处理：加大剂量再治疗，待症状缓解后再缓慢减量、停药。
3. 糖皮质激素抵抗：大剂量糖皮质激素治疗疗效很差或无效。

### （三）😊禁忌证

肾上腺皮质功能亢进综合征；严重糖尿病、高血压，骨折、创伤修复期，角膜溃疡；抗菌药物不能控制的感染（如水痘、带状疱疹、真菌感染等）；活动性消化性溃疡，新近胃肠吻合术；有严重精神病或癫痫病史者；孕妇。

## 五、❤糖皮质激素 —— 用法及疗程

| 方案 | 适用 | 代表药物与剂量 |
| ---- | ---- | ---- |
| <font color="#ff0000">大剂量冲击疗法</font> | <font color="#ff0000">严重感染及休克</font>、急性中毒、危及生命的疾病抢救（如休克、急性移植排斥反应） | 氢化可的松静滴 200~300 mg，一日达 1 g 以上；疗程 ≤ 3 d；<font color="#ff0000">可立即停</font> |
| <font color="#ff0000">隔日清晨疗法</font> | <font color="#ff0000">慢性病</font> | 一般采用中效类泼尼松、泼尼松龙等，可减轻对内源性皮质激素分泌的抑制作用；长期；逐渐停 |
| <font color="#ff0000">小剂量替代疗法</font> | <font color="#ff0000">垂体前叶功能 ↓</font>、<font color="#ff0000">肾上腺皮质功能 ↓</font> | 氢化可的松 10~20 mg/日；长期或终身；逐渐停 |

药物选择：

- 氢化可的松 —— 急性荨麻疹、过敏性休克等急性疾病（短疗程）。
- 地塞米松 —— 急性荨麻疹、过敏性休克等急性疾病，或不能口服给药的患者（短疗程）。
- 泼尼松 —— 慢性疾病或需要长期疗法用药的患者（中、长疗程）。
- 甲泼尼龙 —— 急危重症患者冲击疗法。
- 曲安奈德 —— 皮损内注射。

## 六、😊盐皮质激素与促皮质素

### （一）盐皮质激素（Mineralocorticoids）

醛固酮、去氧皮质酮等，可促进肾对 Na⁺、Cl⁻ 的重吸收和 K⁺ 的排出；有一定糖皮质激素样作用但很弱。

主要用于慢性肾上腺皮质功能减退症，纠正水、电解质紊乱。

### （二）促皮质素（ACTH）

39 个氨基酸的多肽；作用于肾上腺，使 GCs 分泌增加，维持肾上腺皮质的正常形态与功能。

- 皮质功能完好才有作用；ACTH 缺乏可引起肾上腺皮质萎缩、功能减退。
- 应用：诊断脑垂体-肾上腺皮质功能。
