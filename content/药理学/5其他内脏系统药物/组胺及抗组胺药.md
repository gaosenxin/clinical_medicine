# 组胺及抗组胺药

## 一、😊组胺（Histamine）

一类广泛分布于体内、具有多种生物活性的自体活性物质。

- 合成：组氨酸经组氨酸脱羧酶生成组胺。
- 储存：与肝素、蛋白质结合（结合型，无活性），存在于肥大细胞、嗜碱性粒细胞中。
- 分布：肺、皮肤、胃肠黏膜中含量高。
- 释放：在组织损伤、炎症、神经刺激、某些药物、一些抗原-抗体反应的条件下，以活性形式（游离型）释放。

| 促进释放的因素 | 抑制释放的因素 |
| ---- | ---- |
| 抗原与肥大细胞、嗜碱性粒细胞表面的 IgE 结合；<font color="#ff0000">某些药物</font>：吗啡、可待因、哌替啶、筒箭毒碱、右旋糖酐等；某些动物的<font color="#ff0000">分泌物</font>：蛇毒、蜂毒等；物理因素：寒冷、外伤、紫外线照射等 | 能升高肥大细胞及嗜碱性粒细胞内 <font color="#ff0000">cAMP</font> 的药物，如儿茶酚胺类、茶碱类等；过敏介质阻断药：色甘酸钠、奈多罗米钠、酮替芬等 |

### （一）😊组胺的受体类型及其效应

| 受体类型 | 分布、效应 | 阻断药 |
| ---- | ---- | ---- |
| H₁ | 支气管、胃肠、子宫等的平滑肌 —— <font color="#ff0000">收缩</font>；皮肤血管 —— <font color="#ff0000">扩张</font>；心房、房室结 —— 收缩 ↑、传导 ↓ | 苯海拉明、异丙嗪、氯苯那敏等 |
| H₂ | <font color="#ff0000">胃壁细胞 —— 分泌 ↑</font>；<font color="#ff0000">血管 —— 扩张</font>；心室、窦房结 —— 收缩 ↑、心率 ↑ | 西咪替丁、雷尼替丁等 |
| H₃ | 中枢与外周神经末梢 —— 负反馈调节；心耳 —— 负性肌力 | —— |
| H₄ | 免疫器官和造血细胞 —— 免疫反应 | —— |

### （二）😊组胺的作用

心血管系统：

1. 心肌：激动 H₂ 受体 → AC 活性 ↑ → cAMP ↑ → 正性肌力作用。
2. 血管：激动<font color="#ff0000">血管平滑肌的 H₁、H₂ 受体 → 小动脉、小静脉扩张，回心血量 ↓</font>（大剂量时，强而持久的降压，甚至发生休克）。
3. 血小板：可作用于血小板 H₁ 受体，激活 PLA₂，介导花生四烯酸的释放，引起血小板聚集；还可作用于 H₂ 受体，增加血小板中 cAMP 水平，对抗血小板聚集，最终效果取决于两者功能的平衡变化。

平滑肌：激动<font color="#ff0000">平滑肌细胞的 H₁ 受体 → 支气管平滑肌收缩 → 呼吸困难</font>（支气管哮喘）；→ <font color="#ff0000">胃肠道平滑肌收缩 → 痉挛性腹痛</font>。

腺体：激动<font color="#ff0000">胃壁细胞的 H₂ 受体 → 激活 AC，使 cAMP ↑ → H⁺-K⁺-ATPase 活性 ↑ → 分泌胃酸 ↑</font>。

中枢 —— 失眠；神经末梢 —— 三联反应，即毛细血管扩张（红斑）、毛细血管通透性 ↑（丘疹）、轴索反射（红晕）。

## 二、❤组胺受体阻断药

### （一）❤H₁ 受体阻断药

- 第一代：苯海拉明、异丙嗪、氯苯那敏（扑尔敏）、曲吡那敏（扑敏宁）；有明显镇静、抗胆碱作用。
- 第二代：西替利嗪、阿司咪唑、阿伐斯汀、左卡巴斯汀、咪唑斯汀；大多长效，<font color="#ff0000">无嗜睡作用</font>，对喷嚏、清涕、鼻痒效果好，对鼻塞效果差。

药理作用：

1. <font color="#ff0000">阻断 H₁ 受体作用</font>
	- <font color="#ff0000">完全对抗平滑肌的收缩作用</font>（如支气管平滑肌、胃肠道平滑肌）。
	- 对组胺直接引起的<font color="#ff0000">局部毛细血管扩张、通透性增加</font>及其所致的水肿有<font color="#ff0000">强大的抑制</font>作用。
	- 对组胺<font color="#ff0000">舒张血管和血压降低</font>作用仅能<font color="#ff0000">部分抵抗</font>（因 H₂ 受体也参与心血管活动的调节，故需同时应用 H₁、H₂ 受体阻断药才能完全抵抗）。
2. <font color="#ff0000">中枢抑制作用</font>：镇静、嗜睡等，以苯海拉明、异丙嗪作用最强（第一代）；机制为阻断中枢 H₁ 受体，阻断中枢内源性组胺介导的觉醒反应。
3. <font color="#ff0000">其他</font>：苯海拉明、异丙嗪具有<font color="#ff0000">阿托品样抗胆碱作用</font>，止吐、防晕效果较强。

临床应用：

- <font color="#ff0000">皮肤黏膜变态反应性疾病</font>：对部分皮肤Ⅰ型变态反应如荨麻疹、过敏性鼻炎等疗效较好；对昆虫咬伤所致皮肤瘙痒、水肿、药疹、血管神经性水肿也有一定疗效。<font color="#ff0000">对支气管哮喘、过敏性休克无效</font>，<font color="#ff0000">严重血管神经性水肿应选用肾上腺素</font>。
- <font color="#ff0000">防晕动病、止吐</font>：苯海拉明、异丙嗪。
- <font color="#ff0000">失眠</font>：苯海拉明、异丙嗪，尤其是皮肤黏膜变态反应引起的失眠。

不良反应：

- 中枢抑制现象：第一代药物多见镇静、嗜睡、乏力等，<font color="#ff0000">服药期间应避免驾车、高空作业等活动</font>。
- 抗胆碱作用：口干、便秘等，<font color="#ff0000">青光眼、尿潴留患者禁用</font>。
- 其他：粒细胞减少、溶血性贫血；阿司咪唑、特非那定可导致尖端扭转型心律失常。

### （二）❤H₂ 受体阻断药

药理作用：<font color="#ff0000">竞争性拮抗胃壁细胞 H₂ 受体，抑制胃酸分泌</font>；明显抑制基础胃酸分泌和其他因素引起的夜间胃酸分泌。

强弱比较：西咪替丁 < 雷尼替丁、尼扎替丁 < 法莫替丁。

临床应用：<font color="#ff0000">消化性溃疡</font>（胃溃疡、十二指肠溃疡）；<font color="#ff0000">其他胃酸分泌过多的疾病</font>，如反流性食管炎、胃肠吻合口溃疡等。

不良反应：

- 一般反应：便秘、腹泻、腹胀（胃肠），头痛、头晕、皮疹、瘙痒等。
- 长期服用西咪替丁可引起阳痿、性欲减退、男性青年女性化，使老人出现幻觉、癫痫发作；引起肝功能损害。
- 西咪替丁为肝药酶抑制剂，影响香豆素类、苯巴比妥、地西泮、苯妥英钠、茶碱、普萘洛尔的代谢。
