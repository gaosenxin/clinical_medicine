# 作用于消化系统的药物

## 一、😊概述

当壁细胞制造、分泌 H⁺ 增加时，胃囊内即呈现高酸状态，产生临床症状，甚至造成酸相关性疾病。

酸相关性疾病：消化道溃疡、胃食管反流病、慢性胃炎、功能性消化不良等。

治疗这些疾病通常需要用到抑酸药，包括 H₂ 受体阻断药、H⁺-K⁺-ATPase 抑制剂、M 胆碱受体阻断药、胃泌素阻断药等。

## 二、❤抑酸药

### （一）❤H₂ 受体阻断药（H₂RA）

基础：肠嗜铬样细胞释放组胺 → 激动壁细胞<font color="#ff0000">基底侧膜上的 H₂-R → H⁺-K⁺-ATPase 活性 ↑</font> → 泌酸 ↑。

药理作用及机制：H₂RA 可<font color="#ff0000">竞争性阻断壁细胞基底膜的 H₂-R，抑制组胺激动该受体引起的胃酸分泌</font>。抑制所有时相的胃酸分泌，抑酸作用弱于 PPIs，副作用也较轻。

临床应用：用于<font color="#ff0000">胃、十二指肠溃疡（首选药物）</font>，减轻溃疡引起的疼痛，促进愈合；也可用于无并发症的胃食管反流综合征，预防应激性溃疡的发生。

不良反应（发生率低）：轻微的腹泻、便秘、眩晕、乏力、肌肉痛、皮疹、皮肤干燥、脱发；少见的中枢神经系统反应，如嗜睡、焦虑、幻觉、谵妄等。

代表药物：西咪替丁、雷尼替丁、法莫替丁等。

![[组胺-H2受体阻断药-p113.png]]

### （二）❤H⁺-K⁺-ATPase 抑制剂 / 质子泵抑制药（PPI）

- 为前体药物，在酸性环境中激活。
- 在酸性的壁细胞分泌小管内，转化为次磺酸和亚磺酰胺，<font color="#ff0000">与 H⁺-K⁺-ATP 酶 α 亚单位的巯基共价结合，使其失活，减少胃酸分泌</font>。
- 注意：H⁺-K⁺-ATPase 是胃酸分泌的最后环节，故对各种因素引起的胃酸分泌均有抑制作用；作用强大而持久；使胃蛋白酶产生减少，对胃黏膜有保护作用；体外实验证明还对幽门螺杆菌有抑制作用。

奥美拉唑：

- 强大而持久地抑制胃酸分泌，抗溃疡作用，机制如上。
- 临床应用：用于消化性溃疡，对 NSAIDs、乙醇、应激所致的<font color="#ff0000">胃黏膜损伤</font>有预防保护作用；Hp 感染；上消化道出血；卓-艾综合征等。
- 不良反应：很少，偶见恶心、呕吐、腹胀、便秘、腹泻等，对肝药酶有一定抑制作用。
- 长期使用存在安全隐患：继发感染（最常见为社区获得性肺炎及艰难梭菌相关性腹泻）；骨髓毒性、低镁血症、骨质疏松、维生素 B 缺乏等；胃窦 G 细胞产生胃泌素增加，血清促胃泌素浓度升高，动物实验提示上消化道肿瘤发生率增加。

### （三）😊M 胆碱受体阻断药

抑制胃酸分泌的机制：

- 阻断胃壁细胞上的 M 受体，抑制胃酸分泌。
- 阻断胃黏膜嗜铬细胞上的 M 受体，减少组胺的释放。
- 阻断胃窦 G 细胞上的 M 受体，减少胃泌素的释放，间接减少胃酸的分泌。
- 此外，M 受体阻断药还有解痉作用。

由于抑酸作用弱、不良反应多，目前较少用于溃疡病的治疗。代表药物：阿托品、溴化丙胺、哌仑西平。

哌仑西平：

- 主要阻断 M₁ 受体（也有 M₂ 受体阻断作用），显著抑制胃酸分泌，明显缓解胃溃疡患者的症状，用于治疗胃、十二指肠溃疡。
- 不良反应以消化道症状为主，表现为口干，此外还可能出现视物模糊、头痛、眩晕、嗜睡等。

### （四）😊胃泌素受体阻断药 —— 丙谷胺

机制：与胃泌素竞争胃泌素受体，抑制胃酸分泌；促进胃黏膜黏液合成，增强胃黏膜的黏液-HCO₃⁻ 保护屏障。代表药物：丙谷胺。

## 三、😊抗酸药

弱碱性物质。

作用有两方面：口服后在胃内直接中和胃酸，升高胃内容物 pH；通过改变 pH 来降低胃蛋白酶活性。

包括：碳酸钙、氢氧化镁、氢氧化铝、三硅酸镁、碳酸氢钠等。

| 药物 | 特点 |
| ---- | ---- |
| 三硅酸镁 | 作用弱、慢、持久；胃内生成胶状二氧化硅，对溃疡面有保护作用 |
| 氢氧化镁 | 作用较强，起效较快；镁离子有导泻作用；肾功能不全引起血中镁离子浓度 ↑ |
| 氢氧化铝 | 作用较强、起效缓慢、作用持久；产生氧化铝，有收敛、止血、致便秘作用；长期服用影响肠道对磷酸盐的吸收 |
| 碳酸氢钠 | 作用强、起效快、持续时间短暂；中和胃酸时产生二氧化碳，引起嗳气、腹胀，继发性胃酸分泌增加；口服后可被肠道吸收，导致血液、尿液碱化 |
| 碳酸钙 | 作用较强、起效快而持久；引起嗳气、腹胀；进入小肠的钙离子促进胃泌素分泌，可引起反跳性胃酸分泌 ↑ |

由于抗酸药仅仅直接中和胃酸，并不能调节胃酸的分泌，甚至可造成反跳性胃酸分泌增加，用于治疗消化性溃疡及反流性食管炎但非首选药物；且大多制成复方制剂，以增强疗效、减少不良反应，如胃舒平（氢氧化铝、三硅酸镁、颠茄流浸膏）、三硅酸镁复方制剂（氢氧化铝、三硅酸镁、海藻酸）。

## 四、😊胃黏膜保护剂

指增强胃黏膜屏障（细胞及黏液-HCO₃⁻ 屏障）功能的药物，可预防和治疗胃黏膜损伤，促进黏膜修复和炎症愈合；有些兼有抗酸作用，有的还具有杀灭幽门螺杆菌的效用。

米索前列醇（前列腺素衍生物）：

- 与壁细胞、胃黏膜浅表细胞基底侧的前列腺素受体结合。
- 促进浅表细胞分泌黏液和 HCO₃⁻；抑制壁细胞的胃酸分泌；抑制胃蛋白酶分泌；增加胃黏膜血流，促进增殖重建。
- 应用：治疗胃、十二指肠溃疡，应对长期使用 NSAIDs 引起的消化性溃疡、胃出血有特效。

硫糖铝：

- 黏附于上皮细胞和溃疡面基底部，在溃疡面形成保护屏障，阻止胃酸和消化酶的侵蚀。
- 促进和合成 PGE₂；增强表皮生长因子的作用；抑制 Hp。
- 应用：消化性溃疡、反流性食管炎、慢性糜烂性胃炎、Hp 感染等。

枸橼酸铋钾：

- 在酸性条件下，于溃疡表面形成坚固的氧化铋胶体沉淀，成为保护性薄膜，减少胃内容物对溃疡部位的侵蚀。
- 还能抑制胃蛋白酶活性，促进合成前列腺素，增加黏液、HCO₃⁻ 分泌；还对 Hp 有一定抑制作用。

## 五、😊消化系统功能调节药

### （一）😊止吐药

呕吐是一种复杂的反射活动，可由多种因素引起，属于保护性反应。呕吐中枢和延髓催吐化学感受区（CTZ）参与呕吐反射；一些化学药物、放射病以及尿毒症时体内蓄积的有毒物质，直接刺激 CTZ，产生恶心呕吐；一些外周刺激也能通过反射导致恶心呕吐（胃十二指肠等内脏的感受神经受刺激、咽部迷走神经感觉神经末梢受刺激、内耳前庭的位置感觉改变等）。因此应针对原因选药。

常用止吐剂：抗组胺药、M 胆碱受体阻断药、多巴胺 D₂ 受体阻断药、5-HT 受体阻断药。

| 类型 | 作用机制 | 应用 | 不良反应 | 代表药物 |
| ---- | ---- | ---- | ---- | ---- |
| 抗组胺药 | 与组胺竞争效应细胞上的 H₁ 受体，对抗组胺收缩胃肠道平滑肌的作用；中枢抑制作用（与阻断中枢 H₁ 受体、中枢抗胆碱作用有关） | 预防、治疗<font color="#ff0000">晕动病、内耳性眩晕病</font>等 | 镇静、嗜睡，用药期间不能驾车、从事机械或高空作业 | 苯海拉明、异丙嗪、美克洛嗪 |
| M 受体阻断药 | 中枢抗胆碱作用抑制前庭系统活性、扩张微血管改善内耳循环 | 抗<font color="#ff0000">晕动病</font>，防治胃肠刺激所致恶心、呕吐 | 口干、瞳孔散大、皮肤潮红、心跳加快；青光眼、严重心脏病患者禁用 | 东莨菪碱、阿托品、苯海索 |
| 多巴胺 D₂ 受体阻断药 | 阻断 CTZ 的 D₂ 受体（部分还有 5-HT₄、胃动素、5-HT₃ 受体作用） | 吗丁啉：胃肠运动障碍型疾病；放疗、偏头痛、手术、胃镜检查等引起的恶心呕吐 | 溢乳、头昏、男性乳房发育等 | 多潘立酮（吗丁啉）、甲氧氯普胺 |
| 5-HT 受体阻断药 | 选择性阻断外周神经系统突触前和呕吐中枢的 5-HT₃ 受体，阻断突触反射 | 高治疗指数止吐药，治疗、预防化疗/放疗相关恶心呕吐及术后呕吐 | 便秘、腹泻、头晕、头痛 | 昂丹司琼 |

![[消化-止吐药分类-p109.png]]

### （二）😊止泻药

| 类别 | 代表药与机制 |
| ---- | ---- |
| 吸附剂 | 吸收肠道内液体、毒物，阻止毒物吸收 —— 白陶土、药用炭 |
| 收敛剂 | 在肠黏膜表面形成保护膜，抑制炎性渗出，发挥收敛、止泻作用 —— 鞣酸蛋白等 |
| 抗动力剂 | 阿片制剂，用于较严重的非细菌感染性腹泻，激动 μ 阿片受体，减少胃肠推进性蠕动 —— 洛哌丁胺、地芬诺酯、复方樟脑酊 |
| 抗分泌药 | 消旋卡多曲 |

### （三）😊泻药

- 硫酸镁：硫酸根和镁离子在肠道难以被吸收，使肠内容物渗透压 ↑，抑制水分的吸收，增加肠腔容积、扩张肠道、刺激肠道蠕动。用于外科术前/结肠镜检查前排空内容物；辅助排出一些肠道寄生虫或肠内毒物。
- 乳果糖：口服不吸收；到结肠被细菌分解成乳酸，刺激结肠局部渗出；还可以抑制对氨的吸收，降低血氨。
- 甘油：轻度刺激性导泻。
- 酚酞：刺激肠壁，抑制水分重吸收。
- 液体石蜡：润滑肠壁、软化大便。

![[消化-腹泻与便秘用药-p110.png]]

### （四）😊利胆药

具有促进胆汁分泌或胆囊排空的药物。

- 胆汁的基本成分是胆汁酸；胆汁酸的主要成分为胆酸、鹅去氧胆酸和去氧胆酸，占 95%；次要成分为石胆酸和熊去氧胆酸，占 5%。
- 胆汁酸的生理功能：反馈性抑制胆汁酸合成，引起胆汁流动，调节胆固醇合成与消除，促进脂质和脂溶性维生素吸收等。
