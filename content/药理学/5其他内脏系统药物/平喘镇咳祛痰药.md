# 作用于呼吸系统的药物

## 一、😊概述

支气管哮喘、COPD 是呼吸系统常见疾病，常伴有喘息、咳嗽、咳痰的症状。

- 喘息 —— 平喘药（抗炎性平喘药、支气管扩张药、抗过敏平喘药）
- 咳嗽 —— 镇咳药
- 咳痰 —— 祛痰药

## 二、❤平喘药

支气管哮喘（asthma）是一种慢性变态反应性炎症疾病。

- 临床表现：反复发作的呼吸短促、胸部紧缩感、喘息并常伴有咳嗽的症状。
- 病理特征：广泛、可逆的支气管狭窄和气道高反应性，支气管黏膜嗜酸性粒细胞和淋巴细胞等炎症细胞的浸润和气道重塑。
- 抗炎性平喘药 —— 对因治疗，能有效缓解疾病进程。
- 支气管扩张药 —— 对症治疗，是支气管哮喘<font color="#ff0000">急性发作时的首选治疗</font>。

### （一）❤支气管扩张药

#### 1.❤β 肾上腺素受体激动药

药理作用、机制：

- 激动支气管平滑肌细胞的 β₂ 受体，<font color="#ff0000">使气道平滑肌松弛</font>。
- 激动肥大细胞表面的 β₂ 受体，<font color="#ff0000">抑制肥大细胞释放炎症介质、过敏介质</font>。
- 机制：β₂ 受体激动药与支气管平滑肌细胞膜上的 β₂ 受体结合，引起受体构型改变 → 激活 Gs → 活化 AC → <font color="#ff0000">细胞内 cAMP ↑</font> → 激活 PKA → [Ca²⁺] ↓ → 支气管平滑肌松弛。

![[呼吸-β2激动药机制-p100.png]]

临床应用：主要用于支气管哮喘、喘息型支气管炎、伴有支气管痉挛的呼吸道疾病。吸入给药 —— 最常用；静脉给药 —— 哮喘急性发作。

不良反应：<font color="#ff0000">心脏反应</font>；<font color="#ff0000">肌肉震颤</font>（激动骨骼肌慢收缩纤维的 β₂ 受体）；<font color="#ff0000">代谢紊乱</font>。

各药特点：

| 药物 | 特点 |
| ---- | ---- |
| 肾上腺素 | 皮下注射用于哮喘急性发作 |
| 麻黄碱 | 作用缓慢温和、持久；口服用于轻症及预防发作 |
| 异丙肾上腺素 | 吸入控制哮喘急性发作；长期应用 → 严重心律失常 |
| 沙丁胺醇（喘乐宁、舒喘灵） | 对呼吸道有高选择性，对支气管平滑肌 β₂ 受体的作用远大于对心脏 β₁ 受体；扩张支气管作用与异丙肾上腺素相近但更持久；气雾吸入迅速缓解症状，口服控制频发性或慢性哮喘 |

#### 2.❤茶碱类

药理作用及机制（茶碱具有平喘、强心、利尿、扩张血管、中枢兴奋等作用，以下与平喘有关）：

1. <font color="#ff0000">舒张支气管平滑肌</font>
	- <font color="#ff0000">抑制 PDE，使细胞内 cAMP ↑</font>，支气管平滑肌舒张。
	- <font color="#ff0000">阻断腺苷受体</font>，减轻内源性腺苷所致的气道收缩。
	- <font color="#ff0000">增加内源性儿茶酚胺的释放</font>：使肾上腺髓质释放儿茶酚胺，间接舒张支气管。
2. <font color="#ff0000">抗炎作用</font>：抑制肥大细胞、嗜酸性粒细胞等功能，减少炎症介质释放、降低微血管通透性，减轻气道炎症反应。
3. <font color="#ff0000">增加膈肌收缩力，促进支气管纤毛运动</font>。
4. <font color="#ff0000">强心利尿作用</font>。

临床应用：

- <font color="#ff0000">支气管哮喘</font>：用于 β₂ 受体激动药不能控制的急性哮喘（静注）；慢性哮喘患者口服氨茶碱，防止急性发作。
- <font color="#ff0000">COPD</font>：对于 COPD 伴有喘息、COPD 伴有右心功能不全的心源性哮喘患者有明显疗效（氨茶碱的扩张肺动脉、强心、利尿作用）。
- 中枢型睡眠呼吸暂停综合征。

不良反应（治疗窗较窄）：<font color="#ff0000">胃肠道不良反应</font>；<font color="#ff0000">中枢兴奋</font>（失眠、震颤、激动）；<font color="#ff0000">心血管系统症状</font>；<font color="#ff0000">急性中毒</font>：常见于静注过快或剂量较大，出现心动过速、心律失常、血压骤降、谵妄、惊厥、昏迷等（<font color="#ff0000">低浓度缓慢注射</font>）。

#### 3.❤抗胆碱药（M 胆碱受体阻断药）

胆碱能神经在气道的分布特点：大气道 > 中气道 > 小气道。亚型：M₁、M₂、M₃。

| 亚型 | 分布 |
| ---- | ---- |
| M₁ | 副交感神经节节后胆碱能神经 |
| M₂ | （负反馈调节） |
| M₃ | 大、小气道平滑肌；气道黏膜下腺体；血管内皮细胞 |

与 β₂ 受体激动药比较：

- 抗胆碱药主要作用于大气道，使大气道松弛，对小气道口径影响小；β 受体激动药对大、小气道均有影响。
- 起效慢、维持时间长、剂量小、副作用少、不易耐药。
- 是 β₂ 受体激动药的替代药，与 β₂ 受体激动药联合使用具有协同、互补作用。
- 对心血管系统作用不明显，对痰液分泌和痰液黏稠度无影响。
- 对<font color="#ff0000">老年性哮喘、伴有迷走神经功能亢进的哮喘</font>疗效较好。
- 副作用：口干、咽部刺激、恶心、干咳。
- <font color="#ff0000">对阿托品类药物过敏者避免使用</font>。
- <font color="#ff0000">青光眼、前列腺肥大患者禁用</font>。

代表药物：异丙托溴铵、异丙托品、噻托溴铵等。可必特气雾剂：异丙托品 + 沙丁胺醇。

### （二）❤抗炎平喘药 —— 糖皮质激素

基本作用机制：强大的抗炎作用与免疫抑制作用。吸入剂型糖皮质激素已成为治疗哮喘的一线药物，主要不良反应是局部不良反应。

倍氯米松（Beclomethasone）：

- 作用机制：抑制多种参与哮喘发病的炎症细胞和免疫细胞的功能；抑制细胞因子和炎症介质的产生；增强支气管及血管平滑肌对儿茶酚胺的敏感性；抑制气道高反应性；对上皮损伤的修复和支气管纤毛的生长有促进作用。
- 临床应用：目前治疗哮喘最有效的抗炎药物（哮喘一线用药）；支气管扩张药不能有效控制的慢性哮喘患者；重度及极重度的 COPD。气雾吸入。<font color="#ff0000">不能缓解急性症状，不适用于哮喘持续状态</font>。
- 不良反应：吸入后药物沉积在咽部并吞咽到胃肠道，引起局部不良反应 —— 声音嘶哑、声带萎缩变形、咽喉疼痛；口咽部念珠菌感染等。<font color="#ff0000">吸入后立即漱口</font>。

### （三）😊抗过敏平喘药

主要是抗过敏 + 轻度抗炎作用。平喘起效较慢，不宜用于哮喘急性发作，临床上主要用于<font color="#ff0000">预防哮喘发作</font>。

#### 1.炎症细胞膜稳定药 —— 色甘酸钠

- 药理作用及机制：稳定肥大细胞膜，抑制钙内流，阻止抗原诱导的脱颗粒；抑制支气管对非特异性刺激的高反应性。
- 临床应用：粉雾吸入，不适用于哮喘急性发作的治疗，主要用于<font color="#ff0000">预防哮喘的发作</font>。

#### 2.白三烯调节剂

CysLTs 与炎症：引起支气管黏液分泌、支气管平滑肌收缩、血管通透性 ↑、嗜酸性粒细胞浸润。

5-脂氧酶抑制剂可减少 CysLTs 合成，而 CysLT₁ 受体拮抗药可通过阻断 CysLTs 的上述作用而治疗哮喘。

白三烯调节剂：具有拮抗白三烯作用的药物，也称白三烯拮抗药，是一类新型的非甾体类治疗哮喘的药物，对多种类型的哮喘有效，治疗指数高，可以口服。

- 5-脂氧酶抑制剂：齐留通（zileuton）
- 白三烯受体拮抗药：扎鲁司特（zafirlukast）、孟鲁司特（montelukast）

![[呼吸-白三烯通路-p103.png]]

扎鲁司特：

- 选择性 CysLT₁ 受体拮抗药。
- 抑制气管炎症及抗原诱导的迟发性支气管收缩反应。
- 减少哮喘病人糖皮质激素及 β₂ 受体激动药的用量。
- 用于轻至中度慢性哮喘的预防及治疗；严重哮喘病人的辅助治疗；阿司匹林过敏性哮喘和运动性哮喘患者的治疗。

![[呼吸-平喘药总结-p104.png]]

## 三、❤镇咳药

咳嗽是一种保护性反射，可以促进呼吸道黏液和异物的排出，保持呼吸道的清洁和通畅。

- 对于<font color="#ff0000">无痰干咳</font>，应采用镇咳药物治疗（减轻患者痛苦、防止原发疾病发展、避免咳嗽引起的并发症）。
- 细菌性感染时，+ 抗菌药物。
- <font color="#ff0000">咳嗽 + 咳痰困难慎用镇咳药</font>，使用祛痰药。

常用的镇咳药可分为：中枢性镇咳药（抑制延髓咳嗽中枢）；外周性镇咳药（抑制咳嗽反射弧中除中枢外的环节）。

可待因（甲基吗啡）：

- 药理作用：<font color="#ff0000">镇咳</font> —— 抑制咳嗽中枢，强度为吗啡的 1/4，维持 4~6 h；<font color="#ff0000">镇痛</font> —— 吗啡的 1/7~1/10，成瘾性 < 吗啡。
- 临床应用：<font color="#ff0000">剧烈干咳</font>（胸膜炎干咳、胸痛等）；<font color="#ff0000">镇痛</font>（中度疼痛）。因此对胸膜炎干咳伴胸痛者尤为适用。
- 不良反应：<font color="#ff0000">久用成瘾</font>。

右美沙芬：

- <font color="#ff0000">中枢镇咳</font>，强度与可待因相当，不镇痛。
- 用于<font color="#ff0000">干咳</font>，无成瘾性。

喷托维林（咳必清）：

- 作用：<font color="#ff0000">中枢镇咳</font>，强度为可待因的 1/3，无成瘾性；轻度的阿托品样解痉作用（使痉挛的支气管平滑肌松弛）；局部麻醉作用（减少刺激）。
- 应用：<font color="#ff0000">少痰干咳</font>。
- 不良反应：口干（阿托品样作用）。青光眼、前列腺肥大、心功能不全者慎用。

## 四、❤祛痰药

包括痰液稀释药、黏痰溶解药。

- 痰液稀释药 —— 增加痰液中水分含量，稀释痰液，包括恶心性祛痰药、刺激性祛痰药。
- 黏痰溶解药 —— 使痰液黏稠度降低/调节黏液成分，使痰液容易排出，包括黏痰溶解药、黏液调节药。

氯化铵（恶心性祛痰药）：

- 作用：口服后<font color="#ff0000">刺激胃黏膜，通过迷走神经反射促进支气管腺体分泌 ↑，使痰液变稀</font>。
- 应用：黏痰不易咳出，复方使用。
- 不良反应：恶心、呕吐，长期使用可造成酸中毒和低血钾。

乙酰半胱氨酸（痰易净，黏痰溶解药）：

- 作用：<font color="#ff0000">打断黏痰蛋白的二硫键</font>，降低痰液的黏稠度；对脓性痰液中的 DNA 也有一定降解作用。
- 应用：用于<font color="#ff0000">黏痰（栓塞）</font>，呼吸困难。
- 使用：雾化吸入法（用于黏痰多、呼吸困难）；气管滴入法（痰栓塞危急病人，需要有吸痰器防窒息）。
- 注意：合用<font color="#ff0000">异丙肾上腺素防呛咳、支气管痉挛</font>；用玻璃、塑料（非金属、橡胶）喷雾装置；<font color="#ff0000">禁与青霉素、头孢菌素类、四环素混合</font>。

溴己新（黏痰调节药）：

- 作用：<font color="#ff0000">溶解黏痰、抑制黏痰合成、祛痰、促进痰液排出</font>（裂解黏多糖；抑制黏多糖合成；支气管分泌 ↑）。
- 应用：<font color="#ff0000">气管炎、哮喘</font>而痰不易咳出者。
- 不良反应：偶见转氨酶升高。
