# 镇静催眠药（Sedative-hypnotics）

> [!important] 目的与要求
> - 掌握：地西泮的体内过程特点、作用、作用机制、对睡眠时相的影响、临床应用、不良反应。
> - 熟悉：巴比妥类药物的作用及作用机制、临床应用及不良反应。
> - 了解：其它镇静催眠药的作用特点及临床应用。

## 一、😊睡眠的生理

### （一）😊睡眠的生理意义

- 醒觉：学习和工作必须处于清醒的头脑，高效
- 睡眠：足够的睡眠，使机体恢复疲劳、得到休整

生理意义：

1. 促进脑功能的发育和发展
2. 保持脑功能的能量
3. 巩固记忆及保证大脑发挥最佳功能
4. 促进机体生长，延缓衰老
5. 增强机体的免疫功能

> [!note] 数据
> - 据世界卫生组织调查，27% 的人有睡眠问题。
> - 每天睡眠时间少于 4 h 或超过 10 h，其全因死亡率增加 1.5 至 2 倍。
> - 每年的 3 月 21 日为「世界睡眠日」——睡眠对健康至关重要。

### （二）😊睡眠障碍的定义（美国精神医学会）

- 连续睡眠障碍时间长达一个月以上。
- 睡眠障碍的程度足以造成主观的疲累、焦虑，或客观的工作效率下降、角色功能损伤。

### （三）😊睡眠机制与分期

- 睡眠机制：脑干尾端睡眠中枢发出冲动向上传导至大脑皮质，与控制觉醒状态的脑干网状结构上行激动系统相互作用，从而调节睡眠与觉醒的相互转化。
- 睡眠分期[[觉醒与睡眠]]
	- <u>NREM</u>（非快动眼睡眠）：分泌大量生长激素，减少蛋白分解、促进合成作用，加速受损组织愈合；利于精力恢复。
	- <u>REM</u>（快动眼睡眠）：梦境可减缓压力，维持情绪平衡。
- 睡眠周期：NREM 与 REM 每隔 90 分钟交替循环出现，4~5 次/夜，NREM 占 70~75%。

## 二、😊镇静催眠药概述

- 概念：一类通过抑制中枢神经系统，达到缓解过度兴奋和引起近似生理睡眠的药物。
- 理想催眠药：应能依需要纠正各种类型的失眠（难入睡、易醒、早醒等），引起完全类似于生理性的睡眠。

镇静药与催眠药（按剂量区分）：

| 名称 | 作用 |
| ---- | ---- |
| 镇静药（Sedative） | 轻度抑制、缓和激动，消除躁动，恢复安静情绪 |
| 催眠药（Hypnotics） | 引起近似生理性睡眠的药物 |

药物分类：

- A　苯二氮䓬类（Benzodiazepines, BDZ）
- B　巴比妥类（Barbiturates）
- C　其它（褪黑素 melatonin）

## 三、❤苯二氮䓬类（Benzodiazepines, BDZ）

### （一）😊基本结构与分类
- 按半衰期分类：长效——地西泮；中效——劳拉西泮；短效——三唑仑
## 地西泮 Diazepam，安定
### （二）❤体内过程

- <font color="#ff0000">脂溶性<u>高</u></font>，弱<u>碱</u>性。
- 口服吸收<font color="#ff0000"><u>较完全</u></font>，肌注<u>慢而不规则</u>（欲快速显效时应<u>静脉给药</u>）。
- <font color="#ff0000">肝药酶代谢，部分代谢物有活性</font>（去甲西泮），有肝药酶<u>诱导</u>作用，有<u>肠肝循环</u>（长效）
- 大多数与血浆蛋白结合程度很<u>高（>95%）</u>。
- 静脉给药能迅速进入<u>脑</u>，再分布至<u>脂肪组织</u>。

### （四）❤药理作用和临床应用

随剂量递增，依次出现下列作用：<u>抗焦虑</u> → <u>镇静催眠</u> → <u>抗惊厥、抗癫痫</u> → <u>中枢性肌肉松弛。</u>

| 药理作用 | 临床应用 |
| ---- | ---- |
| 抗焦虑 | 焦虑症、麻醉前给药 |
| 镇静催眠 | 失眠症（焦虑性失眠） |
| 抗惊厥、抗癫痫 | 惊厥、癫痫 |
| 中枢性肌肉松弛 | 中枢性肌强直、腰肌劳损 |
| 暂时性记忆缺失 | 心脏电击复律、内镜检查 |

#### 1.❤<u>抗焦虑作用</u>

- ① 作用发生<u>快</u>而<u>确实</u>；
- ② <font color="#ff0000">选择性<u>高</u></font>（小剂量作用于边缘系统）。
- 【临床应用】
	- <font color="#ff0000"><u>抗焦虑首选药</u></font>；

#### 2.❤<u>镇静催眠作用</u>

特点：

- ① 作用迅速，<font color="#ff0000">诱导入睡（时间↓）</font>
- ②<font color="#ff0000">延长睡眠时间</font>
	- 对<u> REMS</u> 影响小，<font color="#ff0000">无明显停药反跳现象</font>，停药困难少；
	- ❤近似生理睡眠时相：
		- NREMS 1 期缩短
		- NREMS 2 期延长
		- 3、4 期缩短，减少夜惊或梦游症；
		- REMS 影响小
		- ![[镇静催眠药-1792205764392.webp|397]]
- ③提高觉醒阈，减少觉醒次数
- ④ 产生耐受性、依赖性<font color="#ff0000">慢</font>，<font color="#ff0000">治疗指数高</font>，安全范围大，对呼吸影响小。
- ⑤有暂时的<font color="#ff0000">记忆缺失</font>（大剂量），加大剂量不会引起全麻
- ⑥对肝药酶几无作用

【临床应用】<font color="#ff0000"><u>镇静催眠</u>首选</font>，较接近生理性睡眠，优于巴比妥类。
	神经衰弱、各种失眠患者
	- 麻醉前给药（缓解恐惧、减少用量、产生暂时记忆缺失）。
	- 内镜检查前给药
	- 夜惊和夜游症的患者
#### 3.❤<u>抗惊厥、抗癫痫作用</u>

- 惊厥：中枢过度兴奋；表现为全身骨骼肌不自主的强烈收缩。
- 癫痫：脑病灶异常放电扩散；表现为意识丧失、抽搐、无意识动作、神经异常等。
- 地西泮、三唑仑作用显著，临床用于破伤风、子痫、小儿高烧惊厥、药物中毒惊厥。
- ❤<font color="#ff0000">地西泮静脉注射是癫痫持续状态的首选药</font>；硝西泮、氯硝西泮主要用于癫痫小发作。

#### 4.😊<u>中枢性骨骼肌松弛</u>
[[N2受体阻断药]]
- 作用：有较强的肌松作用和降低肌张力作用，<font color="#ff0000">但不影响正常活动</font>。
- 应用：用于治疗中枢或局部病变引起的肌张力增高及肌肉痉挛。
- 机制：小剂量抑制脑干网状系统下行系统对 γ 神经元的易化作用；大剂量增强脊髓神经元突触前抑制，抑制多突触反射。（γ 神经元位于脊髓前角，调节肌梭对牵拉刺激的敏感性，支配梭内肌。）
临床应用
	缓解<font color="#ff0000">中枢神经系统病变引起的肌张力升高</font>
	加强全麻药物的肌松作用
### （五）❤作用机制
<sub></sub>
通过增强中枢抑制性递质<font color="#ff0000"> γ-氨基丁酸（GABA）</font>的作用实现：

> [!note] 机制链条
> BZ 药物 + BZ 位点结合 → GABA + <font color="#ff0000">GABA<sub>A</sub></font> → Cl⁻ 通道<font color="#ff0000">开放频率增加</font>（Cl⁻ 内流）→ 超极化 → 中枢抑制

![[镇静催眠药-1791616202800.webp|249]]
### （六）😊BZ 受体脑内分布

分布密度：<u>大脑皮质 ＞ 边缘系统、中脑 ＞ 脑干、脊髓</u>。
小剂量先进入边缘系统

| 部位 | 功能 |
| ---- | ---- |
| 边缘系统（海马、杏仁核） | 抗焦虑 |
| 延脑、下丘脑等网状结构 | 镇静、催眠 |
| 网状结构及脊髓 | 中枢性肌松弛 |
| 大脑皮层、丘脑、边缘系统 | 抗惊厥、抗癫痫（抑制癫痫灶异常放电扩散） |

### （七）❤不良反应
中枢抑制作用相关
1. 嗜睡、头晕、乏力。
2. 长期较大剂量服用（300–600 mg/日）无明显中毒症状发生，但有耐受性和成瘾。
3. 静脉过快易引起心血管抑制、呼吸抑制，故宜慢速推注。
4. BZ 类与其他中枢抑制药、乙醇合用会加重嗜睡、昏睡、呼吸抑制甚至昏迷，严重可致死。
- ❤中毒抢救：<font color="#ff0000"><u>氟马西尼（flumazenil）（BZ 位点拮抗）</u></font>。
	- <font color="#ff0000">只拮抗 BZ 类</font>药物，对巴比妥类和三环类过量所致的中枢抑制无对抗作用；还可改善酒精性肝硬化患者的记忆缺失，并用于 BZ 过量的诊断。

## 四、❤巴比妥类（Barbiturates）

- 为巴比妥酸衍生物。
- 由 C5 上的两个 H 被不同基团取代而成，取代基不同则作用强弱不等。
- 最常用的有 10 种左右。
- 目前已被苯二氮䓬类取代。
#### 体内过程
- 吸收：口服、注射均易吸收
- 分布：分布于全身组织、体液
  - 脂溶性影响药物进入脑组织的速度
- 代谢与排泄
  - 脂溶性高的药物：在肝脏代谢
  - 脂溶性小的药物：主要以原形由肾排出
- 尿液pH值对苯巴比妥（弱酸性药）的排泄影响较大
  - （碳酸氢钠）<font color="#ff0000">碱化尿液</font>，药物解离增多，肾小管重吸收减少，排出增多

### （一）❤药理作用和临床应用

1. 镇静：选苯巴比妥。
2. 催眠：选异戊巴比妥、司可巴比妥、苯巴比妥。特点：<font color="#ff0000">缩短快波睡眠（REM）</font>，久服<font color="#ff0000">停药易反跳</font>（REM 显著延长，出现多梦），因而易致药物<font color="#ff0000">依赖性</font>。
3. 抗惊厥：苯巴比妥，用于癫痫大发作或癫痫持续状态。[[抗癫痫和抗惊厥药]]
4. 麻醉前给药：用<font color="#ff0000">硫喷妥钠</font>（超短效）。
5. 增强其他药物的中枢抑制作用

### （二）❤作用机制

巴比妥类与 GABA 受体上的巴比妥类结合位点结合
	增加 Cl⁻ 通道开放<font color="#ff0000"><u>持续时间</u></font>，促进 GABA 引起的 Cl⁻ 内流，引起细胞膜超极化。
	拟GABA作用，直接促进Cl⁻ 内流

### （三）😭不良反应

1. [[后遗效应]]
2. [[耐受性]]（肝药酶诱导剂）
3. [[依赖性]]（兼有精神依赖与躯体依赖）
4. <font color="#ff0000">呼吸抑制</font>
5. 诱导肝药酶活性，干扰其他药物代谢
6. 禁用于严重肺功能不全和颅脑损伤所致呼吸抑制者。
### （四）😊中毒解救
维持血压和呼吸
<font color="#ff0000">碱化</font>（碳酸氢钠）：苯巴比妥为弱酸性

## 五、😊新型非苯二氮䓬类（Z-药）
<font color="#ff0000">只有镇静催眠作用</font>
### （二）❤唑吡坦（Zolpidem）

- 机制：选择性激动 GABAA 受体上的 BZ 位点（类似地西泮）。
- 特点：<font color="#ff0000">仅用于镇静催眠</font>；安全范围大；对正常睡眠结构干扰小（区别于 BZ 的要点）。

### （三）😊佐匹克隆（zopiclone，忆梦返）

- 分类：第三代快速催眠药，作用于 GABAA 受体 BZ 位点。
- 药代：作用<font color="#ff0000">迅速</font>，达峰时间 0.5~1 h，半衰期 5~6 h。
- 作用特点：缩短睡眠潜伏期，减少觉醒次数，提高睡眠质量。
- 适应症：适用于各种类型失眠症。
- 不良反应：较少；部分患者口干、口苦、恶心、便秘、肌无力等。
- 注意事项：长期用药突然停药会出现戒断症状；<u>严重呼吸功能不全、本药过敏者禁用；孕妇、哺乳期妇女慎用</u>。

> [!note] 右佐匹克隆（dexzopiclone）为其异构体。

### （四）😊扎来普隆（zaleplon，思威坦 Sonata）

- 特点：起效快，作用时间短，属于<u>短效催眠药</u>。
- 适应症：适用于<u>入睡困难</u>型失眠症的治疗。

## 六、😊5-羟色胺（serotonin）及其受体

- 主要存在中枢，集中于<u>中缝核</u>内。
- <u>通路</u>
	- 上行部：中缝核低位脑干 → 纹状体、丘脑、下丘脑、边缘前脑、大脑皮层
	- 下行部：脊髓后角、侧角、前角
- <u>受体</u>：5-HT₁~5-HT₇，有多种亚型；5-HT₃ 是离子通道型受体，其余为 G 蛋白耦联受体；5-HT1A 是突触前受体。
- <u>生理调节</u>：痛觉、精神情绪、睡眠、体温、性行为、垂体内分泌。
### ❤丁螺环酮（Buspirone）

- 特点：小剂量即可缓解焦虑
	- <font color="#ff0000">起效慢</font>，需 1~2 周；<font color="#ff0000"><u>无耐受性、无成瘾性</u></font>。
	- 无致遗忘、镇静、肌松、抗惊厥作用，不增强乙醇的中枢抑制作用。
	- <font color="#ff0000">首过效应明显</font>；剂量 15~30 mg/d，起始 5 mg、每日 3 次。
- 作用机制：作用于海马 <font color="#ff0000">5-HT₁A 受体</font>，为<u>部分激动剂</u>，发挥<font color="#ff0000">抗焦虑</font>作用；降低体内 5-HT₂ 受体敏感性，兼具<font color="#ff0000">抗抑郁</font>作用。
	- 激动海马突触前 5-HT1A 受体，通过反馈抑制 5-HT 释放而抗焦虑。
- 临床应用：<u>广泛性焦虑</u>；对恐惧症疗效差。
