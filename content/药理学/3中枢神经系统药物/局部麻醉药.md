## 一、😊概念

局部麻醉药（local anesthetic），简称局麻药：局部应用于神经末梢或神经干，能可逆地阻断神经冲动的产生和传导，在意识清醒的条件下引起有关神经支配的部位出现暂时性、可逆性感觉丧失的药物。

## 二、😭化学结构

基本结构由三部分组成：芳香环 —— 中间链 —— 胺基团。芳香环为亲脂性部分，胺基团为亲水性部分。

| ---- | ---- | ---- |
| 酯类 | 具 —COO— 基团 | 普鲁卡因、丁卡因 |
| 酰胺类 | 具 —CONH— 基团 | 利多卡因、布比卡因、罗哌卡因、依替卡因（Etidocaine） |

结构与性质的关系：

| ---- | ---- | ---- |

| 代谢 | 由胆碱酯酶降解 | 由肝药酶代谢 |

## 三、❤局麻作用及其机理

### （一）❤作用机制
- 阻滞神经细胞膜上的<font color="#ff0000">电压门控Na⁺通道</font>→抑制膜兴奋性
- 过程：以<font color="#ff0000">非解离型</font>进入神经细胞内→以<font color="#ff0000">解离型</font>作用在细胞膜内表面→与Na⁺通道特异性结合位点结合→阻滞Na⁺通道
	- 进入细胞（要求）：亲脂性、非解离型
	- 阻滞通道（要求）：解离型
![[局部麻醉药-1793608409206.webp|388]]
- 高浓度也阻断钾通道。
- 具有使用依赖性
	- 频率依赖性：神经组织受到的刺激频率越高，开放的通道数目越多，受阻滞越明显，局麻作用越强。
	- 电压依赖性

### （二）❤局麻作用的表现

提高产生神经冲动所需的阈电位，抑制动作电位去极化上升的速度，延长不应期，甚至丧失兴奋性及传导性。

- 对任何神经都有阻断作用；高浓度时也抑制平滑肌和骨骼肌的活动。
- 对膜静息电位无明显影响，主要抑制动作电位。
- 具有使用依赖性（频率依赖性）。

| ---------------------------------------------------------------------------------------------------------------------------------- | ------ | ----------------------------- |

|                                                                                                                                    | 髓鞘     | 无髓鞘的交感、副交感神经节后纤维在低浓度即可显效（较敏感） |

## 五、❤不良反应及防治
- **1. 毒性反应**：局麻药剂量过高、误注入血管所致
  - 中枢神经系统毒性（先于心脏毒性）：<font color="#ff0000">先兴奋后抑制</font>（抑制性神经元更敏感）
    - 表现：抑制性神经元首先被阻滞→兴奋症状（眩晕、惊恐、震颤、焦虑、神志错乱、阵挛性惊厥）→抑制（昏迷、呼吸衰竭状态）
    - 处理：1）静脉注射<font color="#ff0000">地西泮</font>可防止惊厥发作、2）维持呼吸重要
  - 心血管系统：局麻药的 #膜稳定作用 →降低心肌兴奋性
    - 心肌收缩力减弱、传导减慢、小动脉扩张、血压降低，甚至休克
    - 防治：1）以预防为主；2）静推脂肪乳抢救布比卡因中毒
- **2. 变态反应**：荨麻疹、支气管痉挛、喉头水肿等
  - 酯类局麻药比酰胺类发生率高；酯类过敏者可改用酰胺类


- 神经状况。
- 血液 pH：pH 越高，非解离型越多，起效越快、阻滞越完善、时效延长。
- 药物浓度。
- 血管收缩药（肾上腺素 1/20 万）：减慢作用部位吸收，降低血内药物浓度，延长作用时效，减少全身不良反应。
- 比重、体积。
- 病理状态：剂量增大 → 毒性发生。
- 时辰。
- 尿液 pH：pH 越高，重吸收越多。
- Na⁺／Ca²⁺ 水平。
- 药物相互作用。

### （一）❤普鲁卡因（Procaine，奴佛卡因 Novocaine）

- 分类与性质：酯类、短效、脂溶性低、黏膜穿透力弱；毒性小，是常用的局麻药之一。
- 用途：浸润麻醉 0.5%~1%、传导麻醉、蛛网膜下腔麻醉、硬膜外麻醉 2% 及局部封闭。
- 时效：1–3 min 起效，维持 30–45 min；加肾上腺素维持时间可延长 20%。
- 代谢：代谢产物对氨苯甲酸（PABA）可对抗磺胺类药物的作用。
- 不良反应：有过敏反应，用药前应做皮试。
- 普鲁卡因过量可引起中枢神经系统和心血管系统反应，用药前应做<font color="#ff0000">皮试</font>。

### （二）❤丁卡因（Tetracaine，地卡因 Dicaine）

- 分类与性质：酯类局麻药；麻醉强度比普鲁卡因强 10 倍，毒性大 10~12 倍。
- 穿透力强，常用于表面麻醉。
- 时效：1–3 min 起效，维持时间长（2–3 h）。
- 注意：毒性大，不作浸润麻醉。

### （三）❤利多卡因（Lidocaine）

- 应用最多的局麻药。
- 特点：快效、强效、长效，t₁/₂ 为 90 min，持续 1–2 h；穿透力强。
- 安全范围大：无扩张血管作用，对组织无刺激性。
- 用途：全能麻醉药，主要用于传导麻醉和硬膜外麻醉；可用于普鲁卡因过敏者。
- 抗心律失常作用：主要用于室性心律失常。
- 浓度：浸润麻醉采用 0.25~0.5% 溶液；表面麻醉、传导麻醉和硬膜外麻醉采用 1~2% 溶液。
- 注意：毒性作用大小与用药浓度有关；反复用药可产生快速耐受性。

### （四）😊布比卡因（Bupivacaine，麻卡因 Marcaine）

- 分类：酰胺类局麻药。
- 作用：比利多卡因强 45 倍；持续时间长，可达 5~10 h。
- 用途：主要用于浸润、传导和硬膜外麻醉。
- 不良反应：严重的心脏毒性，尤其在酸中毒、低氧血症时。

### （五）😊罗哌卡因（Ropivacaine）

- 对心肌毒性小。
- 有明显收缩血管作用，使用时无需加肾上腺素。
- 用途：硬膜外麻醉、臂丛阻滞和浸润麻醉。
- 对子宫胎盘血流无影响，可用于产科麻醉。
