## 一、😊概述

### （一）😊精神失常与药物分类

精神失常（Psychiatric disorders）：由多种原因引起的精神活动障碍，表现为思维、情感、知觉、智能、意志和行为诸方面的障碍。以思维障碍、情感障碍为最常见。

- <font color="#ff0000">精神分裂症</font>：
	- 思维、情感、行为之间互不协调，精神活动脱离现实环境；临床表现为思维缺乏逻辑性、语言不连贯，并出现各种幻觉、妄想。
		- Ⅰ型以阳性症状（幻觉、妄想）为主
		- Ⅱ型以阴性症状（情感淡漠、缺乏主动性）为主。治疗以氯丙嗪为代表。
- <font color="#ff0000"> 躁狂症</font>：情感活动呈病态性高涨，表现为兴奋、多话、多动作，直至发生躁狂行为。
- <font color="#ff0000">抑郁症</font>：情绪低落、语言减少、消极厌世，甚至企图自杀。治疗以丙咪嗪为代表。
- <font color="#ff0000">焦虑症</font>：表现为紧张、焦虑、心悸、出冷汗、震颤及睡眠障碍等。治疗以安定为代表。

## 二、😊抗精神病药（Antischizophrenia drugs）

- 又称神经安定药（Neuroleptic drugs），主要用于治疗精神分裂症和躁狂症。

### （一）😊多巴胺通路、发病机制与药物分类
![[抗精神失常药-1791764286392.webp]]
多巴胺系统功能亢进学说：

| 通路                                               | 解剖               | 生理功能                           | 受体亚型                    |
| ------------------------------------------------ | ---------------- | ------------------------------ | ----------------------- |
| 黑质-纹状体（Nigrostriatal）                            | 黑质 → 纹状体         | 锥体外系运动的高级中枢                    | D₁、D₅（D₁ 样）；D₂、D₃（D₂ 样） |
| <font color="#ff0000">中脑-边缘（Mesolimbic）</font>   | 顶盖 — 伏隔核和嗅结节     | 调节精神活动（控制情绪反应，认识、思想、感觉、理解、推理等） | D₂、D₃、D₄（D₂ 样）          |
| <font color="#ff0000">中脑-皮质（Mesocortical）</font> | 顶盖 — 大脑皮层        | 调节精神活动                         | D₂、D₃、D₄（D₂ 样）          |
| 结节-漏斗（Tuberoinfundibular）                        | 弓状核和室周核、漏斗核和正中隆起 | 调控垂体激素的分泌                      | D₂                      |

作用机制：

1. 阻断中脑-边缘和中脑-皮质通路的多巴胺 D₂ 样受体；
2. 阻断中枢 5-HT 受体 —— 新型（非经典型）抗精神病药，如氯氮平、利培酮。

抗精神失常药可阻断多种受体。

药物分类：吩噻嗪类（Phenothiazines）、硫杂蒽类（Thioxanthenes）、丁酰苯类（Butyrophenones）及其他药物（非经典型）。

### （二）❤氯丙嗪（Chlorpromazine，冬眠灵 Wintermin）

#### 1.😊吩噻嗪类的结构与常用药

由硫、氮原子联结两个苯环（称为吩噻嗪母核）的一类化合物。国内临床常用的有氯丙嗪（1952 年，法国）、氟奋乃静及三氟拉嗪等，以氯丙嗪应用最广。

| 类别 | 药物（取代基） |
| ---- | ---- |
| 二甲胺类 | 氯丙嗪（R₁ = —(CH₂)₃N(CH₃)₂，R₂ = —Cl） |
| 哌嗪类 | 奋乃静、氟奋乃静（R₂ = —CF₃）、三氟拉嗪（R₂ = —CF₃） |
| 哌啶类 | 硫利达嗪（R₂ = —SCH₃） |

#### 2.😊体内过程
- <font color="#ff0000"> 脂溶性高</font>
- 吸收：口服不规则，多<u> im</u>。
- 分布：全身，尤<font color="#ff0000">脑内浓度高</font>（约为血药浓度的 10 倍）。
- 代谢：肝脏。
- 排泄：肾脏。
- <font color="#ff0000">容易蓄积于脂肪组织；个体差异大，应个体化给药。</font>

#### 3.❤药理作用

##### （1）❤中枢神经系统

① <u>抗精神病作用</u>

- 对中枢有较强的选择性抑制作用（又称神经安定作用）；有耐受性
- 控制兴奋躁动，消除幻觉、妄想、恢复理智等；无耐受性。
- <font color="#ff0000">对抑郁无效</font>，甚至可使抑郁加剧；一般需连续用药 6 周～6 个月才充分显效。

 氯丙嗪抗精神病作用机制
![[抗精神失常药-1791765294162.webp|342]]

② <u>镇吐作用</u>

- 特点：A 作用强大；B <font color="#ff0000">对刺激前庭引起的呕吐无效（晕动症）</font>[[M受体阻断药#1.❤ 东莨菪碱 （scopolamine）|关联东莨菪碱]]；C 抑制呃逆。
- 机制：小剂量阻断延髓催吐化学感受区的 D₂ 受体；大剂量直接抑制呕吐中枢。

③ <u>对体温调节的影响</u>

- 机制：抑制下丘脑体温调节中枢，使体温调节失灵。
- 特点：A 体温随环境温度改变；B 不仅降低发热者的体温，也能降低正常人体温（不同于[[解热镇痛抗炎药|解热镇痛药]]）。
④<u>加强中枢抑制药的作用</u>
##### （2）❤自主神经系统作用

- 阻断 α 受体（较强）
	- 致血管扩张、血压下降，但可因连续用药产生耐受性，且有较多副作用，故不适用于高血压的治疗。
- 阻断 M 受体（较弱）
	- 作用较弱，可引起口干、便秘、视物模糊

##### （3）😊对内分泌系统的影响

- 抑制催乳素抑制因子 → 催乳素 ↑ → 乳房肿大、泌乳；月经紊乱、延迟排卵。
- 抑制促性腺激素（FSH、LH），排卵延迟、月经延长，性功能↓
- 生长激素↓，可试用于治疗巨人症。
- 阻断结节-漏斗 D₂ 受体还使糖皮质激素释放减少。

#### 4.❤临床应用

1. <u> 精神分裂症</u>
	- 主要用于Ⅰ型精神分裂症的治疗。
	- 对Ⅱ型精分症（情感淡漠、主动性缺乏）<font color="#ff0000">无效</font>，甚至加重病情。
	- 对各种器质性精神病和症状性精神病的兴奋、幻觉和妄想症状也有效，但剂量要小，症状控制后须立即停药。
2. <u>呕吐和顽固性呃逆</u>
	- 对多种药物（强心苷、吗啡、四环素等）及疾病（尿毒症、恶性肿瘤）引起的呕吐有显著止吐作用。
	- 对顽固性呃逆也有显著疗效。
	- 但对晕动症（晕车、船）引起的呕吐无效 → 由前庭刺激引起，应用抗组胺药止呕。
3. <u>低温麻醉与人工冬眠</u>
	- 氯丙嗪加物理降温（冰袋、冰浴）可用于低温麻醉。
	- 人工冬眠
		- <font color="#ff0000">冬眠合剂 = 氯丙嗪 + 异丙嗪 + 哌替啶（度冷丁）</font>。
		- 人工冬眠 → 体温 ↓、基础代谢 ↓、组织耗氧量 ↓ → 提高机体对缺氧的耐受力、减轻机体对伤害性刺激的反应。
	- 应用：严重创伤、感染性休克、高热惊厥、中枢性高热及甲状腺危象等辅助治疗。
4. <u>加强中枢抑制药的作用</u>
	加强催眠药、镇痛药的作用
#### 5.❤不良反应
![[抗精神失常药-1791766709589.webp|464]]
1. 常见不良反应
	- 中枢症状：嗜睡、淡漠、无力。
	- M 受体阻断效应：口干、便秘、视力模糊、眼压升高、无汗。
	- α 受体阻断效应：鼻塞、血压下降、体位性低血压及反射性心悸。

> [!note] 氯丙嗪引起的血压下降能用肾上腺素急救吗？
> 不能。原因：氯丙嗪阻断 α 受体、保留了 β 受体作用，引起肾上腺素的血压翻转作用，使其升压转为降压。应用去甲肾上腺素。
> 麻黄碱可以，因为可以促进去甲的释放

2. 锥体外系反应
	- 急性锥体外系运动障碍（三种形式）：① <u>帕金森综合征（最常见）</u>；② <u>静坐不能</u>；③ <u>急性肌张力障碍</u>。
		- 机制：氯丙嗪阻断黑质-纹状体 D₂ 受体，胆碱能神经功能相对占优势所致。
		- 治疗：中枢性抗胆碱药（安坦或东莨菪碱）。
	- <u>迟发生运动障碍</u>（tardive dyskinesia, TD）：
		- 机制：DA 受体长期被阻断 → DA 受体向上调节，受体数目、敏感性 ↑，突触前膜 DA 释放 ↑。
		- 治疗：抗胆碱药反加重症状，可试用氯氮平治疗。
		- 除口-舌-颊刻板动作外，还可见广泛性舞蹈样手足徐动症。
	- 精神异常：一旦发生立即减量或停药。
	- 惊厥与癫痫：必要时加用抗癫痫药。
	- 过敏反应：皮疹、皮炎、微胆管阻塞性黄疸、粒细胞减少。
	- 心血管和内分泌系统反应。
	- 急性中毒：昏睡、血压下降至休克、心肌损害，昏迷至死。治疗：洗胃、对症处理、中枢兴奋药氯酯醒，严重者血透。

#### 6.😊药物相互作用及禁忌

- 与其它中枢抑制药合用要注意调整剂量；抑制 DA 受体激动药和左旋多巴的作用；肝药酶诱导剂（苯妥英钠、卡马西平）可加速其代谢，合用时应调整剂量。
- 禁忌：有癫痫及惊厥史者、青光眼患者、乳腺增生症和乳腺癌患者，严重肝肾疾病等禁用；
- 慎用：冠心病患者易致猝死，应慎用。

### （三）😊其他抗精神病药（前六：熟悉；舒必利、氯氮平、利培酮：掌握）

#### 吩噻嗪类其他药物：

| 药物 | 特点 |
| --- | --- |
| 奋乃静 | 作用较缓和；对心血管系统、造血系统的副作用相对较小；对慢性精神分裂症的疗效强于氯丙嗪 |
| 三氟拉嗪、氟奋乃静 | 中枢镇静作用较弱，有明显的抗幻觉、妄想作用；对退缩、情感淡漠者有较好疗效；适用于精神分裂症偏执型和慢性精神分裂症 |

## 三、😊抗躁狂药 —— 碳酸锂（Lithium carbonate）（熟悉）

躁狂症：情感活动呈病态性高涨，表现为兴奋、多话、多动作，直至发生躁狂行为。

发病机制：单胺学说 —— 5-HT ↓、NA ↑。

作用特点：

1. 主要以锂离子形式发挥作用，为首选药。
2. 治疗量时对正常人精神活动几无影响；对躁狂病人则疗效显著；对精神分裂症的躁狂症状亦有较好疗效。

作用机制：Li抑制脑内NA，DA释放，促进再摄取

临床应用：

- 躁狂症。
- 精神分裂症的兴奋躁动状态：+ 抗精神病药。

不良反应：

- <font color="#ff0000">安全范围小</font>（0.8–1.5 mmol/L）。
1. 轻度：恶心、呕吐、腹泻、无力、肢体震颤。
2. 中毒：脑病综合征 —— 意识障碍、深反射亢进、共济失调、震颤。
	- 解救：立即停药，静滴生理盐水。

## 四、❤抗抑郁药（Antidepressant drugs）

### （一）😊发病机制（单胺学说）

- 脑 5-HT ↓
- 脑 NA ↓：抑郁 —— 情绪低落、寡语、运动迟缓、丧失社会交往能力、自杀等
- 脑 NA ↑：躁狂 —— 情绪高涨、联想敏捷、活动增多、语言不能自制等
- 该组药物均提高突触间隙 NA 或 5-HT 浓度 → 治疗抑郁症。

| 递质 | 相关表现 |
| ---- | ---- |
| NE | 能量、兴趣、焦虑、激惹、冲动 |
| 5-HT | 心情、情绪、认知功能、动机、食欲、性欲、攻击 |
| DA | 驱动力 |

### （二）❤三环类抗抑郁药（TCAs）—— 米帕明（Imipramine，丙米嗪）

| 药名 | 英文 | 剂量范围（mg/day） | 备注 |
| ---- | ---- | ---- | ---- |
| 丙咪嗪 | imipramine | 50–300 |  |
| 氯米帕明 | clomipramine | 75–250 |  |
| 阿米替林 | amitriptyline | 50–300 | 5-HT 再摄取抑制作用强 |
| 多塞平 | doxepin | 75–300 | 抗焦虑作用强 |

药理作用与机制：

1. 中枢神经系统
	- 对正常人：思睡乏力，注意力不集中，思维能力降低等现象。
	- 对抑郁症患者：明显提高情绪，精神振奋，消除自责，减轻运动抑制；连续用药 2–3 周后疗效才显著，故<font color="#ff0000">不作应急治疗用药</font>。
	- 作用机制：属非选择性单胺再摄取抑制药，主要阻断 NA、5-HT 在神经末梢（前膜）的再摄取，从而使突触间隙的递质浓度增高，发挥抗抑郁作用。
2. 植物神经系统：阻断 M 受体。
3. 心血管系统：血压下降、心律失常（心动过速）。机制：抑制心肌中 NA 再摄取，NA ↑。

临床应用：

1. 治疗抑郁症：内源性、反应性及更年期等各型抑郁症首选药。
2. 治疗遗尿症。
3. 焦虑和恐怖症。
	- 起效缓慢，不能作为应急药。

不良反应与药物相互作用：

- 抗胆碱不良反应：视物模糊、眼压升高、口干、便秘、排尿困难、心动过速；前列腺肥大、青光眼患者禁用；其他反应有多汗、无力、直立性低血压、反射亢进、共济失调、粒细胞缺乏。
- 与 MAOI 合用可致血压明显升高、高热、惊厥；与苯妥英钠、阿司匹林竞争血浆蛋白结合而减效；可增强中枢抑制药作用。

### （三）❤选择性 5-羟色胺再摄取抑制剂（SSRI）

| 优点 | 缺点 |
| ---- | ---- |
| 抑制 5-HT 再摄取 | 起效慢 |
| 副作用较 TCA 轻 | 肝药酶抑制作用强 |
| 相互间无干扰 | 胃肠道功能、性功能障碍 |

常用药物：<font color="#ff0000">氟西汀（Fluoxetine，百优解、优克）</font>、帕罗西汀（Paroxetine，赛乐特）、<font color="#ff0000">舍曲林（Sertraline，郁乐复）</font>、氟伏沙明（Fluvoxamine）、西酞普兰（Citalopram，喜普妙）、艾司西酞普兰（Escitalopram）。

SSRI 的药效学特性和临床意义：

| 药效学特性 | 临床意义 |
| ---- | ---- |
| 与 α、β 肾上腺素能受体亲和力低 | 对心血管系统影响小；心动过速、心悸、体位性低血压、头晕等 |
| 与多巴胺受体亲和力低 | 无锥体外系副反应；震颤、共济失调等 |
| 与组胺受体亲和力低 | 无镇静样副反应，对认知和精神运动性活动无损害；低血压、镇静、头晕、体重增加等 |
| 与胆碱能受体亲和力低 | 抗胆碱能方面的副反应很少；口干、视物模糊、心动过速、便秘、尿潴留等 |

- 氟西汀可治疗神经性贪食症，疗效与 TCAs 相当而安全性更好；肝功能不良时用隔日疗法；与 MAOI 合用须警惕<font color="#ff0000">血清素综合征</font>；心血管疾病、糖尿病患者慎用。

| 度洛西汀 | Duloxetine | 40–60 |

去甲肾上腺素和特异性 5-羟色胺抗抑郁药（NaSSA）：

- 特别适用于老年患者和一些心血管系统疾病患者。

- 有利于睡眠，比 SNRI 在抗抑郁、焦虑方面能更快起效。
