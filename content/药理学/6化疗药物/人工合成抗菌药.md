# 人工合成抗菌药

## 一、❤喹诺酮类

分类：第 2 代吡哌酸 —— 对多数 G⁻ 有效，仅用于治疗<font color="#ff0000">泌尿道和肠道感染</font>；第 3 代氟喹诺酮类（诺氟沙星、环丙沙星、氧氟沙星、氟罗沙星、依诺沙星、司氟沙星等）；第 4 代（曲伐沙星、克林沙星、加替沙星、莫西沙星、加雷沙星、吉米沙星等）。

### （一）❤药理作用及机制（杀菌药）

抗菌谱：

- 第 2 代吡哌酸：对肠杆菌科有强大作用，对不动杆菌科、铜绿假单胞菌作用相对较弱，主要用于泌尿道和肠道感染。
- 第 3 代：对 G⁻ 菌作用增强，对金葡菌、肺炎球菌、溶血性链球菌、肠球菌等 G⁺ 球菌及<font color="#ff0000">结核杆菌</font>有效。
- 第 4 代：抗菌谱广、活性强、组织渗透性好，对衣原体、支原体、军团菌特别是<font color="#ff0000">厌氧菌</font>有效。

抗菌机制：

- 对 G⁻ 菌：抑制由 2 个 A 亚基和 2 个 B 亚基组成四聚体的 DNA 回旋酶的 A 亚基切割及封口活性，阻碍细菌 DNA 合成。
- 对 G⁺ 菌：抑制由 2 个 C 亚基和 2 个 E 亚基组成四聚体的 DNA 拓扑酶Ⅳ，阻碍 DNA 复制后期姐妹染色单体分离。
- 诱导细菌启动 DNA 的 <font color="#ff0000">SOS 修复</font>，出现 DNA 错误复制。
- <font color="#ff0000">抑制细菌 RNA 及蛋白质的合成</font>。
- 明显的 PAE 效应。

![[化疗-喹诺酮类机制-p139.png]]

### （二）❤临床应用（全身感染）

特点：抗菌谱广、抗菌活性强、口服吸收良好、与其他类别抗菌药之间较少交叉耐药。

1. <font color="#ff0000">泌尿生殖道感染</font>：环丙沙星、氧氟沙星、β-内酰胺类 —— <font color="#ff0000">首选药</font>，治疗单纯性淋球菌尿道炎或宫颈炎；环丙沙星 —— 铜绿假单胞菌性尿道炎<font color="#ff0000">首选药</font>。
2. <font color="#ff0000">肠道感染、伤寒</font>：<font color="#ff0000">首选</font>治疗志贺菌引起的急、慢性菌痢，中毒性菌痢，鼠伤寒沙门菌等引起的胃肠炎；沙门菌引起的伤寒、副伤寒 —— 首选氟喹诺酮类、头孢曲松。
3. 呼吸道感染。
4. 骨、关节、软组织感染：敏感菌株诱发的慢性骨髓炎 —— 长期治疗。

### （三）❤不良反应

1. 胃肠道反应。
2. <font color="#ff0000">中枢神经系统反应</font> —— 精神异常、抽搐、惊厥。机制：<font color="#ff0000">抑制 GABA 与 GABA_A 受体结合，激动 NMDA 受体</font>，导致中枢神经兴奋。※<font color="#ff0000">精神病、癫痫病史者禁用</font>；环丙、诺氟等与茶碱合用可使茶碱血药浓度升高，合用茶碱、NSAIDs 者易出现神经毒性。
3. <font color="#ff0000">光敏反应（光毒性）</font> —— 光照部位出现瘙痒性红斑。※过敏者禁用、避光防护。
4. 心脏毒性。
5. <font color="#ff0000">软骨损害</font> —— 损伤负重关节软骨；年龄 ↓、浓度 ↑、损害 ↑。※<font color="#ff0000">儿童、孕妇禁用</font>。
6. 跟腱炎症、跟腱撕裂等。
7. 肝毒性、肾毒性等。

### （四）❤各药特点

| 药物 | 特点 |
| ---- | ---- |
| 诺氟沙星（氟哌酸） | 对 G⁺、G⁻ 均有抗菌作用；口服吸收不完全，血药浓度低，但尿、粪药物浓度仍高；用于<font color="#ff0000">尿路和肠道感染</font> |
| 环丙沙星 | 抗菌谱广，对铜绿假单胞菌、耐药 G⁻、G⁺ 菌仍敏感，<font color="#ff0000">厌氧菌无效</font>；体外抗菌活性最强；用于耐药 G⁻ 杆菌所致的泌尿生殖道、消化道、呼吸道、骨与关节、皮肤软组织感染 |
| 氧氟沙星 | 抗菌活性高，对 G⁻、G⁺ 菌包括铜绿假单胞菌作用较强；对<font color="#ff0000">肺炎支原体、衣原体、厌氧菌、奈瑟菌属和结核杆菌</font>也有一定作用；可透过血脑屏障 |

## 二、❤磺胺类抗菌药

分类：用于全身感染 —— <font color="#ff0000">磺胺嘧啶 SD（可透过血脑屏障）、磺胺甲噁唑 SMZ</font>，易吸收；用于肠道感染 —— <font color="#ff0000">柳氮磺吡啶 SASP</font>，难吸收；外用 —— <font color="#ff0000">磺胺醋酰钠 SA、磺胺嘧啶银 SD-Ag</font>。

### （一）😊抗菌作用

抗菌谱：广谱。

- G⁺ 球：链球菌、葡萄球菌、肺炎球菌；G⁺ 杆：破伤风、产气、炭疽、白喉；G⁻ 球：脑膜炎奈瑟菌、淋病奈瑟菌；G⁻ 杆：痢疾杆菌、大肠杆菌、鼠疫耶尔森菌、变形杆菌；衣原体、疟原虫等。
- <font color="#ff0000">无效：螺旋体、立克次体、支原体</font>。

机制：竞争性抑制<font color="#ff0000">二氢蝶酸合酶</font>，干扰细菌的叶酸代谢，使细菌的生长繁殖受阻。

![[化疗-磺胺类叶酸代谢-p140.png]]

### （二）😊耐药性

高，可通过质粒转移或随机突变产生，通常不可逆：细菌二氢蝶酸合酶经突变或质粒转移导致对磺胺类亲和力降低，不能有效与 PABA 竞争；某些耐药菌株降低对磺胺类的通透性；细菌通过选择或突变产生更多的 PABA。

### （三）❤临床应用

- 全身使用：泌尿系感染（短效类）；<font color="#ff0000">流行性脑脊髓膜炎 —— 首选 SD</font>；呼吸道感染、伤寒、菌痢 —— 复方新诺明。
- 肠道感染：<font color="#ff0000">柳氮磺吡啶（SASP）</font>，溃疡性结肠炎、肠道术前预防用药。在肠道分解成磺胺吡啶和 5-氨基水杨酸盐：前者有抗菌作用，后者具抗炎和免疫抑制作用，还用于强直性脊柱炎。
- 外用：烧伤 —— 对铜绿、金葡、破伤风有效，<font color="#ff0000">磺胺米隆（SML）、磺胺嘧啶银（SD-Ag）</font>；眼科 —— <font color="#ff0000">磺胺醋酰（SA）</font>。

### （四）❤不良反应

1. <font color="#ff0000">泌尿系统损害</font>：尿中的磺胺药及其乙酰化物形成<font color="#ff0000">结晶</font>，产生尿道刺激、梗阻症状。防治：<font color="#ff0000">口服碳酸氢钠碱化尿液，增加磺胺药及其乙酰化物的溶解度；多饮水</font>；定期检查尿液。
2. 过敏反应：皮疹、药热等。
3. <font color="#ff0000">血液系统反应</font>：长期用药抑制造血功能，巨幼红细胞贫血，<font color="#ff0000">定期补充叶酸</font>。
4. 黄疸、肝损害。※<font color="#ff0000">新生儿、早产儿、孕妇、哺乳期妇女不宜使用</font>。

### （五）❤甲氧苄啶（TMP）

- 药理作用：抗菌谱与磺胺相似，单用易耐药；<font color="#ff0000">二氢叶酸还原酶抑制剂</font>。
- <font color="#ff0000">加强磺胺抗菌作用</font>：抑菌 → 杀菌，耐药性 ↓，不良反应 ↓。
- 不良反应：<font color="#ff0000">叶酸缺乏</font>（贫血、肝、头发），需补充四氢叶酸。

※<font color="#ff0000">复方新诺明（SD : TMP = 5 : 1）</font>：两者药动学参数相近，血药浓度可同期达峰；合用对细菌叶酸合成起<font color="#ff0000">双重阻断</font>作用，抗菌活性增加数倍至数十倍，甚至呈现杀菌作用；抗菌谱扩大、耐药菌减少；用药量 ↓、不良反应发生率 ↓。

## 三、😊硝基呋喃类和硝基咪唑类

### （一）😊硝基呋喃类

共性：

- 抗菌谱：广谱（铜绿假单胞菌不敏感）。
- 抗菌力强（5~ μg/mL），在 pH 低时作用强。
- 耐药性低。
- 不良反应：胃肠道反应、<font color="#ff0000">周围 N 炎</font>。
- 作用机理：可能是干扰细菌糖代谢。

| 药物 | 特点 |
| ---- | ---- |
| 呋喃妥因 | 口服吸收，消除快（t₁/₂ 20 分钟），组织和血中浓度低，<font color="#ff0000">尿中浓度高</font>；主用于<font color="#ff0000">泌尿道感染</font>，代谢物为<font color="#ff0000">棕色</font> |
| 呋喃唑酮（痢特灵） | 口服吸收少，用于<font color="#ff0000">胃肠道感染</font>（痢疾、霍乱、胃溃疡），尿液黄染 |

### （二）❤硝基咪唑类 —— 甲硝唑（灭滴灵）

药理作用 —— 「四抗」：

- <font color="#ff0000">抗厌氧菌</font>；
- <font color="#ff0000">抗滴虫</font>；
- <font color="#ff0000">抗阿米巴原虫</font>：对大、小滋养体有杀灭作用，对包囊无效；
- <font color="#ff0000">抗贾第鞭毛虫</font>。

机制：分子中的硝基在细胞内无氧环境下被还原成氨基，从而抑制病原体 DNA 合成。

※<font color="#ff0000">用时需戒酒 —— 双硫仑反应</font>。

体内过程：口服吸收良好；分布广，在肝、脑、牙槽骨中浓度高；肝代谢，从尿中排出，可原形从腺体排出。

临床应用：

- 主要用于<font color="#ff0000">厌氧菌</font>引起的口腔、腹腔、女性生殖器、下呼吸道、骨和关节等部位厌氧菌感染。
- 对<font color="#ff0000">幽门螺杆菌</font>感染引起的消化性溃疡及难辨梭状芽孢杆菌引起的<font color="#ff0000">伪膜性肠炎</font>有效。
- 也可用于败血症、破伤风、心内膜炎、脑膜炎。
- 治疗<font color="#ff0000">阿米巴病、滴虫病、破伤风首选</font>药物。

不良反应：胃肠道反应、过敏反应、外周神经炎等。
