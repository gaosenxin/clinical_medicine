# 抗恶性肿瘤药

## 一、😊分类

### （一）按化学结构和来源分类

- 烷化剂：如环磷酰胺。
- 抗肿瘤抗生素：放线菌素 D 等。
- 抗代谢药：如甲氨蝶呤、氟尿嘧啶、阿糖胞苷等。
- 抗肿瘤植物药：长春碱、紫杉醇等。
- 其他：顺铂、卡铂等。
- 激素类：糖皮质激素、雌激素、雄激素等。

### （二）按药物作用周期分类

| 类别 | 特点 |
| ---- | ---- |
| 细胞周期非特异性药物 | 对增殖周期<font color="#ff0000">各时期</font>的细胞敏感，<font color="#ff0000">G₀ 期</font>敏感；剂量反应曲线是一条直线；直接破坏 DNA 或影响其复制、转录功能；举例：烷化剂、抗肿瘤抗生素；作用<font color="#ff0000">强，杀伤作用呈剂量依赖性</font> |
| 细胞周期特异性药物 | 仅对增殖周期<font color="#ff0000">某些</font>时相敏感，对 G₀ 期不敏感；剂量反应曲线是一条渐近线；举例：作用于 S 期的抗代谢药物、作用于 M 期的长春碱类；作用往往较弱，杀伤作用呈<font color="#ff0000">时间依赖性</font> |

## 二、❤细胞毒类抗肿瘤药

### （一）❤干扰核酸生物合成的药物 / 抗代谢药（<font color="#ff0000">主要作用于 S 期</font>）

| 机制 | 药物 | 应用 |
| ---- | ---- | ---- |
| 二氢叶酸还原酶抑制剂 | 甲氨蝶呤（MTX） | 儿童急性白血病 |
| 胸苷酸合成酶抑制药 | <font color="#ff0000">氟尿嘧啶（5-FU）</font> | <font color="#ff0000">消化道癌、乳腺癌</font>等 |
| 嘌呤核苷酸互变抑制药 | <font color="#ff0000">巯嘌呤（6-MP）</font> | <font color="#ff0000">儿童急性淋巴细胞白血病</font>（维持治疗） |
| 核苷酸还原酶抑制剂 | 羟基脲 | 慢性粒细胞白血病 |
| DNA 多聚酶抑制剂 | 阿糖胞苷 | 成人急性粒细胞／单核细胞白血病 |

### （二）❤影响 DNA 结构和功能 —— 烷化剂

机制：与 DNA 或蛋白质分子中亲核基团（氨基、羧基、羟基、磷酸基）起<font color="#ff0000">烷化反应</font> → 交叉联结或脱嘌呤 → DNA 链断裂或复制时碱基配对错码 → DNA 结构、功能损害，细胞死亡。

特点：对<font color="#ff0000">恶性淋巴瘤</font>疗效显著；诱发出血性膀胱炎。

其他：破坏 DNA 的抗生素类；破坏 DNA 的铂类（顺铂、卡铂等）。

### （三）😊其他机制

- 影响转录过程，阻止 RNA 合成。
- 干扰蛋白质合成：微管蛋白活性抑制药；干扰核蛋白体功能的药物；影响氨基酸供应的药物。

## 三、😊非细胞毒类抗肿瘤药 —— 调节体内激素平衡的药物

| 药物 | 应用 |
| ---- | ---- |
| 糖皮质激素 | 急性淋巴细胞白血病、恶性淋巴瘤、慢性淋巴细胞白血病 |
| 雌激素 | 前列腺癌、绝经期乳腺癌 |
| 雄激素 | 晚期乳腺癌 |
| 选择性雌激素受体阻断药 —— <font color="#ff0000">他莫昔芬</font> | 乳腺癌 |

## 四、❤抗肿瘤药的毒性反应

### （一）😊共有反应

- <font color="#ff0000">骨髓抑制</font>：除外激素类、博来霉素、门冬酰胺酶。
- 消化道反应：恶心、呕吐。
- 脱发。

### （二）❤特有反应

| 毒性 | 药物 |
| ---- | ---- |
| 心脏毒性 | 柔红霉素、多柔比星、三尖杉酯碱 |
| 呼吸系统毒性 | 博来霉素、白消安、CTX |
| 肝脏毒性 | MTX、羟基脲、CTX、鬼臼毒素类 |
| 肾和膀胱毒性 | CTX、顺铂 |
| 神经毒性 | 长春新碱、紫杉醇、门冬酰胺酶 |
| 过敏反应 | 博来霉素、门冬酰胺酶、紫杉醇 |
