# 抗菌药概论

## 一、❤常用术语

1. 抗菌谱（antibacterial spectrum）：抗菌药物的抗菌范围，包括广谱和窄谱两种。
	- 广谱 —— 对<font color="#ff0000">多种</font>病原微生物有效，如四环素、氯霉素、第三、四代氟喹诺酮类等。
	- 窄谱 —— 仅对<font color="#ff0000">单一</font>菌种或种属有效，如异烟肼。
	- 意义：临床选药的基础。
2. 抗菌活性：抗菌药抑制或杀灭病原体的能力，体外抗菌活性常用 MIC 和 MBC 表示。
	- 最低抑菌浓度（MIC）：体外培养 18~24 h 后能抑制培养基内病原菌生长的最低药物浓度。
	- 最低杀菌浓度（MBC）：能够杀灭培养基内细菌或使细菌数减少 99.9% 的最低药物浓度。
3. 抑菌药 —— 仅能抑制微生物生长而无杀灭作用的药物；杀菌药 —— 既能抑制微生物生长又有杀灭作用的药物。
4. 化疗指数（CI）：评价化学治疗药物<font color="#ff0000">安全性与应用价值</font>的指标，<font color="#ff0000">LD50/ED50 或 LD5/ED95</font>。
	- 意义：<font color="#ff0000">CI ↑，毒性越小，临床应用价值越高</font>。
	- 注意：<font color="#ff0000">青霉素类</font>药物 CI 大，几乎对身体无毒性，但可能发生过敏性休克这种严重不良反应。
5. 抗生素后效应（PAE）：细菌与抗生素短暂接触，当抗生素<font color="#ff0000">浓度下降、低于 MIC 或消失后</font>，细菌生长<font color="#ff0000">仍受到持续抑制</font>的效应。
6. 首次接触效应：抗菌药物在初次接触细菌时有强大的抗菌效应，再度接触时不再出现该强大效应，或与细菌接触后抗菌效应不再明显增强，需要间隔相当时间以后才会再起作用（如氨基苷类）。

## 二、❤抗菌药的作用机制

| 机制 | 药物 |
| ---- | ---- |
| 1. 抑制细菌细胞壁的合成 | 万古霉素和杆菌肽 —— 抑制粘肽合成；青霉素和头孢菌素 —— 抑制交叉联结过程 |
| 2. 改变胞浆膜的通透性 | 多黏菌素 —— 与膜磷脂结合；两性霉素 —— 与固醇类物质结合 |
| 3. 抑制蛋白质合成 | 氨基苷类 —— 影响蛋白质合成的全过程；大环内酯类、林可霉素类、氯霉素类 —— 50S，抑制转肽；四环素 —— 30S，抑制进位 |
| 4. 影响核酸代谢 | 喹诺酮类 —— 抑制 DNA 合成；利福平 —— 抑制 RNA 合成 |
| 5. 影响叶酸代谢 | 磺胺与 TMP |

## 三、❤耐药性

耐药性（bacterial resistance）：细菌产生对抗生素不敏感的现象，产生原因是细菌在自身生存过程中的一种特殊表现形式。

种类：

- 固有耐药：由细菌染色体基因决定，代代相传。
- 获得性耐药：由质粒介导，亦可由染色体介导，如金葡菌对青霉素的耐药。

## 四、😊合理应用

- 防止不合理应用：非细菌性感染不用；病因不明少用；避免局部使用。
- 剂量、疗程足够。
- 预防应用 —— 少用。
- 根据肝、肾功能用药。
