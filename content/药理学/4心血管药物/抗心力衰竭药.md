# 治疗充血性心力衰竭的药物（Anticongestive heart failure drugs）

## 一、😊概述

慢性心力衰竭（chronic heart failure）：各种病因引起的多种心脏疾病的终末阶段。

- 病理状态：适当静脉回流下，心排出量<font color="#ff0000">绝对/相对</font>减少，不能满足机体、组织所需；同时又是一种<font color="#ff0000">超负荷心脏病，收缩/舒张功能下降</font>，最终导致体/肺循环淤血。

药物分类：

1. 正性肌力药
	- 强心苷类药：地高辛等
	- 非苷类正性肌力药
2. 利尿药与血管扩张药
3. 肾素-血管紧张素-醛固酮系统抑制药
4. 其他治疗 CHF 的药物

## 二、❤正性肌力药物 —— 强心苷类

来源：玄参科和夹竹桃科植物如紫花洋地黄、毛花洋地黄、黄花夹竹桃等，故又称洋地黄类药物。临床常用：地高辛（digoxin）、洋地黄毒苷、毛花苷 C 等。

### （一）❤地高辛（Digoxin）

#### 1.❤药理作用

对心脏：

1. <font color="#ff0000">正性肌力作用</font>：明显地加强衰竭心脏的收缩力，增加 CO，解除心衰的症状。
	- 特点：心肌收缩敏捷、增加心输出量、不增加/甚至降低心肌耗氧量。
	- 机制：治疗剂量下<font color="#ff0000">部分抑制 Na⁺-K⁺-ATP 酶</font>，导致细胞内 Na⁺ 浓度升高，又通过 <font color="#ff0000">Na⁺-Ca²⁺ 双向交换</font>，使心肌细胞内 Ca²⁺ 增加，心肌收缩力增强。
2. <font color="#ff0000">负性频率作用</font>：反射性<font color="#ff0000">增强迷走神经的活性</font>；使心肌对迷走神经的敏感性增加。
	- 意义：心动周期 ↑ → 舒张期 ↑ → 心室充盈好，有利于心脏射血；心脏自身供血 ↑；心肌获得充分休息，心功能得到改善。
	- 对心肌耗氧量的影响：增加正常心脏耗氧量，<font color="#ff0000">降低 CHF 心脏耗氧量</font>。
3. <font color="#ff0000">对心肌电生理的影响</font>：治疗剂量下，与增加迷走神经活性有关。

| 电生理特性 | 窦房结 | 心房 | 房室结 | 浦肯野纤维 |
| ---- | ---- | ---- | ---- | ---- |
| 自律性 | ↓ | ↑ | | |
| 传导性 | | ↑ | ↓ | ↓ |
| ERP | | ↓ | ↓ | |

- 高浓度下，<font color="#ff0000">过度</font>抑制 Na⁺-K⁺-ATP 酶 → 细胞内 K⁺ ↓ → 最大舒张电位 ↓ → 自律性 ↑；去极速率 ↓ → ERP ↓；<font color="#ff0000">引发室性心动过速/室颤</font>。

对神经、内分泌系统：

- 神经：治疗量直接/反射性<font color="#ff0000">抑制交感神经活性</font>，长期应用降低循环 NA；中毒量<font color="#ff0000">增加交感活性</font>（通过中枢和外周作用），可引起心律失常的发生。
- 内分泌：抑制 RAAS。

利尿：CO ↑ → 肾血流 ↑ → 间接利尿；抑制肾小管 Na⁺-K⁺-ATP 酶，对 Na⁺ 的重吸收 ↓ → 促进钠和水排出，直接利尿。

对血管作用：收缩血管平滑肌 → 外周阻力 ↑ → 局部血流 ↓；CHF 时，强心苷直接/间接<font color="#ff0000">抑制交感活性的作用 >></font> 直接缩血管效应 → 局部血流 ↑。

#### 2.❤临床应用

治疗心力衰竭（对不同病因引起的 CHF 疗效有差异）：

- <font color="#ff0000">伴有房颤及心室率快</font> —— 疗效最好。
- 瓣膜病、冠脉粥样硬化性心脏病、高血压心脏病所致的心功能不全 —— 疗效较好。
- 继发于肺源性心脏病、心肌炎风湿活动期 —— 较差。
- <font color="#ff0000">伴有机械性阻塞</font>（缩窄性心包炎、高度二尖瓣狭窄、心包积液）、<font color="#ff0000">舒张性心力衰竭者</font> —— 不宜使用。

心律失常：

1. <font color="#ff0000">心房纤颤</font>（350~600 次/分）：主要危害是心房过多的冲动下传至心室，引起心室率过快，CO ↓。强心苷通过<font color="#ff0000">兴奋迷走神经</font>或对房室结的直接作用，<font color="#ff0000">减慢房室传导</font>，<font color="#ff0000">增加房室结中隐匿性传导</font> → 心室率 ↓，CO ↑。
2. <font color="#ff0000">心房扑动</font>（240~430 次/分）：主要危害是心房扑动的冲动较强而规则，更易传入心室，使得心室率快而难以控制。强心苷通过不均一地缩短心房 ERP → 扑动变颤动 → 在纤颤时增加房室结中隐匿性传导 → 心室率 ↓。
3. <font color="#ff0000">阵发性室上性心动过速</font> —— 现已少用。

#### 3.❤不良反应（<font color="#ff0000">安全范围小</font>）

1. <font color="#ff0000">心脏反应（最严重、最危险的不良反应</font>，各种心律失常）
	- <font color="#ff0000">快速型心律失常：室性早搏</font>、二联律（1/3），室性心动过速甚至室颤。
	- <font color="#ff0000">窦性心动过缓</font>（< 60 次/分）：抑制窦房结，降低其自律性，停药指征之一。
	- <font color="#ff0000">房室传导阻滞</font>：与提高迷走神经兴奋性、高度抑制 Na⁺-K⁺-ATP 酶有关。
2. <font color="#ff0000">胃肠道反应</font>：主要表现为恶心、呕吐、厌食、腹泻等（兴奋延髓催吐化学感受区）。剧烈呕吐可失钾而加重强心苷中毒，应注意补钾或停药。注意与 CHF 未控制症状相区别。
3. <font color="#ff0000">中枢神经系统反应</font>：眩晕、头痛、失眠、疲倦；<font color="#ff0000">视觉障碍（停药指征之一）</font>（黄视、绿视、复视等）。

#### 4.❤<font color="#ff0000">中毒救治</font>

1. <font color="#ff0000">补钾</font> —— <font color="#ff0000">快速型心律失常</font>，与强心苷竞争 Na⁺-K⁺-ATP 酶，减少强心苷与酶的结合。
2. <font color="#ff0000">苯妥英钠</font> —— <font color="#ff0000">室性心动过速</font>，抗心律失常，与强心苷竞争结合 Na⁺-K⁺-ATP 酶，恢复酶活性。
3. <font color="#ff0000">利多卡因</font> —— <font color="#ff0000">室性心动过速、室颤</font>。
4. <font color="#ff0000">阿托品</font> —— <font color="#ff0000">窦性心动过缓、房室传导阻滞</font>（<font color="#ff0000">不宜补钾</font>）。
5. 地高辛抗体 Fab 片段 —— 极严重中毒。

#### 5.😊中毒预防

1. 明确中毒症状，停药指征（窦性心动过缓、视觉障碍）。
2. 血药浓度检测：地高辛 > 3 ng/ml，洋地黄毒苷 > 45 ng/ml —— 停药。
3. 注意药物的相互作用：
	- 奎尼丁：90% 患者血药浓度提高一倍 —— 合用时减少地高辛用量 30–50%。
	- 排钾利尿药：低血钾加重毒性，注意补钾。
	- 钙阻滞剂：维拉帕米抑制地高辛经肾小管分泌 —— 减量 50%。
	- 肝药酶诱导剂；消胆胺类树脂（吸附剂）—— 血药浓度 ↓。
4. 给药方法：经典给药法（较少采用）；每日维持量法（目前倾向于<font color="#ff0000">小剂量化</font>）。

## 三、❤其他抗 CHF 药物

### （一）😊利尿药

对心衰的作用：减少血容量，降低心脏前负荷；血管扩张，降低后负荷（排钠，使血管内 Ca²⁺ ↓）。

临床应用：轻度 CHF —— 噻嗪类；急性/严重 CHF —— 呋塞米 + 螺内酯。

### （二）❤ACEI 与 ARB

ACEI（卡托普利、依那普利等）抗 CHF 的作用机制：

1. <font color="#ff0000">抑制 ACE 的活性</font>：AngⅡ ↓，减弱缩血管作用；缓激肽降解 ↓，促进 NO 及 PGI₂ 生成，发挥扩血管、降低心脏后负荷作用；降低儿茶酚胺、加压素含量，恢复下调的 β₁；醛固酮生成 ↓，减轻水钠潴留，降低前负荷；恢复心房钠尿肽含量及清除自由基。
2. <font color="#ff0000">改善血流动力学</font>：降低全身血管阻力，增加心输出量，降低室壁张力，增加肾血流量等。
3. <font color="#ff0000">抑制并逆转心肌及血管重构</font>：减少 AngⅡ 和醛固酮生成，防止和逆转心肌与血管重构，改善心功能。

临床应用：对各阶段心力衰竭患者均有作用。

ARB（氯沙坦、缬沙坦、厄贝沙坦等）：

- 不仅拮抗 ACE 途径产生的 AngⅡ，同样拮抗非 ACE 途径（糜酶）产生的 AngⅡ。
- 不良反应少，不易引起咳嗽、血管神经性水肿等。
- 抗 CHF 作用类似 ACEI，常作为 ACEI 不耐受者的替代品，降低患者再住院率和病死率。

### （三）❤β 受体阻断药 —— 美托洛尔、卡维地洛

药理作用：

1. <font color="#ff0000">拮抗 CHF 时过高的交感活性</font>。
2. 拮抗过量儿茶酚胺对心脏的毒性作用（大量 Ca²⁺ 内流引起的损伤）；抑制 RAAS；<font color="#ff0000">上调 β 受体，恢复信号传导能力</font>。
3. <font color="#ff0000">抗心律失常及心肌缺血</font>。
4. <font color="#ff0000">卡维地洛兼有阻断 α₁ 受体、抗氧化等作用</font>。

临床应用：<font color="#ff0000">扩张型心肌病者</font>尤为适用。

注意：用于已采取了标准的利尿剂 + ACEI + 地高辛治疗的非卧床的、稳定的心衰患者；应用初期可出现（第 3–5 周内）心功能恶化，须小剂量给药，逐渐增量到最大耐受剂量（数月内），不能突然停药。

### （四）😊钙拮抗药

机制：扩张外周小动脉；扩张冠脉；缓解钙超载。

- 短效 CCB 如硝苯地平、维拉帕米、地尔硫䓬等可使 CHF 恶化（负性肌力、反射性激活神经内分泌系统），增加 CHF 患者的病死率，不适于 CHF 治疗。
- <font color="#ff0000">长效 CCB</font>如氨氯地平，作用出现缓慢、持久，负性肌力作用弱，治疗时不伴有反射性激活神经内分泌系统的作用，还可逆转心肌肥厚。氨氯地平还有抗动脉粥样硬化、抗 TNF-α 及 IL 等作用。

### （五）😊其他药物

磷酸二酯酶抑制药 —— 米力农、氨力农：

- <font color="#ff0000">抑制磷酸二酯酶Ⅲ</font>（PDE Ⅲ）→ cAMP ↑ → 正性肌力和扩血管 → 外周阻力 ↓ → 心输出量 ↑。
- 用于心衰短时间的支持疗法，尤其对强心苷、利尿药、扩血管药反应差者。

钙增敏剂：

- <font color="#ff0000">增加肌钙蛋白 C 对 Ca²⁺ 的敏感性</font>，增加收缩力但不增加能量消耗，但有舒张延缓和提高舒张期张力等副作用。多数还兼具 <font color="#ff0000">PDE Ⅲ 抑制作用</font>。

多巴酚丁胺：激动心脏 β₁ 受体，增强心肌收缩性，降低血管阻力，提高衰竭心脏的心指数，增加心排血量。
