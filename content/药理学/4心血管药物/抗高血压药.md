# 抗高血压药（Antihypertensive drugs）

## 一、😊概述

- 靶器官：心、血管、脑、肾等；可引起心衰、冠心病、脑卒中、肾衰、眼底病变等。
- 治疗原则：降低血压的同时预防或逆转心血管重构，降低并发症的产生，降低死亡率。
- 发病机制：与血压调节有关，最主要的是交感神经-肾上腺髓质系统和肾素-血管紧张素系统；抗高血压药可分别作用于上述不同环节，降低血压。

神经调节（交感神经系统）的各个环节与药物：

| 环节 | 药物举例 |
| ---- | ---- |
| 中枢 | 可乐定、α-甲基多巴、莫索尼定 |
| 神经节 | 美加明 |
| 末梢递质释放 | 利血平、胍乙啶 |
| 突触后膜受体 | 普萘洛尔、哌唑嗪、拉贝洛尔 |
| 血管平滑肌 | 硝普钠、肼屈嗪、硝苯地平、米诺地尔 |
![[心血管-抗高血压药作用环节-p70_crop.png]]
## 二、😊抗高血压药的分类

1. <font color="#ff0000">利尿药</font>：氢氯噻嗪。
2. 交感神经抑制药
	- 中枢性降压药：可乐定、α-甲基多巴、莫索尼定
	- 神经节阻断药：樟磺咪芬
	- 去甲肾上腺素能神经末梢阻断药：利血平、胍乙啶
	- <font color="#ff0000">肾上腺素受体阻断药</font>：β 受体阻断药（普萘洛尔）、α 受体阻断药（哌唑嗪）、α 和 β 受体阻断药（拉贝洛尔）
3. <font color="#ff0000">钙通道阻滞药</font>：硝苯地平、氨氯地平。
4. 血管扩张药：硝普钠、肼屈嗪、米诺地尔。
5. 肾素-血管紧张素系统抑制药
	- 肾素抑制药：雷米克林
	- <font color="#ff0000">ACEI</font>：卡托普利
	- <font color="#ff0000">ARB</font>：氯沙坦




## 三、❤常用抗高血压药

### （一）😊利尿药 —— 氢氯噻嗪

作用机制尚不明确：

- 初期：排钠利尿 → <font color="#ff0000">血容量 ↓</font> → BP ↓。
- <font color="#ff0000">长期</font>：
	- 排钠 → 血管平滑肌细胞内 Na⁺ ↓ → <font color="#ff0000">胞内 Ca²⁺ ↓ → 血管平滑肌舒张</font> → BP ↓。
	- 胞内 Ca²⁺ ↓ → 血管平滑肌<font color="#ff0000">对缩血管物质反应性 ↓</font> / 舒血管物质反应性 ↑ → BP ↓。

降压特点及应用：

- 作用温和、持久，对卧位、立位均有效。
- 多数病人在用药后 2~4 周内减效；可用于各型高血压（基础降压药）。
- 轻症单用（剂量 < 25 mg）；中、重症与其他药合用。

不良反应：

- 血浆肾素水平 ↑ → 血管紧张素 ↑ → 醛固酮 ↑，水钠潴留 —— 耐受性。
- 长期使用 <font color="#ff0000">↓ 血 K⁺</font>、Na⁺、Mg²⁺。
- <font color="#ff0000">高血糖、高血脂</font>。
- <font color="#ff0000">升高血尿酸</font>。
- <font color="#ff0000">高血压合并氮质血症、尿毒症、高血压危象</font> —— 用呋塞米；吲达帕胺不引起血脂改变，适用于<font color="#ff0000">伴有高血脂的高血压患者</font>。


### （二）😊交感神经抑制药

#### 1.中枢性降压药 —— 可乐定（Clonidine）

代表药：可乐定、α-甲基多巴、莫索尼定等。

药理作用（中等偏强）：

- <font color="#ff0000">抑制交感神经活性</font> → 心收缩力 ↓、CO ↓，外周血管舒张 → BP ↓（不影响肾血流量和肾小球滤过率）。
- <font color="#ff0000">抑制胃酸分泌和胃肠蠕动</font>。
- 对中枢神经系统有<font color="#ff0000">镇静</font>作用。

作用机制：

- <font color="#ff0000">选择性激动</font>延髓孤束核突触后膜的 <font color="#ff0000">α₂ 受体</font> → 外周交感活性 ↓ → BP ↓。
- <font color="#ff0000">激动咪唑啉 I₁ 受体</font>（延髓头端腹外侧核）→ 外周交感活性 ↓ → BP ↓。
- 大剂量时，激活外周血管平滑肌上的 α₂ 受体，血管收缩，降压作用 ↓。

![[心血管-可乐定作用机制-p72.png]]

临床应用：适用于治疗中度高血压，尤其是<font color="#ff0000">肾性高血压或高血压兼溃疡者</font>。

不良反应：口干、便秘；嗜睡、恶心、眩晕、腮腺痛；<font color="#ff0000">停药反跳</font>现象（突然停药会有交感功能亢进的症状）。

莫索尼定：作用与可乐定相似，但对<font color="#ff0000">咪唑啉 I₁ 受体</font>选择性更高，不良反应少（无镇静、停药反跳）。


#### 2.神经节阻断药（使用较少）

- 选择性与神经节细胞 N₁ 胆碱受体结合，妨碍 ACh 与受体结合，阻断神经冲动在神经节中的传递。
- 交感神经支配占优势的部位（如血管）使 A、V 扩张 → 外周阻力 ↓ → BP ↓。
- 副交感神经支配占优势的器官（眼、肠道、膀胱平滑肌等）可引起视物模糊、便秘、尿潴留等。
- 仅用于<font color="#ff0000">高血压危象、主动脉夹层动脉瘤、外科手术中的控制性低血压</font>等。

#### 3.去甲肾上腺素能神经末梢阻断药

利血平：

- 降压作用缓慢、温和、持久。
- 抑制 NE 合成、再摄取，促使其排出囊泡。
- 不良反应多，现已少用。

胍乙啶：

- 降压作用迅速、强大、持久。
- 抑制 NE 释放，耗竭囊泡内递质。
- <font color="#ff0000">易引起肾、脑血流减少及水钠潴留</font>。
- <font color="#ff0000">主要用于重症高血压</font>。

#### 4.β 受体阻断药 —— 普萘洛尔（心得安）

对 β₁ 和 β₂ 受体具有相同的亲和力，缺乏拟交感活性。

降压作用机制：

- 阻断<font color="#ff0000">心脏的 β₁</font> 受体 → CO ↓ → BP ↓。
- 阻断<font color="#ff0000">肾小球旁器 β₁</font> 受体 → 肾素分泌 ↓。
- 阻断<font color="#ff0000">中枢的 β</font> 受体 → 外周交感活性 ↓。
- 阻断外周 <font color="#ff0000">NA 能神经末梢突触前膜的 β₂</font> 受体 → 正反馈作用 ↓，NA 释放 ↓。
- 增加<font color="#ff0000">前列环素</font>的合成。

作用特点：作用温和、缓慢、持久，中等强度；不易产生耐受；降压时伴 HR ↓、CO ↓。

临床应用：

- 适用于各种程度的原发性高血压，尤其适用于<font color="#ff0000">肾素活性高、CO 高者</font>。
- 高血压伴心绞痛、偏头痛、焦虑症者。
- β 受体阻断药 + 利尿药 + 扩血管药 —— 有效治疗中度/顽固性高血压。

拉贝洛尔：

- 作用强度：β₁ = β₂ > α₁。
- 适用于各种程度的高血压及<font color="#ff0000">高血压急症</font>、妊娠期高血压、嗜铬细胞瘤、麻醉或手术时高血压。
- 大剂量引起直立性低血压。

#### 5.α 受体阻断药 —— 哌唑嗪、特拉唑嗪

机制：<font color="#ff0000">选择性阻断</font>交感神经突触后膜的 α₁ 受体。

降压特点：

- 起效快，作用中等偏强。
- <font color="#ff0000">扩张阻力血管和容量血管</font>。
- 降压时不减少肾血流量及肾小球滤过率。
- 降压时不影响心率及肾素分泌，<font color="#ff0000">对血脂代谢无不良影响</font>。

临床应用：用于各型高血压，重度高血压时合用利尿药、β 受体阻断药。

不良反应：

- <font color="#ff0000">首剂现象</font>：严重的体位性低血压、晕厥、心悸等；哌唑嗪首剂 0.5 mg，临睡前服可避免。
- 长期用药可引起水、钠潴留。


### （三）😊钙通道阻滞药

可分为二氢吡啶类（<font color="#ff0000">对血管平滑肌有选择性</font>，较少影响心肌）和非二氢吡啶类（对心脏和血管均有作用）。

<font color="#ff0000">硝苯地平</font>：

- 机制：作用于血管平滑肌细胞膜的 <font color="#ff0000">L 型钙通道</font>，抑制 Ca²⁺ 进入细胞内，细胞内 Ca²⁺ 浓度降低，导致<font color="#ff0000">小动脉（A）</font>舒张。
- 降压特点：
	- 口服吸收好，起效<font color="#ff0000">快、强</font>。
	- 松弛 A 平滑肌，对 V 影响小。
	- 对高血压者降压显著，对正常人无作用。
	- 久用<font color="#ff0000">反射性心率 ↑、血浆肾素活性 ↑</font>（合用 β 受体阻断剂）。
	- 作用短暂，可引起血压的剧烈波动。
- 临床应用：用于各型高血压，适用于<font color="#ff0000">合并心绞痛</font>或肾脏疾病、糖尿病、高脂血症、哮喘、恶性高血压患者。

氨氯地平：

- 降压特点：对血管平滑肌选择性更强；口服吸收率及生物利用度更高；起效<font color="#ff0000">缓和、持久</font>；<font color="#ff0000">不增加交感活性</font>。
- 应用：适用于轻中度高血压。


### （四）😊血管扩张药（直接扩血管药）

共同特点：

- 机制：直接作用于小 A → 松弛血管 → 外周阻力 ↓ → BP ↓。
- 缺点：反射性交感激活，心率 ↑、CO ↑ → 心肌耗氧量 ↑ → 诱发心绞痛；肾素活性 ↑ → 血管紧张素、醛固酮 ↑ → 水钠潴留、BP ↑（合用利尿药及 β 受体阻断药来纠正）。

硝普钠：

- 降压特点：起效快、作用强；短效；口服不吸收，需静脉滴注。
- 临床应用：<font color="#ff0000">高血压危象</font>；<font color="#ff0000">严重高血压合并左心衰竭</font>；<font color="#ff0000">手术麻醉时降压</font>。
- 不良反应：BP ↓ → 头痛、心悸、出汗、呕吐；静脉滴注过快可致过度降压；可导致氰化物中毒，药液应新鲜配置并避光使用。

肼屈嗪：

- 降压特点：口服有效，舒张小 <font color="#ff0000">A</font>，对 V 作用不明显；中效降压药，适用于中、重度高血压。
- 机制：NO ↑ → GC → cGMP ↑ → 胞浆内 Ca²⁺ ↓。
- 大剂量可导致<font color="#ff0000">全身性狼疮样综合征</font>（≥ 200 mg/日，发生率 10~20%）。

![[心血管-ACEI降压机制-p76.png]]


钾通道开放药 —— 米诺地尔、尼可地尔：

- 机制：使钾通道开放，钾外流增多，细胞膜超极化，膜兴奋性降低；Ca²⁺ 内流减少，血管平滑肌舒张，BP ↓。扩张作用具有选择性，见于冠脉、胃肠道血管、脑血管。
- 不良反应：反射性心动过速。

### （五）❤肾素-血管紧张素系统抑制药

#### 1.ACEI

降压机制：

- <font color="#ff0000">抑制血浆、组织的 ACE</font>，减少 AngⅡ 的生成，起到舒张 A/V、外周阻力 ↓、减少醛固酮释放及促心血管肥大增生的作用。
- <font color="#ff0000">缓激肽降解 ↓</font> → 促进 NO 和 PGI₂ 的生成 → 扩血管。
- 保护血管内皮细胞。
- 抗心肌缺血与心肌保护。
- 增敏胰岛素受体（可能由缓激肽介导）。

降压特点：

- 降压时不伴有心率 ↑，不影响 CO。
- 可防止和逆转心肌与血管的重构。
- 长期应用不易引起电解质紊乱、脂质代谢障碍。
- 增加肾血流量，保护肾脏。

适应证：各型高血压，尤其是<font color="#ff0000">伴有心衰、缺血性心脏病、糖尿病肾病的高血压患者（首选药）</font>。

不良反应：

- <font color="#ff0000">首剂低血压</font>：口服吸收快、生物利用度高的 ACEI 较常见，应从小量开始服用。
- 刺激性干咳：肺血管的缓激肽、PGs ↑ 所致。
- <font color="#ff0000">高血钾、低血糖、血管神经性水肿、肾功能损伤</font>。
- <font color="#ff0000">影响胎儿发育</font>（AT₂）。
- 久用使<font color="#ff0000">血 Zn²⁺ ↓</font>、味觉 ↓、嗅觉受损、脱发（巯基与 ACE 的 Zn²⁺ 结合，最终使酶失去活性），应补充 Zn²⁺。

卡托普利（第一个用于临床的 ACEI）：

- 口服吸收快，生物利用度高，食物能影响其吸收，宜餐前 1 h 服用。
- 含 -SH，起效快；降压效果与 RAAS 的状态有关，肾素水平高的、低盐饮食、服利尿药者，降压持续 8–12 h。
- 可以清除自由基，保护缺血心肌。
- 用于高血压、充血性心力衰竭、心肌梗死、<font color="#ff0000">糖尿病肾病</font>（FDA 批准唯一用于此病的 ACEI）。
- 毒性小，耐受性好。<font color="#ff0000">禁用于双侧肾动脉狭窄者及孕妇</font>。


依那普利（前体药）：

- 口服易吸收，不受食物影响。
- 在体内需转化，起效<font color="#ff0000">慢</font>（药后 4–6 h 达峰值），持续时间<font color="#ff0000">长</font>（24 h），作用<font color="#ff0000">强</font>（ACE 抑制作用是卡托普利的 10 倍）。
- 可用于高血压、慢性心功能不全。
- 毒性小，不含 -SH，味觉障碍、皮疹、白细胞缺乏等少见。

#### 2.ARB —— 氯沙坦

受体基础：

- <font color="#ff0000">AT₁ 受体 —— 收缩血管、促进醛固酮释放、促进心肌、血管平滑肌增殖</font>。
- AT₂ 受体 —— 激活激肽 B₂ 受体与 NO 合酶，促进 NO 合成，舒张血管，降低血压，还与胎儿发育有关。

机制：<font color="#ff0000">选择性阻断 AT₁ 受体</font> → 阻滞 AngⅡ 介导的血管收缩、醛固酮释放、促心肌和血管平滑肌增殖的效应。

降压特点：

- 口服起效快，首过消除明显，作用维持久（代谢物活性更强，阻断 AT₁ 受体的作用比氯沙坦强 10~40 倍）。
- 不良反应较 ACEI 少，较少引起干咳及血管神经性水肿。
- 仍可导致低血压及高血钾。<font color="#ff0000">禁用于孕妇、哺乳期妇女、肾动脉狭窄者</font>。

## 四、😊抗高血压药物的应用原则

1. 有效治疗、终身治疗：将血压控制在 140/90 mmHg 以下；高血压病因不明，无法根治，需终身治疗。
2. 保护靶器官：高血压的靶器官损伤包括心肌肥厚、肾小球硬化、小动脉重构等，治疗过程中必须考虑逆转或阻止靶器官损伤。
3. 平稳降压：血压不稳定可造成器官损伤，应尽可能减少人为因素造成的血压不稳定。
4. 个体化治疗。
5. 联合用药。
