- 和神经肌肉接头处运动终板上受体结合，激动受体使持续去极化，阻断神经冲动向肌肉传递，导致骨骼肌松弛。
## 非竞争型肌松药（noncompetitive muscular relaxants）（<u>去极化型肌松药</u>）

### 1.❤特点

先出现短暂肌肉震颤
连续用药易产生耐药性
抗AchE药<u>不能</u>拮抗
治疗剂量<u>无</u>神经节阻断作用

结构上与 ACh 相似，与运动终板 N 受体亲和力强，且不易被 AChE 水解，故作用持久。
### 2.❤代表药琥珀胆碱（司可林）（suxamethonnium）

#### 1. ❤药理作用与特点
持续时间<u>短</u>，<u>小</u>肌肉先松弛（<u>颈部→肩胛→腹部→四肢</u>）
#### 2. ❤临床应用

1. 应用于气管插管（喉头、气管肌作用强）
2. 内窥镜检查
3. 麻醉辅助用药(清醒患者慎用)

#### 3. 不良反应

1. 窒息
2. 眼内压升高：使眼外骨骼肌短暂收缩引起眼内压升高，故禁用于青光眼
3. 肌束颤动
4. 血钾升高：由于肌肉持久性除极化而释放钾离子，使血钾升高
5.  #恶性高热 ：属遗传病

过量时<font color="#ff0000">禁用新斯的明</font>：抗 AChE 药不仅不能拮抗，反而加强其去极化阻滞。

## （二）竞争性肌松药（非去极化型肌松药）

### 1.❤作用机制与特点
竞争性拮抗Ach对N受体的作用
抗AchE药有拮抗作用
### 2.❤ #筒箭毒碱 （d-tubocurarine）

#### 2.1药理作用

1. <u>肌松作用</u>

- 快速运动肌如眼部肌肉首先松弛，随后四肢、颈部和躯干肌出现松弛，继而肋间肌松弛出现腹式呼吸，剂量加大最终可导致膈肌麻痹，患者呼吸停止
- 肌松弛恢复时，其次序与肌松弛相反，即膈肌麻痹首先恢复

2. <u>组胺释放作用</u>

促进体内组胺的释放，表现为组胺样皮疹、支气管痉挛、低血压和唾液分泌等

3. <u>神经节阻滞作用</u>

常用量有自主神经节阻滞作用，并可部分抑制肾上腺髓质分泌，造成<font color="#ff0000">血压降低</font>

#### 2.2❤特点与应用

1. 是临床应用最早的典型非除极化型肌松药，临床上可作为麻醉辅助药

2. 筒箭毒碱作用时间较长，用药后不易逆转，不良反应多，目前临床已少用

#### 2.3❤过量解救

抗胆碱酯酶药可拮抗其肌松作用，过量时可用新斯的明解救。

## （三）二者对比
|  | 琥珀胆碱 | 筒箭毒碱 |
| ---- | ---- | ---- |
| 前期给予氯化筒箭毒碱 | 拮抗 | 增强 |
| 前期给予琥珀胆碱 | 快速耐受/增强 | 无效/拮抗 |
| ChE inhibitor | 无拮抗 | 逆转 |
| 对运动终板作用 | 部分、持久除极化 | 提高Ach作用阈值，无除极化 |
| 对横纹肌的初始兴奋效果 | 短暂肌束震颤 | 无 |
| 对呼吸肌麻痹作用 | 不明显 | 大剂量有 |

## （四）去极化型与非去极化型对比

# 非去极化型肌松药和去极化型肌松药的作用特点
| 对比项目        | 去极化型肌松药（琥）                             | 非去极化型肌松药（筒）                               |
| ----------- | -------------------------------------- | ----------------------------------------- |
| 作用时间        | 短（~8min）                               | 长（1-2h）                                   |
| 对横纹肌的初始兴奋效果 | 常见短暂的<font color="#ff0000">肌束颤动</font> | 松弛前无肌兴奋现象                                 |
| 前期给氯化筒箭毒碱   | 拮抗                                     | 作用可被同类肌松药增强；作用可被吸入性全麻药和氨基糖苷类抗生素增强         |
| 前期给琥珀胆碱     | 连续用药快速耐受/增强                            | 无效or拮抗                                    |
| 对运动终板作用     | 部分、持久除极化                               | 提高Ach作用阈值，无除极化                            |
| 对神经节阻断作用    | 治疗剂量无                                  | 程度不等的阻断作用                                 |
| 胆碱酯酶抑制剂的作用  | <font color="#ff0000">无拮抗</font>       | 过量中毒<font color="#ff0000">可用新斯的明逆转</font> |
| 对呼吸肌麻痹作用    | 不明显                                    | 大剂量有                                      |
