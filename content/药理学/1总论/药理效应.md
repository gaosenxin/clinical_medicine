# 概念
药物引起机体<u><font color="#ff0000">生理、生化功能或形态</font></u>的变化

# 药理效应的基本类型
| 类型   | 定义               |
| ---- | ---------------- |
| 兴奋   | 机体的生理、生化功能**增强** |
| 抑制   | 机体的生理、生化功能**减弱** |
| 基因治疗 |                  |
> [!note] 注意
> 药理效应的兴奋是看**功能的变化**，不是看作用受体的激动或抑制。**激动受体也可能产生抑制效应**。
# 药理效应选择性（VS[[药物作用|特异性]]）(selectivity)
熟悉
- 定义：药物引起机体产生效应的范围的专一或广泛程度，反映[[药物作用]]的范围
- 通常情况下, 药物选择性低是产生药物 #副作用 (side effect)的基础
## 选择性特点
熟悉
### 相对性
- 不同药物选择性不同
- 相同药物不同剂量选择性也有差异
## 选择性原因
- 结构差异
- 药物和组织亲和力不同(药物分布的差异)
- 组织细胞对药物的敏感性不同 (组织生化功能差异、细胞结构差异）
> [!note] 选择性高≠疗效好
> 选择性高，针对性强，应用范围小，不良反应少≠疗效好
> 选择性低，针对性差，应用范围广，不良反应多
