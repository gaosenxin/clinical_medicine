# 概念
**量-效关系**：<u>药理效应与剂量在一定范围内成比例</u>
# 量-效曲线(dose effect curve)
熟悉
以效应强度为纵坐标、药物剂量/药物浓度为横坐标作图所得曲线

---

> [!warning] [[药理效应]]按性质分类：
> -  #量反应(graded response)：
> 	- 药理效应大小用计量资料来衡量。
> 	- 强弱随药物剂量或浓度的逐渐增加或减少呈连续性量的变化
> 	- 个体
> -  #质反应 (all-or-none response)：
> 	- 计数资料
> 	- 只能用有效和无效，阳性或阴性来表示的药理效应
> 	- 群体


---
## 量反应的量-效曲线
量反应以剂量为横坐标得直方双曲线，改用对数浓度后呈 S 形曲线。
### 曲线参数
| 参数            | 定义                                                               |
| ------------- | ---------------------------------------------------------------- |
| 最小有效剂量 / 阈剂量  | 刚能引起效应的最小药物剂量或最小药物浓度                                             |
| [[效能]] / 最大效应 | 效应增加到一定程度后，若继续增加药物浓度或剂量而其效应不再继续增强，这一药理效应的极限                      |
| 半最大效应浓度（EC50） | 能引起 **50% 最大效应** 的药物浓度                                           |
| [[效价强度]] / 效价 | 两种或两种以上药物能引起**等效反应**的相对浓度或剂量（一般采用 EC50），其值越小则效价强度越大，反映药物的**亲和力** |
| 中段斜率          | 斜率较陡的提示药效较剧烈，较平坦的则提示药效较温和                                        |

## 质反应的量-效曲线
质反应以累计阳性百分率为纵坐标得 S 形曲线；若改以各剂量区段的阳性反应频率作图，则为常态分布曲线。
### 曲线参数
| 参数              | 定义                                |
| --------------- | --------------------------------- |
| [[半数有效量]]（ED50） | 能引起 50% 的实验动物出现阳性反应时的药物剂量         |
| [[半数致死量]]（LD50） | 引起 50% 的实验动物死亡时的药物剂量，**不可用于临床研究** |
| 半数中毒量（TD50）     | 引起 50% 的实验对象中毒时的药物剂量              |
| 中段斜率            | 质反应斜率反应**个体差异**，斜率小个体差异大          |
### 意义：药物安全性评价
1. [[治疗指数]]
2. 😊安全范围（margin of safety, SM）
	- LD5/ED95 的值或 LD5～ED95 之间的距离。
3. 可靠安全系数 （safety margin，SM） 熟悉
	- LD1/ED99，比值**大于 1**，药物较安全。
