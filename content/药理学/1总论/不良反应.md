# 概念
上市的合格药品在<u>常规用法、用量</u>情况下出现的，<u>与用药目的无关</u>，并引起患者其他病痛或危害的反应。

治疗作用与不良反应是同一药物由生物活性与作用机制决定、必然并存的两重性。
# 分类
## 药物相关不良反应：药效过强
1. [[副反应]]<u><font color="#ffff00">（side reaction）</font></u>
2. [[毒性反应]]❤
3. [[后遗效应]]
4. [[继发反应]]
5. [[停药反应]]
### 副反应 vs 毒性反应

| 对比维度 | 副反应 | 毒性反应 |
|---------|--------|---------|
| 发生剂量 | 治疗剂量下产生 | 用药量过大或体内蓄积 |
| 严重程度 | 反应轻微 | 比较严重 |
| 可预知性 | 可预知 | 可预知 |
| 可避免性 | 难以完全避免（可合用药物减轻） | 可以避免 |
| 本质原因 | 选择性差，效应范围广 | 药物在体内过多积聚 |
## 机体相关不良反应：特别的反应
1. [[特异性反应]]
2. [[依赖性]]
3. [[变态反应]]
### ❤ 特异性反应 vs 变态反应

| 对比维度  | 特异性反应         | 变态反应      |
| ----- | ------------- | --------- |
| 发生机制  | 先天遗传异常，不是免疫反应 | 异常免疫反应    |
| 敏化过程  | 不需敏化过程        | 需要预先敏化过程  |
| 与剂量关系 | 严重程度与剂量成正比    | 与剂量无关，差异大 |
| 反应性质  | 与药物作用一致       | 与药物固有效应无关 |
| 药理拮抗药 | 救治有效          | 无效        |
| 可预测性  | 可以预测          | 无法预测      |
