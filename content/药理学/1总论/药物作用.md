# 概念
药物导致效应的<u><font color="#ff0000">初始</font></u>反应。（直接作用于target）

药物作用是引起效应的初始动因，药理效应是其后继的功能或形态改变，二者为因果前后关系。
# 药物作用分类
## 按作用范围分类

| 类型   | 定义                 | 举例                         |
| ---- | ------------------ | -------------------------- |
| 局部作用 | 药物吸收入血之前在用药部位发生的作用 | 局麻药<br>肠道感染患者口服难吸收的磺胺药抑制细菌 |
| 吸收作用 | 药物吸收入血之后分布到全身发生的作用 | —                          |

## 按作用方式分类

| 类型   | 定义                | 举例                                |
| ---- | ----------------- | --------------------------------- |
| 直接作用 | 药物在分布的组织器官直接产生的作用 | 肾上腺素导致血压升高                        |
| 间接作用 | 由直接作用引发的其他作用      | 去甲肾上腺素导致心率下降<br>血管钙通道阻断剂反射性引起心率加快 |
# 药物作用特异性（VS[[药理效应|选择性]]）（specificity）
- **概念**：通过化学反应而产生药理效应，表现为药物与受体结合的专一性
- **特点**：取决于药物的**化学结构**

> [!tip] 考点提示
> 特异性强 ≠ 药效好。特异性和选择性都受**药物剂量**影响。


> [!note] 特点
> - 通过化学反应而产生药理效应
> - 具有的专一性
> - 取决于药物的化学结构

- 特异性与选择性不一定平行：特异性强不等于选择性高，二者都受药物剂量影响。
- 特异性由药物化学结构决定；选择性由组织亲和力差异与组织敏感性差异决定，两者决定因素不同。
- 例：阿托品特异性地阻断 M 受体。
