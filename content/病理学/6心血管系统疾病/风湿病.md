# ❤ 三、风湿病

【风湿病】（rheumatism）
	- 是一种与<font color="#ff0000"> A群乙型溶血性链球菌</font>感染有关（而非直接引起）的变态反应性疾病
	- 主要累及全身结缔组织和血管，最常累及<font color="#ff0000">心脏（最严重）</font>、关节和血管。
	- 形成特征性的<font color="#ff0000">风湿肉芽肿，即 Aschoff 小体</font>，有诊断意义

## 😭 （一）病因与发病机制

①<font color="#ff0000">A群乙型溶血性链球菌感染M蛋白抗原</font>（与人心瓣膜、脑存在<font color="#ff0000">交叉抗原</font>性）；<br>②自身免疫反应机制；<br>③遗传易感性；<br>④链球菌毒素学说。

> [!note] 交叉抗原的两个环节
> 抗原-抗体交叉反应学说：<font color="#ff0000">C 抗原（糖蛋白）</font>与结缔组织的糖蛋白存在交叉抗原性；<font color="#ff0000">M 蛋白</font>与心脏、关节等组织存在交叉抗原性，由此发生交叉免疫反应。
>
> 流行病学：多发于<font color="#ff0000">冬春阴雨季节</font>，潮湿、寒冷为重要诱因；好发于 <font color="#ff0000">5～15 岁</font>；属于结缔组织病／胶原病。

## ❤ （二）基本病理变化

风湿小体形成，病程长（4～6 个月），可大致分为：

|                  | 发生时间   | 病理变化                                                                                                                  |
| ---------------- | ------ | --------------------------------------------------------------------------------------------------------------------- |
| 变质渗出期（早期） | 持续1月   | 结缔组织发生<font color="#ff0000">粘液样变</font>和<font color="#ff0000">纤维素样坏死</font>；伴<font color="#ff0000">浆液、纤维素渗出</font>，少量淋巴细胞、浆细胞、单核细胞浸润 |
| 增生期（肉芽肿期） | 持续2-3月 | 心肌间质、心内膜下、皮下结缔组织出现特征性的<font color="#ff0000">Aschoff小体</font>（<font color="#ff0000">Aschoff细胞+纤维素坏死+少量淋巴细胞、浆细胞</font>） |
| 纤维化期（硬化期） | 持续2-3月 | Aschoff细胞变为成纤维细胞，纤维化形成梭形小<font color="#ff0000">瘢痕</font> |

> [!important] 反复发作
> 风湿病病变可反复发作 → <font color="#ff0000">新旧病变并存</font>；瘢痕不断形成，破坏组织结构，影响器官的结构与功能。

> <font color="#ff0000">特征性病理变化为风湿小体，即<font color="#ff0000">Aschoff小体</font>，对风湿病有诊断意义。</font>
> <font color="#ff0000">Aschoff细胞（风湿细胞）</font>：<font color="#ff0000">巨噬细胞</font>吞噬纤维素样坏死形成，多位于心肌间质小血管旁，横切面似枭眼状，纵切面呈毛虫状，可融合形成<font color="#ff0000">Aschoff巨细胞</font>。

## ❤ （三）各器官病变

### ❤ 1. 风湿性心脏病

可累及心脏全层，称风湿性全心炎（rheumatic pancarditis）。

| 类型                                               | 部位                                      | 病理变化                                                                                                                                                                                                                                      |
| ------------------------------------------------ | --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 风湿性心内膜炎<br>（<font color="#ff0000">疣状心内膜炎</font>） | <font color="#ff0000">心瓣膜，二尖瓣最多见</font> | 心房面<font color="#ff0000">疣状赘生物</font>，<font color="#ff0000">灰白色，半透明</font>，单行排列，附着牢固<font color="#ff0000">不易脱落</font>；后期瓣膜、腱索变形。<font color="#ff0000">McCallum斑</font>。<br>镜下：[[血栓形成#白色血栓（white thrombus）\|白色血栓]]（血小板+少量纤维蛋白+少量白细胞+少量红细胞） |
| 风湿性心肌炎                                           | 心肌<font color="#ff0000">间质</font>结缔组织   | <font color="#ff0000">间质</font>水肿，间质血管附近见<font color="#ff0000">Aschoff小体</font>和少量的淋巴细胞浸润                                                                                                                                                 |
| 风湿性心外膜炎                                          | 心外膜脏层                                   | 以纤维素渗出为主：绒毛心（干性心包炎）→缩窄；<br>以浆液渗出为主时：心包炎性积液（湿性心包炎）。                                                                                                                                                                                        |
病变所致瓣膜口狭窄或关闭不全，受血流反流冲击较重，引起内膜灶状增厚，称为McCallum斑。
##### 总结
|      | 急性期                                                       | 慢性期                                       | 本质         |
| ---- | --------------------------------------------------------- | ----------------------------------------- | ---------- |
| 心外膜炎 | 纤维性炎、<font color="#ff0000">绒毛心</font>                     | 机化，<font color="#ff0000">粘连</font>，缩窄性心包炎 | 浆液性炎；纤维素性炎 |
| 心肌炎  | <font color="#ff0000">风湿小体</font>                         | 机化，纤维瘢痕                                   | 肉芽肿性炎      |
| 心内膜炎 | 二尖瓣，<font color="#ff0000">赘生物（白色血栓）</font><br>串珠样排列于瓣膜闭锁缘 | 机化，瓣膜狭窄或关闭不全                              | 血栓         |

### ❤ 2. 其他病变

- 风湿性关节炎：<font color="#ff0000">肩、肘、腕、膝、踝</font>等大关节，呈<font color="#ff0000">游走性、反复发作性</font>，局部红肿热痛伴功能障碍；腔内浆液及少量纤维蛋白渗出，邻近组织内可见<font color="#ff0000">不典型Aschoff小体</font>，渗出可吸收，预后好，<font color="#ff0000">一般不留后遗症</font>。<font color="#ff0000">浆液性炎症</font>
- 皮肤病变
	- 环形红斑：渗出性病变，血管充血、炎细胞浸润
	- 皮下结节：增生性病变，肘、腕、膝、踝关节附近伸侧；镜下<font color="#ff0000">Aschoff小体</font>
- 风湿性动脉炎：小动脉受累多见，急性期纤维素样坏死，淋巴细胞浸润，并伴有<font color="#ff0000">Aschoff小体</font>形成；后期血管壁纤维化增厚→管腔狭窄
- 风湿性脑病：<font color="#ff0000">5-12岁儿童，女孩较多</font>；主要病变为风湿性动脉炎和皮质下脑炎；<font color="#ff0000">累及锥体外系</font>→肢体不自主运动，称小舞蹈病

> [!summary] Aschoff小体部位
> 心肌炎
> 风湿性关节炎（不典型）
> 皮肤：皮下结节
> 风湿性动脉炎
