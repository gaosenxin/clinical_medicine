# ❤ 三、高血压病

|      | 内容                                                                                                                                      |
| ---- | --------------------------------------------------------------------------------------------------------------------------------------- |
| 定义   | 以体循环动脉压持续升高为主要特点的临床综合征，可导致心、脑、肾和血管改变 |
| 诊断标准 | 成年人<font color="#ff0000">收缩压≥140mmHg和（或）舒张压≥90mmHg</font> |
| 分型   | ①<font color="#ff0000">原发性高血压</font>（又称特发性高血压、高血压病）：原因未明、独立性疾病；包括<font color="#ff0000">良性（缓进型）</font>与<font color="#ff0000">恶性（急进型）</font>高血压<br>②继发性高血压：患有某些疾病时出现的血压升高，如慢性肾小球肾炎、肾动脉狭窄、肾盂肾炎→肾性高血压；嗜铬细胞瘤、肾上腺肿瘤→内分泌性高血压<br>③特殊类型高血压 |

## 😭 （一）病因和发病机制

主要危险因素：遗传和基因、超重肥胖、高盐膳食、饮酒、长期精神紧张、体力活动缺乏、神经内分泌因素。

促高血压产生的机制：

| 机制 | 要点 |
| ---- | ---- |
| RAAS 系统 | <font color="#ff0000">AngⅡ 是发病机制的中心环节</font> |
| 交感神经系统 | 作用于心脏、血管、肾脏、肾上腺髓质 |
| 血管内皮功能紊乱 | <font color="#ff0000">NO↓</font> |
| 胰岛素抵抗 | 胰岛素本有舒血管、抗炎抗凋亡、抗动脉粥样硬化作用；<font color="#ff0000">约 50% 高血压患者，特别是肥胖者，存在胰岛素抵抗和高胰岛素血症</font> |

血管重构机制：

| 类型 | 机制 |
| ---- | ---- |
| 壁／腔比值增大型 | 压力升高，管壁增厚 |
| 壁／腔比值减小型 | 持续高血流状态致血管扩张 |
| 壁／腔比值不变型 | 血流缓慢减少 |
| 微血管减少型 | 毛细血管面积减少，血管外周阻力升高 |

## ❤ （二）良性高血压

良性高血压（benign hypertension）又称缓进性高血压（chronic hypertension）。

| ------------------------------------------------------------------------------------------------------------------------ | ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------ |
| 机能紊乱期                                                                                                             | 全身细小动脉                               | 痉挛收缩，动脉无器质性病变                                                                                                            |
| 动脉病变期                                                                                                             | <font color="#ff0000">细动脉硬化</font>   | <font color="#ff0000">高血压主要病变特征---细动脉玻璃样变</font>，尤其<font color="#ff0000">肾入球小动脉、视网膜动脉、脾动脉最常见</font> |
|                                                                                                                          | <font color="#ff0000">肌型小动脉硬化</font> | 内膜胶原纤维及弹性纤维增生，中膜平滑肌细胞增生、肥大，尤其<font color="#ff0000">肾小叶间动脉、弓状动脉、脑小动脉</font>                          |
|                                                                                                                          | 大动脉                                  | 主动脉及其主要分支，<font color="#ff0000">无</font>病变或并发动脉粥样硬化                                                                      |
| <font color="#ff0000">内脏病变期</font>                                                                                | 心脏                                   | <font color="#ff0000">向心性肥大：左心室壁增厚，乳头肌和肉柱增粗；<br>晚期离心性肥大。</font><br>镜下：心肌细胞核肥大、核深染                                        |
|                                                                                                                          | 肾脏                                   | <font color="#ff0000">原发性颗粒性固缩肾。</font><br>镜下：肾入球小动脉玻璃样变，肌型小动脉硬化；部分肾小球因缺血发生纤维化和玻璃样变                                      |
|                                                                                                                          | 脑                                    | 脑水肿或高血压脑病、脑软化（液化性坏死）、脑出血（<font color="#ff0000">基底节、内囊最常见，基底节出血主要是豆纹动脉病变</font>）                                   |
|                                                                                                                          | 视网膜                                  | 中央动脉发生细动脉硬化，视盘水肿，视网膜出血                                                                                                   |

## ❤ （四）恶性高血压

|         | 良性高血压                                            | 恶性高血压                                                                                                      |
| ------- | ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------- |
| 易发人群    | 中老年，多见，95%                                       | 青少年，少见，5%                                                                                                  |
| 疾病进展    | 缓慢                                               | 迅速                                                                                                         |
| 主要靶器官   | 心、肾、脑、视网膜                                        | <font color="#ff0000">肾脏（入球小动脉、肾小球）</font>                                                                 |
| 特征性病理改变 | 胶原纤维、弹力纤维增生<font color="#ff0000">细小动脉玻璃样变</font> | 增生性小动脉硬化（<font color="#ff0000">SMC增生，胶原纤维增多，洋葱皮样增厚</font>）<br>坏死性细动脉炎（<font color="#ff0000">纤维素样坏死</font>） |
![[高血压病-1792735301883.webp]]

> [!note] 两个机制链与一个数值
> 细动脉硬化形成链：高血压刺激→内皮细胞与基底膜受损→间隙扩大、通透性升高→血浆蛋白渗入管壁，SMC 分泌大量细胞外基质并因缺氧变性坏死→管壁逐渐由血浆蛋白、细胞外基质、坏死 SMC 产生的修复性胶原纤维及蛋白多糖替代。
> 原发性颗粒性固缩肾成因：肾单位的萎缩坏死与肾单位增生肥大交替出现。
> 恶性高血压（malignant hypertension，急进型高血压 accelerated hypertension）：多见于<font color="#ff0000">青少年</font>，血压显著升高，常超过 230/130 mmHg，病变进展迅速；可发生<font color="#ff0000">高血压脑病</font>，或较早就出现<font color="#ff0000">肾衰竭</font>，或常出现<font color="#ff0000">视网膜出血及视盘水肿</font>；可由良性高血压恶化而来，或起病即急进型。

恶性高血压累及肾与脑的表现：

| 部位 | 病变 |
| ---- | ---- |
| 肾 | 最常累及<font color="#ff0000">入球小动脉</font>，可波及肾小球；肾小球毛细血管袢<font color="#ff0000">节段性坏死</font> |
| 脑 | 局部脑组织缺血、微梗死形成、脑出血 |
