# 😭 六、心包炎

【心包炎】（pericarditis）多继发于其他疾病。

## 😭 （一）急性心包炎

急性心包炎属渗出性炎症，常形成心包积液。按渗出成分可分为四型：

| 类型 | 要点 |
| ---- | ---- |
| 浆液性心包炎 | 以浆液性渗出为主要特征，主要由<font color="#ff0000">非感染性疾病</font>引起，如风湿病、系统性红斑狼疮、硬皮病、肿瘤、尿毒症等 |
| 纤维素性及浆液纤维素性心包炎 | <font color="#ff0000">心包炎中最常见的类型</font>；可见粗糙黄白色纤维素性渗出物，呈绒毛状，称绒毛心；可恶化为缩窄性心包炎 |
| 化脓性心包炎 | 由<font color="#ff0000">链球菌、葡萄球菌、肺炎双球菌</font>等化脓菌侵袭心包所致；心包腔面覆盖灰绿色浑浊黏稠的纤维素性渗出物，或形成脓肿 |
| 出血性心包炎 | 大多数由结核杆菌经血道感染引起，亦可由恶性肿瘤累及心包所致 |

## 😭 （二）慢性心包炎

| 类型 | 要点 |
| ---- | ---- |
| 非特殊型慢性心包炎 | —— |
| 特殊型慢性心包炎 | 粘连性纵隔心包炎、缩窄性心包炎 |

如缩窄性心包炎，由于心包内渗出物机化和瘢痕形成，导致心脏舒张期充盈受限，多继发于其他疾病。

# 😭 心肌炎

| 分类 | 病因 | 发病机制 | 病理特点 |
| ---- | ---- | ---- | ---- |
| 病毒性心肌炎 | <font color="#ff0000">柯萨奇病毒、埃可病毒、腺病毒、流感病毒等</font> | T细胞介导免疫反应 | 心肌细胞间质水肿，可见<font color="#ff0000">淋巴细胞和巨噬细胞浸润</font>，将心肌分割成条索状，有的心肌断裂 |
| 细菌性心肌炎 | <font color="#ff0000">白喉杆菌、沙门菌属、链球菌</font> | 细菌感染 | <font color="#ff0000">心肌及间质内有多发小脓肿，心肌细胞变性坏死</font> |
| 孤立性心肌炎 | 不明确 | 不明确 | 弥漫性间质性心肌炎：心肌间质或小血管周围有较多淋巴细胞、巨噬细胞浸润；<br><font color="#ff0000">特发性巨细胞性心肌炎：病灶的心肌内可见灶性坏死和肉芽肿的形成，可见多核巨细胞。</font> |
| 免疫反应性心肌炎 | <font color="#ff0000">风湿病、类风湿、SLE</font> | 变态反应 | 心肌间质及小血管周围可见嗜酸性粒细胞、淋巴细胞、巨噬细胞浸润，偶见<font color="#ff0000">肉芽肿形成</font> |
