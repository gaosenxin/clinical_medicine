# 😭 七、动脉瘤

【动脉瘤】（aneurysm）：动脉壁因局部病变（薄弱或结构破坏）向外膨出，形成永久性局限性扩张。

## （一）按形态与结构分型

| 类型 | 形态特点 |
| ---- | ---- |
| 囊状动脉瘤 | 某一段血管壁局部性向外膨出，呈气球状囊性扩张；可使血流形成<font color="#ff0000">逆行性旋涡</font> |
| 梭形动脉瘤 | 血管部位呈均匀性扩张，两端均匀性缩小，可回到正常血管直径 |
| <font color="#ff0000">蜿蜒性动脉瘤</font> | 血管呈不对称性扩张，呈蜿蜒状膨隆 |
| <font color="#ff0000">舟状动脉瘤</font> | 血管壁一侧扩张，对侧管壁正常 |
| 夹层动脉瘤 | 常发生于血压变动最明显的<font color="#ff0000">升主动脉和主动脉弓</font>；血液从动脉内膜破裂口进入动脉中膜，使中膜形成假血管腔 |
| 假性动脉瘤 | 多由外伤引起，也称外伤性动脉瘤 |

> [!important] 最严重的并发症
> 动脉瘤最严重的并发症为<font color="#ff0000">破裂出血</font>。

## （二）心脏肿瘤

心脏肿瘤颇为少见，其中原发性肿瘤更为罕见。

| 肿瘤 | 要点 |
| ---- | ---- |
| <font color="#ff0000">心房粘液瘤</font> | 多发生于中年人，大多数位于<font color="#ff0000">左心房</font>；肿瘤呈息肉状或绒毛状，表面淡黄色、半透明胶冻状，质软易碎；镜下主要为散在的星芒状细胞分布于大量黏液样基质中 |
| 横纹肌瘤 | 儿童，最多见于<font color="#ff0000">室间隔</font>；光镜下瘤细胞胞质因含大量糖原而呈空泡状，核位于中央，肌原纤维疏松，呈网状、放射状分布，<font color="#ff0000">似蜘蛛</font>，具有诊断意义 |
