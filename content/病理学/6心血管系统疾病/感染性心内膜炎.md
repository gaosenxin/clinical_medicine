# 😊 四、感染性心内膜炎

【感染性心内膜炎】（infective endocarditis, IE）是由病原微生物经血行途径直接侵袭心内膜、尤其是心瓣膜而引起的炎症性疾病。

| 比较项目   | 急性感染性心内膜炎                                                                    | 亚急性感染性心内膜炎                                                                           | 风湿性心内膜炎                                                                                 |
| ------ | ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------- |
| 发病机制   | 毒力较强的化脓菌破坏<font color="#ff0000">正常心瓣膜</font>                                 | 毒力相对较弱的细菌<font color="#ff0000">定植于已病变心瓣膜（＞6周）</font>                                 | 交叉自身免疫性炎                                                                                |
| 常见细菌   | <font color="#ff0000">金黄色葡萄球菌</font>                                         | 草绿色链球菌（9版）<br><font color="#ff0000">甲型溶血性链球菌（10版）</font>                             | <font color="#ff0000">A群乙型溶血性链球菌</font>                                                 |
| 炎症类型   | <font color="#ff0000">化脓性炎症等</font>                                          | 急性渗出性炎+血色血栓                                                                          | 增生性炎                                                                                    |
| 累及瓣膜   | <font color="#ff0000">二尖瓣+主动脉瓣</font>                                        | <font color="#ff0000">二尖瓣+主动脉瓣</font>                                                | <font color="#ff0000">二尖瓣</font>                                                        |
| 赘生物特点  | ①组成：脓性渗出物、血栓坏死组织、细菌菌落<br>②特点：体积大、质地松软、<font color="#ff0000">易脱落形成细菌栓子</font> | ①组成：血小板、纤维蛋白、细菌菌落坏死组织、中性粒细胞等<br>②特点：赘生物呈息肉状或菜花状、质松脆、<font color="#ff0000">易脱落</font> | ①组成：血小板、纤维蛋白构成，伴小灶状纤维蛋白样坏死<br>②特点：细小灰白色，半透明、单行排列、附着牢固，<font color="#ff0000">不易脱落</font> |
| 细菌     | <font color="#ff0000">含细菌(化脓性感染)</font>                                      | <font color="#ff0000">不含细菌或仅含极少的细菌</font>                                            | <font color="#ff0000">不含细菌(变态反应)</font>                                                 |
| 瓣膜情况   | <font color="#ff0000">瓣膜严重破坏时，可破裂穿孔</font>                                   | <font color="#ff0000">瓣膜变形、导致慢性心瓣膜病</font>                                           | <font color="#ff0000">瓣膜增厚、心内膜增厚</font>                                                 |
| 瓣膜继发病变 | 破裂、穿孔或腱索断裂                                                                   | 瓣膜狭窄或关闭不全                                                                            | 瓣膜狭窄或关闭不全                                                                               |
| 器官梗死   | 心、脑、肾、脾的感染性梗死和脓肿                                                             | <font color="#ff0000">脑（最常见）</font>、肾、脾的<font color="#ff0000">无菌性梗死</font>           | —                                                                                       |
| 变态反应   | 局灶性或弥漫性肾小球肾炎和<font color="#ff0000">Osler小结</font>少见                          | 局灶性或弥漫性肾小球肾炎和<font color="#ff0000">Osler小结</font>多见                                  | —                                                                                       |

## 三种心内膜炎赘生物的比较

| | 风湿性心内膜炎 | 感染性心内膜炎 | 非感染性血栓性心内膜炎 |
| ---- | ---- | ---- | ---- |
| 体积 | 小，粟粒状 | 大 | 中等 |
| 成分 | 白色血栓 | 混合血栓、坏死组织、细菌 | 纤维素 |
| 连接 | 紧密 | 不紧密 | 不紧密 |
| 好发 | 二尖瓣瓣膜闭锁缘 | — | — |
