# 😭 五、心肌病

【心肌病】（cardiomyopathy）：<font color="#ff0000">除 CHD、高血压性心脏病、心脏瓣膜病、先天性心脏病和肺源性心脏病等以外</font>的、以心肌结构和功能异常为主要表现的一组疾病（原发性或特发性心肌病）。定义中的排除项不可省，考试常以"下列哪种不属于心肌病"设问。

## 😭 （一）分类

| 类别 | 内容 |
| ---- | ---- |
| 扩张性心肌病 | 复合性心肌病，以左心室、右心室或双心室腔扩大、收缩功能障碍为特征 |
| 肥厚性心肌病 | 以左心室和（或）右心室肥厚、心室腔变小、左心室充盈受阻和舒张期顺应性下降为特征 |
| 限制性心肌病 | 以单侧或双侧心室充盈受限、舒张期容量减少为特征 |
| 致心律失常性右室心肌病 | 右心室心肌被<font color="#ff0000">纤维脂肪组织</font>进行性替代 |
| 特异性心肌病（继发性心肌病） | 克山病、酒精性心肌病、围生期心肌病（妊娠末期或产后 5 个月内首次发生，以累及心肌为主，曾称产后心肌病）、药物性心肌病 |

## 😭 （二）四型的病理与临床比较

| 项目 | 扩张性心肌病 | 肥厚性心肌病 | 限制性心肌病 | 特异性心肌病（克山病） |
| ---- | ---- | ---- | ---- | ---- |
| 特征 | 左心室和（或）右心室腔扩大，收缩功能障碍（<font color="#ff0000">收缩性心衰</font>） | 左心室和（或）右心室肥厚、非对称性室间隔肥厚，舒张期顺应性下降（<font color="#ff0000">舒张性心衰</font>） | 心室充盈受限、舒张期容量减少，收缩功能正常（<font color="#ff0000">舒张性心衰</font>） | 硒元素缺乏，心肌严重变性、坏死和瘢痕 |
| 肉眼 | 心脏重量增加，可达 <font color="#ff0000">500～800 g</font>；两侧心腔扩张，心尖钝圆；<font color="#ff0000">二尖瓣和三尖瓣关闭不全</font>；心室壁略厚或正常（离心性肥大），心内膜增厚 | 两侧心室壁肥厚，室间隔非对称性肥厚尤为突出（90%）；乳头肌肥大；<font color="#ff0000">二尖瓣增厚和主动脉瓣下内膜增厚</font> | 心腔狭窄；心内膜及心内膜下纤维性增厚（心尖部为重）；可累及二尖瓣或三尖瓣而关闭不全 | 两侧心腔扩大，心室壁变薄并散在瘢痕，心尖部为重、呈球形 |
| 光镜 | 心肌细胞不均匀性肥大、伸长，心肌细胞空泡变、小灶性肌溶解；间质<font color="#ff0000">纤维化和微小坏死灶</font> | 心肌细胞弥漫性肥大，核大畸形，心肌纤维走行紊乱、分支交叉 | <font color="#ff0000">心内膜纤维化、玻璃样变和钙化</font>，心内膜下心肌纤维化 | 心肌细胞变性或凝固性坏死，慢性以瘢痕为主 |
| 临床表现 | 心力衰竭 | 肺动脉高压导致呼吸困难 | 心力衰竭、猝死 | 心力衰竭 |

> [!important] 肥厚性心肌病的量化标准
> 室间隔厚度大于左心室游离壁，二者之比 <font color="#ff0000">&gt;1.3</font>（正常约 0.95）。
