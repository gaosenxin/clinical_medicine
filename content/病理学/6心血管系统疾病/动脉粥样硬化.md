# ❤ 一、动脉粥样硬化
![[动脉粥样硬化-1791786134233.webp|478]]
动脉粥样硬化（atherosclerosis, AS）是发生于<font color="#ff0000">大中动脉</font>的弥漫性病变，主要病理变化为动脉<font color="#ff0000">内膜脂质沉积、内膜局灶性纤维化</font>、<font color="#ff0000">粥样斑块形成</font>，致使<font color="#ff0000">管壁变硬、管腔狭窄</font>，引起相应器官缺血性改变。
危害最大：<font color="#ff0000">中动脉</font>
> [!note] 动脉硬化（arteriosclerosis）
> 动脉壁增厚、变硬、弹性减退的一类疾病的总称，包括：
> - 动脉粥样硬化（AS，本章重点）
> - 细小动脉玻璃样变（见 [[高血压病]]）
> - 动脉中层钙化
> - <font color="#ff0000"> 纤维肌性内膜增生</font>（十版新增）（一种发生于比细动脉大的肌型动脉内的非动脉粥样硬化过程

## 😭 （一）病因和发病机制

### 😭 1. 危险因素

- 高脂血症：LDL（主要）、VLDL 为致 AS 性脂蛋白；HDL 为预防 AS 的脂蛋白；
- 其他：吸烟、遗传因素、年龄；高血压、致继发性高脂血症的疾病、代谢综合征。
> [!warning] 注意
> 高血压：细小动脉
> 高血脂：大中动脉

> [!important] ox-LDL
> 氧化 LDL（ox-LDL）是最重要的致粥样硬化因子，是损伤内皮细胞和 SMC 的主要因子；它不能被正常 LDL 受体识别，而易被巨噬细胞的<font color="#ff0000">清道夫受体</font>识别并快速摄取，促进泡沫细胞形成。

### 😭 2. 发病机制

以<font color="#ff0000">损伤-应答反应学说</font>（内皮损伤学说）为主：

1. 在各种刺激因素（LDL、机械性、吸烟等）作用下，血管内皮细胞结构和功能发生损伤，其通透性增高或直接坏死脱落，导致血浆成分过量进入动脉壁，同时引起血小板聚集黏附，释放活性因子加重损伤；
2. 内皮细胞在增殖更新时释放的生长因子可激活动脉平滑肌细胞（smooth muscle cell, SMC）增殖和迁移，其通过动脉壁内弹力膜窗孔后发生增殖、转化、分泌细胞外基质，且可由表面 LDL 受体介导吞噬脂质，形成 <font color="#ffff00">SMC 源性泡沫细胞</font>；
3. 单核细胞亦可在趋化因子作用下进入内膜并转化为有清道夫样作用的吞噬细胞，通过清道夫受体吞噬脂质，成为<font color="#ffff00">泡沫细胞</font>并形成脂质条纹。

其余学说：

| 学说 | 要点 |
| ---- | ---- |
| 脂质渗入学说 | 小、致密 LDL 沉积于动脉内膜 |
| 动脉 SMC 的作用 | 中膜 SMC 迁入内膜并增生，是进展期病变的重要环节，也是此时期泡沫细胞的主要来源；SMC 由<font color="#ff0000">收缩型转变为合成型</font>，合成胶原蛋白等细胞外基质 |
| 慢性炎症学说 | 炎症机制贯穿 AS 病变的起始、进展和并发症形成的全过程 |

#### 病变基本成分

- 细胞成分：平滑肌细胞、巨噬细胞、T 细胞
- 细胞外间质：胶原、弹性蛋白、蛋白多糖
- 细胞内和细胞外脂质
![[动脉粥样硬化-1791787351036.webp|301]]
### ❤ 2. 继发性改变

1. 斑块内出血：可进一步压迫血管导致急性供血中断；
2. 斑块破裂：粥样物流入血液可形成胆固醇栓子，同时遗留粥瘤样溃疡；
3. 血栓形成：溃疡形成后胶原暴露可形成血栓，导致器官缺血梗死；
4. 钙化：管壁变硬变脆；
5. 动脉瘤形成：中膜平滑肌萎缩、弹性下降导致的动脉局限性扩张，<font color="#ff0000">是最危险的并发症</font>；
6. 血管腔狭窄：中动脉因粥样斑块导致管腔狭窄，可导致相应部位缺血性改变。

|                                         | 成因                              | 后果                                                      |
| --------------------------------------- | ------------------------------- | ------------------------------------------------------- |
| <font color="#ff0000">斑块内出血</font>  | 斑块内新生血管破裂                       | 动脉管腔阻塞程度加重<br><font color="#ff0000">急性供血中断</font>   |
| 斑块破裂                                | 斑块表面纤维帽破裂                       | 形成<font color="#ff0000">粥瘤样溃疡</font><br>胆固醇栓子引起栓塞   |
| <font color="#ff0000">血栓形成</font>   | 斑块破裂，胶原暴露，可促进血栓形成               | 引起动脉管腔阻塞，引起器官梗死，脱落<font color="#ff0000">形成栓塞</font> |
| 钙化                                  | 钙盐沉积于坏死物中                       | 动脉壁变硬、变脆                                                |
| 动脉瘤形成                               | 中膜平滑肌萎缩和弹性下降，在血管内压力作用下，动脉壁局限性扩张 | 破裂造成致命性大出血                                              |
| <font color="#ff0000">血管管腔狭窄</font> | 因粥样斑块而导致官腔狭窄                    | 供血区域血量减少，致相应<font color="#ff0000">器官发生缺血性病变</font>  |

## ❤ （四）冠状动脉性心脏病
【冠状动脉粥样硬化】（coronary atherosclerosis）：冠状动脉<font color="#ff0000">最常见的疾病</font>，多发生于动脉的心壁侧，横切面呈向心位新月形；其特点是冠状动脉反应性改变，常伴发冠状动脉痉挛，造成急性心脏供血中断，引起心肌缺血和相应的心脏病变。

【冠状动脉性心脏病】（coronary atherosclerotic heart disease, CHD）简称冠心病，是因冠状动脉狭窄所致心肌缺血、缺氧而引起的功能性或器质性病变，亦称缺血性心脏病（ischemic heart disease, IHD）。冠状动脉粥样硬化是 CHD <font color="#ff0000">最常见的病因</font>。
### 2. 心绞痛

【心绞痛】（angina pectoris）是由于心肌<font color="#ff0000">急剧的、暂时性缺血、缺氧</font>所引起的一种常见临床综合征，可因心肌耗氧量增加或冠状动脉痉挛引起。

- 临床表现：阵发性心前区疼痛或压迫感，可放射至心前区或左上肢，服用硝酸酯制剂或稍休息后症状可缓解；
- 发生机制：心肌缺血缺氧导致酸性代谢产物或多肽类物质累积，刺激局部神经末梢，通过脊髓传至大脑而引起的痛觉。

按原因和疼痛程度分类：

| 分型      | 核心特点                                                                                                 |
| ------- | ---------------------------------------------------------------------------------------------------- |
| 稳定性心绞痛  | <font color="#ff0000">一般不发作</font>，仅在体力活动过度增加、心肌耗氧量增多时发作；冠脉横切面斑块阻塞管腔＞75%                             |
| 不稳定性心绞痛 | 症状进行性加重，常由<font color="#ff0000">斑块破裂或血栓形成</font>引起；休息或负荷状态下均可发作；常存在两支以上冠脉狭窄，镜下可见弥漫心肌坏死继发心肌纤维化        |
| 变异性心绞痛  | <font color="#ff0000">发作性</font>，无明显诱因，休息、睡眠时即可发作；冠脉可存在明显狭窄，也可由<font color="#ff0000">冠状动脉痉挛</font>诱发 |

### 3. 心肌梗死

【心肌梗死】（myocardial infarction, MI）是因冠状动脉供血中断、心肌<font color="#ff0000">持续性</font>缺血所导致的心肌大范围坏死。临床上有剧烈而持续的<font color="#ff0000">胸骨后</font>疼痛，<font color="#ff0000">使用硝酸酯制剂或休息后不能完全缓解</font>，可并发心律失常、休克、心力衰竭。

#### （1）病理变化

- 肉眼观：6 小时后方可见苍白色，<font color="#ff0000">8～9 小时</font>后变为土黄色；
- 镜下观：
	- 早期为凝固性坏死，细胞核碎裂消失，胞质均质红染或呈不规则颗粒状（收缩带），间质水肿且有不同程度中性粒细胞浸润；
	- 4 天后梗死灶周围出现充血出血炎症反应带；
	- 1～2 周后出现肉芽组织向梗死灶内长入；
	- 3 周后肉芽组织逐渐机化形成瘢痕；
- 心肌受损后心肌纤维内肌红蛋白迅速入血，随后心肌细胞内酶（肌酸磷酸激酶 CPK）亦通过损伤的细胞膜入血。
![[动脉粥样硬化-1792725964134.webp|481]]
#### （2）分类

除小动脉梗死造成的灶状梗死外，尚包括：

|      | 临床分型                               | 病理特点                                        | 镜下特点                                                                                                                                |
| ---- | ---------------------------------- | ------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| 心肌梗死 | 心内膜下梗死                             | <font color="#ff0000">室壁内侧1/3+肉柱+乳头肌</font> | <font color="#ff0000">多发性、小灶性坏死或环状梗死</font>；不局限于某一冠脉的供血范围                                                                     |
|      | <font color="#ff0000">透壁性梗死</font> | 室壁全层或达室壁2/3                                | 贫血性梗死<br>6小时：梗死灶<font color="#ff0000">呈苍白色</font><br>8-9小时：<font color="#ff0000">土黄色</font>，凝固性坏死、中性粒细胞浸润<br>4天：充血出血带<br>1-2周：<font color="#ff0000">肉芽组织</font>，呈红色<br>3周后：机化形成瘢痕组织 |

> [!important] 透壁性心肌梗死的三大冠脉供血区
> 左冠状动脉前降支：左心室前壁、心尖部、室间隔前 2/3、前内乳头肌
> 右冠状动脉：左心室后壁、室间隔后 1/3、右心室
> 左冠状动脉左旋支：左心室侧壁

#### （3）临床表现

- <font color="#ff0000">胸骨后疼痛</font>
- 胃肠道症状
- 发热、白细胞数量及血沉升高
- 心脏标志物检查：肌钙蛋白、血清心肌酶、肌红蛋白
- 心电图监测
- 并发症

#### （4）并发症

> [!caution] 要背：心肌梗死的并发症
> 心力衰竭、心脏破裂、室壁瘤、附壁血栓形成，以及心源性休克、急性心包炎、心律失常。

- 心力衰竭：当心内膜下 MI 累及左心室乳头肌时可造成二尖瓣关闭不全，诱发急性左心衰；梗死后心肌收缩力下降可导致左、右或全心衰竭；
- 心脏破裂：急性透壁性 MI 的严重并发症，发生在梗死后 2 周内，好发于左心室下 1/3。梗死灶失去弹性，坏死的心肌细胞、中性粒细胞、单核细胞释放蛋白溶解酶破坏梗死灶；发生于左室前壁者血液拥入心包腔可引起急性心包填塞而致死，发生在室间隔者可因左心分流而导致急性右心功能不全；
- 室壁瘤（ventricular aneurysm）：常见于 MI 的愈合期，梗死的心肌或瘢痕组织在左心室内压力作用下形成局限性向外膨隆，可引起心功能不全或继发附壁血栓形成；
- 附壁血栓（mural thrombosis）形成：MI 波及心内膜使其粗糙或室壁瘤造成血栓；
- 其他并发症：心源性休克、急性心包炎、心律失常。
