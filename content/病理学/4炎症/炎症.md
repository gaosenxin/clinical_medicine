# 第四章 炎症

## ❤ 一、炎症的概念

- #炎症 （inflammation）是具有血管系统的活体组织，在各种损伤因子刺激下所发生的、以防御反应为主的基本病理过程。
- 血管反应是炎症过程的主要特征和防御的中心环节

- 前提——具有血管系统的活体组织。
	- 单细胞、多细胞生物在局部损伤时的反应（吞噬损伤因子、细胞器肥大等）不能称为炎症
- 中心环节——血管反应。
	- 生物进化到具有血管时，才出现以血管反应为中心环节、又保留吞噬清除功能的复杂而完善的炎症反应
- 本质——损伤、抗损伤与修复的动态过程

炎症反应的步骤：
1. 各种损伤因子对机体组织和细胞造成损伤
2. 损伤周围组织中的前哨细胞（例如[[单核巨噬细胞|巨噬细胞]]）识别损伤因子及组织坏死物，产生炎症介质
3. 炎症介质激活宿主的血管反应及白细胞反应，使血液循环中的白细胞及血浆蛋白渗出到损伤部位，稀释、中和、杀伤及清除有害物质
4. 炎症反应消退与终止
5. 实质细胞和间质细胞增生，修复受损伤的组织

> [!note] 步骤注释
> 白细胞可分泌成纤维细胞生长因子，促进成纤维细胞的增殖；血管内皮生长因子（VEGF）或血小板源性生长因子（PDGF）也会刺激成纤维细胞的增殖。

## 😊 二、炎症的原因

凡能引起组织和细胞损伤的因子都能引起炎症。
能否引起炎症还与自身状态和敏感性相关

1. 物理性因子：高温、低温、机械性创伤、紫外线、放射线
2. 化学性因子
	- 外源性：强酸、强碱、强氧化剂、芥子气
	- 内源性：坏死组织的分解产物、病理条件下堆积于体内的代谢产物（如尿素）
	- 药物和其他生物制剂使用不当
3. 生物性因子（最常见）：病毒、细菌、[[立克次体]]、[[原虫概述|原虫]]、真菌、[[螺旋体]]、[[寄生虫的生物学|寄生虫]]
	- 由生物病原体引起的炎症又称 #感染 （infection）
	- 病毒在细胞内复制致感染细胞坏死；细菌及其内、外毒素和某些酶可激发炎症；寄生虫、[[结核分枝杆菌]] 等通过抗原性诱发免疫反应而损伤组织（见 [[寄生虫感染的免疫]]）
4. 组织坏死：任何原因引起的组织坏死都是潜在的致炎因子（如缺血所致新鲜梗死灶边缘的出血、充血带及炎症细胞浸润）
5. [[超敏反应简介|超敏反应]]：机体免疫反应状态异常所致，如 #过敏性鼻炎 、 #肾小球肾炎
6. 异物：手术缝线、二氧化硅晶体或物质碎片等残留于组织内

## ❤ 三、炎症的基本病理变化

变质、渗出、增生。

- 早期以变质或渗出为主，后期以增生为主
- 变质是损伤性过程；渗出和增生是抗损伤和修复过程

### ❤ 1. 变质（alteration）

炎症局部组织发生的变性和坏死统称为 #变质 （alteration），可发生于实质细胞和间质细胞。

- 实质细胞：细胞水肿、脂肪变性、凝固性坏死、液化性坏死
- 间质细胞：黏液样变性、纤维蛋白样坏死
- 原因：致病因子直接作用；或血液循环障碍及炎症反应产物间接作用
- 轻重取决于：致病因子的性质和强度、机体的反应情况
![[炎症-1789719725806.webp]]
### ❤ 2. 渗出（exudation）
- 炎症局部组织血管内的液体成分、纤维蛋白等蛋白质和各种炎症细胞，通过血管壁进入组织间隙、体腔、体表和黏膜表面的过程，称为 #渗出 （exudation）；所渗出的液体和细胞成分总称为渗出物或 #渗出液 （exudate）。
- 炎症最具特征的病理表现

- 机制：血管通透性增高 + 白细胞主动游出血管
- 渗出液聚于组织间隙——炎性水肿；聚于浆膜腔——炎性浆膜腔积液
- 渗出液与漏出液

| 项目 | 渗出液 | 漏出液 |
| ---- | ------------------- | ------------------- |
| 原因 | 炎症；血管通透性↑，WBC游出 | 非炎症；渗透压、静水压失衡 |
| 蛋白量 | <font color="#ff0000">>30 g/L</font> | <30 g/L |
| 细胞数 | 通常 <font color="#ff0000">>500×10⁶/L</font> | 通常 <100×10⁶/L |
| 比重 | <font color="#ff0000">>1.018（多数 >1.020）</font> | <1.018 |
| 外观 | 浑浊 | 清亮 |
| 凝固性 | 易自凝 | 不自凝 |

![[炎症-1789387483709.webp]]

<font color="#7f7f7f">渗出液对机体的积极意义：</font>
<font color="#7f7f7f">1. 稀释和中和毒素，减轻毒素对局部组织的损伤</font>
<font color="#7f7f7f">2. 为局部浸润的白细胞带来营养物质，运走代谢产物</font>
<font color="#7f7f7f">3. 所含的[[免疫球蛋白的结构|抗体]]和[[补体概述|补体]]有利于消灭病原体</font>
<font color="#7f7f7f">4. 纤维蛋白交织成网：限制病原微生物扩散、有利于白细胞吞噬；炎症后期的网架可成为修复的支架，并有利于成纤维细胞产生胶原纤维</font>
<font color="#7f7f7f">5. 白细胞吞噬和杀灭病原微生物，清除坏死组织</font>
<font color="#7f7f7f">6. 病原微生物和毒素随渗出液的淋巴回流到达局部淋巴结，刺激[[细胞介导的免疫反应|细胞免疫]]和[[体液免疫应答概述|体液免疫]]的产生</font>

<font color="#7f7f7f">渗出液过多的危害：</font>
<font color="#7f7f7f">- 压迫和阻塞：肺泡内渗出液堆积影响换气功能；心包或胸膜腔积液压迫心脏或肺脏；严重喉头水肿引起窒息</font>
<font color="#7f7f7f">- 渗出物中纤维蛋白吸收不良可发生机化：肺肉质变、浆膜粘连甚至浆膜腔闭锁</font>
> [!note]
> 肺泡腔内纤维素：渗出
> 蛛网膜下腔脓液：渗出
> 表皮内水泡：渗出（浆液）
> 乙型脑炎神经细胞溶解：变质
> 慢性肝炎汇管区炎细胞：渗出

### ❤ 3. 增生

在致炎因子作用下，炎症局部的实质细胞和间质细胞发生增生。

- 实质细胞增生：鼻黏膜慢性炎症时被覆上皮和腺体增生、慢性肝炎时肝细胞增生
- 间质细胞增生：巨噬细胞、内皮细胞、成纤维细胞
- 由相应的生长因子刺激引起
- 作用：限制炎症扩散、修复损伤组织

## 😊 四、炎症的局部表现、全身反应及意义

### 😊 （一）局部表现

红、肿、热、痛和功能障碍。

- 红——局部血管扩张、充血
- 肿——炎性水肿，组织增生
- 热——动脉性充血、血流加快、代谢旺盛
- 痛——渗出物压迫 +  #炎症介质 作用于感觉神经末梢
- 功能障碍——疼痛，水肿，实质细胞损害

### 😊 （二）全身反应

- [[发热]] 、嗜睡，厌食、心率加快、血压升高、 [[体温及其调节|寒战]] 
- 末梢血白细胞数目增加，急性期反应蛋白合成增多

> [!important] 发热机制
> 外源性致热源（细菌产物等）→ 刺激白细胞，释放内源性致热源（IL-1、TNF、PG）→ 作用于下丘脑体温调节中枢，COX↑，促进花生四烯酸（AA）转化为 PGE → 发热

末梢血白细胞计数增加（炎症反应的常见表现，尤其细菌感染）：
- 正常值：(4.0～10.0)×10⁹/L
- 可达（15～20）×10⁹/L；若达（40～100）×10⁹/L，称 #类白血病反应
- 机制：
	- 核象：粒细胞的分叶状况，反映成熟度
	- #核左移 ：外周血中核象图左侧细胞增多外周血杆状核增多，其与分叶核比例增大(>1:13);甚或出现更不成熟的粒细胞
	- <font color="#ff0000">IL-1、TNF</font> 促进白细胞从骨髓储存库释放，相对不成熟的<font color="#ff0000">杆状核</font>中性粒细胞所占比例↑
	![[炎症-1789453109222.webp|446]]
- 持续感染还能促进集落刺激因子的产生，引起骨髓造血前体细胞增殖
> [!caution]
> 立克次体，伤寒，病毒感染末梢血中性粒细胞降低

> [!important] 白细胞变化的规律（易考）
> - 多数细菌感染 → 中性粒细胞增加
> - [[寄生虫感染的免疫|寄生虫感染]]、过敏反应 → 嗜酸性粒细胞增加
> - 部分病毒感染（ #传染性单核细胞增多症 、 #腮腺炎 、 #风疹 ）→ 单核巨噬细胞或淋巴细胞比例增加
> - 多数病毒、[[立克次体]]、[[原虫概述|原虫]]，甚至极少数细菌（ [[沙门菌属|伤寒沙门菌]] ）→ 白细胞计数减少

### 😭 （三）意义

积极作用（防御反应）：
1. 抗感染：液体和白细胞渗出可稀释毒素、消灭入侵微生物、清除坏死组织；纤维蛋白网可阻止病原微生物蔓延；炎症性增生也可限制微生物扩散
2. 修复损伤组织：清除坏死组织后，实质细胞和间质细胞在相应生长因子作用下增生，修复组织、恢复功能
3. 适应应激、恢复[[机体的内环境，稳态和生物节律|稳态]]

危害：
1. 变质——重要器官发生较严重的变性和坏死时影响其功能（如 #病毒性心肌炎 影响心脏功能）
2. 渗出——大量炎性渗出物累及重要器官可致严重后果（如 #细菌性脑膜炎 的脓性渗出物引起颅内压增高，甚至形成脑疝）
3. 增生——如 #慢性肝炎 的肝细胞增生及纤维结缔组织增生可导致 #肝硬化
4. 长期慢性炎症刺激可引起多种其他疾病，如 #2型糖尿病 、 #肿瘤

## ❤ 五、炎症的分类

### 😭 1. 依累及器官分类

在病变器官后加「炎」字：心肌炎、肝炎、肾炎；临床常用具体部位或致病因子修饰： #肾盂肾炎 、 #肾小球肾炎 、 #病毒性心肌炎 、 #细菌性心肌炎 。

### 😭 2. 依病变程度分类

轻度炎症、中度炎症、重度炎症。

### ❤ 3. 依基本病变性质分类

任何炎症都在一定程度上包含变质、渗出、增生三种基本病变，但往往以一种为主。

- 以变质为主——变质性炎
- 以渗出为主——渗出性炎
- 以增生为主——增生性炎
- 渗出性炎根据渗出物的主要成分和病变特点，再分为 #浆液性炎 、 #纤维蛋白性炎 、 #化脓性炎 、 #出血性炎 等（详见 [[急性炎症#❤ 四、急性炎症的病理学类型|急性炎症]]）

典型疾病举例：

- 变质性炎：乙肝、乙脑、阿米巴肝脓肿、风湿性心脏病
- 增生性炎：伤寒、大部分慢性炎症（如慢性肝炎→肝硬化）

### ❤ 4. 依持续时间分类

- 超急性炎症（hyper-acute）：暴发经过，持续几小时至数天，常以变质和渗出性变化为主
- ❤[[急性炎症]]（acute）：反应迅速、持续时间短，仅几天、一般不超过一个月；以渗出性病变为主，浸润的炎症细胞主要为中性粒细胞；有时可表现为变质性炎（<font color="#ff0000">急性肝炎</font>）或增生性炎（<font color="#ff0000">伤寒</font>）
- 亚急性炎症（subacute）：介于急性与慢性之间，病程一个月到几个月
- ❤[[慢性炎症]]（chronic）：持续数周至数年（外科学≥2个月）；以增生性病变为主，浸润的炎症细胞主要为巨噬细胞和淋巴细胞；注意：<font color="#ff0000">慢性炎症也可以是渗出性炎</font>，比如肾盂肾炎

> [!note] 炎性息肉与腺瘤性息肉、增生性息肉的区别
> 腺瘤性息肉主要是上皮或腺体增生，癌变率高；炎性息肉和增生性息肉是多克隆性增生，血管和实质细胞都增生，癌变率低。

# 急性炎症与慢性炎症的比较
| 项目   | 急性炎症                                   | 慢性炎症                                                |
| ---- | -------------------------------------- | --------------------------------------------------- |
| 临床表现 | 起病快，病程短                                | 起病缓慢或由急性炎症转变而来，病程较长                                 |
| 血管反应 | 明显的血管反应（血管扩张，血管通透性增加）                  | 可以不明显                                               |
| 渗出   | 常以<font color="#ff0000">中性粒细胞</font>为主 | <font color="#ff0000">慢性炎细胞</font>（淋巴细胞、浆细胞、单核巨噬细胞） |
| 变质   | 较突出                                    | 不突出                                                 |
| 间质改变 | 较轻，以炎性水肿为主                             | 成纤维细胞增生，纤维化                                         |
