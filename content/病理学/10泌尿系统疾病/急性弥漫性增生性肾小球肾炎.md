# ❤ 二、急性弥漫性增生性肾小球肾炎（学长笔记）

急性弥漫性增生性肾小球肾炎，又称急性肾炎、毛细血管内增生性肾小球肾炎、感染后肾小球肾炎。

## ❤ （一）好发人群与病因

- 好发人群：儿童。
- 病因：感染。A 族乙型溶血性链球菌中的致肾炎菌株（12、13、49、4、1 型）是最常见原因，常发生在皮肤或咽部链球菌感染 1–4 周后。
- 大部分患者血清抗链球菌溶血素「O」和抗链球菌其他抗原的抗体滴度增高，说明近期有链球菌感染史；血清补体水平降低，说明有补体的激活和消耗；肾小球内有免疫复合物沉积，损伤由<font color="#ff0000">免疫复合物介导</font>。

## ❤ （二）病理变化

| 项目 | 内容 |
| ---- | ---- |
| 肉眼 | 双肾肿大，表面充血，可有散在粟粒大小的出血点，故称「<font color="#ff0000">大红肾</font>」「<font color="#ff0000">蚤咬肾</font>」 |
| 光镜 | 肾小球体积增大，<font color="#ff0000">内皮细胞和系膜细胞弥漫性增生</font>；中性粒细胞、单核细胞浸润；毛细血管闭塞狭窄，病变严重处血管壁发生纤维素样坏死，局部出血，可伴血栓形成；近曲小管上皮细胞变性；肾小管管腔内出现蛋白管型、红细胞或白细胞管型及颗粒管型；肾间质充血、水肿并有炎细胞浸润 |
| 电镜 | <font color="#ff0000">驼峰状</font>高电子密度沉积物，多位于脏层上皮细胞和肾小球基膜之间 |
| 免疫荧光 | <font color="#ff0000">颗粒状</font> IgG、IgM、C3 沉积 |

## （三）临床表现

急性肾炎综合征。

## （四）预后

儿童预后好，成人预后较差。
