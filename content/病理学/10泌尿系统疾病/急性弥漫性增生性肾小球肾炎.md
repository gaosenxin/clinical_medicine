# ❤ 二、急性弥漫性增生性肾小球肾炎

| ⁣‍⁣​‌‌​‌‌​‌​‌‌​‌‌​‌​‌‌‌​‌‌‌​​‌‌‌​​​​‌‌‌​‌‌​​‌‌‌​‌‌‌​‌‌​​​‌‌​‌‌​​‌‌‌​‌‌‌​​​​​‌‌​‌‌‌​​‌‌‌‌​​​​​‌‌​‌​‌​​‌‌​​​​​‌‌​​​​‌​​‌‌‌​​‌⁣‌⁣项目 | 内容                                                                                                                                                                                                            |
| -------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 别称                                                                                                                               | 毛细血管内增生性肾小球肾炎、急性肾炎、感染后性肾小球肾炎                                                                                                                                                                                  |
| 病因                                                                                                                               | <font color="#ff0000">A族乙型溶血性链球菌感染</font>，在<font color="#ff0000">血液循环中形成免疫复合物沉积</font>于肾小球内                                                                                                                   |
| 好发人群                                                                                                                             | <font color="#ff0000">儿童</font>，男性多于女性                                                                                                                                                                        |
| 起病与进展                                                                                                                            | 1-4周前<font color="#ff0000">A族乙型溶血性链球菌感染；起病急</font>，病情轻重不一                                                                                                                                                     |
| 临床表现                                                                                                                             | 急性肾炎综合征，<font color="#ff0000">一过性肾功能减低</font>                                                                                                                                                                 |
| 肾肉眼观                                                                                                                             | 双侧对称性肿大，被膜紧张表面充血(<font color="#ff0000">大红肾</font>)、点状出血(<font color="#ff0000">蚤咬肾</font>)                                                                                                                     |
| 光镜                                                                                                                               | 肾小球体积增大，<font color="#ff0000">内皮细胞和系膜细胞增生</font>，病变严重处<font color="#ff0000">毛细血管壁发生纤维蛋白样坏死</font><br>近曲小管上皮细胞<font color="#ff0000">变性</font>，肾小管出现管型，肾间质充血水肿并有炎细胞浸润（<font color="#ff0000">中性粒细胞、单核细胞等</font>） |
| 电镜                                                                                                                               | <font color="#ff0000">驼峰状电子致密物沉积</font>，多位于脏层上皮细胞和肾小球基膜之间（上皮下）                                                                                                                                                |
| 免疫荧光                                                                                                                             | 肾小球内有<font color="#ff0000">颗粒状</font>IgG、IgM和C₃<font color="#ff0000">沉积</font>                                                                                                                                |
| 预后                                                                                                                               | <font color="#ff0000">大多预后良好</font>，数月内临床自愈                                                                                                                                                                   |
