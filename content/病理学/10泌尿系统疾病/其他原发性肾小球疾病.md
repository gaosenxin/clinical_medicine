# ❤ 五、其他原发性肾小球疾病
## 膜增生性肾小球肾炎

| ⁣‍⁣​‌‌​‌‌​‌​‌‌​‌‌​‌​‌‌‌​‌‌‌​​‌‌‌​​​​‌‌‌‌​​​​‌‌​​‌‌‌​‌‌‌‌​​​​‌‌‌​​‌​​​‌‌​‌‌​​‌‌‌​​‌​​​‌‌​‌​‌​‌‌‌​​‌‌​‌‌​‌​​​​‌‌‌​‌‌​​‌‌​‌​‌​⁣‌⁣项目 | 内容                                                                                                                                                                                                           |
| -------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 别称                                                                                                                               | 系膜毛细血管性肾小球肾炎                                                                                                                                                                                                 |
| 发病特点                                                                                                                             | 好发于儿童和青年，可有上<font color="#ff0000">呼吸道感染史</font>                                                                                                                                                              |
| 发病机制                                                                                                                             | I型：由循环免疫复合物引起，并有补体的激活；<br>II型：补体替代途径异常激活，血清<font color="#ff0000">C3明显降低</font>；<br>III型：包括免疫复合物介导的肾小球肾炎及C3肾小球病。                                                                                              |
| 光镜                                                                                                                               | <font color="#ff0000">系膜细胞增生和系膜基质增多，基膜弥漫增厚（特征）</font>；增生的系膜细胞和基质插入基膜<font color="#ff0000">呈双线或双轨状。</font>                                                                                                    |
| 免疫荧光                                                                                                                             | I型：C₃颗粒状沉积，可出现IgG、补体C₁q和C₄；<br>II型：<font color="#ff0000">C₃沉积，常无IgG、补体C₁q和C₄</font>。                                                                                                                         |
| 电镜                                                                                                                               | I型：系膜区和内皮细胞下出现<font color="#ff0000">电子致密物沉积</font>；II型：块状电子致密物在基膜致密层呈带状沉积；<font color="#ff0000">III型：上皮下和内皮下均有电子致密物沉积（十版新增）</font>。                                                                          |
| 系统分型（十版新增）                                                                                                                       | 按免疫荧光肾小球免疫沉积物染色分：<br>①<font color="#ff0000">免疫球蛋白及补体</font>沉积，分为传染性、自身免疫性和单克隆性。<br>②<font color="#ff0000">C3</font>沉积为主，C3的沉积强度是其他免疫沉积物的2倍以上（伴或不伴膜增生性肾小球肾炎）。<br><br>根据电镜下电子致密物沉积特点分：<br>①致密物沉积病DDD；②C3肾小球肾炎。 |
| 临床表现                                                                                                                             | 肾病综合征                                                                                                                                                                                                        |
| 治疗                                                                                                                               | <font color="#ff0000">激素和细胞毒药物的治疗效果差</font>                                                                                                                                                                  |
| 预后                                                                                                                               | 慢性进展性，较差，约50%的患者在10年内出现慢性肾衰竭                                                                                                                                                                                 |
## 系膜增生性肾小球肾炎

| 项目   | 内容                                                   |
| ---- | ---------------------------------------------------- |
| 好发人群 | 青少年，男性多于女性                                           |
| 前驱病史 | 常<font color="#ff0000">有上呼吸道感染史</font>               |
| 发病机制 | 病因和发病机制不明                                            |
| 光镜   | 弥漫性系膜细胞增生和系膜基质增多<font color="#ff0000">（无插入现象）</font> |
| 免疫荧光 | IgG和C₃颗粒状沿肾小球毛细血管壁沉积                                 |
| 电镜   | 部分病例可见<font color="#ff0000">系膜区电子致密物沉积</font>        |
| 临床表现 | 具有<font color="#ff0000">多样性</font>，可表现为肾病综合征         |
| 治疗   | <font color="#ff0000">激素和细胞毒药物对病变轻者疗效好</font>        |
| 预后   | 病变轻者好，病变严重者较差                                        |
## 灶性节段性肾小球

| 项目   | 内容                                          |
| ---- | ------------------------------------------- |
| 病因   | 不清，可能与循环性通透性增高因子作用及足细胞损伤有关                  |
| 临床表现 | 肾病综合征或蛋白尿                                   |
| 肉眼   | -                                           |
| 光镜   | <font color="#ff0000">局部灶性节段性玻璃样变和硬化</font> |
| 电镜   | 上皮细胞足突消失、上皮细胞剥脱                             |
| 免疫荧光 | 局灶性IgM和C3沉积                                 |
| 转归   | 糖皮质激素治疗效果不佳。多发展为慢性肾小球肾炎。小儿患者预后较好            |

# ❤三种肾小球疾病的对比

| 项目   | 局灶性节段性肾小球硬化                                | 膜增生性肾小球肾炎                                                          | 系膜增生性肾小球肾炎                                        |
| ---- | ------------------------------------------ | --------------------------------------------------------------------------------- | ------------------------------------------------- |
| 病因   | 不清，与足细胞损伤有关 | Ⅰ型：循环免疫复合物；Ⅱ型：补体替代途径激活（<font color="#ff0000">低补体血症</font>）；Ⅲ型：免疫复合物 / C3                               | 尚未明确，常有<font color="#ff0000">上呼吸道感染</font>前驱                             |
| 光镜   | <font color="#ff0000">局灶性节段性玻璃样变和硬化</font>              | 系膜细胞和基质增生并<font color="#ff0000">插入基膜</font>，基膜弥漫增厚，呈<font color="#ff0000">双轨状</font> | 弥漫性系膜细胞增生和系膜基质增多<font color="#ff0000">（无插入）</font>                                 |
| 电镜   | 足突消失，部分上皮细胞从基膜剥脱                  | Ⅰ型：内皮下、系膜区电子致密物；Ⅱ型：基膜致密层带状沉积；Ⅲ型：内皮下、上皮下均有沉积                 | 部分病例<font color="#ff0000">系膜区</font>电子致密物沉积                                  |
| 免疫荧光 | 局灶性 IgM、C3 沉积                                  | <font color="#ff0000">C3 沉积为主</font>（Ⅱ型仅 C3）                                                   | IgG 及 C3 沉积最常见（他国多 IgM＋C3，称 IgM 肾病） |
| 临床表现 | 肾病综合征，<font color="#ff0000">非选择性蛋白尿</font>                    | 儿童和青年；肾病综合征或蛋白尿                                                             | 青少年；肾病综合征，或无症状蛋白尿、血尿                            |
| 治疗与转归 | <font color="#ff0000">激素效果不佳</font>；多发展为慢性肾小球肾炎，小儿患者预后较好                       | <font color="#ff0000">激素和细胞毒药物效果差</font>；慢性进展，约 50% 在 10 年内出现慢性肾衰竭                                                                        | 病变轻者<font color="#ff0000">激素疗效好</font>，预后较好；重者较差                                                |

> 三者均可表现为肾病综合征；膜增生性与系膜增生性肾炎发病前常有上呼吸道感染史。

## ❤ （二）IgA 肾病

- 分为 IgA1 和 IgA2 两个亚型，仅 <font color="#ff0000">IgA1</font> 可导致肾脏内免疫复合物的沉积。
- 好发人群：<font color="#ff0000">儿童、青年</font>；发病前常有上呼吸道感染，少数发生于胃肠道或尿路感染后。
- 病因：免疫调节异常。病毒、细菌、食物蛋白对呼吸道、消化道的刺激使黏膜合成 IgA 增多，沉积于系膜区并激活补体替代途径，导致肾小球损伤。

| 项目   | 内容                                                                                                |
| ---- | ------------------------------------------------------------------------------------------------- |
| 病因   | 免疫调节异常，黏膜合成IgA增多并沉积于肾脏                                                                            |
| 临床表现 | 反复<font color="#ff0000">发作的肉眼或镜下血尿</font>                                                         |
| 分型   | 可表现为<font color="#ff0000">三种病理类型</font>：<br>① 系膜细胞和系膜基质增多（系膜增生性病变，最常见）<br>② 局灶节段性增生或硬化<br>③ 新月体形成 |
| 光镜   | 系膜细胞、系膜基质增多（最常见），也可表现为局灶性节段性增生或硬化，少数病例有较多新月体生成                                                    |
| 电镜   | <font color="#ff0000">系膜区</font>电子致密物沉积                                                           |
| 免疫荧光 | <font color="#ff0000">系膜区</font> IgA 沉积，常伴有 C3 和备解素                                               |
| 临床表现 | 差异大                                                                                               |
| 转归   | 差异大。发病年龄大、大量蛋白尿、高血压、肾活检时发现血管硬化或新月体者预后较差                                                           |
