# ❤ 五、其他原发性肾小球疾病（学长笔记）

## ❤ （一）三种肾小球疾病的对比

| 项目 | 局灶性节段性肾小球硬化 | 膜增生性肾小球肾炎（系膜毛细血管性肾小球肾炎） | 系膜增生性肾小球肾炎 |
| ---- | ---- | ---- | ---- |
| 病因 | 脏层上皮细胞的损伤和改变，血浆蛋白、脂质外渗，激活系膜细胞，导致节段性玻璃样变、硬化 | Ⅰ型：循环免疫复合物，补体；Ⅱ型：C3 激活补体替代途径（出现低补体血症）；Ⅲ型：免疫复合物 / C3 | 尚未明确。起病前常有上呼吸道感染等前驱症状 |
| 光镜 | 病变呈局灶性分布，肾小球节段性玻璃样变和硬化；系膜基质增多 | 系膜细胞和内皮细胞增生，增生的系膜细胞和基质沿毛细血管内皮细胞下向基膜插入，PASM 染色呈<font color="#ff0000">双线或双轨状</font> | 弥漫性系膜细胞增生和系膜基质增多 |
| 电镜 | 弥漫性脏层上皮细胞足突消失，部分上皮细胞从基膜剥脱 | Ⅰ型：内皮细胞下、系膜区出现电子致密沉积物；Ⅱ型：高电子密度沉积物在基底膜致密层呈带状沉积；Ⅲ型：内皮下、上皮下均有电子致密物沉积 | 部分病例系膜区见有电子致密物沉积 |
| 免疫荧光 | IgM、C3 沉积 | Ⅰ型：C3、IgG、C1q、C4 颗粒状沉积；Ⅱ型：C3 沉积 | 我国最常见 IgG 及 C3 沉积；其他国家多表现为 IgM 及 C3 沉积（又称 IgM 肾病） |
| 临床表现 | 肾病综合征，非选择性蛋白尿，糖皮质激素治疗不佳 | 多见于儿童和青年。肾病综合征，或仅有蛋白尿 | 多见于青少年。肾病综合征，或无症状蛋白尿血尿 |
| 转归 | 多发展为慢性肾小球肾炎，小儿患者预后较好 | 慢性进展性，预后较差 | —— |

## ❤ （二）IgA 肾病

- 分为 IgA1 和 IgA2 两个亚型，仅 <font color="#ff0000">IgA1</font> 可导致肾脏内免疫复合物的沉积。
- 好发人群：儿童、青年；发病前常有上呼吸道感染，少数发生于胃肠道或尿路感染后。
- 病因：免疫调节异常。病毒、细菌、食物蛋白对呼吸道、消化道的刺激使黏膜合成 IgA 增多，沉积于系膜区并激活补体替代途径，导致肾小球损伤。

病理变化：

| 项目 | 内容 |
| ---- | ---- |
| 光镜 | 系膜细胞、系膜基质增多（最常见），也可表现为局灶性节段性增生或硬化，少数病例有较多新月体生成 |
| 电镜 | <font color="#ff0000">系膜区</font>电子致密物沉积 |
| 免疫荧光 | 系膜区 IgA 沉积，常伴有 C3 和备解素 |
| 临床表现 | 差异大 |
| 转归 | 差异大。发病年龄大、大量蛋白尿、高血压、肾活检时发现血管硬化或新月体者预后较差 |

## ❤ （三）各型特点总结

| 类型 | 特点 |
| ---- | ---- |
| 急性弥漫性增生性肾小球肾炎 | 大红肾；内皮细胞和系膜细胞弥漫性增生；上皮下驼峰状沉积物；颗粒状荧光 |
| 急进性肾小球肾炎 | 新月体形成（壁层上皮细胞增生 + 渗出的单核细胞）；Ⅰ型线性荧光，Ⅱ型颗粒状荧光，Ⅲ型阴性 |
| 膜性肾小球病 | 大白肾；上皮细胞足突消失，上皮下电子致密物沉积；GBM 弥漫性增厚、钉突；颗粒状荧光 |
| 膜增生性肾小球肾炎 | 系膜细胞和内皮细胞增生，增生的系膜细胞和基质向基膜广泛插入，形成双轨征或双线征 |
| 系膜增生性肾小球肾炎 | 弥漫性系膜细胞增生和基质增多，系膜区免疫物沉积 |
| 微小病变性肾小球病 | 切面肾皮质黄白色条纹；上皮细胞足突消失，无沉积物；近曲小管上皮细胞可见大量脂滴、蛋白小滴 |
| 局灶性节段性肾小球硬化 | 病变呈局灶性分布，肾小球节段性玻璃样变和硬化 |
| IgA 肾病 | 系膜区 IgA 沉积，电子致密沉积物 |
| 慢性肾小球肾炎 | 双肾对称缩小，弥漫性细颗粒状，皮质变薄，皮髓质不清，肾盂周围脂肪增多；肾小球玻璃样变，间质纤维化，管型 |
