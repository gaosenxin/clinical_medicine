# ❤ 一、肾小球疾病概述（学长笔记）

肾脏是泌尿系统中最重要的脏器，肾脏疾病中最常见的是肾实质的肾小球疾病。肾小球疾病（glomerular diseases）是以肾小球损伤和病变为主的一组疾病。

## ❤ （一）分类

肾小球疾病可分为原发性、继发性和遗传性三类。

| 类型 | 含义 |
| ---- | ---- |
| 原发性肾小球疾病 | 原发于肾脏的独立疾病，肾脏是唯一或主要受累的脏器 |
| 继发性肾小球疾病 | 由免疫性、代谢性、血管性疾病引起的肾小球病变，肾脏的病变是系统性疾病的组成部分 |
| 遗传性疾病 | 遗传因素所致的肾小球病变 |

## ❤ （二）肾单位解剖与滤过膜

肾单位是肾脏基本的结构和功能单位，由肾小球和与之相连的肾小管组成。肾小球由血管球和肾球囊构成，血管球包括毛细血管袢、系膜细胞和系膜基质；滤过膜由毛细血管内皮细胞、肾小球基膜（GBM）和脏层上皮细胞（足细胞）组成。

- 足细胞的足突间有大量唾液酸糖蛋白，一般带负电，对其他蛋白产生排斥作用，使蛋白难以滤出，只能让水和一些小分子溶质通过，所以一般情况下没有蛋白尿。
- <font color="#ff0000">电荷屏障</font>受损时，小分子物质漏出；<font color="#ff0000">机械屏障</font>受损时，大分子物质也漏出，受损越严重蛋白漏出越严重；红细胞也可通过受损的滤过膜漏出，因此滤过膜受损后会出现血尿、蛋白尿。
- 脏层上皮细胞与壁层上皮细胞：基膜主要由脏层上皮细胞分泌的基质形成。病理状态下脏层上皮细胞持续受损、持续增生时，基膜也会增厚。
- 系膜区：位于毛细血管袢之间，主要由系膜细胞和系膜基质构成。系膜细胞有收缩功能，还有一定的吞噬作用，并可分泌基质，在慢性炎症和肾小球的损伤与增生中发挥重要作用。

## ❤ （三）病因与发病机制

抗原抗体反应是最主要的发病原因，有关抗原分为外源性、内源性两大类：

- 外源性抗原：细菌、病毒、寄生虫等生物性病原体的成分、药物、外源性凝集素、异种血清等。
- 内源性抗原：肾小球性抗原（基膜、足细胞、内皮细胞、系膜细胞的细胞膜抗原）、非肾小球性抗原（DNA、核抗原、免疫球蛋白、肿瘤抗原、甲状腺球蛋白等）。

主要通过两种机制：

| 机制 | 要点 |
| ---- | ---- |
| 循环免疫复合物沉积 | 在血液循环中形成的抗原抗体复合物在肾小球内沉积。抗原为外源性或非肾小球性；定位为系膜区、内皮细胞与基膜之间（内皮下沉积物）、基膜与足细胞之间（上皮下沉积物）。<br>是否沉积、沉积位置和数量主要取决于免疫复合物分子的大小和所携带的电荷：<br>· 大分子复合物常被血液中的巨噬细胞吞噬清除；小分子容易通过滤过膜；中分子容易沉积在肾小球内<br>· 含阳离子可穿过基膜，易沉积于上皮下；含阴离子不易通过基膜，易沉积于内皮下；电荷中性易沉积于系膜区 |
| 原位免疫复合物沉积 | 抗体与肾小球内的抗原在原位发生反应。抗原为肾小球本身的抗原或经血液循环植入肾小球的抗原。<br>· 抗 GBM 抗体引起的肾炎：自身免疫性疾病，抗体沿 GBM 沉积，<font color="#ff0000">免疫荧光见连续线性荧光</font><br>· Heymann 肾炎：研究人类原发性膜性肾小球病的经典动物模型。抗体与足细胞小凹上的抗原复合物结合并激活补体，免疫复合物从细胞表面脱落形成上皮下沉积物；电镜下 GBM 与足细胞之间见许多小块状电子致密沉积物，免疫荧光见弥漫颗粒状分布的免疫球蛋白或补体沉积<br>· 抗体与植入抗原的反应：植入性抗原本为肾小球以外的成分，随血液流经肝脏时通过与肾小球成分的反应定位于肾小球，抗体与之反应，免疫荧光示散在的颗粒状荧光 |

肾小球损伤及疾病可由补体-白细胞介导的机制、抗肾小球细胞抗体的作用、以及各种介质的作用引起。

## ❤ （四）观察技术

| 技术 | 用途 |
| ---- | ---- |
| 光镜 | 苏木素伊红染色（HE）；过碘酸-Schiff 染色（PAS）可显示基膜和基质；过碘酸六胺银染色（PASM）对基膜染色更加清晰；Masson 染色显示特殊蛋白性物质（包括免疫复合物），也可显示胶原纤维等 |
| 电镜 | 观察超微结构改变、免疫复合物沉积的状况和部位 |
| 免疫荧光 | 检查免疫球蛋白（IgG、IgM、IgA 等）和补体成分（C3、C1q、C4 等）的沉积 |

## ❤ （五）肾小球疾病综合征

| 综合征 | 临床表现 | 常见病理类型 |
| ---- | ---- | ---- |
| 急性肾炎综合征 | 明显的血尿、轻至中度蛋白尿、水肿、高血压，严重者出现氮质血症 | 急性弥漫性增生性肾小球肾炎 |
| 急进性肾炎综合征 | 起病急、进展快，出现血尿、蛋白尿、水肿后迅速发展为少尿或无尿，伴氮质血症，发生急性肾衰竭 | 急进性肾小球肾炎 |
| 肾病综合征 | 大量蛋白尿（≥3.5g/L）、明显水肿、低白蛋白血症、高脂血症及脂尿 | 膜性肾小球病、微小病变性肾小球病、局灶性节段性肾小球硬化、膜增生性肾小球肾炎、系膜增生性肾小球肾炎 |
| 无症状性血尿或蛋白尿 | 持续或反复发作的镜下或肉眼血尿，和（或）轻度蛋白尿 | IgA 肾病、膜增生性肾小球肾炎、系膜增生性肾小球肾炎 |
| 慢性肾炎综合征 | 多尿、夜尿、低比重尿、高血压、贫血、氮质血症、尿毒症，见于各型肾炎的终末阶段 | 慢性肾小球肾炎 |

## ❤ （六）临床表现的病理学基础

| 表现 | 病理学基础 |
| ---- | ---- |
| 少尿或无尿 | 肾小球细胞增生肥大（急性弥漫增生性肾小球肾炎）、数量增多或新月体形成（急进性肾小球肾炎）使毛细血管受压，肾小球滤过率下降 |
| 多尿、夜尿、低比重尿 | 大量肾单位结构破坏，尤其是肾小管结构受累、重吸收功能下降，导致多尿、夜尿；大量肾单位破坏后血液流经残留肾单位时速度加快、肾小球滤过率升高，而肾小管重吸收功能有限，故尿比重低 |
| 低蛋白血症 | 长期大量蛋白尿使血浆蛋白含量减少 |
| 水肿 | 主要原因是低蛋白血症使血浆胶体渗透压下降 |
| 高脂血症 | 低蛋白血症刺激肝脏合成脂蛋白增多；还可能与血液循环中脂质颗粒运送障碍、外周脂蛋白分解障碍有关 |
| 高血压 | 水钠潴留使血容量升高；肾小球硬化、严重缺血使肾素升高；高血压使细、小动脉硬化，肾缺血加重，血压持续升高 |
| 贫血 | 肾组织破坏使 EPO 减少；体内代谢产物堆积抑制骨髓造血功能 |
| 氮质血症和尿毒症 | 肾小球病变、大量肾单位受损使肾小球滤过减少，代谢产物不能及时排出，水、电解质、酸碱平衡失调，血尿素氮升高、血浆肌酐升高。<br>尿毒症发生于急性、慢性肾衰的晚期，除氮质血症外还有一系列自体中毒的症状和体征，如尿毒症性胃肠炎、周围神经病变、纤维素性心外膜炎等；急性肾衰表现为少尿和无尿并出现氮质血症，慢性肾衰时持续出现尿毒症的症状和体征 |

## ❤ （七）基本病理变化

| 变化 | 内容 |
| ---- | ---- |
| 细胞增多 | 肾小球细胞数量增多，系膜细胞和内皮细胞增生或肥大，并可有中性粒细胞、单核细胞及淋巴细胞浸润；壁层上皮细胞增生可导致肾球囊内新月体形成 |
| 基膜增厚 | 光镜下 PAS 和 PASM 等染色可显示基膜增厚；电镜观察表明基膜改变可以是基膜本身增厚，也可为内皮下、上皮下或基膜内免疫复合物沉积所致 |
| 炎性渗出和坏死 | 急性肾炎的肾小球内可有中性粒细胞等炎细胞浸润和纤维素渗出；毛细血管壁可发生纤维素样坏死，可伴有血栓形成 |
| 玻璃样变和硬化 | 肾小球玻璃样变指光镜下 HE 染色显示均质的嗜酸性物质沉积；电镜下见细胞外出现无定形物质，成分为沉积的血浆蛋白、增厚的基膜和增多的系膜基质。严重时毛细血管管腔狭窄和闭塞，肾小球固有细胞减少甚至消失，胶原纤维增加，形成节段性或整个肾小球的硬化。<font color="#ff0000">肾小球玻璃样变和硬化</font>是各种肾小球病变发展的最终结果 |
| 肾小管和间质的改变 | 肾小球血流和滤过性状改变使肾小管上皮细胞常发生变性，管腔内可出现由蛋白质、细胞或细胞碎片浓聚形成的管型；肾间质可发生充血、水肿和炎细胞浸润。肾小球玻璃样变和硬化时，相应肾小管萎缩或消失，间质纤维化 |

## ❤ （八）病变分布的几个定义

| 术语 | 定义 |
| ---- | ---- |
| 弥漫性 | 病变累及 <font color="#ff0000">>50%</font> 的肾小球 |
| 局灶性 | 病变累及 <font color="#ff0000"><50%</font> 的肾小球 |
| 球性 | 病变累及肾小球的 >50% |
| 节段性 | 病变累及肾小球的 <50% |
