# ❤ 七、肾盂肾炎（学长笔记）

## ❤ （一）概念

- 肾小管间质性肾炎：一组累及肾小管和肾间质的炎性疾病，分为急性和慢性两类。
- 肾盂肾炎：<font color="#ff0000">肾盂、肾间质和肾小管</font>的炎性疾病。

## ❤ （二）感染途径

| 途径 | 要点 |
| ---- | ---- |
| 下行性感染 | 发生败血症或感染性心内膜炎时，细菌随血流进入肾脏，在肾小球或肾小管周围毛细血管内停留引起炎症；病变多累及双侧肾脏；<font color="#ff0000">金葡菌</font>最常见 |
| 上行性感染 | 发生下尿路感染（如尿道炎、膀胱炎）时，细菌沿输尿管或输尿管周围淋巴管上行至肾盂、肾盏、肾间质；病变可为单侧或双侧；主要是 G<sup>-</sup>，最常见的致病菌是<font color="#ff0000">大肠杆菌</font>，其次为变形杆菌、产气杆菌、肠杆菌、葡萄球菌等 |

上行性感染是引起肾盂肾炎的<font color="#ff0000">主要途径</font>，且女性尿道感染更多见。上行性感染引起的急性肾盂肾炎，病变程度为肾盂 > 肾小管 > 肾小球（肾小球基本不受累）。

## ❤ （三）急性与慢性肾盂肾炎对比

| 项目 | 急性肾盂肾炎 | 慢性肾盂肾炎 |
| ---- | ---- | ---- |
| 病因 | 下行性感染：血源性，金葡菌最常见；上行性感染：下尿路感染，大肠杆菌最常见 | 慢性阻塞性肾盂肾炎（尿路阻塞）；反流性肾病 / 慢性返流性肾盂肾炎 |
| 炎症类型 | <font color="#ff0000">急性化脓性炎症</font> | 慢性化脓性炎症 |
| 肉眼 | 肾体积增大，表面充血，有散在黄白色脓肿、紫红充血带；肾盂黏膜水肿，表面有脓性渗出物 | 一侧或双侧肾体积缩小，出现不规则瘢痕；切面皮、髓质界限不清，肾乳头萎缩，肾盂、肾盏变形（瘢痕收缩）；肾盂黏膜粗糙 |
| 镜下 | 间质：灶状分布的化脓性炎或脓肿形成；肾小管：腔内中性粒细胞集聚，肾小管坏死 | 部分肾小球玻璃样变、纤维化；部分肾小管萎缩、部分扩张，腔内有胶样管型，形似甲状腺滤泡；间质：局灶性淋巴细胞、浆细胞浸润，纤维化 |
| 临床病理联系 | 起病急，发热、寒战、腰部酸痛和肾区叩痛，并有尿频、尿急、尿痛等膀胱和尿道刺激症状；尿检显示脓尿、蛋白尿、管型尿、菌尿，<font color="#ff0000">白细胞管型</font>对诊断意义较大 | 腰痛、发热，频发的脓尿、菌尿；多尿、夜尿（肾小管尿浓缩功能下降）；低钠、低钾、代酸；高血压；晚期可致肾衰 |
| 预后 | 大多数患者经抗生素治疗后症状数天内消失，但尿中细菌可持续存在，常复发；并发症：肾乳头坏死（最严重）、肾盂积脓、肾周脓肿 | 常缓慢起病，也可表现为急性肾盂肾炎的反复发作 |
