# ❤ 六、慢性肾小球肾炎（学长笔记）

慢性肾小球肾炎是不同类型肾小球疾病发展的<font color="#ff0000">终末阶段</font>。

## ❤ （一）病理改变

| 项目 | 内容 |
| ---- | ---- |
| 肉眼 | <font color="#ff0000">继发性颗粒性固缩肾</font>：双肾对称、体积缩小，表面呈弥漫性颗粒状；切面皮质变薄，皮髓质界限不清；肾盂周围脂肪增多 |
| 光镜 | 肾小球玻璃样变和硬化；肾小管萎缩或消失；间质纤维化；淋巴细胞、浆细胞浸润；肾小管扩张，出现各种管型。（病变轻的肾单位可代偿性肥大） |

## （二）转归

晚期预后很差，可发生肾功能衰竭。

## ❤ （三）三种固缩肾的鉴别

- 原发性颗粒性固缩肾：多见于良性高血压，由部分肾单位萎缩、部分代偿性肥大形成。
- 动脉粥样硬化性固缩肾：多见于肾动脉粥样硬化，斑块继发血栓导致肾梗死，肾脏出现大凹性瘢痕。
- 慢性肾炎继发性颗粒性固缩肾：各型慢性肾小球肾炎的终末期。

| 特征 | 原发性颗粒性固缩肾 | 动脉粥样硬化性固缩肾 | 慢性肾炎继发性颗粒性固缩肾 |
| ---- | ---- | ---- | ---- |
| 对应疾病 | 良性高血压病（肾细小动脉硬化） | 肾动脉粥样硬化 | 各型慢性肾小球肾炎的终末期 |
| 病变本质 | 入球小动脉玻璃样变 + 肾单位缺血性萎缩、健存单位代偿肥大 | 肾动脉主干或大分支粥样斑块导致肾缺血、梗死和瘢痕形成 | 肾小球广泛纤维化、玻璃样变 + 肾小管萎缩消失 + 间质纤维化 |
| 大体形态 | 双侧对称、均匀弥漫缩小。表面呈均匀、弥漫、细颗粒状 | 双侧不对称，或单侧性。表面呈粗大、不规则的凹陷性瘢痕（梗死区）与相对正常区域相间 | 双侧对称、均匀弥漫缩小。质地极硬。表面呈均匀、弥漫的细颗粒状（与高血压肾类似，但更甚） |
| 切面 | 皮质变薄，皮髓质分界尚清 | 可见楔形、凹陷的梗死瘢痕 | 皮质显著变薄，皮髓质分界不清，呈「牛皮纸」样粘连 |
