# ❤ 六、慢性肾小球肾炎

| ⁣‍⁣​‌‌​‌‌​‌​‌‌​‌‌​‌​‌‌‌​‌‌‌​​‌‌‌​​​​‌‌‌‌​​‌​‌‌​​​​‌​‌‌​​​‌​​‌‌​‌‌‌​​‌‌​‌‌‌​​‌‌​‌‌‌‌​‌‌‌​‌​‌​​‌‌​‌‌‌​‌‌​‌‌​‌​​‌‌​‌​​​‌‌‌‌​​‌⁣‌⁣项目 | 内容                                                                                                                        |
| -------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| 病因                                                                                                                               | 由不同类型肾小球肾炎（如系膜增生型肾炎、膜性肾病、局灶性肾小球硬化、膜增生性肾）炎<font color="#ff0000">发展</font>而来，部分<font color="#ff0000">无明确的急性或其他类型肾炎病史</font> |
| 病变部位                                                                                                                             | 主要病变部位在<font color="#ff0000">肾小球</font>                                                                                   |
| 炎症分类                                                                                                                             | 多为<font color="#ff0000">免疫性炎症(变态反应性疾病)</font>                                                                             |
| 肉眼特点                                                                                                                             | <font color="#ff0000">继发性颗粒性固缩肾</font>（原发性是高血压）                                                                           |
| 肾脏萎缩                                                                                                                             | 双肾体积缩小，两肾病变对称（实质萎缩，间质胶原增生）                                                                                                |
| 病变分布                                                                                                                             | 肾脏表面呈<font color="#ff0000">弥漫性细颗粒状，分布均匀</font>                                                                            |
| 肾盂肾盏                                                                                                                             | <font color="#ff0000">周围脂肪增多</font>                                                                                       |
| 肾间质                                                                                                                              | 间质纤维化，伴有淋巴细胞和浆细胞浸润                                                                                                        |
| 肾小管                                                                                                                              | 萎缩或消失                                                                                                                     |
| 肾小球                                                                                                                              | 早期具有原相应类型的改变，后期大量肾小球发生玻璃样变和硬化                                                                                             |
| 尿毒症                                                                                                                              | 晚期有                                                                                                                       |

---
> [!note] 颗粒性固缩肾
> 原发：高血压
> 继发：肾病、肾炎
> 动脉粥样硬化
