# ❤ 四、膜性肾小球病与微小病变性肾小球病（学长笔记）

## ❤ （一）两者对比

| 项目 | 膜性肾小球病（膜性肾病） | 微小病变性肾小球病（微小病变性肾小球肾炎 / 微小病变性肾病） |
| ---- | ---- | ---- |
| 好发人群 | 多见于成人，是引起<font color="#ff0000">成人肾病综合征最常见</font>的原因 | 多见于儿童，是引起<font color="#ff0000">儿童肾病综合征最常见</font>的原因；可发生于呼吸道感染或免疫接种后 |
| 发病机制 | 与 Heymann 肾炎相似，自身抗体与上皮细胞膜抗原反应，在上皮细胞与基膜之间形成免疫复合物，免疫复合物介导补体 C5b–C9 组成膜攻击复合物，激活上皮细胞、系膜细胞，使之释放蛋白酶、氧化剂，导致毛细血管壁损伤、蛋白漏出 | 免疫异常导致上皮细胞损伤，滤过膜阴离子丧失，但<font color="#ff0000">无免疫复合物沉积</font> |
| 肉眼 | 双肾增大，颜色苍白，「<font color="#ff0000">大白肾</font>」 | 肾脏肿胀，颜色苍白，切面可见黄白色条纹 |
| 光镜 | 早期肾小球基本正常；后期弥漫性基膜增厚；PASM 染色基膜形成齿梳状（<font color="#ff0000">钉突</font>：增厚的基膜向沉积物表面延伸）；Masson 染色可见上皮下免疫复合物颗粒状沉积 | 肾小球结构基本正常，近曲小管上皮细胞内出现大量脂滴和蛋白小滴 |
| 电镜 | 上皮细胞肿胀，足突消失，基膜与上皮之间有大量电子致密物沉积 | 弥漫性脏层上皮细胞足突消失，胞体肿胀；GBM 正常，无电子致密物沉积 |
| 免疫荧光 | 免疫球蛋白和补体沉积形成颗粒状荧光 | 阴性 |
| 临床表现 | 成人肾病综合征；非选择性蛋白尿 | 儿童肾病综合征；选择性蛋白尿 |
| 转归 | 慢性进行性加重，40% 肾功能不全 | 预后较好，糖皮质激素治疗 90% 有效 |

## ❤ （二）补充说明

- 微小病变性肾小球病出现选择性蛋白尿，大量脂蛋白漏出后被近曲小管重吸收，导致细胞内玻璃样变，可见玻璃样小滴和脂滴。
- 非选择性蛋白尿：滤过膜机械屏障受损。
- 选择性蛋白尿：<font color="#ff0000">滤过膜电荷屏障</font>受损。
