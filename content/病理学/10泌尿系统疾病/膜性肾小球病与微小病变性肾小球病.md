# ❤ 四、膜性肾小球病与微小病变性肾小球病

## ❤ （一）膜性肾小球病

| ⁣‍⁣​‌‌​‌‌​‌​‌‌​‌‌​‌​‌‌‌​‌‌‌​​‌‌‌​​​​‌‌‌‌​​​​​‌‌​‌‌​​‌‌‌‌​‌​​‌‌‌​‌​‌​‌‌‌​​​‌​‌‌​‌​‌‌​​‌‌​​​‌​‌‌​‌‌‌‌​​‌‌​​​​​‌‌​‌​​‌​​‌‌​​​‌⁣‌⁣项目 | 内容                                                                                      |
| -------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| 别称                                                                                                                               | 膜<font color="#ff0000">性肾病、</font>膜性肾小球肾炎、弥漫性膜性肾小球肾炎                                    |
| 好发人群                                                                                                                             | 中老年(男性多于女性)；<font color="#ff0000">成人肾病综合征最常见</font>的类型                                  |
| 病理特征                                                                                                                             | 肾小球<font color="#ff0000">毛细血管壁弥漫性增厚</font>，基膜<font color="#ff0000">上皮下电子致密物沉积</font>    |
| 肾肉眼观                                                                                                                             | <font color="#ff0000">大白肾</font>                                                        |
| <font color="#ff0000">光镜</font>                                                                                                  | 早期肾小球基本正常，之后肾小球<font color="#ff0000">毛细血管壁弥漫性增厚</font>                                  |
| 免疫荧光                                                                                                                             | IgG和C₃<font color="#ff0000">颗粒状</font>沿肾小球毛细血管壁沉积                                       |
| <font color="#ff0000">电镜</font>                                                                                                  | <font color="#ff0000">基膜钉状突起形成呈齿梳状</font>，后期电子致密物吸收后<font color="#ff0000">呈虫蚀状空隙</font> |
| 临床表现                                                                                                                             | <font color="#ff0000">肾病综合征(80%)、肾静脉栓塞(40%-50%)</font>                                  |
| 治疗                                                                                                                               | 60%~70%的早期患者经糖皮质激素和细胞毒药物治疗后可达临床缓解；<font color="#ff0000">单用激素无效。</font>                  |
| 预后                                                                                                                               | 早期缓解率高，晚期缓慢进展为肾衰竭                                                                       |
## （二）微小病变性肾小球病

| 项目                                | 内容                                                                                                                              |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 别称                                | 脂<font color="#ff0000">性肾病、</font>微小病变性肾小球肾炎、微小病变性肾病、轻微病变性肾病(肾小球肾炎)                                                             |
| 好发人群                              | <font color="#ff0000">儿童</font>，儿童肾病综合征<font color="#ff0000">最常见</font>的类型                                                      |
| 病理特征                              | 弥漫性肾小球<font color="#ff0000">脏层上皮细胞足突融合或消失</font>；肾小球<font color="#ff0000">基膜正常</font>，无免疫沉积物。                                   |
| 肾肉眼观                              | 黄色油腻                                                                                                                            |
| 光镜                                | <font color="#ff0000">肾小球基本正常</font>，近曲小管上皮细胞内出现<font color="#ff0000">大量脂滴(脂肪变性)</font>和<font color="#ff0000">蛋白小滴(玻璃样变)</font> |
| <font color="#ff0000">免疫荧光</font> | <font color="#ff0000">阴性(无免疫复合物沉积)</font>                                                                                       |
| 电镜                                | 弥漫性肾小球<font color="#ff0000">脏层上皮细胞足突消失</font>，无免疫沉积物。                                                                           |
| 临床表现                              | <font color="#ff0000">典型的肾病综合征</font>                                                                                           |
| 治疗                                | 90%病例对<font color="#ff0000">糖皮质激素治疗敏感</font>；初治者可单用激素<font color="#ff0000">(首选</font>)；疗效差可用激素和细胞毒药物                            |
| 预后                                | 自发缓解率高(30%~40%)，易复发(60%)。                                                                                                       |
## 对比

| ⁣‍⁣​‌‌​‌‌​‌​‌‌​‌‌​‌​‌‌‌​‌‌‌​​‌‌‌​​​​‌‌‌​‌‌‌​‌‌‌‌​‌​​‌‌​​​‌‌​‌‌​‌​​​​‌‌​​‌‌​​‌‌‌‌​‌​​‌‌​‌​‌‌​‌‌​​​​‌​​‌‌​​​​​‌‌‌‌​‌​​‌‌‌​‌​‌⁣‌⁣项目 | 膜性肾小球病 | 微小病变性肾小球病 |
| ---- | ---- | ---- |
| 好发 | <font color="#ff0000">成人肾病综合征最常见</font>的类型 | <font color="#ff0000">儿童肾病综合征最常见</font>的类型 |
| 发病机制 | 上皮下<font color="#ff0000">免疫复合物沉积</font>（与 Heymann 肾炎相似） | 上皮细胞损伤、滤过膜阴离子丧失，<font color="#ff0000">无免疫复合物沉积</font> |
| 光镜 | 毛细血管壁<font color="#ff0000">弥漫性增厚</font>，PASM 染色见<font color="#ff0000">钉突</font> | <font color="#ff0000">肾小球基本正常</font>，近曲小管上皮细胞内大量<font color="#ff0000">脂滴</font>和<font color="#ff0000">蛋白小滴</font> |
| 电镜 | 基膜上皮下<font color="#ff0000">电子致密物沉积</font>，足突消失 | <font color="#ff0000">足突消失</font>，GBM 正常，<font color="#ff0000">无电子致密物沉积</font> |
| 免疫荧光 | IgG 和 C₃ 沉积，呈<font color="#ff0000">颗粒状</font>荧光 | <font color="#ff0000">阴性</font> |
| 蛋白尿 | <font color="#ff0000">非选择性</font>蛋白尿 | <font color="#ff0000">选择性</font>蛋白尿 |
| 治疗与转归 | <font color="#ff0000">单用激素无效</font>；慢性进展，40% 肾功能不全 | <font color="#ff0000">90% 对激素敏感</font>，易复发 |

> 膜性肾小球病肉眼为「<font color="#ff0000">大白肾</font>」；微小病变性肾小球病肉眼呈黄色油腻，切面可见黄白色条纹。

## ❤ （二）补充说明

- 微小病变性肾小球病出现选择性蛋白尿，大量脂蛋白漏出后被近曲小管重吸收，导致细胞内玻璃样变，可见玻璃样小滴和脂滴。
- 非选择性蛋白尿：滤过膜机械屏障受损。
- 选择性蛋白尿：<font color="#ff0000">滤过膜电荷屏障</font>受损。
