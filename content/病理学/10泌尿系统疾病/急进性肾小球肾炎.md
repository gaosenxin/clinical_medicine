# ❤ 三、急进性肾小球肾炎（学长笔记）

急进性肾小球肾炎，又称新月体性肾小球肾炎。

## ❤ （一）病因与分型

由不同原因引起，根据免疫学和病理学检查结果分为三型。

| 分型 | 免疫学机制 | 免疫荧光 | 电镜 |
| ---- | ---- | ---- | ---- |
| Ⅰ型 | <font color="#ff0000">抗 GBM 抗体</font>引起，最常见 | <font color="#ff0000">线性荧光</font>，主要为 IgG 沉积 | —— |
| Ⅱ型 | 免疫复合物性肾炎 | <font color="#ff0000">颗粒状荧光</font> | 电子致密沉积物 |
| Ⅲ型 | <font color="#ff0000">免疫缺乏型</font>肾炎（ANCA 导致血管炎） | 阴性 | 阴性 |

Ⅰ型中部分患者的抗 GBM 抗体可与肺泡基膜发生交叉反应，引起肺出血，同时伴有血尿、蛋白尿、高血压等肾炎症状，常发展为肾衰竭，称为<font color="#ff0000">肺出血肾炎综合征</font>（Goodpasture syndrome）。

## ❤ （二）病理变化

| 项目 | 内容 |
| ---- | ---- |
| 肉眼 | 双肾体积增大，色苍白，表面可有点状出血，切面见皮质增厚 |
| 光镜 | 多数肾小球球囊内有<font color="#ff0000">新月体</font>形成（增生的壁层上皮细胞 + 渗出的单核细胞）。新月体使肾小球球囊腔闭塞，并压迫毛细血管丛 |
| 电镜 | 新月体；Ⅱ型可见电子致密沉积物 |
| 免疫荧光 | Ⅰ型线性荧光；Ⅱ型颗粒状荧光；Ⅲ型阴性 |

新月体的演变：纤维素渗出刺激新月体形成。早期以细胞成分为主（细胞性新月体），随后胶原纤维增多形成纤维-细胞性新月体，最终成为纤维性新月体。

## （三）临床表现

- 急进性肾炎综合征：蛋白尿、血尿迅速发展为少尿、无尿，如不及时治疗，患者常在数周至数月内死于急性肾衰竭。
- Ⅰ型可见 Goodpasture 综合征（肺出血肾炎综合征），可有反复发作的咯血，严重者致死。

## ❤ （四）与急性弥漫性增生性肾小球肾炎的鉴别

| 项目 | 急性弥漫性增生性肾小球肾炎 | 急进性肾小球肾炎 |
| ---- | ---- | ---- |
| 病因 | 感染，A 族乙型溶血性链球菌中的致肾炎菌株（12、13、49、4、1 型）是最常见的病原体，损伤由免疫复合物介导 | Ⅰ型：抗 GBM 抗体；Ⅱ型：免疫复合物沉积；Ⅲ型：ANCA 导致血管炎 |
| 肉眼 | 双肾轻到中度肿大，被膜紧张，表面充血，可有散在的粟粒大小出血点，「大红肾」或「蚤咬肾」；切面可见皮质增厚 | 双肾体积增大，色苍白 |
| 光镜 | 肾小球体积增大，内皮细胞和系膜细胞增生；中性粒细胞、单核细胞浸润 | 肾小球新月体（壁层上皮细胞增生 + 渗出的单核细胞） |
| 电镜 | 脏层上皮细胞和基膜之间高电子密度沉积物，呈驼峰状 | 新月体；Ⅱ型病例出现电子致密沉积物；均有基膜缺损断裂 |
| 免疫荧光 | IgG、IgM、C3 颗粒状沉积 | Ⅰ型线性荧光；Ⅱ型颗粒状荧光；Ⅲ型阴性 |
| 临床表现 | 急性肾炎综合征；抗「O」抗体阳性 | 急进性肾炎综合征；Goodpasture 综合征（抗 GBM 抗体对肺泡基膜有交叉反应时） |
| 转归 | 多见于儿童，儿童预后好，成人预后较差 | 预后较差 |
