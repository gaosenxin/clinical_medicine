# ❤ 三、急进性肾小球肾炎

| 项目    | 内容                                                                                                                                                   |
| ----- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| 别称    | 新月体性肾小球肾炎、急进性肾炎、快速进行性肾小球肾炎                                                                                                                           |
| 病因    | 免疫机制引起                                                                                                                                               |
| 好发人群  | I型好发于<font color="#ff0000">中青年</font>，II、III型好发于<font color="#ff0000">老年，男性多</font>                                                                  |
| 起病与进展 | 可有前驱<font color="#ff0000">呼吸道感染史，起病更急</font>，病情可急骤进展                                                                                                 |
| 临床表现  | I型表现为Goodpasture综合征（<font color="#ff0000">肺出血肾炎综合征</font>）（<font color="#ff0000">交叉免疫引起的肺损害</font>）；急进性肾炎综合征，<font color="#ff0000">短期内出现肾功能衰竭</font> |
| 肾肉眼观  | 体积增大，色苍白，表面可有点状出血，切面见肾皮质增厚                                                                                                                           |
| 光镜    | <font color="#ff0000">早期细胞性新月体形成（壁层上皮增生+单核细胞）</font>，后期纤维化变成纤维性新月体；炎细胞浸润（中性粒细胞、<font color="#ff0000">单核细胞</font>等）                                   |
| 电镜    | 肾小球基膜<font color="#ffff00">变质</font><font color="#ff0000">缺损和断裂（其主要基础病变）</font>；<font color="#ff0000">II型电子致密物沉积，I型、III型无电子致密物沉积</font>              |
| 免疫荧光  | I型<font color="#ff0000">线性荧光</font>、II型<font color="#ff0000">颗粒状荧光</font>、III型<font color="#ff0000">无免疫荧光</font>                                     |
| 预后    | <font color="#ff0000">III型较好，I型差，II型居中</font>                                                                                                        |

## ❤ 与急性弥漫性增生性肾小球肾炎的鉴别

| 项目 | 急性弥漫性增生性肾小球肾炎 | 急进性肾小球肾炎 |
| ---- | ---- | ---- |
| 病因 | 感染，A 族乙型溶血性链球菌中的致肾炎菌株（12、13、49、4、1 型）是最常见的病原体，损伤由免疫复合物介导 | Ⅰ型：抗 GBM 抗体；Ⅱ型：免疫复合物沉积；Ⅲ型：ANCA 导致血管炎 |
| 肉眼 | 双肾轻到中度肿大，被膜紧张，表面充血，可有散在的粟粒大小出血点，「大红肾」或「蚤咬肾」；切面可见皮质增厚 | 双肾体积增大，色苍白 |
| 光镜 | 肾小球体积增大，内皮细胞和系膜细胞增生；中性粒细胞、单核细胞浸润 | 肾小球新月体（壁层上皮细胞增生 + 渗出的单核细胞） |
| 电镜 | 脏层上皮细胞和基膜之间高电子密度沉积物，呈驼峰状 | 新月体；Ⅱ型病例出现电子致密沉积物；均有基膜缺损断裂 |
| 免疫荧光 | IgG、IgM、C3 颗粒状沉积 | Ⅰ型线性荧光；Ⅱ型颗粒状荧光；Ⅲ型阴性 |
| 临床表现 | 急性肾炎综合征；抗「O」抗体阳性 | 急进性肾炎综合征；Goodpasture 综合征（抗 GBM 抗体对肺泡基膜有交叉反应时） |
| 转归 | 多见于儿童，儿童预后好，成人预后较差 | 预后较差 |
