# ❤ 四、伤寒（typhoid fever）（学长笔记）

【伤寒】：由伤寒杆菌引起的急性传染病，全身单核巨噬细胞系统细胞的增生为其病变特征，以回肠末端淋巴组织的病变最为突出。

临床主要表现为持续高热、相对缓脉、脾大、皮肤玫瑰疹及中性粒细胞和嗜酸性粒细胞减少等。

## 一、流行病学

| 项目 | 内容 |
| ---- | ---- |
| 传染源 | 伤寒患者或带菌者 |
| 传播途径 | 粪-口途径 |
| 病变部位 | 回肠末端集合和孤立淋巴小结 |

## 二、发病机制

感染菌量较大时，细菌得以进入小肠，穿过小肠黏膜上皮而侵入肠壁淋巴组织（尤其是回肠末端的集合淋巴小结、孤立淋巴小结）→被巨噬细胞吞噬，并在其中生长繁殖→经胸导管入血，菌血症。

- 血中的伤寒杆菌被全身单核巨噬细胞系统的细胞吞噬，并在其中大量繁殖，致肝、脾、淋巴结肿大
- 随着细菌繁殖和内毒素释放，再次入血→败血症、毒血症症状
- 胆囊中大量的伤寒杆菌随胆汁再次入肠→重复侵入已致敏的淋巴组织→<font color="#ff0000">强烈的超敏反应</font>→肠黏膜坏死、脱落→溃疡形成

## 三、病理改变

伤寒杆菌引起以全身单核巨噬细胞系统细胞的增生为特征的<font color="#ff0000">急性增生性炎</font>。

### （一）伤寒小结

- 增生活跃的巨噬细胞吞噬伤寒杆菌、红细胞、组织碎片，这种巨噬细胞称为伤寒细胞
- 伤寒细胞聚集成团，形成的小结节——伤寒小结（伤寒肉芽肿）
- 伤寒的特征性病变，具有<font color="#ff0000">病理诊断价值</font>

### （二）肠道病变（四期）

| 分期 | 时间 | 病理改变 |
| ---- | ---- | ---- |
| 髓样肿胀期 | 第 1 周 | 回肠下端淋巴组织略肿胀，隆起于黏膜表面，色灰红，质软，表面形似脑的沟回（集合淋巴小结肿胀最显著）；<br>镜下：巨噬细胞增生，伤寒肉芽肿形成 |
| 坏死期 | 第 2 周 | 肿胀的淋巴组织在中心部发生灶性坏死，并逐渐融合扩大，累及黏膜表层 |
| 溃疡期 | 第 3 周 | 坏死肠黏膜脱落后形成溃疡；<br>集合淋巴小结发生的溃疡，<font color="#ff0000">其长轴与肠的长轴平行</font>，孤立淋巴小结处的溃疡小而圆；<br>溃疡一般深及黏膜下层，严重者可深达肌层及浆膜层，可穿孔（穿孔率比肠结核、菌痢高） |
| 愈合期 | 第 4 周 | 溃疡处肉芽组织将其填平，溃疡边缘上皮再生覆盖→愈合 |

### （三）其他病变

- 其他部位的巨噬细胞增生→肠系膜淋巴结、肝、脾、骨髓肿大，镜检可见伤寒肉芽肿 + 灶性坏死
- 心肌纤维可有颗粒变形，甚至坏死
- 肾小管上皮细胞增生，也可发生颗粒变形
- 皮肤出现淡红色小丘疹——玫瑰疹
- 膈肌、腹直肌、股内收肌常发生凝固性坏死——蜡样变性
- 大多数患者胆囊无明显病变，但伤寒杆菌可在胆汁中大量繁殖→临床痊愈后，细菌仍可通过胆汁由肠道排出→<font color="#ff0000">重要传染源</font>
