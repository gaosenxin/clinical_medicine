# ❤ 五、细菌性痢疾（bacillary dysentery）（学长笔记）

【细菌性痢疾】：由痢疾杆菌引起的一种<font color="#ff0000">假膜性肠炎</font>；病变多局限于结肠，以大量纤维素渗出形成假膜为特征，假膜脱落伴有不规则浅表溃疡形成。

临床主要表现为腹痛、腹泻、里急后重、黏液脓血便。

## 一、流行病学

| 项目 | 内容 |
| ---- | ---- |
| 传染源 | 患者和带菌者 |
| 传播途径 | 粪-口途径（食物和饮水的污染有时可引起暴发流行） |
| 易感人群 | 儿童，其次是青壮年 |
| 病变部位 | 大肠，以<font color="#ff0000">乙状结肠和直肠</font>为重 |

## 二、病原体

痢疾杆菌，可分为四群：福氏、宋内、鲍氏、志贺。

## 三、发病机制

经口入胃的痢疾杆菌大部分被胃酸杀死，少部分进入肠道→在结肠内，侵入黏膜固有层繁殖→释放内毒素→肠黏膜溃疡。

- 内毒素吸收入血还可引起全身毒血症
- 志贺菌释放的外毒素是导致水样腹泻的主要因素

## 四、病理改变与临床病理联系

### （一）急性细菌性痢疾

| 阶段 | 病理改变 |
| ---- | ---- |
| 初期——急性卡他性炎 | 黏液分泌亢进，黏膜充血水肿，中性粒细胞、巨噬细胞浸润，可见点状出血 |
| →★假膜性炎 | 肉眼：糠皮状，一般呈灰白色，先出现于黏膜皱襞的顶部，随着病变扩大可融合成片<br>镜下：大量纤维素、坏死组织、中性粒细胞、红细胞、细菌 |
| →溃疡 | 假膜脱落，形成不规则的地图状溃疡（多表浅） |
| →愈合 | — |

临床表现：腹痛、腹泻、里急后重、黏液脓血便。

预后：经适当治疗大多痊愈，并发症如肠出血、肠穿孔少见，少数病例可转为慢性。

### （二）慢性细菌性痢疾

- 菌痢病程超过 2 个月以上者，多由急性菌痢转变而来，福氏菌居多
- 新旧病灶同时存在
- 息肉形成
- 瘢痕形成→肠壁不规则增厚、变硬，严重者可致肠腔狭窄

### （三）中毒性细菌性痢疾

- 起病急骤、严重的全身中毒症状，但肠道病变和症状轻微
- 多见于儿童，发病后数小时即可出现中毒性休克或呼吸衰竭而死亡
- 病原菌常为福氏／宋内菌
