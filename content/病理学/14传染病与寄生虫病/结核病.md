# ❤ 一、结核病（tuberculosis）（学长笔记）

【结核病】：由结核杆菌引起的一种慢性肉芽肿性炎症；可见于全身各器官，但以肺结核最常见；典型病变为结核结节形成，伴有不同程度的干酪样坏死。

## 一、病原体与流行病学

| 项目 | 内容 |
| ---- | ---- |
| 病原体 | 结核分枝杆菌，<font color="#ff0000">抗酸染色呈红色</font> |
| 对人致病类型 | 主要为人型和牛型 |
| 传染源 | 排菌的患者（特别是空洞型肺结核的患者） |
| 传播途径 | 呼吸道（最常见、最重要）、消化道、皮肤伤口 |

- 呼吸道——排菌的患者从呼吸道排出大量带菌微滴，吸入即可造成感染
- 消化道——食入带菌的食物，如含菌牛奶

## 二、发病机制

结核杆菌引起的细胞免疫和Ⅳ型超敏反应。

- 双刃剑：一方面杀灭细菌，另一方面导致组织破坏
- 到达肺泡的结核杆菌首先被巨噬细胞吞噬，但在有效的细胞免疫建立之前，巨噬细胞杀灭细菌的能力有限，而结核杆菌在细胞内繁殖，一方面引起局部炎症，另一方面可发生全身性血源性播散，成为以后肺外结核病发生的根源
- 结核病的超敏反应和免疫反应常同时发生并相伴出现；超敏反应出现，提示机体已获得免疫力，对病原菌有抵抗力，且同时伴随干酪样坏死
- 已致敏的个体，动员机体防御反应更快，但组织坏死也更明显

![[结核病-细胞免疫与IV型超敏反应.png|500]]

机体对结核杆菌感染所呈现的临床表现，取决于机体反应性的不同：

- 保护性反应为主：病灶局限，结核杆菌被杀灭
- 破坏性反应为主：表现为有结构和功能损害的结核病

## 三、基本病理变化

| 类型 | 病理特点 | 结局 |
| ---- | ---- | ---- |
| 以渗出为主的病变 | 浆液性或浆液纤维素性炎；<br>好发于肺、浆膜、滑膜、脑膜等处 | 吸收→痊愈；<br>转变为以增生为主或以坏死为主的病变 |
| 以增生为主的病变 | ★结核结节（结核肉芽肿）形成<br>中心：干酪样坏死<br>周围：上皮样细胞、Langhans 巨细胞、淋巴细胞、反应性增生的成纤维细胞<br>具有诊断价值 | 纤维化→瘢痕<br>溶解播散 |
| 以坏死为主的病变 | ★干酪样坏死<br>肉眼：因含脂质较多而呈淡黄色、质地较实、均匀细腻、状似奶酪<br>镜下：红染无结构的颗粒状物<br>具有诊断价值<br>干酪样坏死中大都会有一定量的结核杆菌→可成为结核病恶化进展的原因 | 小的坏死灶→纤维化→瘢痕<br>较大的坏死灶→纤维包裹、钙化<br>溶解播散 |

### （一）结核分枝杆菌和机体状态决定病变类型

![[结核病-病变类型与机体状态关系.png|500]]

| 条件 | 病变倾向 |
| ---- | ---- |
| 细菌数量少、毒力较低，人体的免疫力较强（同时变态反应较弱） | 倾向于修复，单核-巨噬细胞的增殖能力、限制病变的能力较强；感染之后可有少量的干酪样坏死，病变主要以增生为主，形成结核结节 |
| 结核病的早期／细菌数量多、毒力强，机体抵抗力低下或变态反应较强 | 无法较好地限制细菌，以渗出为主要表现 |
| 细菌数量多、毒力强、机体抵抗力低下或变态反应强 | 以坏死为主要表现 |

### （二）结核结节与相关细胞

- 吞噬有结核杆菌的巨噬细胞，体积增大，逐渐转变为上皮样细胞（淡伊红色，境界不清，活性更强，有利于吞噬、杀灭结核杆菌）
- 多个上皮样细胞融合→Langhans 巨细胞（核的数目有十几个到几十个不等，核排列在胞质周围呈马蹄形，或密集于胞体的一端）

## 四、基本病理变化的转归

取决于机体抵抗力和结核杆菌致病力之间的关系。

| 转归 | 内容 |
| ---- | ---- |
| 转向愈合 | 吸收消散——渗出性病变的主要愈合方式<br>纤维化——增生性病变、较小的坏死灶，最终形成瘢痕而愈合<br>纤维包裹、钙化——较大的坏死灶，<font color="#ff0000">钙化灶内常有少量结核杆菌残留</font>→机体抵抗力降低时仍可复发进展 |
| 转向恶化 | 浸润进展——病灶周围出现渗出性病变，范围不断扩大，并继发干酪样坏死<br>溶解播散——病情恶化时，干酪样坏死可液化，形成的半流体物质含大量结核杆菌，随自然管道播散到其他部位，形成新的结核病灶；除了经自然管道播散，还可经淋巴道、血道播散 |
