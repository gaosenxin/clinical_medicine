# ❤ 六、梅毒（syphilis）（学长笔记）

【梅毒】：由梅毒螺旋体引起的慢性传染病；本病特点是病程的长期性和潜匿性，病原体可侵犯任何器官，临床表现多样，也可隐匿多年而无症状。

## 一、病原体与流行病学

| 项目 | 内容 |
| ---- | ---- |
| 病原体 | 梅毒螺旋体 |
| 传染源 | <font color="#ff0000">梅毒患者为唯一的传染源</font> |
| 传播途径 | <font color="#ff0000">95% 以上通过性交传播</font>；少数因输血、医务人员不慎受染等直接接触传播（后天性梅毒）；还可经胎盘感染胎儿（先天性梅毒） |

## 二、基本病理改变

### （一）闭塞性动脉内膜炎和小血管周围炎

可见于各期梅毒。

- 闭塞性动脉内膜炎：小动脉内皮细胞及纤维细胞增生→管壁增厚、管腔狭窄
- 小血管周围炎：围管性单核细胞、淋巴细胞、浆细胞浸润；<font color="#ff0000">浆细胞恒定出现</font>是本病的特点之一

### （二）树胶样肿（gumma）

又称为梅毒瘤（syphiloma），是梅毒的特征性病变；最常见于皮肤、黏膜、肝、骨、睾丸，仅见于三期梅毒。

| 项目 | 内容 |
| ---- | ---- |
| 肉眼 | 灰白色，大小不一，质韧而有弹性，如树胶 |
| 镜下 | 中央——凝固性坏死（不如干酪样坏死彻底）<br>周围——富含淋巴细胞和浆细胞，而上皮样细胞和 Langhans 巨细胞较少，外围有致密的纤维组织<br>必有闭塞性动脉内膜炎和动脉周围炎 |
| 结局 | 后期，树胶样肿可被吸收、纤维化→器官变形，但绝少钙化 |

## 三、临床类型

后天性梅毒分为三期：

| 分期 | 病理改变 | 临床特点 |
| ---- | ---- | ---- |
| 第一期梅毒 | 侵入人体后 3 周左右；<br>硬性下疳；<br>镜下可见闭塞性动脉内膜炎、小血管周围炎 | 早期梅毒<br>传染性强 |
| 第二期梅毒 | 下疳发生后 7～8 周；<br>梅毒疹，全身非特异性淋巴结肿大；<br>镜下呈典型的血管周围炎改变，病灶内可见螺旋体 | 早期梅毒<br>传染性强 |
| 第三期梅毒 | 感染后 4～5 年，树胶肿、瘢痕形成；<br>病变累及内脏，特别是心血管、中枢神经系统 | 晚期梅毒<br>传染性小<br>又称为内脏梅毒 |

第三期梅毒的内脏受累：

- 侵犯主动脉→梅毒性主动脉炎、主动脉瓣关闭不全、梅毒性主动脉瘤（患者猝死的主要原因）等
  - 梅毒性主动脉炎：主动脉外膜滋养血管闭塞性内膜炎
  - 主动脉瘤：弹力纤维破坏所致
  - 主动脉瓣关闭不全：左心室肥大扩张
- 侵犯神经系统：主要累及中枢神经及脑脊髓膜，可导致麻痹性痴呆和脊髓痨

> [!note] 注
> 后天梅毒为成人梅毒主要的类型，小孩主要为先天梅毒。
>
> 第一期时会在男性的龟头、冠状沟，女性的会阴部出现皮损。
>
> 第二期时典型的血管周围炎非常明显，有大量慢性炎症细胞的浸润，单核巨噬细胞和淋巴细胞、浆细胞的浸润。
