# ❤ 七、尖锐湿疣与血吸虫病（学长笔记）

> [!warning] 源笔记残缺
> 本节在源笔记中仅存零星内容，以下按现有内容如实整理，未作补齐。

## 一、尖锐湿疣

| 项目 | 内容 |
| ---- | ---- |
| 病原体 | 人乳头瘤病毒（主要是 HPV6 和 HPV11 型） |
| 好发部位 | 男性：阴茎冠状沟、龟头、系带、尿道口或肛门附近<br>女性：阴蒂、阴唇、会阴部、肛周 |
| 传播途径 | 主要通过性传播；也可通过性接触途径间接感染 |

病理变化：

- 肉眼：呈淡红或暗红色，质软，表面凹凸不平的疣状颗粒；较大时呈菜花状生长
- 镜下：表皮角质层轻度增厚，几乎全为角化不全细胞，棘层肥厚，有乳头状瘤样增生；<font color="#ff0000">表皮浅层凹空细胞</font>出现有助于诊断
- 真皮层：毛细血管及淋巴管扩张，大量慢性炎细胞浸润
- 凹空细胞：胞质空泡状，细胞边缘常残存带状胞质；核增大居中，圆形、椭圆形或不规则形，染色深，可见双核或多核

> [!note] 注
> (1) 宫颈的经典的四个高危亚型：16、18、31、33。
>
> (2) HPV 感染人的鳞状上皮（宫颈、皮肤、阴道），被感染后鳞状上皮的增殖活性增强，导致鳞癌的发病率增高。宫颈癌中 80%～90% 都是鳞癌。
>
> (3) 鳞状上皮分为五层：最底下是基底细胞层，分化出来的细胞为棘细胞层，棘细胞老化到了半死半活的状态为颗粒细胞层，再往上就是透明细胞层，最上层为角质层。

## 二、血吸虫病

| 项目 | 内容 |
| ---- | ---- |
| 病原体 | 日本血吸虫（我国） |
| 病变部位 | 结肠、肝脏、脾脏、肺脏、脑 |

基本病理变化：

| 阶段 | 病变 |
| ---- | ---- |
| 尾蚴 | 尾蚴性皮炎；镜下见真皮充血、出血及水肿，起初有嗜中性及嗜酸性粒细胞浸润 |
| 童虫 | 引起血管炎和血管周围炎；以肺组织受损最为明显，表现为肺组织充血、水肿、点状出血及白细胞浸润 |
| 成虫 | 死亡虫体周围组织坏死，大量嗜酸性粒细胞浸润，形成嗜酸性脓肿 |
| 虫卵（急性虫卵结节） | 主要沉着于乙状结肠壁、直肠壁和肝；<br>镜下：中央 1～2 个成熟虫卵 + 放射状嗜酸性棒状体 + 周围无结构的颗粒状坏死物质及大量嗜酸性粒细胞浸润，状似脓肿，故称为嗜酸性脓肿 |
| 虫卵（慢性虫卵结节） | 病灶内巨噬细胞变为类上皮细胞和少量异物巨细胞，病灶周围有淋巴细胞浸润和肉芽组织增生，形态上似结核样肉芽肿，故称为<font color="#ff0000">假结核结节</font>，即慢性虫卵结节 |

> [!note] 生活史与致病
> 传染源：人。寄生在人的门脉系统中（肠道肠管中的静脉），成虫在此生存并产卵，随肠黏膜将卵排到肠腔，人排出的粪便就会有虫卵进入水中，在水中发育为毛蚴（此时有感染中间宿主钉螺的能力），在钉螺体内发育为尾蚴（此阶段具有感染人的能力），在水中能接触到人类皮肤的情况下就可以感染人，形成尾蚴性皮炎，进入血液循环系统中，首先进入到静脉，当血液回流到肺静脉的过程中发育为童虫，对肺的小静脉产生广泛性的损伤，通过血液循环系统进而到达各个脏器，在该过程中会发育成成虫，尤其爱寄生在肠管壁中的静脉系统中，产卵后卵会排到肠腔和肠管壁中，第一个病变就是结肠病变，结肠壁中会有虫卵和成虫，成虫致病性差，因为它的免疫原性低。主要的感染阶段是虫卵，它很难被清除，进而出现肉芽肿性炎，被包裹后形成肉芽肿，肠管壁慢慢出现瘢痕、纤维化、狭窄、癌变。虫卵也会随着血流向肝脏回流，肠系膜静脉向肝脏回流形成门脉，虫卵就沉积在门脉汇管区，形成汇管区周围的肉芽肿性炎和纤维化导致门脉高压症。门脉高压越早越重，脾大就越厉害，所以病人会出现巨脾的表现。
>
> 虫卵的致病性最强，原因：病变持续，很难被清除；免疫原性很强。

主要病变器官：

| 器官 | 病变 |
| ---- | ---- |
| 结肠 | 直肠、乙状结肠和降结肠为著<br>1. 急性期：引起急性虫卵结节形成，肠黏膜充血水肿及灰黄色细颗粒状扁平隆起的病灶，边缘不规则的浅表溃疡<br>2. 慢性期：肠壁增厚变硬、肠腔狭窄，甚至肠梗阻 |
| 肝脏 | 肝虫卵随门静脉血流到达肝汇管区，形成急、慢性虫卵结节，导致血吸虫肝硬化，但<font color="#ff0000">不形成明显假小叶</font>是其特点；肉眼：肝表面不平滑，可见粗大的结节状隆起 |
