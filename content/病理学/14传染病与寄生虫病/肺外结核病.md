# ❤ 三、肺外结核病（学长笔记）

## 一、肠结核病

多发生于<font color="#ff0000">回盲部</font>（该段淋巴组织最丰富）。

| 类型 | 内容 |
| ---- | ---- |
| 原发性 | 好发于小儿；<br>一般由饮用含结核杆菌的牛奶或乳制品而感染；<br>病理特点：肠原发综合征——肠的原发性结核性溃疡 + 结核性淋巴管炎 + 肠系膜淋巴结结核 |
| 继发性 | 播散途径：继发于活动性空洞型肺结核，由反复咽下含结核杆菌的痰液引起 |

继发性肠结核分两型：

- 溃疡型（较多见）
  - 结核杆菌侵入肠壁淋巴组织→结核结节→融合并发生干酪样坏死→破溃，形成溃疡
  - 典型的肠结核溃疡呈环形，<font color="#ff0000">其长轴与肠腔长轴垂直</font>；一般较浅
  - 偶尔会形成穿孔，穿孔率比伤寒低得多
  - 溃疡愈合→瘢痕形成，纤维收缩→导致肠腔狭窄
- 增生型
  - 肠壁大量结核性肉芽组织形成，纤维组织增生
  - 肠壁高度肥厚、肠腔狭窄

## 二、结核性腹膜炎

- 播散途径：腹腔内结核病灶直接蔓延，<font color="#ff0000">溃疡型肠结核病是最常见的原发病灶</font>
- 可分为干性和湿性两型，以混合型多见
  - 干性——大量纤维素性渗出物→机化→腹腔脏器粘连
  - 湿性——大量结核性渗出

## 三、结核性脑膜炎

- 儿童常见，主要经<font color="#ff0000">血道播散</font>
- 病变以脑底最为明显，（脑桥、视交叉等处的）蛛网膜下腔内有大量灰黄色浑浊的胶冻样渗出物积聚

## 四、肾结核病

- 常见于 20～40 岁男性，多为单侧性，结核杆菌多来自肺结核病的血道播散
- 病变大多起始于<font color="#ff0000">肾皮、髓质交界处／肾锥体乳头</font>，最初为局灶性结核病变→干酪样坏死→破坏肾乳头，破入肾盂→结核性空洞
- 病变继续扩大，形成多个空洞→肾仅剩一空壳，功能丧失
- 干酪性坏死物随尿下行→常感染输尿管、膀胱→输尿管结核、膀胱结核

### （一）输尿管结核

输尿管黏膜溃疡、结核肉芽肿形成→管壁增厚、管腔狭窄，甚至阻塞→肾盂积水、积脓。

### （二）膀胱结核

- 膀胱三角区最先受累形成溃疡，后累及整个膀胱
- 膀胱壁纤维化、肌层破坏→容积↓
- 若纤维组织增生影响到对侧输尿管口→管口狭窄，对侧健肾引流不畅→肾盂积水

> [!note] 注
> 膀胱结核也是一种炎症，症状：尿频、尿急、尿痛，普通的抗生素治疗不好，对结核分枝杆菌没有效果，所以病人是顽固的反复发作的膀胱炎的表现，长此以往，容易形成膀胱的纤维化，导致膀胱三角区的早期渗出，后期纤维化、挛缩，输尿管管口狭窄。
>
> 泌尿系结核可以通过生殖系统扩散，男性的泌尿道和生殖道是共用一条路的，女性的阴道和尿道是分开的，所以尿中的结核分枝杆菌可以通过输精管逆流形成附睾结核，50% 的人会继发附睾结核，属于生殖系统结核，是男性不育的原因之一。

## 五、脊椎结核

- 脊椎结核是最常见的骨结核病类型，<font color="#ff0000">腰椎</font>是脊柱最常受累的节段
- 后期淋巴结可以发生破溃，也可以形成冷脓肿破溃，但是很难愈合
