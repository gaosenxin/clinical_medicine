# 第十四章 传染病与寄生虫病（学长笔记）

【感染性疾病】（infectious disease）：指由病原微生物通过不同方式侵入，引起人体发生感染并出现临床症状的一组疾病。

感染性疾病病程久者多为慢性炎症，其病理形态可表现为肉芽肿性炎、坏死、化脓性炎、细胞增殖或纤维瘢痕形成；本章各病多以肉芽肿或坏死为特征性病变。

> [!abstract] 本章重点概念
> - [[结核病]]（抗酸染色、结核结节、干酪样坏死、细胞免疫与 Ⅳ 型超敏反应）
> - [[肺结核病]]（原发综合征、继发性肺结核各型）
> - [[肺外结核病]]（肠结核环形溃疡、结核性脑膜炎、肾结核空洞）
> - [[伤寒]]（伤寒小结、肠道四期病变）
> - [[细菌性痢疾]]（假膜性炎、地图状溃疡、里急后重）
> - [[梅毒]]（闭塞性动脉内膜炎、树胶样肿、三期分型）
> - [[尖锐湿疣与血吸虫病]]（凹空细胞、虫卵结节）

## 概述

### （一）病原微生物的传播途径

- 经皮肤入侵
- 经消化道入侵
- 经呼吸道入侵
- 经泌尿生殖道入侵
- 母婴垂直传播

### （二）宿主和病原微生物之间的相互作用

病原微生物的免疫逃逸：

- 抗原变异
- 逃逸巨噬细胞吞噬
- 逃逸 CD4 及 CD8 阳性 T 细胞的识别
- 通过「隐匿」感染逃避免疫监视

免疫反应所致的组织损伤：

> [!note] 不同病原的炎细胞反应
> 普通的细菌感染——早期是中性粒细胞作出反应，后期是单核-巨噬细胞、淋巴细胞作出反应；
> 慢性炎症以单核巨噬细胞和淋巴细胞为主；
> 对于结核分枝杆菌来说，以单核-巨噬细胞和淋巴细胞作出反应为主；
> 血吸虫病主要是嗜酸性粒细胞作出反应。

### （三）病原微生物的致病机制

| 病原 | 致病机制 |
| ---- | ---- |
| 病毒 | 直接杀伤作用；抗病毒免疫反应；感染细胞的转化 |
| 细菌 | 细菌黏附于宿主细胞；细菌毒素 |

### （四）感染性疾病的类型

| 类型 | 举例 |
| ---- | ---- |
| 化脓性炎 | 淋病——表面化脓 |
| 肉芽肿性炎 | 结核结节、伤寒小结、三期梅毒的树胶肿、血吸虫病的虫卵结节 |
| 以细胞增殖为主的炎症 | 见于某些病毒感染，以形成细胞内包涵体为其病变特征；<br>HPV 感染导致上皮细胞增生——尖锐湿疣 |
| 组织坏死 | HBV 感染——亚大片／大片肝坏死<br>溶组织性阿米巴——液化性坏死<br>产气荚膜杆菌——气性坏疽 |
| 慢性炎症及瘢痕形成 | 绝大多数慢性感染性疾病的最终结局<br>HBV 感染所致的慢性肝炎→肝硬化<br>感染性心外膜炎由于最终的纤维组织修复→慢性缩窄性心包炎 |

## 一、[[结核病]]
- 病原体与抗酸染色
- 细胞免疫与 Ⅳ 型超敏反应的双刃剑
- 基本病理变化：渗出、增生、坏死及其转归

## 二、[[肺结核病]]
- 原发性肺结核病：原发综合征
- 继发性肺结核病：局灶型、浸润型、慢性纤维空洞型、干酪性肺炎、结核球、结核性胸膜炎

## 三、[[肺外结核病]]
- 肠结核、结核性腹膜炎、结核性脑膜炎
- 肾结核、输尿管结核、膀胱结核、脊椎结核

## 四、[[伤寒]]
- 伤寒小结
- 肠道四期病变
- 其他器官病变

## 五、[[细菌性痢疾]]
- 假膜性肠炎
- 急性、慢性、中毒性菌痢

## 六、[[梅毒]]
- 闭塞性动脉内膜炎与小血管周围炎
- 树胶样肿
- 后天性梅毒三期

## 七、[[尖锐湿疣与血吸虫病]]
- 尖锐湿疣：HPV 与鳞状上皮
- 血吸虫病：虫卵结节与主要病变器官

# 总结

## 四种肠道疾病的鉴别

| 项目 | 肠伤寒 | 菌痢 | 肠阿米巴病 | 肠结核 |
| ---- | ---- | ---- | ---- | ---- |
| 病原体 | 伤寒杆菌 | 痢疾杆菌 | 阿米巴滋养体 | 结核杆菌 |
| 主要病变部位 | 回肠末端 | 乙状结肠、直肠 | 盲肠、升结肠 | 回盲部 |
| 病理特点 | 急性增生性炎 | 渗出性炎 | 变质坏死 | 变质坏死 |
| 溃疡特征 | 集合淋巴小结发生的溃疡其长轴与肠的长轴平行，易穿孔 | 表浅「地图样」溃疡，极少穿孔 | 口小底大的烧瓶状溃疡，边缘呈潜行性 | 溃疡与肠长轴垂直，环状狭窄，可穿孔 |

## 常见肉芽肿的形态特点

| 名称 | 镜下组成 | 常见疾病 |
| ---- | ---- | ---- |
| 结核结节 | 干酪样坏死 + 上皮样细胞及 Langhans 巨细胞 + 淋巴细胞及增生的纤维母细胞 | 继发性结核 |
| 慢性虫卵结节 | 类上皮细胞和少量异物巨细胞，病灶周围有淋巴细胞浸润和肉芽组织增生 | 血吸虫病 |
| 树胶样肿 | 中央为凝固性坏死（不彻底），外周淋巴细胞和浆细胞多，周围上皮样细胞和朗罕斯巨细胞较少，外围有致密的纤维组织 | 晚期梅毒 |
| 风湿小结 | Aschoff 细胞 + 纤维素坏死 + 淋巴细胞、浆细胞 | 风湿病 |
| 硅结节 | 同心圆状或漩涡状排列的胶原纤维（可发生玻璃样变） | 肺硅沉着症 |
| 伤寒小结 | 伤寒细胞聚集而成 | 伤寒 |
