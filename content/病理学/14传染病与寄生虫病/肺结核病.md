# ❤ 二、肺结核病（学长笔记）

肺结核病是结核病中最常见的类型。因初次感染和再次感染的不同，病变的发生发展可呈现出不同的特点，分为原发性肺结核病、继发性肺结核病两类。

## 一、原发性与继发性肺结核的比较

| 项目 | 原发性肺结核 | 继发性肺结核 |
| ---- | ---- | ---- |
| 定义 | 初次感染结核杆菌引起的肺结核病 | 再次感染结核杆菌引起的肺结核病 |
| 好发人群 | 儿童 | 成人 |
| 对结核杆菌的免疫力或致敏性 | 无 | 有 |
| 发病机制 | 初次接触结核杆菌，免疫反应不强烈 | 强烈变态反应，坏死及肉芽肿常见 |
| 好发部位 | 上叶下部或下叶上部近胸膜处 | 肺尖部 |
| 病变性质 | 渗出、坏死为主 | 肉芽肿形成、坏死 |
| 病理改变 | ★<font color="#ff0000">原发综合征</font>：肺的原发病灶 + 淋巴管炎 + 肺门淋巴结结核 | 病变多样，新旧病变共存，根据患者免疫力、细菌致病力的不同而多样化 |
| X 线 | 哑铃状阴影 | 多样化 |
| 播散方式 | 淋巴道或血道为主 | 支气管为主 |
| 临床表现 | 起病隐匿，95% 可自愈；<br>少数营养不良／同时患有其他传染病的患儿→病灶恶化、干酪样坏死、空洞形成；有的甚至→粟粒性肺结核病、全身性粟粒性结核病 | 临床症状明显，病程长，需要治疗 |

## 二、原发性肺结核病

- 原发病灶——灰白色炎性实变灶，以结核性肉芽肿形成为特点
- 原发病灶的细菌经淋巴管引流到肺门淋巴结，引起淋巴管炎、淋巴结结核
- 三者合称原发综合征，X 线上表现为哑铃状阴影

## 三、继发性肺结核病

在继发性肺结核中，若细菌量少、毒力小，以增生为主要表现，以结核结节收场；如果细菌量多、毒力大、免疫功能低下，以渗出为主，表现为浸润性肺结核或干酪样肺炎；如果机体免疫反应过度，会产生大量的干酪样坏死。

### （一）局灶型肺结核

| 项目 | 内容 |
| ---- | ---- |
| 好发部位 | 肺尖 |
| 病理改变 | X 线示肺尖部有单个或多个结节状病灶，直径 0.5～1 cm；<br>镜下病变以增生为主，中央为干酪样坏死 |
| 临床特点 | 继发性结核病的早期病变；常无临床症状，属非活动性结核病 |

### （二）浸润型肺结核

| 项目 | 内容 |
| ---- | ---- |
| 好发部位 | 肺尖 |
| 病理改变 | X 线示锁骨下边缘模糊的云絮状阴影；<br>镜下病变以渗出为主，中央有干酪样坏死，病灶周围有炎症 |
| 临床特点 | 多由局灶型结核病发展而来；<br>★<font color="#ff0000">最常见的活动性、继发性肺结核</font>；<br>患者常有低热、疲乏、盗汗、咳嗽等症状；<br>病变继续发展：浸润进展，溶解播散 |

浸润型肺结核的进展：

- 局部可形成急性空洞，洞壁坏死层有大量结核分枝杆菌，经支气管播散可引起干酪性肺炎
- 急性空洞经久不愈→慢性纤维空洞型结核

### （三）干酪性肺炎

| 项目 | 内容 |
| ---- | ---- |
| 好发部位 | 全肺 |
| 病理改变 | 镜下为大片干酪样坏死灶，肺泡腔内有大量浆液纤维蛋白性渗出物 |
| 临床特点 | 由浸润性肺结核恶化进展而来，也可由急、慢性空洞内的细菌经支气管播散所致；病情危重 |

### （四）慢性纤维空洞型肺结核

| 项目 | 内容 |
| ---- | ---- |
| 好发部位 | 肺上叶 |
| 病理改变 | 肺内有一个或多个厚壁空洞，分三层：<br>内层——干酪样坏死物（含大量结核杆菌）<br>中层——结核性肉芽组织<br>外层——纤维结缔组织<br>同侧或对侧肺组织可见许多新旧不一、大小不等、病变类型不同的病灶，越往下越新鲜；后期肺组织纤维化，胸膜增厚 |
| 临床特点 | 病变空洞与支气管相通，成为新的传染源，故又称为<font color="#ff0000">开放型肺结核</font> |

慢性纤维空洞型肺结核的并发症与结局：

- 空洞壁的干酪样坏死侵蚀较大血管→大咯血→可因吸入大量血液而窒息死亡
- 经常排出含菌痰液→喉结核
- 咽下含菌痰液→肠结核
- 后期→肺动脉高压→肺心病
- 结局：
  - 较小的空洞：机化、收缩而闭塞
  - 大空洞：内壁坏死组织脱落，肉芽组织逐渐变为纤维瘢痕组织，由支气管上皮覆盖，此时空洞虽仍然存在，但已无菌，实际上已愈合，故称为开放型愈合

### （五）结核球（结核瘤）

| 项目 | 内容 |
| ---- | ---- |
| 好发部位 | 肺上叶 |
| 病理改变 | 孤立的有纤维包裹的境界分明的球形干酪样坏死灶，直径 2～5 cm，可为单个／多个 |
| 临床特点 | 由于纤维包膜的存在，抗结核药不易发挥作用，临床上多采取手术切除 |

### （六）结核性胸膜炎

| 项目 | 内容 |
| ---- | ---- |
| 好发部位 | 胸膜腔 |
| 病理改变 | 根据病变性质分为干性、湿性两种：<br>湿性——渗出为主，主要为浆液纤维素性炎<br>干性——增生性改变为主，胸腔积液少见 |
| 临床特点 | 湿性结核性胸膜炎：多见于年轻人，渗出液量少时可吸收；若纤维素较多，不易吸收→机化→胸膜增厚粘连<br>干性结核性胸膜炎：一般由肺膜下结核病灶直接蔓延到胸膜所致，一般通过纤维化而愈合 |

## 四、注

- <font color="#ff0000">慢性纤维空洞型肺结核病人必须隔离</font>（最主要的传染源，传染性最强）；浸润型肺结核病人必要时需隔离
- 浸润型肺结核经支气管急性地向下播散会形成干酪性肺炎
