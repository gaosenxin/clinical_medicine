# ❤ 病理学概念
- 病理学是研究疾病的科学
- 研究疾病时细胞、组织和器官的<u><font color="#ff0000">结构</font></u>（形态学）和<u><font color="#ff0000">功能</font></u>（分子病理学）的改变，解释疾病的<u><font color="#ff0000">病因、发病机制</font></u>和临床表现，提供疾病的病理诊断，为临床治疗提供直接依据。

# 病理学四个核心
1. 病因学 etiology  or cause
	遗传性 Genetic
	获得性 Acquired
2. 发病机制 Pathogenesis
	细胞 cellular 
	生物化学 biochemical 
	分子 molecular 
	免疫 immunologic
3. 病理改变 pathologic changes
	形态学改变 Morphologic changes（解剖病理）
	分子改变 Molecular changes  （分子病理）
    功能改变 Functional changes（病理生理学）
4. 临床表现和转归 Clinical manifestations and outcome

# 😊 病理学地位

- 研究疾病：病理学是医学基础科学和临床医学之间的桥梁，也是现代医学的科学基础。
- 诊断疾病：在临床实践中，病理学是诊断疾病的最重要的手段之一。因此，也是临床医学的重要学科之一
