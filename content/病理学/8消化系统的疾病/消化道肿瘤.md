# ❤ 八、消化道肿瘤

## ❤ （一）食管癌

【食管癌】（esophageal carcinoma）：由食管黏膜上皮或腺体发生的恶性肿瘤。

|                                      | 内容                                                                                                                                                                                                                                                                                   |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 病因                                   | 生活习惯（饮酒、吸烟、<font color="#ff0000">亚硝酸盐</font>、过热过硬）；慢性炎症(各种长期不愈的食管炎)；遗传因素                                                                                                                                                                                                             |
| 好发部位                                 | 三个生理狭窄，食管<font color="#ff0000">中段＞下段＞上段</font>                                                                                                                                                                                                                                       |
| 病理特点                                 | <font color="#ff0000">鳞状细胞癌（90%）</font>，<font color="#ff0000">腺癌</font>次之。腺鳞癌、黏液表皮样癌、腺样囊性癌、未分化癌（十版新增）等。腺癌大部分来自贲门，少部分来自食管黏膜下腺体。                                                                                                                                                                               |
| 早期                                   | 定义：病变局限，多为<font color="#ff0000">原位癌</font>或<font color="#ff0000">黏膜内癌，未侵犯肌层，无论是否存在淋巴结转移。</font><br>肉眼：病变处黏膜轻度糜烂或表面呈颗粒状、微小乳头状。                                                                                                                                                        |
| 中晚期                                  | 肉眼类型（括注临床提示）：<br>①<font color="#ff0000">髓质型（最常见）</font>：浸润性生长，累及食管全周或大部分，管壁增厚、管腔变小，切面质较软、色灰白，状似脑髓；<br>②<font color="#ff0000">蕈伞型</font>：扁圆形肿块突向食管腔，表面有浅溃疡、边缘外翻；<br>③<font color="#ff0000">溃疡型</font>：肿瘤表面有较深溃疡，深达肌层，底部凹凸不平（最容易引发胸骨后疼痛）；<br>④<font color="#ff0000">缩窄型</font>：癌组织质硬、有明显结缔组织增生并浸润食管全周，食管局部管壁呈环形狭窄（最早出现吞咽困难）。<br>镜下：<font color="#ff0000">90%以上为鳞状细胞癌</font>，腺癌少见（来自贲门） |
| 临床病理联系 | 早期，无明显浸润、无肿块形成 → 症状不明显，部分患者可出现轻微的胸骨后疼痛、烧灼感或哽咽感；中晚期，肿瘤不断浸润生长 → 管壁狭窄，患者吞咽困难 → 恶病质、全身衰竭。 |
| 扩散转移                                 | <font color="#ff0000">淋巴道转移常见</font>                                                                                                                                                                                                                                                 |
| [[食管疾病#😊 （二）Barrett 食管\|Barrett食管]] | 食管与胃交界的齿状线数厘米以上出现单层柱状上皮化生，<font color="#ff0000">鳞状上皮被柱状上皮取代</font>                                                                                                                                                                                                                   |

## ❤ （二）胃癌

【胃癌】（gastric carcinoma）：由胃黏膜上皮和腺上皮发生的恶性肿瘤。发病率与死亡率均居我国恶性肿瘤第三位；好发年龄 40～60 岁，男多于女；好发于胃窦小弯部。

胃癌主要发生自<font color="#ff0000">胃腺颈部和胃小凹底部的组织干细胞</font>；结肠型不完全化生可过渡为<font color="#ff0000">肠型胃癌</font>。

> [!warning] 早期胃癌定义的分歧
> 第 10 版教材的早期胃癌定义只到「癌组织浸润仅限于黏膜层或黏膜下层，无论有无淋巴结转移」，不含「无远处脏器转移」这一条。旧版/部分复习资料另有「无远处脏器转移（如肝）」的表述，本笔记按第 10 版处理。

|             | 内容                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 病因          | ①饮食与环境因素；<font color="#ff0000">亚硝基类化合物；幽门螺杆菌</font>；<br>②慢性胃疾病<font color="#ff0000">（癌前病</font>变）：<font color="#ff0000">萎缩性胃炎、胃腺瘤型息肉、胃溃疡伴有异型增生、胃粘膜大肠型上皮化生</font>                                                                                                                                                                                                                                                                                         |
| 好发部位        | <font color="#ff0000">胃窦部，特别是小弯侧</font>                                                                                                                                                                                                                                                                                                                                                                                                                  |
| 早期胃癌        | 定义：癌组织浸润<font color="#ff0000">仅限于黏膜层或黏膜下层，无论肿块大小，无论有无胃周淋巴结转移</font>。<br>①<font color="#ff0000">一点癌</font>：胃镜钳取活检确诊为癌，但手术切除标本未发现癌。<br>②<font color="#ff0000">微小癌</font>：直径小于0.5cm。<br>③<font color="#ff0000">小胃癌</font>：直径0.6～1.0cm。<br>肉眼类型：<br><font color="#ff0000">隆起型</font>：向外长<br><font color="#ff0000">表浅型</font>：浸润<br><font color="#ff0000">凹陷型（最多见）</font>：溃疡<br>镜下：腺癌（原位癌、高分化管状<font color="#ff0000">腺癌常见</font>）、其次为乳头状癌，未分化癌最少见 |
| 中晚期癌（进展期胃癌） | 定义：癌组织浸润<font color="#ff0000">超过黏膜下层或浸润胃壁全层</font>的胃癌<br>肉眼类型：<font color="#ff0000">息肉型（蕈伞型）</font>；<font color="#ff0000">溃疡型（最常见）</font>；<font color="#ff0000">浸润型（革囊胃）</font>；胶样癌（十版删除）<br>镜下：主要为<font color="#ff0000">管状腺癌</font>和<font color="#ff0000">黏液癌</font>（包括<font color="#ff0000">印戒细胞癌</font>）                                                                                                                                              |
| 扩散转移        | ①直接蔓延；②淋巴道转移：主要转移途径。胃的血供丰富，<font color="#ff0000">首先转移至幽门下胃小弯的局部淋巴结</font>，进一步转移至腹主动脉旁淋巴结、肝门或肠系膜根部淋巴结，晚期可经<font color="#ff0000">胸导管</font>转移至左锁骨上淋巴结（<font color="#ff0000">Virchow信号结</font>）；③<font color="#ff0000">血道转移</font>：常转移至肝脏；④种植转移：<font color="#ff0000">胃黏液癌（印戒细胞癌）</font>常在双侧卵巢形成转移性黏液癌，称为<font color="#ff0000">Krukenberg瘤</font>。                                                                                                                                                                                                                            |

### 附：良恶性溃疡的大体形态鉴别
| 特征 | 良性（胃溃疡） | 恶性（溃疡型胃癌） |
| ---- | ---- | ---- |
| 外形 | 圆、椭圆 | <font color="#ff0000">不规则或火山口状</font> |
| 大小 | ＜2cm | <font color="#ff0000">＞2cm</font> |
| 深度 | 较深 | 较浅 |
| 边缘 | 平整、不隆起 | 不规则、隆起 |
| 底部 | 平坦 | 凹凸不平 |
| 周围粘膜 | 皱襞向溃疡集中 | <font color="#ff0000">皱襞中断、增粗、呈结节状</font> |

## ❤ （三）结直肠癌

【结直肠癌】（colorectal carcinoma）：结直肠黏膜上皮和腺体发生的恶性肿瘤。全世界第三大常见恶性肿瘤，我国居第四位，城市高于农村。

| ------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 病因<br>（2遗传2息肉病2腺瘤2慢性炎）                                                                                                         | 饮食习惯：高蛋白高脂肪低纤维<br>遗传因素：<font color="#ff0000">家族腺瘤性息肉病（FAP）</font>、<font color="#ffff00">遗传性非息肉性大肠癌</font><br>伴肠粘膜增生的慢性肠疾病：<font color="#ffff00">增生性息肉病、幼年性息肉病</font>（有“病”会致癌）、肠息肉状腺瘤、绒毛状腺瘤、慢性血吸虫病、慢性溃疡性结肠炎 |
| 好发部位                                                                                                                           | <font color="#ff0000">直肠（50%）＞乙状（20%）＞盲＞升＞横＞降</font>                                                                                                                                                       |
| 病理特点                                                                                                                           | 肉眼：①隆起型：右侧多见，肿块。②<font color="#ff0000">溃疡型：最多见</font>。③浸润型：左侧多见，环状狭窄。④<font color="#ffff00">胶样型：预后差</font>。<br>镜下：腺癌（<font color="#ff0000">乳头状腺癌、管状腺癌最常见</font>、粘液腺癌、印戒细胞癌）、腺鳞癌、鳞癌。                        |
| 上皮内瘤变                                                                                                                          | 大肠肿瘤组织<font color="#ff0000">局限于粘膜层，不超过粘膜肌层</font>。<br>包括：高级别上皮内瘤变（上皮重度异型增生、原位癌）和粘膜内瘤变（粘膜内癌）。                                                                                                               |
| 扩散转移                                                                                                                           | 直接蔓延；<font color="#ff0000">淋巴道转移（主要）</font>：未穿透肠壁肌层时较少发生，一旦穿透肌层则转移率明显升高；血道转移（<font color="#ff0000">肝转移多见</font>）；种植性转移                                                                                                                 |

> [!note] 家族性腺瘤性息肉病（FAP）
> APC 基因突变，50 岁前 100% 发展为腺癌，一般需在 20 岁前行全结肠切除。
> 林奇综合征（Lynch syndrome）：错配修复基因突变导致的常染色体显性遗传病，患病率 1/1000～1/250；一生中结直肠癌风险约 80%、子宫内膜癌约 60%、卵巢癌约 15%。
