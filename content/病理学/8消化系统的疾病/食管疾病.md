# 😭 一、食管疾病

## 正常食管组织学

| ⁣‍⁣​‌‌​‌‌​‌​‌‌​‌‌​‌​‌‌‌​‌‌​​‌‌‌​​​‌​‌‌​​​‌‌​‌‌‌​‌‌‌​​‌‌​​​​​​‌‌​​‌​​‌‌​‌‌‌‌​​‌‌​‌‌​​‌‌‌‌​​‌​​‌‌​​​‌​‌‌‌​‌​​​‌‌‌​​​‌​‌‌​​‌‌​⁣‌⁣项目 | 内容 |
| --- | --- |
| 解剖 | 连接咽与胃的肌性管道，全长约 25～30 cm |
| 功能 | 通过蠕动输送食物，并作为屏障防止胃内容物反流 |
| 管壁分层 | 黏膜（鳞状上皮、固有层、黏膜肌）、黏膜下层（含黏液腺）、固有肌层、外膜 |
| Z 线 | 鳞状上皮与柱状上皮交界处（齿状线），判断 Barrett 食管的解剖标志 |

## 😭 （一）反流性食管炎

【反流性食管炎】（reflux esophagitis）：胃液反流导致的食管下段黏膜慢性炎症反应。

### 1. 病因与致病机制

| 项目 | 内容 |
| --- | --- |
| 病因 | ①胃液反流（胃食管反流病，GERD）；②进食刺激性食物；③长期胃置管；④细菌、真菌感染；⑤尿毒症；⑥放疗、化疗；⑦吞入腐蚀性或刺激性物质 |
| 易感因素 | 吸烟；腹内及胃内压增高（妊娠、腹水、肥胖）；胃排空延迟；糖尿病；酒精性神经病；贲门失弛缓；硬皮病；食管裂孔疝 |
| 流行病学 | 白人发病率高于其他人种，亚洲发病率逐渐增高 |

### 2. 病理改变

| 项目 | 内容 |
| --- | --- |
| 大体 | 轻者黏膜充血、水肿、出血；重者糜烂或溃疡。黏膜呈红色（充血、出血）或黄色（糜烂、渗出） |
| 镜下 | 大多仅见黏膜充血，严重时出现浅表糜烂 |
| 组织学特征 ① | <font color="#ff0000">嗜酸性粒细胞浸润</font>（可伴中性粒细胞，提示损伤较重），多局限于上皮下 1/3；严重时累及食管壁可导致环状纤维化并伴狭窄形成 |
| 组织学特征 ② | <font color="#ff0000">基底细胞增生</font>，可导致上皮钉突延长 |
| 组织学特征 ③ | <font color="#ff0000">固有层乳头延长</font> |

### 3. 临床特点

| 项目      | 内容                                                                                                                   |
| ------- | -------------------------------------------------------------------------------------------------------------------- |
| 症状      | <font color="#ff0000">胸骨后烧</font>灼感（heartburn）、<font color="#ff0000">反酸</font>（sour regurgitation）、胸痛、吞咽困难、出血（呕血、黑便） |
| 前提      | 多数人经历过短暂轻微的反流性病变，反流程度重时才出现症状                                                                                         |
| 严重时     | 瘢痕收缩可出现吞咽困难                                                                                                          |
| 特点      | <font color="#ff0000">临床症状严重程度与组织学改变程度不相关</font>                                                                     |
| 并发症高峰年龄 | 50～70 岁                                                                                                              |
| 最严重并发症  | 在 Barrett 食管基础上发生癌变                                                                                                  |

## 😊 （二）Barrett 食管

【Barrett 食管】：食管远端黏膜的鳞状上皮被化生的柱状上皮替代（有或无杯状细胞）。本质是慢性 GERD 的并发症，特征为食管鳞状黏膜内出现<font color="#ff0000">肠上皮化生</font>。

### 1. 病因与致病机制

| 项目 | 内容 |
| --- | --- |
| 机制 | 反流的胃酸诱导不耐酸的鳞状上皮增殖分化为耐酸耐酶的柱状上皮 |

### 2. 病理改变

| 项目 | 内容 |
| --- | --- |
| 大体 | 橘红色、天鹅绒样不规则病变，可见糜烂、溃疡和食管狭窄 |
| 胃镜下背景 | 灰白色正常食管黏膜 |
| 胃镜下形态 ① | 舌状：自食管胃交界向上延伸的舌状突起 |
| 胃镜下形态 ② | 补丁状、岛状：远端食管孤立斑片 |
| 胃镜下形态 ③ | 环状：不规则环行带推移鳞柱交界 |
| 镜下 | 黏膜由胃型或肠型上皮构成，可见柱状上皮和腺上皮（杯状细胞）；上皮内可见慢性炎浸润 |
| 癌前病变 | <font color="#ff0000">伴异型增生者</font> |

### 3. 临床特点

| 项目 | 内容 |
| --- | --- |
| 年龄 | 双峰分布（0～15 岁与 40～80 岁） |
| 症状 | 约 90% 无症状 |
| 腺癌风险 | 正常人群的 <font color="#ff0000">30～40 倍</font>；伴肠化者恶变风险更高，癌变率可达 <font color="#ff0000">10%</font> |
| 诊断 | 属癌前病变，宜胃镜 + 活检及早发现诊断 |

## （三）总结

| ⁣‍⁣​‌‌​‌‌​‌​‌‌​‌‌​‌​‌‌‌​‌‌​​‌‌‌​​​‌​‌‌​​​‌‌​‌‌‌​‌‌‌​‌‌​​​‌​​​‌‌​‌​‌​​‌‌‌​​​​‌‌‌​‌‌​​​‌‌​​‌​​‌‌​​​‌​​‌‌​​​‌​​‌‌​‌‌‌​​‌‌​​‌‌​⁣‌⁣项目 | 反流性食管炎 | Barrett 食管 |
| --- | --- | --- |
| 本质 | 胃液反流导致的食管下段黏膜慢性炎症 | 鳞状上皮被化生的柱状上皮替代 |
| 部位 | 食管下段 | 食管远端 |
| 镜下 | 嗜酸性粒细胞浸润、基底细胞增生、固有层乳头延长 | 柱状上皮和腺上皮（杯状细胞）、慢性炎浸润 |
| 意义 | 最严重并发症为癌变 | 癌前病变，腺癌风险 30～40 倍 |
