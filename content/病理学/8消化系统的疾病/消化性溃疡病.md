# ❤ 三、消化性溃疡病

【溃疡】（ulcer）：器官或组织<font color="#ff0000">表面</font>因细胞坏死、坏死组织脱落所形成的局限性缺损或凹陷，病变需深达黏膜肌层、进入黏膜下层或更深。

【消化性溃疡病】（peptic ulcer disease, PUD）：发生在任何暴露于酸性胃液的消化道部位的慢性溃疡，以胃或十二指肠黏膜形成慢性溃疡为特征，多见于成人，反复发作、呈慢性经过。其发生与胃液的自我消化作用、HP 和神经内分泌功能失调有关。

## ❤ （一）好发部位与易感机制

- 好发部位：胃窦部胃小弯侧、十二指肠球部前/后壁。
- 胃小弯易感的力学解释：胃小弯是胃窦和胃体的交界处，肌肉由<font color="#ff0000">环行肌变为纵行肌</font>，肌肉的收缩方向不一致，会产生切割力；在切割力作用下，黏膜下的血管受到挤压容易缺血。

## ❤ （二）十二指肠溃疡特点

十二指肠溃疡多发生在十二指肠球部的前后壁，与胃溃疡病变相似，但溃疡一般较小，<font color="#ff0000">直径常小于1 cm</font>，溃疡较浅且较易愈合，<font color="#ff0000">几乎不癌变</font>。

## ❤ （三）镜下补充（溃疡底部四层，由内向外）

1. 炎性渗出层（纤维素、白细胞等）；
2. 坏死组织层；
3. 较新鲜的肉芽组织层；
4. 瘢痕层（瘢痕底部小动脉因炎症刺激常有增生性小动脉炎）。

> [!note] 增生性小动脉炎
> 溃疡处的小血管经常会出现增生性小动脉炎：慢性炎症→生长因子→刺激小血管壁增生，内皮细胞增生最活跃→管壁增厚、管腔狭窄→影响局部血供→溃疡不易愈合。

## ❤ （四）临床病理联系

- 周期性上腹部疼痛：胃酸刺激、平滑肌痉挛；胃溃疡<font color="#ff0000">餐后痛</font>，十二指肠溃疡<font color="#ff0000">饥饿痛</font>。
- 反酸、嗳气：幽门括约肌痉挛、幽门狭窄、胃逆蠕动。

## ❤ （五）愈合过程

- 渗出物、坏死组织吸收、排出；
- 已被破坏的肌层无法再生，由底部的肉芽组织增生形成瘢痕组织修复；
- 周围黏膜上皮再生覆盖溃疡面。

## ❤ （六）并发症

| 并发症 | 细节 |
| ---- | ---- |
| 出血 | <font color="#ff0000">最常见</font>。溃疡底部毛细血管破裂→溃疡面少量出血，大便潜血试验常阳性；溃疡底部大血管破裂→呕血、柏油样便，严重者失血性休克。 |
| 穿孔 | 十二指肠肠壁较薄→<font color="#ff0000">十二指肠溃疡更易穿孔</font>。穿孔后，胃肠内容物漏入腹腔→腹膜炎；胃后壁穿孔→漏入小网膜囊。 |
| 幽门狭窄 | 经久溃疡→大量瘢痕形成→瘢痕收缩→幽门狭窄→胃内容物潴留，继发胃扩张，反复呕吐，严重者可致<font color="#ff0000">碱中毒</font>。 |
| 癌变 | 多发生于长期胃溃疡患者，癌变来自溃疡边缘的黏膜上皮/腺体；十二指肠溃疡几乎不癌变。 |
