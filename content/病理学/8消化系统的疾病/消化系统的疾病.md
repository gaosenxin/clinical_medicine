# 第八章 消化系统疾病
[video](https://www.bilibili.com/video/BV1KhoeBJEh2?vd_source=e3f38a278c15424386552c69fd80fc60&spm_id_from=333.788.videopod.sections)
消化系统疾病可分为消化管疾病（炎症、溃疡、肿瘤）与肝胆胰疾病（病毒性肝炎、肝硬化、肝癌、胆囊炎胆石症、胰腺炎）两大类；消化管与肝脏的慢性炎症均与相应器官的癌变密切相关。

> [!abstract] 本章重点概念
> - [[胃炎]]（慢性萎缩性胃炎、肠上皮化生）
> - [[消化性溃疡病]]（四层结构、并发症）
> - [[病毒性肝炎]]（毛玻璃样肝细胞、点状/碎片状/桥接坏死）
> - [[肝硬化]]（假小叶、门脉高压症）
> - [[消化道肿瘤]]（革囊胃、Krukenberg 瘤、良恶性溃疡）
> - [[原发性肝癌]]（小肝癌、AFP）

# 总结
| 名称 | 内容 |
| ---- | ---- |
| 早期肺癌 | <font color="#ff0000">中央型早期肺癌</font>：发生于段支气管以上的大支气管，管壁内生长，<font color="#ff0000">无局部淋巴结转移</font><br><font color="#ff0000">周围型早期肺癌</font>：发生于小支气管，肿块直径＜2cm，<font color="#ff0000">无局部淋巴结转移</font>。 |
| 隐性肺癌 | 指肺内无明显肿块，影像学检查阴性而痰细胞学检查癌细胞阳性，手术切除标本经病理学证实为<font color="#ff0000">支气管黏膜原位癌或早期浸润癌</font>，而无淋巴结转移。 |
| 小肝癌 | 三套标准并存，注意区分版本：<br>国际外科标准：直径＞2cm 但≤5cm 的肝癌；单个癌结节＜3cm；<br>九版之前病理学标准：单个癌结节最大直径＜3cm，或两个癌结节合计最大直径＜3cm；<br>十版标准：单个癌结节最大直径＜5cm，或≤3 个病灶其中最大直径≤3cm。 |
| 早期肝癌 | 强调无血管侵犯与肝内转移（与小肝癌的体积标准不同，二者不可混用）。 |
| 早期食管癌 | 病变局限，未侵犯肌层，无论是否存在淋巴结转移，多为原位癌或黏膜内癌。 |
| 早期胃癌 | 是指局限于黏膜或黏膜下层的癌，无论有无淋巴结转移。 |
| 微小胃癌 | <font color="#ff0000">直径＜0.5cm的胃癌。</font> |
| 小胃癌 | 直径0.6-1.0cm的胃癌；指癌灶直径＜1.0cm的胃癌。 |
| 进展期胃癌 | 指癌组织浸润超过黏膜下层的胃癌。 |
| 宫颈上皮内瘤变 | 宫颈上皮异型增生 + 原位癌。 |
| 胃肠间质瘤 | 起源于胃肠道间叶组织；好发年龄为 50 岁以上，儿童罕见。 |
