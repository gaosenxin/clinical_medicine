# 😭 十、胆囊炎胆石症与胰腺炎

## 😭 （一）胆囊炎

【胆囊炎】（cholecystitis）：细菌引起，有胆汁淤滞为基础。

## 😭 （二）胆石症

【胆石症】（cholelithiasis）：发生于胆囊内的结石。

- 临床表现：黄（黄疸）、热（发热）、痛；
- 病因：胆汁的某些成分析出（胆红素钙、胆固醇结晶）凝集形成；
- 胆石的种类：①色素性：沙粒状、泥沙样；②胆固醇性：可发生于表面，多单个体积较大。

## 😊 （三）胰腺炎

【胰腺炎】（pancreatitis）：胰腺酶异常激活导致的胰腺自我消化造成的胰腺炎性疾病。

### 附：急性出血性胰腺炎的并发症

1. 休克：剧痛或大量体液丢失导致，可造成肾衰；
2. 腹膜炎：胰液外溢导致，疼痛剧烈并放射；
3. 酶改变：淀粉酶、脂酶外溢，可随尿排出；
4. 血清离子改变：钙（胰岛 A 细胞受刺激释放胰高血糖素导致甲状腺分泌降钙素）、钾钠（持续呕吐）水平降低。

## （四）😭胰腺癌

| 项目 | 内容 |
| ---- | ---- |
| 好发人群 | 多为50岁以上，男多于女 |
| 病因机制 | 吸烟可使风险增加，<font color="#ff0000">约90%的患者出现KRAS基因点突变</font>，也可有CMYC过度表达和TP53基因突变。 |
