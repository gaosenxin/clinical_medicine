# ❤ 九、原发性肝癌

【原发性肝癌】：原发于<font color="#ff0000">肝细胞</font>或<font color="#ff0000">肝内胆管上皮细胞</font>的恶性肿瘤。
## VS转移性的肝癌
[[肿瘤的生长和扩散#❤ 2. 血行转移（hematogenous metastasis）|图片]]

| ⁣‍⁣​‌‌​‌‌​‌​‌‌​‌‌​‌​‌‌‌​‌‌‌​‌‌​​‌‌​​‌‌‌​​‌‌​‌‌​‌​‌​​‌‌​​‌‌​​‌‌​​‌​‌​‌‌‌​‌‌‌​​‌‌​​‌​​‌‌​​‌​​​​‌‌​‌‌​​‌‌‌‌​‌​​‌‌​‌​‌​​‌‌‌‌​‌​⁣‌⁣特征 | 原发性肝癌（以HCC为例）           | 转移性肝癌                     |
| -------------------------------------------------------------------------------------------------------------------------------- | ----------------------- | ------------------------- |
| 背景肝脏                                                                                                                             | 常伴肝硬化（病毒性、酒精性等），质地硬、结节状 | 通常正常（除非合并其他肝病），质地软        |
| 肿瘤数目                                                                                                                             | 可为单发，但多结节型常见            | 多发性更典型，散布于全肝              |
| 切面特征                                                                                                                             | 灰黄/灰绿色，质软、易出血坏死         | 多样，常保留原发癌特征（如肠癌转移的“坏死脐凹”） |
| 血管侵犯                                                                                                                             | 门静脉癌栓常见（HCC特征性）         | 少见，若出现多为肝静脉受累             |

> [!note] 转移性肝癌的特点
> 多发结节、大小不一呈分批性、中央坏死形成癌脐。

> [!warning] 早期肝癌 ≠ 小肝癌
> 小肝癌强调的是体积标准（见下），早期肝癌强调的是<font color="#ff0000">无血管侵犯与肝内转移</font>。两者判断标准不同，不能混用。

> [!note] 小肝癌的三套标准（按版本区分）
> - 国际外科标准：直径＞2cm 但≤5cm 的肝癌；单个癌结节＜3cm。
> - 九版之前病理学标准：单个癌结节最大直径＜3cm，或两个癌结节合计最大直径＜3cm。
> - 十版标准：单个癌结节最大直径＜5cm，或≤3 个病灶其中最大直径≤3cm（即单结节型/小肝癌的米兰标准）。

| ❤肝细胞癌（十版）                                                                                                                           | 肉眼：<br>①<font color="#ffff00"><u>单结节型</u></font>：小肝癌，米兰标准，单个癌结节最大直径＜5cm，或≤3个病灶其中最大直径≤3cm；<br>②<font color="#ffff00"><u>多结节型</u></font>：<font color="#ff0000">一个界限较清，周围卫星结节</font>；<font color="#ff0000">最常见，通常合并肝硬化</font>；<br>③<font color="#ffff00"><u>弥漫型</u></font>：弥散于肝内，结节不明显，形态易与肝硬化混淆；<br>④<font color="#ffff00"><u>巨块型</u></font>：<font color="#ff0000">右叶多见</font>，体积巨大，<font color="#ff0000">直径多＞10cm</font>，中心常有出血、坏死，周围常有卫星状癌结节，不合并或仅合并轻度肝硬化。<br><br>镜下：分化高者癌细胞类似于肝细胞，分泌胆汁，<font color="#ff0000">血管多（似肝血窦），间质少</font>。分化低者异型性明显，癌细胞大小不一，形态各异。 |
| 胆管细胞癌（十版）                                                                                                                           | 一般与肝硬化和HBV或HCV感染无关<br>肉眼：块状型、管周浸润型和管内生长型<br>镜下：<font color="#ff0000">腺癌最为常见</font>，癌细胞呈腺管状排列，可分泌黏液，癌组织<font color="#ff0000">间质较多</font>。                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ❤转移扩散                                                                                                                               | ①易<font color="#ff0000">肝内直接蔓延</font>：沿门静脉分支播散 → 肝内多处转移结节；②淋巴道转移；③<font color="#ff0000">血道转移</font>：晚期可转移至<font color="#ff0000">肺、肾上腺、脑、肾</font>等处；④种植性转移。                                                                                                                                                                                                                                                                                                                                                                                                 |
| ❤预后                                                                                                                                 | 起病隐匿，预后不佳。高危人群（慢性肝炎、家族性、乙肝表面抗原阳性）需定期检查（肝功能、甲胎蛋白 AFP、B 超）。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
