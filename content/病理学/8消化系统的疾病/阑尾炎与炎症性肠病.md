# 😊 四、阑尾炎与炎症性肠病

## 😊 （一）阑尾炎

消化系统常见疾病，临床主要表现为<font color="#ff0000">转移性右下腹痛</font>、呕吐伴有体温升高及末梢血中性粒细胞升高。根据病程常分为急性和慢性两类。

### 1. 病因和发病机制

<font color="#ff0000">细菌感染和阑尾腔的阻塞</font>为发病的两个主要因素。

- 阑尾炎因细菌感染引起，但无特定的病原菌。
- 有 50%～80% 的阑尾炎病例伴有阑尾腔阻塞。
- 阑尾腔可因<font color="#ff0000">粪石、寄生虫</font>等造成机械性阻塞；也可因各种刺激引起阑尾挛缩，致使阑尾壁血液循环障碍，造成黏膜损害，有利于细菌感染而引起阑尾炎。

补充：

- 慢性阑尾炎多由急性阑尾炎转变而来，也可开始就呈慢性经过。
- 急性阑尾炎经外科治疗预后良好；少数因治疗不及时或机体抵抗力过低出现并发症或转为慢性。
- 并发症路径：穿孔→急性弥漫性腹膜炎/阑尾周围脓肿；阑尾系膜静脉的血栓性静脉炎→细菌或脱落的含菌血栓循门静脉到达肝脏→肝脓肿；阑尾近端堵塞→远端高度膨胀形成囊肿，内容物为脓汁或黏液。

## 😊 （二）炎症性肠病

【炎症性肠病】（inflammatory bowel disease, IBD）：由不恰当的黏膜免疫激活所致的慢性疾病，包括溃疡性结肠炎与 Crohn 病。

### 1. 概述

| 项目 | 内容 |
| --- | --- |
| 流行病学 | 近年由「西方病」变为「全球病」；2019 年全球新发约 40.5 万例、患病约 600 万 |
| 发病机制 | 遗传易感个体对共生微生物群的免疫反应失调：已发现 200 多个 IBD 风险位点（NFKB1 与溃疡性结肠炎、NOD2 与 Crohn 病），约 70% 与其他免疫介导疾病共享；环境因素亦参与 |

### 2. 溃疡性结肠炎与 Crohn 病比较

| 项目 | 局限性肠炎（regional enteritis），Crohn 病 | 溃疡型结肠炎（ulcerative colitis） |
| ---- | ---- | ---- |
| 部位与深度 | 全消化道（口腔至肛门），最常见回肠末端；<font color="#ff0000">节段性、跳跃性</font>；<font color="#ff0000">透壁性（全层）</font> | 结、直肠，自直肠（90%）向近端；<font color="#ff0000">连续性</font>；限黏膜及黏膜下层 |
| 好发年龄 | 青少年，20+ 岁高峰；肠外免疫病（游走性多关节炎、强直性脊柱炎） | — |
| 临床 | 腹痛、腹泻、黑便、腹部肿块、营养不良；穿孔、肠瘘、肠梗阻；慢性经过、常复发 | 反复血性黏液便、腹痛、体重下降；中毒性巨结肠（暴发型） |
| 大体 | 肠壁增厚变硬；<font color="#ff0000">铺路石样</font>皱襞；<font color="#ff0000">裂隙状（纵行）溃疡</font>，可穿孔成瘘；脂肪缠绕；纤维化狭窄、粘连成团 | 弥漫、连续；水肿充血出血，糜烂或浅表溃疡；<font color="#ff0000">假息肉</font>；肠壁厚度正常；黏膜萎缩 |
| 镜下 | <font color="#ff0000">裂隙样溃疡</font>（可深达黏膜下层、肌层）；<font color="#ff0000">透壁性炎</font>；<font color="#ff0000">非干酪性肉芽肿</font>（50%～70%，需与结核性肉芽肿鉴别） | <font color="#ff0000">隐窝结构扭曲</font>；<font color="#ff0000">隐窝炎与隐窝脓肿</font>；杯状细胞减少；隐窝减少、黏膜萎缩；异型增生可致腺癌（>10 年 0～3%，>20 年 12%～15%，>30 年 50%） |
| 预后 | 隐匿慢性经过，常复发 | 异型增生可伴肠癌 |

## 附一：感染性肠炎

分病毒性肠炎、细菌性肠炎、原虫感染、寄生虫病。常见病原：霍乱弧菌、弯曲杆菌、志贺菌、沙门菌、伤寒杆菌、耶尔森菌、大肠埃希菌等；原虫与寄生虫：溶组织阿米巴、蓝氏贾第鞭毛虫、隐孢子虫、蛔虫、类圆线虫、血吸虫。

【假膜性肠炎】（伪膜性结肠炎）：由艰难梭菌感染引起，属菌群失调性肠炎 / 抗生素性肠炎；各年龄段、各段肠道均可受累，长期使用广谱抗生素导致肠道菌群失调，主要表现为纤维蛋白渗出、黏膜坏死、假膜形成。

## 附二：急性出血性坏死性肠炎

【急性出血性坏死性肠炎】（acute hemorrhagic enteritis）：小肠急性出血性坏死性炎症为主要病变的儿科急症。
