# ❤ 六、肝硬化

|       | 内容                                                                                                                                                                                                     |
| ----- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 定义    | 各种病因引起的肝脏疾病的终末期病变；<font color="#ff0000">病变以慢性进行性、弥漫性的肝细胞变性坏死、肝内纤维组织增生和肝细胞结节状再生</font>为基本病理特征；广泛增生的纤维组织分割原来的肝小叶并包绕成大小不等的圆形或类圆形的肝细胞团形成<font color="#ff0000">假小叶</font>，进而引起肝小叶结构及血液循环途径逐渐被改建。            |
| 病因    | 病毒性肝炎、慢性酒精中毒、胆汁淤积、药物及化学毒物、代谢障碍、营养障碍、其他（血吸虫虫卵反复在肝脏沉积）、原因不明                                                                                                                                              |
| ❤发病机制 | 肝小叶内网状支架塌陷后，再生的肝细胞不能沿原有支架排列，而形成不规则的<font color="#ff0000">再生肝细胞结节</font>。<br>广泛增生的胶原纤维可向肝小叶内伸展，<font color="#ff0000">分割肝小叶</font>；也可与肝小叶内的胶原纤维连接形成纤维间隔包绕原有的或再生的肝细胞团，<font color="#ff0000">形成假小叶</font>。 |

| -------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------- | ---------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 小结节性                                                                                                                       | <font color="#ff0000">轻型肝炎、慢性酒精中毒</font> | 结节大小相仿，直径一般均<font color="#ff0000">小于3mm</font>，<font color="#ff0000">纤维间隔较细</font>。            | 肉眼观：<font color="#ff0000">早期肝体积可正常或稍增大，晚期肝体积缩小</font>。<br>镜下：<br>■ <font color="#ff0000">假小叶</font>：肝细胞排列紊乱，可见变性、坏死及再生的肝细胞；<font color="#ff0000">中央静脉常缺如，偏位或两个以上</font>。<br> |

| 混合结节性                                                                                                                      | 重型肝炎或中毒性肝炎                               | 粗、细结节的<font color="#ff0000">含量大致相等</font>，为上述两型的混合型。                                           |                                                                                                                                                                              |

补充：
1. 酒精性肝硬化病理特点：肝细胞<font color="#ff0000">脂肪变性</font>常见；特征性的马洛里(Mallory)小体。
2. 胆汁淤积性肝硬化：肝脏<font color="#ff0000">深绿色或绿褐色</font>；肝细胞<font color="#ff0000">网状或羽毛状坏死</font>；既往为不全分割型。
3. 小结节性肝硬化可转化为大结节性或混合性。

## ❤ （二）门脉性、坏死后性、胆汁性三型对比

| 分型 | 门脉性肝硬化 | 坏死后性肝硬化 | 胆汁性肝硬化 |
| ---- | ---- | ---- | ---- |
| 病因 | 轻型肝炎、慢性酒精中毒、营养不良、有毒物质的损伤作用 | 重型肝炎、中毒性肝炎 | 自身免疫病、胆道梗阻 |
| 肉眼 | 早、中期：体积正常或稍大，质地稍硬；后期：体积缩小，重量减轻，质地硬。表面及切面可见弥漫性分布的小结节，大小相近，直径 < 1 cm，呈黄褐色（脂肪变）或黄绿色（淤胆），有纤维包绕 | 肝脏不对称缩小<font color="#ff0000">（以左叶为甚）</font>，重量减轻，质地变硬；表面有较大且大小不等的结节，直径最大可达 6 cm，呈黄绿或黄褐色，由较宽的纤维包绕 | 肝脏深绿色或绿褐色（不全分隔型） |
| 镜下 | 假小叶：纤维分割导致小叶内中央静脉缺如、偏位或两个以上；再生肝细胞结节，结构紊乱 | 假小叶，假小叶形态大小不一；纤维间隔宽，厚薄不均 | 肝细胞网状或羽毛状坏死、纤维组织不完全分割小叶 |

## ❤ （三）门脉高压症

【门脉高压症】：门静脉压力升高后患者出现的一系列症状和体征。

### 1. 病因
1. 窦性阻塞：血窦闭塞或窦周纤维化，循环受阻；
2. 窦后性阻塞：假小叶压迫小叶下静脉，流出受阻；
3. 窦前性阻塞：门静脉和肝动脉在汇入血窦之前出现异常吻合，高压力动脉血进入门静脉。

### 2. 表现
1. 淤血性脾大：可形成糖衣脾；导致脾功能亢进，单核吞噬细胞破坏血细胞形成含铁结节；伴血液在各器官淤滞可导致机体贫血，部分可见含铁结节；
2. 腹水形成：淡黄色的漏出液，形成机制包括：
	1. 门静脉压力升高导致毛细血管静水压升高；
	2. 蛋白质合成能力下降导致毛细血管胶渗压下降；
	3. 降解醛固酮、抗利尿激素等物质的能力下降导致水钠潴留；
	4. 肝淋巴回流障碍；
3. 侧支循环形成：
	1. 经胃冠状静脉、食管静脉丛、奇静脉汇入上腔静脉；胃底、食管下段静脉曲张，进食粗糙食物时可导致消化道大出血，为常见死因；
	2. 经肠系膜下静脉、直肠静脉丛、髂静脉汇入下腔静脉；直肠静脉丛曲张成痔核，可致便血；
	3. 经附脐静脉、脐周静脉网、胸腹壁静脉汇入上下腔静脉；脐周静脉网曲张，形成「海蛇头」；
4. 胃肠淤血水肿：腹胀、食欲减退。

## ❤ （四）肝功能衰竭

肝细胞长期受损导致，可表现为：

1. 蛋白质合成障碍：低蛋白血症，白蛋白降低；
2. 凝血因子合成障碍：出血倾向；
3. 胆色素代谢障碍：与黄疸出现有关；
4. 雌激素灭活障碍：蜘蛛痣、肝掌、男性乳房发育睾丸萎缩、女性月经不调；
5. 肝性脑病：肝功能极度衰竭，重要死因；
6. <font color="#ff0000">肝肾综合征</font>：与肝性脑病并列，为重要死因之一。
