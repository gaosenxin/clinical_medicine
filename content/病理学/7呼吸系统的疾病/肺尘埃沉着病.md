# 😭 三、肺尘埃沉着病

## 😭 （一）肺硅沉着病

【肺硅沉着病】（silicosis）：长期吸入含游离二氧化硅粉尘、沉着于肺组织引起的一种职业病。

| 项目   | 内容                                                                                                                                                                                                                                  |
| ---- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 病因   | SiO₂，&lt;5μm，<font color="#ff0000">1-2μm颗粒致病力最强</font>                                                                                                                                                                              |
| 发病机制 | SiO₂+H₂O→硅酸→巨噬细胞吞噬→巨噬细胞自溶→慢性炎症→肺纤维化<br>（巨噬细胞自溶后释放硅尘，循环往复）<br>即便患者脱离硅尘作业环境后，肺部疾病仍会继续发展                                                                                                                                                                           |
| 基本病变 | <font color="#ff0000">硅结节、肺组织弥漫纤维化</font>→感染，呼衰<br>硅结节属于异物性肉芽肿，有研究认为异常免疫反应也参与发病（血清 IgG、IgM、抗核抗体异常）                                                                                                                                                                                     |
| 病理特点 | 硅结节<br>肉眼：圆形或椭圆形，直径3-5mm结节，灰白色、质硬，<font color="#ff0000">砂砾感</font><br>镜下：细胞性硅结节（吞噬硅尘的巨噬细胞聚集而成）→纤维性硅结节：<font color="#ff0000">同心圆状或漩涡状排列的胶原纤维（可发生玻璃样变）</font>；融合性结节中心可因缺血缺氧发生变性、坏死和液化形成<font color="#ff0000">硅肺性空洞</font>；肺门淋巴结亦可见；还会有异常免疫球蛋白沉积<br>肺组织弥漫性纤维化：镜下为致密的玻璃样变胶原纤维，胸膜也可因弥漫性纤维化而广泛增厚 |
| 并发症  | <font color="#ff0000">硅肺肺结核</font>；肺部感染；阻塞性肺气肿、慢性肺源性心脏病                                                                                                                                                                             |

### 硅肺分期和病变特点

| 分期 | 病变特点 |
| --- | --- |
| Ⅰ期硅肺 | 肺门淋巴结肿大，散在硅结节生成（数量较少，主要分布于双肺中下叶近肺门处）及纤维化改变 |
| Ⅱ期硅肺 | 硅结节数量↑、体积↑，散在分布于双肺，仍以双肺中下叶近肺门处密度较高；纤维化较明显，范围不超过全肺 1/3 |
| Ⅲ期硅肺 | 硅结节密度↑，与肺纤维化融合成团块；弥漫性纤维化范围 <font color="#ff0000">&gt;1/3</font>；切开阻力大，有砂砾感，大团块病灶中央可见<font color="#ff0000">硅肺空洞</font> |

## 😭 （二）肺石棉沉着病

【肺石棉沉着病】（asbestosis）：石棉小体导致的肺间质弥漫性纤维化。

- 病变肺体积缩小变硬，呈蜂窝状；主要局限于双肺下部和胸膜下肺组织，除间质纤维化外尚可见胸膜脏、壁两层纤维性增厚；
- 镜下可见深棕色分节的石棉小体（有铁蛋白沉着的石棉纤维）；
- <font color="#ff0000">可明显致癌（恶性胸膜间皮瘤）</font>。
