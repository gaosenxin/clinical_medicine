# ❤ 一、肺炎

【肺炎】（pneumonia）：肺的<font color="#ff0000">急性渗出性</font>炎症，是肺血管系统对各种致炎因子产生的防御反应。
## 分类
| 分类   | 内容                                                                                                         |
| ---- | ---------------------------------------------------------------------------------------------------------- |
| 生物因素 | <font color="#ff0000">细菌性、病毒性、支原体性、</font>真菌性、寄生虫性。<br><font color="#ff0000">以细菌性肺炎最为常见，大约占肺炎的80%。</font>  |
| 理化因素 | 放射性肺炎、类脂性肺炎和吸入性肺炎或过敏性肺炎等。                                                                                  |
| 累及部位 | 肺泡性肺炎（实质性）：大叶性肺炎、小叶性肺炎、节段性肺炎。<font color="#ff0000">多细菌</font><br>间质性肺炎，<font color="#ff0000">多病毒支原体</font> |
| 病变性质 | 浆液性、纤维蛋白性、化脓性、出血性、干酪性及肉芽肿性肺炎等。                                                                             |
细菌性肺炎（最常见）的特点：
1. 可原发或继发；
2. 多为<font color="#ff0000">急性炎症</font>，表现为<font color="#ff0000">渗出</font>；
3. 内源性细菌（上呼吸道常驻菌）感染多见。

### ❤ （一）大叶性肺炎

【大叶性肺炎】（lobar pneumonia）：肺炎链球菌引起的累及肺大叶全部或大部的弥漫性<font color="#ff0000">纤维素性渗出</font>炎。

病原血清型：肺炎链球菌 <font color="#ff0000">1、2、3、7 型</font>多见，<font color="#ff0000">3 型毒力最强</font>。

#### 1. 临床表现
多见于（有上呼吸道感染史的）<font color="#ff0000">青壮年</font>，<font color="#ff0000">起病急</font>；主要症状为气急、发绀、胸闷、胸痛、咳嗽、<font color="#ff0000">咳铁锈色痰</font>，可有肺实变体征、寒战发热和外周白细胞增多。

铁锈色痰成因：红细胞在肺泡腔被巨噬细胞吞噬破坏，含铁血黄素随痰液排出。

#### 2. 病因和发病机制
1. 上呼吸道常驻菌（肺炎球菌等）在机体呼吸道防御力下降（醉酒、昏迷、麻醉）时侵入肺泡定植；
2. 其胞壁荚膜多糖引发机体变态反应，导致组织充血渗出；
3. 大量纤维素渗出物伴细菌通过肺泡间孔或呼吸细支气管蔓延，波及整个肺大叶。

#### 3. 病理变化

#### 4. 预后和并发症
具有自限性，2～4 周可痊愈，但可能发生以下并发症：
1. <font color="#ff0000">肺肉质变</font>（pulmonary carnification）：中性粒细胞渗出不足、蛋白水解酶不足时，纤维素被肉芽组织增生取代而机化，肺组织实变呈褐色肉样；
2. 胸膜增厚粘连：炎症累及胸膜导致局部胸膜纤维素性炎，机化后粘连增厚；
3. 肺脓肿及脓胸：病原菌毒力强大或伴化脓性细菌感染；
4. 败血症和脓毒败血症：细菌入血大量繁殖；
5. 感染性休克：重症病例，死亡率高。

### ❤ （二）小叶性肺炎/<font color="#ff0000">支气管肺炎</font>

【小叶性肺炎】（lobular pneumonia）：化脓性细菌引起的<font color="#ff0000">以细支气管为中心</font>、累及<font color="#ff0000">肺小叶</font>的<font color="#ff0000">化脓性</font>炎症。

#### 1. 临床表现
多见于<font color="#ff0000">儿童、体弱老人、久卧病床者</font>，通常为其他疾病的并发症。常表现为发热、咳嗽、咳痰（脓痰）；X 线见小片或斑块状模糊阴影；听诊可闻及湿啰音；病灶小，散布；预后差

#### 2. 病因和发病机制
口腔或上呼吸道的常驻菌中致病力较弱的细菌，在机体抵抗力下降（传染病、恶病质、营养不良；昏迷、脑病、尿毒症）时侵入无菌的细支气管至末梢支气管。

常与葡萄球菌、肺炎链球菌、链球菌、流感嗜血杆菌、肺炎克雷伯菌、铜绿假单胞菌、大肠埃希菌等中致病力较弱的菌群有关。

- 急性传染病：麻疹、百日咳、流感、白喉等；受寒、醉酒、全身麻醉 → 上呼吸道细菌下行
- 长期卧床、慢性心衰 → 肺下叶、背侧淤血水肿、易于细菌繁殖（坠积性肺炎）
- 昏迷者、脑病、尿毒症 → 咳嗽、吞咽反射↓、吸入分泌物或呕吐物伴发细菌感染（吸入性肺炎）
#### 3. 病理变化
- 大体：双侧肺表面和切面散在灰黄质实病灶，<font color="#ff0000">以下叶和背侧多见</font>，中央可见病变的细支气管横截面，周围有出血区；病变严重者病灶可相互融合甚至累及大叶，发展为<font color="#ff0000">融合性支气管肺炎</font>；
- 镜下：
	1. 早期：病变支气管黏膜充血，表面覆盖炎性渗出物，周围肺组织炎症反应不明显；
	2. 发展：a. 病变管腔内出现<font color="#ff0000">较多中性粒细胞、红细胞和脱落肺泡上皮</font>，肺组织充血、浆液渗出，病变肺泡支气管完全破坏，呈完全化脓性炎症反应；b. <font color="#ff0000">部分完好的肺泡过度扩张</font>（代偿性肺气肿）。

#### 4. 预后
及时治疗可痊愈；伴严重疾病者预后不良；并发症多且危险（呼吸功能不全、心力衰竭、脓毒血症、肺脓肿、脓胸）。

#### 1. 病毒性肺炎

【病毒性肺炎】（viral pneumonia）：呼吸道病毒感染向下蔓延所致的肺间质性炎症。

- 临床表现：流感、副流感病毒常为群体成人发病，腺病毒等常见于小儿发病。表现为发热、全身中毒症状；频繁咳嗽（干咳无痰）、气急、发绀；
- 病因和发病机制：呼吸道病毒感染（流感病毒最常见）向下蔓延所致；
- 病理变化：
	- 大体：不明显，可因充血水肿而轻度肿大；
	- 镜下：
		1. 早期：肺泡间隔变宽，内血管扩张充血，间质水肿，慢性炎细胞浸润；肺泡腔内无渗出物；
		2. 发展：肺泡腔内出现由浆液、少量纤维素、巨噬细胞混合成的渗出物；
		3. 特征性改变：
			- 透明膜：<font color="#ff0000">浆液性渗出物</font>浓缩成薄层红染膜状物贴附于肺泡腔内表面（流感病毒、冠状病毒、麻疹病毒、腺病毒）；
			- 多核巨细胞：<font color="#ff0000">肺泡和支气管上皮增生融合形成（麻疹性肺炎尤多）</font>；
			- 病毒包涵体：检见可诊断，位于上皮细胞和多核巨细胞内。可出现于核内（腺病毒、单纯疱疹病毒、巨细胞病毒），嗜碱性；胞质内（呼吸道合胞病毒），嗜酸性；或均可见（麻疹肺炎）。
- 预后：混合感染时病变可复杂而严重，病毒感染的病变特征易被掩盖。

#### 2. 支原体肺炎

肺炎支原体引起的间质性肺炎，多见于青少年和儿童，预后良好。

| 好发 | 青壮年 | 儿童、体弱老人、久卧病床者 | 成人（流感）或小儿（腺病毒等） | 儿童、青少年 | 孕妇、老年、免疫功能低下者 |
| 部位 | 单肺肺下叶 | 双侧肺散在，下叶和背侧多见 | 双肺弥漫 | 常累及一叶，下叶多见 | 单个或多个肺叶，可累及胸膜、肺外 |
| 特征 | 四期；铁锈色痰 | 以细支气管为中心；脓痰、湿啰音 | 肺泡腔可无渗出；透明膜、多核巨细胞、病毒包涵体 | 与病毒性肺炎相似但无包涵体；顽固剧烈干咳 | 起病急、病情重，常有消化系统及神经系统症状 |
| 预后 | 好 | 差 | 大多可治愈 | 良好 | 很差，死亡率高 |

## 附：成人呼吸窘迫综合征

| 项目 | 内容 |
| ---- | ---- |
| 定义 | 全身遭受创伤、感染及肺内严重疾患时出现的一种以<font color="#ff0000">进行性呼吸窘迫和低氧血症为特征</font>的急性呼吸窘迫综合症。 |
| 发病机制 | 严重损伤（严重全身感染、创伤、休克、肺直接损伤）→肺毛细血管受损→通透性↑→肺泡内、间质水肿，纤维素渗出；<font color="#ff0000">Ⅱ型肺泡上皮细胞受损→表面活性物质↓</font>→肺泡表面透明膜形成、肺萎陷；两者均致氧弥散障碍、通气/血流比例失调→低氧血症、呼吸窘迫 |
| 病理特点 | <font color="#ff0000">肺泡腔内大量蛋白质浆液</font><br>呼吸性细支气管、肺泡管、肺泡内表面<font color="#ff0000">透明膜</font>（血浆蛋白+坏死上皮细胞碎屑）形成 |
| 并发症 | 肺泡和肺间质弥漫性纤维化；患者常在病变基础上并发支气管肺炎而死亡 |
