# 😊 六、鼻咽癌与喉癌

## 😊 （一）鼻咽癌

【鼻咽癌】（nasopharyngeal carcinoma）：起源于<font color="#ff0000">鼻咽黏膜上皮</font>的恶性肿瘤。

| 项目   | 内容                                                                                                                                                          |
| ---- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 病因   | <font color="#ff0000">EB病毒</font>（大多数患者有 EB 病毒壳抗原的 IgA 抗体，具有一定诊断意义）、遗传因素、化学致癌物                                                                                                                |
| 好发部位 | 鼻咽<font color="#ff0000">顶部</font>最常见，其次是外侧壁和咽隐窝，前壁最少见                                                                                                             |
| 来源   | 鼻咽黏膜柱状上皮的<font color="#ff0000">储备细胞</font>（具备多向分化潜能）                                                                                                         |
| 病理特点 | 肉眼：早期局部黏膜粗糙或稍隆起；后期结节型（<font color="#ff0000">最常见</font>）、菜花型（其次）、黏膜下浸润型、溃疡型<br>镜下<br>▪ 鳞状细胞癌（多）：分化性鳞癌（多）——角化型（高分化）、非角化型（低分化，最常见，与 EBV 感染关系密切）；未分化性鳞癌——<font color="#ff0000">泡状核细胞癌</font>（癌细胞片状或不规则巢状分布；核大、空泡状，胞质丰富、合体状，对放疗敏感）；另一类癌细胞小、胞质少，弥漫分布，无明显巢状结构。<br>▪ 腺癌：少见，主要来自鼻咽黏膜柱状上皮，也可来自鼻咽部小腺体 |
| 扩散途径 | 直接蔓延、<font color="#ff0000">淋巴道转移</font>（早，同侧颈上深淋巴结，首发症状）、血道转移（晚） |

淋巴道转移的定位：首先转移至同侧颈上深淋巴结，患者胸锁乳突肌后缘上 1/3 与 2/3 交界处皮下出现<font color="#ff0000">无痛性结节</font>，常为首发症状。同侧转移为多，对侧极少发生，后期可双侧受累；若相邻淋巴结同时受累可融合成巨大肿块。血道转移晚。

## 😭 （二）喉癌

【喉癌】（laryngeal carcinoma）：喉部黏膜上皮来源的恶性肿瘤，很少转移。
