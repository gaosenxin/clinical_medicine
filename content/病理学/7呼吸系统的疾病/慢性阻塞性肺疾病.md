# ❤ 二、慢性阻塞性肺疾病
|     | 内容                                                                                                                                                                                                                                                      |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 概念  | COPD是一组慢性气道阻塞性疾病的统称，其共同特点是<font color="#ff0000">肺实质</font>与<font color="#ff0000">小气道</font>受损伤，导致慢性气道阻塞、呼气阻力增加以及肺功能不全。 |
| 分类  | ①<font color="#ff0000">慢性支气管炎</font>：慢性炎症，管壁纤维化，管腔阻塞；<br>②<font color="#ff0000">肺气肿</font>：末梢肺组织(呼吸细支气管、肺泡管、肺泡囊、肺泡) 因肺组织弹性减弱而过度充气，呈永久性扩张。<br><br><font color="#ff0000">支气管哮喘</font>：支气管痉挛；<br><font color="#ff0000">支气管扩张</font>：肺内小支气管管腔持久性扩张伴管壁纤维性增厚； |

## ❤ （一）慢性支气管炎　😊 （二）支气管扩张症

都属于<font color="#ff0000">慢性非特异性炎症</font>

|      | 慢性支气管炎                                                                                                                                                                                                                                          | 支气管扩张症                                                                                                                                                                                                       |
| ---- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 定义   | 支气管粘膜及周围组织的慢性<font color="#ff0000">非特异性炎</font>                                                                                                                                                                                                 | 小支气管管腔持久性扩张伴管壁纤维性增厚                                                                                                                                                                                          |
| 发病机制 | 病毒和<font color="#ff0000">细菌感染</font>、<font color="#ff0000">吸烟</font>、空气污染和过敏因素、机体内在因素                                                                                                                                                           | 支气管壁的炎症破坏及阻塞、支气管先天性及遗传性发育不全及异常                                                                                                                                                                               |
| 受累部位 | 较大的支气管→小支气管→COPD→肺气肿                                                                                                                                                                                                                            | 小支气管                                                                                                                                                                                                         |
| 病理特点 | <font color="#ff0000">变质</font>：纤毛柱状上皮变性、坏死脱落，杯状细胞增多，鳞状上皮<font color="#ff0000">化生</font>；平滑肌断裂、软骨变性、萎缩或骨化<br><font color="#ff0000">增生</font>：粘膜下腺体增生肥大；黏液腺化生<br><font color="#ff0000">渗出</font>：管壁充血水肿，<font color="#ff0000">淋巴细胞</font>、浆细胞浸润， | <font color="#ff0000">支气管呈圆柱状或囊状扩张，使肺呈蜂窝状；</font><br><font color="#ff0000">管腔内</font>常含有粘液脓性或<font color="#ff0000">脓性渗出物；</font><br>支气管壁呈慢性炎症；<br>管壁的平滑肌、弹力纤维和软骨遭受破坏和肉芽组织取代，<font color="#ff0000">纤维化</font> |
| 临床特点 | 咳嗽、咳痰，<font color="#ff0000">白色粘液泡沫状</font>；后期黏膜与腺体萎缩（慢性萎缩性气管炎），转为少痰、无痰                                                                                                                                                                                                      | 频发咳嗽、咳<font color="#ff0000">大量脓痰</font>，<font color="#ff0000">咯血</font>；胸闷、闭气，累及胸膜可有胸痛                                                                                                                                      |
| 并发症  | 支气管扩张；<font color="#ff0000">肺气肿；肺心病</font>                                                                                                                                                                                                      | <font color="#ff0000">肺脓肿、脓胸、肺动脉高压、肺心病</font>                                                                                                                                                                |

慢性支气管炎病原谱：
- 致病的主要病毒：鼻病毒、腺病毒、呼吸道合胞病毒；
- 导致急性发作的主要细菌：肺炎球菌、肺炎克雷伯杆菌、流感嗜血杆菌。

支气管扩张症继发病因：多继发于慢性支气管炎、麻疹及百日咳后的支气管肺炎、肺结核等。左肺下叶最常见。

镜下：支气管壁明显增厚，黏膜上皮增生伴鳞状上皮化生；黏膜下血管扩张充血，腺体、平滑肌、弹力纤维和软骨破坏、萎缩或消失，代之以肉芽组织或纤维组织；邻近肺组织纤维化，淋巴组织增生。

## 😊 （二）支气管哮喘

| 项目   | 内容                                                                                                                                                                                                                                                                                                          |
| ---- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 定义   | 简称哮喘，是一种由呼吸道过敏引起的<font color="#ff0000">以支气管可逆性发作性痉挛为特征</font>的慢性阻塞性炎性疾病。                                                                                                                                                                                                                                    |
| 发病机制 | 诱因：过敏原（花粉、尘埃、动物毛屑、真菌、药物、食品等），呼吸道感染，精神因素；Th2 细胞释放 IL-4、IL-5，IL-4 促 B 细胞产生 IgE 并使致敏肥大细胞与抗原反应引发哮喘，IL-5 激活嗜酸性粒细胞参与气道上皮损伤、平滑肌收缩、成纤维细胞增生及细胞外基质形成。                                                                                                                                                                                                         |
| 病理特点 | 肉眼：肺因<font color="#ff0000">过度充气而膨胀、柔软、疏松而有弹性</font>，<font color="#ff0000">支气管腔内有粘稠痰液和粘液栓</font>。<br>镜下：<br>①粘膜上皮局部脱落，基底膜显著增厚及玻璃样变，粘膜下水肿，粘液腺增生，杯状细胞增多、管壁平滑肌增生肥厚；<br>②管壁各层见<font color="#ff0000">嗜酸性粒细胞</font>、单核细胞、淋巴细胞和浆细胞浸润；<br>③管壁及粘液栓中可见<font color="#ff0000">嗜酸性粒细胞的崩解产物夏科-雷登（charcot-Leyden）结晶</font>。 |
| 临床特点 | 反复发作性喘息，带有哮鸣音的<font color="#ff0000">呼气性呼吸困难</font>，咳嗽或胸闷等症状                                                                                                                                                                                                                                                 |
| 并发症  | <font color="#ff0000">严重</font>病例可合并<font color="#ff0000">慢性支气管炎</font>，并导致肺气肿和慢性肺源性心脏病                                                                                                                                                                                                                     |

## ❤ （四）肺气肿

| 项目     | 内容                                                                                                                                                                                                                                                                                                                                  |
| ------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 定义     | 指<font color="#ff0000">末梢肺组织</font>（呼吸性细支气管、肺泡管、肺泡囊和肺泡）含气量过多伴肺泡间隔破坏，肺组织弹性减弱，导致肺体积膨大、通气功能降低的疾病状态。<br>                                                                                                                                                                                                                                |
| 发病机制   | <font color="#ff0000">阻塞性通气功能障碍</font>、呼吸性细支气管和肺泡壁弹性降低、<font color="#ff0000">α₁-抗胰蛋白酶水平降低</font>                                                                                                                                                                                                                                    |
| 分型     | ①肺泡性肺气肿（阻塞性肺气肿）：病变发生在肺腺泡内，常合并小气道阻塞性通气障碍<br>   腺泡中央型：腺泡中央的<font color="#ff0000">呼吸性细支气管呈囊状扩张</font>，肺泡管、肺泡囊扩张不明显；<font color="#ff0000">最常见</font>，多见于中老年吸烟者/慢支病史者<br>   全腺泡型：呼吸性细支气管、肺泡管、肺泡囊、肺泡弥漫性扩张，含气小囊腔布满肺腺泡内；多见于青壮年及先天性 α₁-抗胰蛋白酶缺乏者；肺泡间隔破坏严重时，气肿囊腔融合形成直径超过 1cm 的较大囊泡，称囊泡性肺气肿<br>   腺泡周围型：又称<font color="#ff0000">隔旁肺气肿</font>，多不合并 COPD；腺泡的呼吸性细支气管基本正常，仅肺泡管、肺泡囊扩张<br>②间质性肺气肿（不是末梢肺组织）：由肋骨骨折、胸壁穿刺伤、剧烈咳嗽等致细支气管或肺泡间隔破裂，气体进入肺间质，沿支气管血管周围间隙扩散至肺门、纵隔，形成串珠状气泡，进而形成皮下气肿<br>③其他类型肺气肿：<br>   瘢痕性肺气肿：肺组织瘢痕灶周围肺泡破裂融合形成的局限性肺气肿，位置、大小形态不一，又称不规则型肺气肿；<br>   肺大疱：气肿囊腔直径 >2cm 并破坏肺小叶间隔；位于肺膜下的肺大疱破裂可引起气胸；<br>   代偿性肺气肿：肺萎缩、肺叶切除、肺实变时代偿性过度充气，肺泡隔无破坏；<br>   老年性肺气肿：肺组织弹性回缩力减弱，肺泡隔无破坏。 |
| 病理特点 | 肉眼：肺显著膨大，边缘钝圆，色灰白，肺组织柔软而缺乏弹性，指压后压痕不易消退。<br>镜下：<br><font color="#ff0000">肺泡扩张，肺泡间隔变窄并断裂，相邻肺泡融合成较大的囊腔</font>；肺<font color="#ff0000">毛细血管床明显减少</font>，间质内肺小动脉内膜呈纤维性增厚；小细支气管可见慢性炎症改变。<br>终末细支气管远端气腔出现异常而持久的扩张，并伴有气腔壁的破坏，而<font color="#ff0000">无明显纤维化</font>                                                                                                        |
| 临床病理联系 | 咳嗽、咳痰；<font color="#ff0000">呼气性呼吸困难</font>；“桶状胸”；后期导致肺心病                                                                                                                                                                                                                                                                            |

## 肺气肿发病机制（酶学链）

- 病因：常继发于其他肺阻塞性疾病，最常见的是慢性支气管炎；吸烟、空气污染、尘肺也是常见原因。
- α₁-抗胰蛋白酶（α₁-AT）可抑制弹性蛋白酶等多种蛋白水解酶。
- 酶学链：慢性炎症使白细胞产生的氧自由基灭活 α₁-AT→弹性蛋白酶活性相对升高→破坏肺组织结构→肺泡回缩力下降、残气量增加；另有遗传性 α₁-AT 缺乏者。
- 长期慢性炎症破坏大量弹性纤维→呼吸性细支气管和肺泡回缩力减弱→残气量↑；慢支致小气道纤维化、管腔狭窄、黏液栓形成→排气不畅，残气量过多。

## 肺气肿与支气管扩张对比

| 项目 | 肺气肿 | 支气管扩张 |
| --- | --- | --- |
| 定义 | <font color="#ff0000">末梢肺组织</font>过度充气、肺泡间隔破坏 | 小支气管持久扩张伴管壁纤维增厚 |
| 部位 | 呼吸细支气管、肺泡管、肺泡囊、肺泡 | 小支气管 |
| 机制 | 气道阻塞、弹性降低、<font color="#ff0000">α₁-抗胰蛋白酶↓</font> | 炎症破坏及阻塞、先天发育异常 |
| 镜下 | 肺泡融合成囊腔，<font color="#ff0000">无明显纤维化</font> | 管壁破坏、<font color="#ff0000">纤维化</font>，管腔含脓性渗出物 |
| 临床 | <font color="#ff0000">呼气性呼吸困难</font>、桶状胸 | <font color="#ff0000">大量脓痰</font>、咯血 |
| 并发症 | 肺心病 | 肺脓肿、脓胸、肺心病 |
