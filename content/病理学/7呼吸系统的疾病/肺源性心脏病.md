# ❤ 四、慢性肺源性心脏病

| 项目     | 内容                                                                                                                                                                                                                                                 |
| ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 定义     | 慢性肺疾病、肺血管及胸廓的病变引起<font color="#ff0000">肺循环阻力增加，肺动脉压升高</font>而导致以右心室壁肥厚、心腔扩大甚或发生<font color="#ff0000">右心衰竭</font>的心脏病                                                                                                                               |
| 病因     | ①肺疾病：<font color="#ff0000">COPD 最常见</font>（又以慢性支气管炎并发阻塞性肺气肿最常见），其后依次为支气管哮喘、支气管扩张、肺尘埃沉着病、慢性纤维空洞型肺结核、肺间质纤维化<br>②胸廓运动障碍性疾病：脊柱侧弯<br>③肺血管疾病 |
| 发病机制   | 肺疾病→<font color="#ff0000">肺毛细血管床数量减少、小血管纤维化闭塞</font>→肺循环阻力升高；<br>缺氧→肺小动脉痉挛，并促发肺血管构型改建（无肌细动脉肌化、肌型小动脉中膜增生肥厚）→肺循环阻力↑，<font color="#ff0000">肺动脉压升高</font>。<br>胸廓运动障碍疾病→限制性通气障碍，或因肺部受压致肺血管扭曲、肺萎陷→肺循环阻力↑ |
| 病理特点   | 肺：<font color="#ff0000">肺无肌型细动脉肌化</font>、<font color="#ff0000">肌型小动脉中膜增厚</font>、<font color="#ff0000">毛细血管减少</font>；肺小动脉弹力纤维、胶原纤维增生，腔内血栓<br>心：肉眼：右心室壁肥厚，心腔扩张，心尖钝圆，肺动脉圆锥显著膨隆，乳头肌和肉柱显著增粗，室上嵴增厚，<font color="#ff0000">肺动脉瓣下 2cm 处右心室肌壁厚 ≥ 5mm</font>作为病理诊断肺心病的形态标准；<br>镜下：心肌细胞肥大、核大深染；缺氧导致<font color="#ff0000">心肌纤维萎缩、肌浆溶解、横纹消失</font>。 |
| 临床病理联系 | 呼吸功能不全：呼吸困难、发绀、气急；<br>右心衰竭：心悸、全身淤血、肝脾肿大、下肢水肿；严重者出现脑水肿、<font color="#ff0000">肺性脑病</font>，机制为缺氧、CO₂ 潴留、呼吸性酸中毒。 |
