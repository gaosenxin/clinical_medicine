# ❤ 三、肿瘤的命名与分类

## ❤ （一）命名的一般原则
- 良性肿瘤：在组织或细胞类型名称后加「瘤」（英文后缀 -oma）。如腺瘤（adenoma）、平滑肌瘤（leiomyoma）
- 恶性肿瘤：
	1. 癌（carcinoma）：上皮组织的恶性肿瘤，具有上皮分化特点。在上皮名称后加"癌"字。鳞状上皮的癌称鳞状细胞癌（squamous cell carcinoma），腺上皮称腺癌（adenocarcinoma），形态和免疫表型为癌但缺乏分化特征的称未分化癌（undifferentiated carcinoma）。
	2. 肉瘤（sarcoma）：间叶组织的恶性肿瘤，具有向纤维组织、肌肉、骨、脂肪、血管淋巴管、软骨分化的特点。在间叶组织名称后加"肉瘤"，亦有未分化肉瘤。
	3. 癌肉瘤（carcinosarcoma）：同时具有两种分化特征的恶性肿瘤

> [!important] 癌与癌症
> 病理学上，癌特指上皮组织的恶性肿瘤；平常所谓的「癌症」（cancer）泛指所有恶性肿瘤，包括癌、肉瘤和白血病等。

## 😊 （二）命名的特殊情况
|             | 良性                                            | 恶性                                              |
| ----------- | --------------------------------------------- | ----------------------------------------------- |
| "母细胞瘤"（-blastoma） | 骨母细胞瘤、软骨母细胞瘤、脂肪母细胞瘤、肌母细胞瘤 | <font color="#ff0000">神经母细胞瘤、髓母细胞瘤、肾母细胞瘤</font>、视网膜母细胞瘤、肝母细胞瘤 |
| "病"或"瘤"     | 神经鞘瘤、成熟性畸胎瘤、葡萄胎、脑膜瘤、间皮瘤（存在恶性间皮瘤）              | <font color="#ff0000">白血病、绿色瘤、多发性骨髓瘤</font>；精原细胞瘤、无性细胞瘤；Bowen 病、蕈样霉菌病 |
| 以人名命名       | ——                                            | Ewing 肉瘤、Hodgkin 淋巴瘤（霍奇金病）                      |
| "恶性"        |                                               | 恶性黑色素瘤、恶性畸胎瘤                                    |
| "淋巴瘤"       | <font color="#ff0000">腺淋巴瘤</font>           | 淋巴瘤                                             |
1. 名称中的"……瘤病"代表肿瘤多发状态（神经纤维瘤病、血管瘤病）；
2. <font color="#ff0000">畸胎瘤（teratoma）</font>：是性腺或胚胎剩件中的全能细胞发生的肿瘤，多发生于性腺，一般含有两个或以上胚层的成分，组织结构混乱。
3. 母细胞瘤：形态类似发育过程中的某种幼稚细胞或组织，因此得名。来自骨、软骨、脂肪、肌肉的母细胞瘤<font color="#ff0000">一般为良性</font>；其余的<font color="#ff0000">一般多为恶性</font>，如神经母细胞瘤、髓母细胞瘤、肾母细胞瘤、视网膜母细胞瘤、肝母细胞瘤。
4. 血液系统的"病"或"瘤"一般为恶性：白血病；绿色瘤是粒系白血病浸润形成的肿块；多发性骨髓瘤是<font color="#ff0000">浆细胞的肿瘤</font>。
5. 生殖系统的"病"或"瘤"一般为恶性：精原细胞瘤；无性细胞瘤指<font color="#ff0000">原始生殖细胞在胚胎期迁移至卵巢后未继续分化、保留原始特征而失控增殖</font>形成的肿瘤。
6. 皮肤的"病"或"瘤"：Bowen 病是<font color="#ff0000">皮肤原位鳞癌</font>；蕈样霉菌病是皮肤 T 细胞淋巴瘤。

## ❤ （三）分类与编码

肿瘤分类主要依据肿瘤的<font color="#ff0000">组织类型、细胞类型、生物学行为</font>，兼顾各种肿瘤的临床病理特征及预后情况。

WHO 国际疾病分类（International Classification of Disease）的肿瘤学部分（ICD-O）

1. 用一个四位数字的主码代表一个特定的肿瘤性疾病（如肝细胞肿瘤 8170）；
2. 在疾病主码之后，用一个斜线加一个附加数码代表肿瘤的生物学行为：
	①/0：良性；
	②/1：交界性、生物学行为未定或不确定；
	③/2：原位癌、Ⅲ级上皮内瘤变、非浸润性癌；
	④/3：恶性。

> [!tip] ICD-O 组合示例
> 肝细胞腺瘤＝8170/0；肝细胞癌＝<font color="#ff0000">8170/3</font>。同一主码（8170）配不同生物学行为代码，即分别表示良性、恶性。
> [!note] 免疫组织化学
> 可借助检测肿瘤细胞表面或细胞内的特定分子来确定肿瘤类型（常用免疫标记参见教材对应表格）。
