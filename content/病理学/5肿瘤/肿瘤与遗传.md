# 😭 十二、肿瘤与遗传

遗传因素对散发性（sporadic）肿瘤的作用是使患者对某些肿瘤具有易感性（susceptibility）。遗传性或家族性肿瘤综合征患者具有特定的染色体和基因异常，使他们比一般人群患某些肿瘤的机会显著增加。

## 😭 （一）遗传性肿瘤综合征

| 遗传方式 | 常见遗传综合征／肿瘤 | 有关基因 |
| ---- | ---- | ---- |
| 常染色体显性遗传 | 家族性视网膜母细胞瘤 | RB 基因 |
| 常染色体显性遗传 | <font color="#ff0000">家族性腺瘤性息肉病</font>、结直肠癌 | APC 基因 |
| 常染色体显性遗传 | <font color="#ff0000">遗传性非息肉病性结直肠癌（HNPCC）</font>、结直肠癌 | <font color="#ff0000">MSH2 等基因</font> |
| 常染色体显性遗传 | 神经纤维瘤病Ⅰ型 | NF1 基因 |
| 常染色体显性遗传 | von Hippel-Lindau 综合征、家族性肾透明细胞癌 | VHL 基因 |
| 常染色体隐性遗传 | 着色性干皮病—皮肤癌 | XP 基因 |
| 常染色体隐性遗传 | <font color="#ff0000">毛细血管扩张性共济失调症</font>，急性白血病和淋巴瘤 | <font color="#ff0000">ATM 基因</font> |
| 常染色体隐性遗传 | Li-Fraumeni 综合征，肉瘤、白血病、乳腺癌等 | p53 基因 |
| 常染色体隐性遗传 | <font color="#ff0000">Fanconi 贫血</font>，白血病 | <font color="#ff0000">FACC 和 FACA 基因</font> |
| 常染色体隐性遗传 | 布卢姆综合征（Bloom 综合征），白血病等 | BLM 基因 |

- 家族性视网膜母细胞瘤——患者从亲代遗传了一个异常的 RB 等位基因，当另一个 RB 等位基因发生突变、丢失等异常时就会发生视网膜母细胞瘤
- 一些癌前疾病（如家族性腺瘤性息肉病、神经纤维瘤病等）也以常染色体显性遗传方式出现，其中突变或缺失的基因是肿瘤抑制基因，如 RB、APC 和 NF1 等
- 常染色体隐性遗传综合征多与 DNA 修复基因异常有关：着色性干皮病（XP）患者受紫外线照射后易患皮肤癌；布卢姆综合征、Fanconi 贫血患者易发生白血病等恶性肿瘤

> [!caution] Li-Fraumeni 综合征的遗传方式
> 教材将其列为常染色体隐性遗传（患者 TP53 基因异常）；临床实为常染色体显性遗传，此处以教材口径为准并作此注记。

## 😭 （二）肿瘤的家族聚集倾向

一些肿瘤有家族聚集倾向，如乳腺癌、胃肠癌等，可能与多因素遗传有关；相应的癌前病变见 [[癌前病变和原位癌#❤ （一）癌前病变（precancerous disease）]]。

> [!tip] 举例：视网膜母细胞瘤的可能发病机制
> RB 基因（13q14）两个等位基因均失活（Knudson 的两次打击假说）而发病——家族性者从亲代遗传一个缺陷拷贝，散发性者需两次体细胞突变。
> 相关机制见 [[肿瘤的分子基础#❤ （三）肿瘤抑制基因功能丧失]]。
