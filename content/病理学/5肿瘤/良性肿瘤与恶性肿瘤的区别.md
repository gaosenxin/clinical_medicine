# ❤ 七、良性肿瘤与恶性肿瘤的区别

良恶性肿瘤的生物学行为和对机体的影响差别很大：良性者危害小、治疗效果好；恶性者危害大、治疗复杂、效果尚不理想。若将恶性误诊为良性，可延误治疗或治疗不彻底；反之可导致过度治疗（overtreatment），故区别二者具有重要意义。

## ❤ （一）鉴别要点

| 鉴别点    | 良性肿瘤                                  | 恶性肿瘤                                           |
| ------ | ------------------------------------- | ---------------------------------------------- |
| 大体形态   | 边界较清楚或包膜完整                            | 向肿瘤周边浸润，缺乏包膜                                   |
| 生长方式   | 膨胀性或外生性生长                             | <font color="#ff0000">浸润性</font>或外生性生长         |
| 分化程度   | 分化好，<font color="#ff0000">异型性</font>小 | 不同程度分化障碍或未分化，<font color="#ff0000">异型性</font>大 |
| 核分裂象   | 无或少，不见病理性核分裂象                         | 多，可见<font color="#ff0000">病理性核分裂象</font>       |
| 生长速度   | 缓慢                                    | 较快                                             |
| 继发改变   | 少见                                    | 常见，如出血、坏死、溃疡形成等                                |
| 转移     | 不转移                                   | 可<font color="#ff0000">转移</font>               |
| 复发     | 不复发或很少复发                              | 易复发                                            |
| 对机体的影响 | 较小，主要为局部压迫或阻塞                         | 较大，破坏原发部位和转移部位的组织；坏死、出血，合并感染；恶病质               |

## ❤ （二）交界性肿瘤

<font color="#ff0000">交界性肿瘤</font>（borderline tumor）
	组织形态和生物学行为介于良性和恶性之间的一大类肿瘤
需根据形态特点评估其复发转移的风险度（低、中、高）。

如：<font color="#ff0000">卵巢交界性浆液性乳头状囊腺瘤</font>
	同一类肿瘤有良性、恶性和交界性三种

> [!note] 良性肿瘤也可转变为恶性肿瘤
> 良性肿瘤并非一成不变，可转变为恶性肿瘤；个别肿瘤不能截然分良、恶，需根据形态特点评估复发转移风险度（如胃肠间质瘤：极低、低、中等、高）。

## ❤ （三）瘤样病变

瘤样病变（tumor-like lesion）/假肿瘤性病变：本身不是真性肿瘤，但临床表现或组织形态类似肿瘤，甚至容易被误认为恶性肿瘤，鉴别诊断时应予充分考虑。常见的非真性肿瘤：

1. <font color="#ff0000">炎性假瘤</font>：肺慢性炎症时，肺的上皮、淋巴管、血管、纤维组织增生形成的小球，属于良性增生。
2. <font color="#ff0000">迷离瘤</font>：误位于异常部位的分化正常的组织，如异位的甲状腺、异位的胰腺等（迷离指胚胎发育过程中体内某些组织离开其正常部位而到达通常不应有的部位，也称组织异位）。
3. <font color="#ff0000">错构瘤</font>：器官内正常组织的错误组合与排列，如肾错构瘤可见肾脏的皮质、髓质、脂肪细胞混合形成一个小球。
4. 结核瘤：一般为单个、直径 2 cm 以上、由纤维组织包绕干酪样结核病变或阻塞性空洞被干酪物质充填而形成的球形病灶。
5. 梅毒瘤：即梅毒树胶样肿。
6. 粥瘤：动脉粥样硬化的第三期。
7. 室壁瘤：心肌梗死后，梗死区域的坏死心肌逐渐被瘢痕组织替代，受血流压力向外膨出而形成的突起。
8. 动脉瘤：血管壁的退行性变或损伤（动脉粥样硬化、高血压长期冲击、遗传性疾病如马凡综合征、外伤、感染等），血管壁中层（富含弹力纤维）被破坏、代之以瘢痕组织，在血流压力冲击下血管壁局部向外膨出。
9. 血管瘤：由血管扩张形成的，但蔓状血管瘤或毛细血管瘤是真的有毛细血管增殖的，属良性肿瘤。


> [!important] 判断良恶性的依据
> 肿瘤的良、恶性是指其生物学行为。病理学通过形态学等指标判断肿瘤的良恶性、借以估计其生物学行为和预后，在大多数情况下是可行的，可谓目前各种肿瘤检查诊断方法中最重要和可靠的方法。
> 近年结合组织病理和分子改变的整合病理诊断使分类、生物学行为和预后判断更为准确，但组织学诊断和分子病理诊断都不可避免地会遇到组织样本是否具有代表性等技术问题。
