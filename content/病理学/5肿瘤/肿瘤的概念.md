# ❤ 一、肿瘤的概念

亦称“新生物”，是基因改变导致的细胞克隆性和自主性过度增殖，常表现为异常组织团块。（白血病为特例）。

### 专用术语

1. 良性肿瘤（benign tumor）：生长慢、侵袭性无或弱、不转移、危害小；
2. 恶性肿瘤（malignant tumor）：生长迅速、侵袭性强、转移、危害大，即所谓癌症（cancer）；
3. 肿瘤生成（neoplasia）：形成肿瘤的过程；
4. 肿瘤性增殖（neoplastic proliferation）：导致肿瘤形成的异常细胞增殖。


## ❤ （一）肿瘤性增殖与非肿瘤性增殖

与肿瘤性增殖相对的是非肿瘤性增殖，如炎性[[肉芽组织]]中血管内皮细胞、成纤维细胞的[[增生]]，以及正常细胞更新、损伤修复等。二者的重要区别：

| 对比项目 | 肿瘤性增殖（Neoplastic Proliferation） | 非肿瘤性增殖（Non‑Neoplastic Proliferation） |
| ---- | ---- | ---- |
| 克隆性 | usually (mono)clonal<br>（单）克隆性 | usually polyclonal<br>多克隆性 |
| 形态功能 | atypia<br>异型性 | normal morphology & function<br>正常形态和功能 |
| 生长调控 | autonomous<br>自主性 | under control<br>受控制 |
| 与机体协调性 | uncoordinated<br>不相协调性 | coordinated<br>相协调 |
| 目的意义 | purposeless<br>无目的性 | serve the body’s need(s)<br>满足身体需要 |

1. 自主性（autonomy）：引起肿瘤生成的初始因素消除后肿瘤仍可持续生长，提示肿瘤细胞发生可传递的基因水平的异常；
2. 克隆性（clonality）：一个肿瘤中的肿瘤细胞群是由发生肿瘤性转化（neoplastic transformation）的单个细胞反复分裂增殖产生的子代细胞构成的。
