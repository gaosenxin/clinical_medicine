# 😊 八、常见肿瘤举例
### 1. 各种肿瘤的对比

#### （1）良性肿瘤与恶性肿瘤的区别

|      | 良性          | 恶性                   |
| ---- | ----------- | -------------------- |
| 分化程度 | 高，异型性小      | 低，异型性大               |
| 核分裂象 | 少           | 多，可见病理性核分裂           |
| 生长速度 | 慢           | 快                    |
| 生长方式 | 膨胀性、外生性     | 外生性、浸润性              |
| 继发改变 | 少           | 坏死、出血、溃疡             |
| 转移   | 无           | 有                    |
| 复发   | 少           | 常见                   |
| 影响   | 小，局部压迫、阻塞为主 | 大，侵袭破坏组织，继发感染、出血，恶病质 |

#### （2）癌和肉瘤的区别
| 鉴别点  | 癌                                                                                   | 肉瘤                                                                                          |
| ---- | ----------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| 组织来源 | 上皮组织                                                                                | 间叶组织                                                                                        |
| 发病率  | <font color="#ff0000">较高</font>，约为肉瘤的 9 倍；<font color="#ff0000">多见于 40 岁以后成人</font> | 较低；有些类型主要发生在<font color="#ff0000">年轻人或儿童</font>，有些主要见于中老年人                                  |
| 大体特点 | 质较<font color="#ff0000">硬</font>、<font color="#ff0000">色灰白</font>（纤维细胞多）            | 质<font color="#ff0000">软</font>、<font color="#ff0000">色灰红、鱼肉状</font>（细胞多）                   |
| 镜下特点 | <font color="#ff0000">多形成癌巢</font>，实质与间质分界清楚，<font color="#ff0000">纤维组织常有增生</font>  | 肉瘤<font color="#ff0000">细胞多弥漫分布</font>，实质与间质分界不清，<font color="#ff0000">间质内血管丰富</font>、纤维组织少 |
| 网状纤维 | 见于癌巢周围，癌细胞间多无网状纤维                                                                   | 肉瘤细胞间多<font color="#ff0000">有网状纤维</font>                                                    |
| 转移   | <font color="#ff0000">多为淋巴道转移</font>                                                | 多经<font color="#ff0000">血道转移</font>                                                            |

## 😊 （一）上皮组织肿瘤

上皮组织包括被覆上皮与腺上皮。上皮组织肿瘤常见，人体的恶性肿瘤大部分是上皮组织恶性肿瘤（癌），在 40 岁以上的人群中发生率显著增加。

### 😊 2. 上皮组织恶性肿瘤

癌是人体最常见的恶性肿瘤。

- 发生在皮肤、黏膜表面的癌，可呈<font color="#ff0000">息肉状、蕈伞状或菜花状</font>，表面常有坏死及溃疡形成；
- 发生在器官内的癌，常为不规则结节状，呈树根或蟹足状向周围组织浸润，质地较硬，切面常为灰白色；
- 镜下，癌细胞可呈<font color="#ff0000">巢状、腺泡状或条索状</font>排列，与间质分界一般较清楚。

## 😊 （二）间叶组织肿瘤

间叶组织肿瘤包括脂肪组织、血管和淋巴管、平滑肌、横纹肌、纤维组织、骨组织等的肿瘤；骨和软骨肿瘤以外的间叶组织肿瘤又常称为软组织肿瘤。间叶组织肿瘤中良性的比较常见，恶性肿瘤（肉瘤）不常见。此外，间叶组织有不少瘤样病变，形成临床可见的「肿块」但并非真性肿瘤，有些形态学类似肉瘤、容易造成诊断困难。

### 😊 1. 间叶组织良性肿瘤

| 来源                               | 病理特点                                                                            | 常见部位                               |
| -------------------------------- | ------------------------------------------------------------------------------- | ---------------------------------- |
| 脂肪瘤                              | 最常见的良性软组织肿瘤，成人多见，<font color="#ff0000">分叶状，有包膜</font>，质地柔软、切面黄色似脂肪；一般无明显症状，<font color="#ff0000">很少恶变</font> | 背、肩、颈及四肢近端皮下组织                     |
| 血管瘤                              | 常见于儿童，可为先天性，可随身体发育长大、成年后一般停止发展甚至自然消退；无被膜，呈浸润性生长，界限不清。有<font color="#ff0000">毛细血管瘤、海绵状血管瘤、静脉血管瘤</font>等类型；皮肤或黏膜可呈突起鲜红肿块或暗红／紫红斑；肢体软组织弥漫性海绵状血管瘤可引起肢体增大；内脏者多呈结节状 | 皮肤、黏膜、肌肉、内脏器官                     |
| 淋巴管瘤                             | 由增生的淋巴管构成，可呈囊性扩张并相互融合，<font color="#ff0000">多见于小儿</font> | 许多部位                               |
| 平滑肌瘤                             | 镜下形态一致的梭形平滑肌细胞排列成束状，互相编织                                                        | <font color="#ff0000">子宫</font>、胃肠 |
| 软骨瘤                              | 镜下由成熟的透明软骨组成，可以恶变                                                               | 四肢长骨、手足短骨                          |

## 😭 （三）神经外胚叶肿瘤

胚胎早期的外胚叶有一部分发育为神经系统，称为神经外胚叶，包括神经管和神经嵴：神经管发育成脑、脊髓、视网膜上皮等；神经嵴产生神经节、施万细胞、黑色素细胞、肾上腺髓质嗜铬细胞等。由神经外胚叶起源的肿瘤种类很多，详细介绍见本书神经系统疾病等章节。

- [[中枢神经系统]]原发性肿瘤约 40% 为胶质瘤；小儿的恶性肿瘤中，颅内恶性肿瘤的发病率仅次于白血病。周围神经系统较常见的肿瘤是神经鞘瘤和神经纤维瘤
- 视网膜母细胞瘤（retinoblastoma）：产生自视网膜胚基，肿瘤细胞为幼稚的小圆细胞、形态类似未分化的视网膜母细胞，可见特征性的 Flexner-Wintersteiner 菊形团；大多数见于 3 岁以下婴幼儿，预后不好（发病机制见 [[肿瘤与遗传#😭 （一）遗传性肿瘤综合征]]）
- 黑色素瘤（melanoma）：多见于皮肤和黏膜，偶见于内脏；皮肤的黑色素瘤可由黑色素细胞痣发展而来。肿瘤细胞可含黑色素，也可为无色素型；其分期与预后密切相关
