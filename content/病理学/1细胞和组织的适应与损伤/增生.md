# ❤ 概念
细胞有丝分裂活跃而致组织或器官内细胞数目增多的现象

# 😊 类型

|  | 生理性增生 | 病理性增生 |
| :------- | :----------------------------- | :------------------------ |
| 代偿性增生 | 部分肝脏切除后残存肝细胞的再生；高海拔地区机体骨髓红细胞前体、外周血红细胞代偿增多 | 组织损伤、慢性炎症 |
| 内分泌性增生 | 月经周期中子宫内膜腺体的增生 | 雌激素↑→子宫内膜腺体增生过长 |

# 病理性增生与肿瘤性增生

炎症造成的增生是典型的病理性增生，病理性增生属于<font color="#ff0000">良性增生</font>。

| 对比项目 | 病理性增生 | 肿瘤性增生 |
| :--------- | :------------------------- | :--------------------- |
| 原因 | 外界因素刺激导致（如炎症等） | DNA 突变导致 |
| 克隆性 | 多克隆 | 单克隆 |
| 诱因去除后 | 增生停止 | 增生不停止 |
| 意义 | 有积极意义 | 可浸润、转移 |

# 😭 对机体的影响

- 机制：
  - 局部生长因子增多
  - 相应生长因子受体增多
  - 相关信号通路激活
- 增生只发生于具有分裂和增殖能力的细胞，可伴肥大
- 形态学：增生致相关器官体积变大、重量增加
- 细胞功能和代谢：增强
- 结局：
  - 生理性或代偿性增生 → 对机体有利
  - 过度增生 → 发生癌变或其他病变

# 与[[肥大]]的关系
- 缺乏增殖能力的实质细胞（心肌细胞、骨骼肌）只有[[肥大]]；
- 具有增殖能力的细胞，增生和[[肥大]]可同时发生。
- 肥大和增生时细胞体积均可增大
