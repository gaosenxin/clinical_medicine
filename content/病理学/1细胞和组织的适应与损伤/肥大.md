# ❤ 概念
因细胞体积增大而导致相关器官的体积增大。肥大可为生理性和病理性。
定义：由于功能增加，合成代谢旺盛，使细胞、组织或器官体积增大；通常由实质细胞体积增大所致，也可伴有实质细胞数量增加。
# 机制
细胞内蛋白质合成的增加
# 😊 类型

|  | 生理性肥大 | 病理性肥大 |
| :------- | :------------------------- | :--------------------------------- |
| 代偿性肥大（组织、器官功能负荷过重所致） | 健身→锻炼后的骨骼肌增粗肥大 | 高血压时左室心肌肥大；一侧肾脏切除时对侧肾脏肥大 |
| 内分泌性肥大（内分泌激素过多作用于效应器所致） | 妊娠期子宫平滑肌细胞明显肥大，同时细胞增多 | 垂体嗜碱性细胞腺瘤→ACTH↑→肾上腺皮质肥大；卵巢颗粒细胞瘤→雌激素↑→乳腺腺体肥大 |

# 病理变化

- 肥大组织与器官体积均匀增大
- 肥大的细胞体积增大，细胞核肥大深染（<font color="#ff0000">原癌基因活化，DNA 含量↑</font>）

# 代偿与失代偿

以高血压时的左室心肌最典型：

- 高血压 → 后负荷↑ → 心肌细胞结构蛋白合成活跃、功能增强、体积增大 → 左室心肌肥厚（高血压心脏病）
- 肥大的功能代偿作用是有限度的，过度肥大可导致损伤：心肌过度肥大 → 血供相对缺乏，且胚胎性基因激活使正常收缩蛋白转变为收缩效率较差的幼稚收缩蛋白 → <font color="#ff0000">失代偿</font>，先出现向心性肥大，后出现离心性肥大

# 假性肥大

假性肥大（pseudohypertrophy）：某些病理情况下，在实质细胞萎缩的同时，间质脂肪细胞增生，以维持组织、器官的原有体积，甚至造成组织和器官的体积增大。
