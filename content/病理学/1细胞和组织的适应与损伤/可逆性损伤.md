# ❤ 概念
细胞或细胞间质损伤后，因代谢障碍致使细胞内或细胞间出现异常物质或异常储积的现象。也称为变性
蓄积的原因：正常或异常物质产生过多、过快；细胞组织缺乏相应的代谢、清除、转运机制。去除病因后，大多数可恢复正常，是非致死性、可逆性的。
# 特点
轻微的细胞损伤，无细胞核的改变
常伴有细胞功能降低
去除病因后多可恢复正常
# 七类蓄积索引

| 类型 | 蓄积物质 | 病变部位 |
| :--------------- | :--------------------------------------------------- | :---------- |
| 细胞水肿/水变性 | 水、Na⁺蓄积 | 细胞内 |
| 脂肪变 | 甘油三酯蓄积 | 细胞内（非脂肪细胞） |
| 玻璃样变 | 蛋白质蓄积（某些变性的免疫球蛋白、胶原蛋白、血浆蛋白等） | 细胞内、细胞间质 |
| 淀粉样变 | 淀粉样蛋白质和黏多糖复合物蓄积 | 细胞间质 |
| 黏液样变 | 黏多糖类物质和蛋白质蓄积 | 细胞间质 |
| 病理性色素沉着 | 含铁血黄素、脂褐素、黑色素等沉着 | 细胞内、细胞间质 |
| 病理性钙化 | 磷酸钙、碳酸钙等钙盐沉积 | 细胞间质、细胞内 |

# ❤ 类型
## 细胞 #水肿 cellular swelling
### 😭 概念

也称水样变（hydropic change）,因细胞容积和胞质离子调节功能的下降至细胞内水储积的现象。
### 😭 机制

线粒体损伤→ATP↓→Na<sup>+</sup>-K<sup>+</sup>泵↓
细胞内代谢产物聚集，酸碱度失衡细胞内外胶体
渗透压失衡(intracellular plasma osmotic pressure ↑)
### ❤ 形态学特征
- 细胞水肿初期线粒体、内质网肿胀，光镜可见胞质红染细颗粒
- 水钠持续蓄积时细胞显著肿大、胞质空泡、核肿胀，严重时发展为 #气球样变 （<font color="#ff0000">常见于肝细胞</font> [[病毒性肝炎|病毒性肝炎]] ）
- 部分病例光镜下细胞病变不明显，但肉眼可见器官体积膨大、边缘圆钝、包膜紧张、切面外翻、颜色变淡。

## 脂类物质积聚
### #脂肪变 fatty change
#### 概念
甘油三酯在实质细胞中的异常聚集所致的改变
主要发生于代谢与功能活跃器官的实质细胞： 肝细胞 、心肌细胞，肾小管上皮细胞等
#### 机制
肝细胞内脂肪酸增多
酗酒：磷酸甘油↑→甘油三脂合成↑
缺氧、营养不良、肝毒性物→载脂蛋白↓

![[可逆性损伤-1788351394102.webp|681]]

#### 器官分布

| 器官 | 分布特点 |
| :------- | :--------------------------------------- |
| 肝 | 慢性肝淤血——首先发生于小叶中央区；磷中毒——小叶周边带受累更明显；严重中毒和传染病（重症肝炎、四氯化碳中毒等）——全部肝细胞受累 |
| 心 | 见下表虎斑心与心肌脂肪浸润 |
| 肾 | 主要发生于肾近曲小管细胞基底部（过量重吸收原尿中的脂蛋白） |

| 对比项目     | 虎斑心（心肌脂肪变）               | 心肌脂肪浸润（脂肪心）                    |
| :------- | :----------------------- | :----------------------------- |
| 病变本质 | 心肌细胞内脂肪变性（胞质脂滴沉积）    | 心外膜脂肪组织伸入心肌间质，无心肌细胞脂肪变 |
| 常见病因 | 慢性酒精中毒、心肌缺氧              | 重度肥胖、长期过量饮用啤酒                  |
| 好发部位 | 左心室内膜下、乳头肌               | 右心室（以心尖区最为显著）                  |
| 肉眼特征 | 病变心肌黄色，与正常暗红色心肌相间，呈黄红色斑纹 | 脂肪组织穿插于心肌细胞之间，心肌受压萎缩           |
| 临床特点 | 心肌细胞损伤，影响心功能             | 轻症多无症状；重度可发生心脏破裂、猝死            |

![[可逆性损伤-1788351415887.webp|280]]
#### 形态学特征
脂肪变较轻时器官肉眼无显著改变
病变加重后，受累器官体积增大、色淡黄、边缘圆钝、切面油腻。

电镜下胞质内先形成有膜包裹的脂质小体，之后融合为脂滴
光镜可见胞质内大小不等球形脂滴，大脂滴可将细胞核挤向一侧
石蜡切片脂滴被溶解呈空泡状，冷冻切片可用苏丹 Ⅲ、苏丹 Ⅳ 染色特异性显示脂肪。
锇酸染色时，蓄积于细胞质内的脂肪呈<font color="#ff0000">黑色</font>。
### 胆固醇和胆固醇脂积聚
胆固醇及胆固醇酯的异常沉积常见于以下病变：

- #动脉粥样硬化 （Atherosclerosis）
- #黄色瘤 （Xanthomas）
- #胆固醇储积病 （Cholesterolosis）
- C型 #尼曼-匹克病 （Niemann-Pick disease, type C）

黄色瘤：动脉粥样硬化、高脂血症时，某些非脂肪细胞（如巨噬细胞、平滑肌细胞）的胞质中充有过量的胆固醇和胆固醇酯，可视为特殊类型的细胞内脂质蓄积；此类巨噬细胞显著增多并聚集在皮下组织时，称为黄色瘤。

## 蛋白质类物质积聚
### 概念
细胞内或间质中出现半透明状蛋白质储积，也称透明变/ #玻璃样变(hyaline change）
### 类型

## 淀粉样变（Amyloid change）
#淀粉样变
### 概念
细胞间质内淀粉样蛋白质和黏多糖复合物蓄积，因具有淀粉染色特征而得名。
### 😭 机制

淀粉样蛋白由多种蛋白成分构成，新生多肽链可形成 β‑折叠结构，人体缺乏可降解该大分子结构的酶，蛋白及其前体易在组织蓄积。
### 形态学变化
淀粉样物质沉积于细胞间质、小血管基底膜等处；HE 染色为淡红色均质物，有特征性淀粉样呈色反应：<font color="#ff0000">遇碘呈棕褐色，再加稀硫酸呈蓝色</font>；刚果红染色橘红色、偏光镜下呈苹果绿色。
### 分型

| 分型 | 分布 |
| :------- | :----------------------------------------------------------- |
| 局部性 | 发生于皮肤、结膜、舌、喉、肺等处，也可见于阿尔茨海默病脑组织，霍奇金病、多发性骨髓瘤等肿瘤的间质 |
| 全身性 | 血清 α-免疫球蛋白轻链沉积于肝、心、肾、脾；非免疫球蛋白沉积于结核病灶及肿瘤间质中 |

## 粘液样变 Mucoid Change
#粘液样变
定义：细胞间质内出现粘多糖（透明质酸、葡萄糖胺聚糖等）和蛋白质的蓄积。

常见于 #风湿热 、 #肿瘤 、 #甲状腺功能低下 、营养不良时的骨髓和脂肪组织等。

组织学表现：
- 弱嗜碱性的疏松粘液样基质
- 不等量的星状细胞分布

鉴别：
- 粘液：Alcian Blue（＋）
- 粘液样变：Alcian Blue（－）

## 病理性色素沉着 pathologic pigmentation
### 内源性色素（endogenous pigment）

| 色素类型 | 来源与特点 | 举例 |
| :------------------ | :------------------------------------------------------------------- | :------------------------------------- |
| 含铁血黄素（hemosiderin） | 巨噬细胞吞噬、降解血红蛋白所产生的铁蛋白微粒体（Fe³⁺＋蛋白质）；镜下呈金黄色/褐色，可被<font color="#ff0000">普鲁士蓝</font>染成蓝色；其存在表明有红细胞的破坏，或全身性/局限性的含铁物质剩余 | 陈旧性出血、溶血性疾病、慢性肺淤血心衰细胞、子宫内膜异位症 |
| 脂褐素（lipofuscin） | 细胞内未被彻底消化的、富含磷脂的膜包被的细胞器残体 | 细胞萎缩（心肌细胞、肝细胞）、阿尔茨海默病 |
| 黑色素（melanin） | 黑色素细胞 | 色素痣、黑色素瘤、基底细胞癌、Addison 病 |
| 胆红素（bilirubin） | 血液中红细胞衰老破坏 | 溶血性疾病、黄疸 |

- 有红细胞破坏的地方都会有含铁血黄素形成；正常情况下，肝、脾、骨髓等部位可有少量生成
- Addison 病：肾上腺皮质功能减退，引起黑色素细胞合成黑色素增加，可出现全身性皮肤、黏膜的黑色素沉着
- 色素痣为良性疾病，黑色素瘤为恶性疾病

## 病理性钙化 pathologic calcification
### 概念
骨和牙以外的组织中出现固态钙盐的沉积。钙盐的主要成分是磷酸钙、碳酸钙 ，少量铁、镁等
### 病理特点
肉眼观察呈灰白色颗粒状；镜下呈<font color="#ff0000">蓝色颗粒、片块状</font>染色。
### 类型
- 营养不良性钙化（Dystrophic calcification）
  - 钙盐沉积于细胞、组织损伤及坏死处的现象
  - 血钙正常
  - 常见于结核[[坏死#干酪样坏死（caseous necrosis）|干酪样坏死]]、血栓
  - 举例：结核病灶内、血栓、动脉硬化斑块、心脏瓣膜病、瘢痕组织；可出现在任何已知炎症或肿瘤的周围
- 转移性钙化（Metastatic calcification）
  - 因系统性钙磷代谢失调（高钙血症）致钙盐沉积于正常组织的现象，常见于甲状旁腺功能亢进患者
  - 血钙升高
  - 举例：甲状旁腺功能亢进、维生素 D 摄入过多、肾衰、某些骨肿瘤 → 钙磷代谢紊乱 → 见于血管，肾、肺、胃的间质组织

## 各型小体的鉴别

| 小体名称 | 病理性质 | 意义 |
| :------------- | :----------------------------------------------------------- | :--------------- |
| Russell 小体 | 浆细胞粗面内质网中免疫球蛋白蓄积 | 慢性炎症、多发性骨髓瘤 |
| Mallory 小体 | 肝细胞胞质中，中间丝前角蛋白变性，玻璃样变 | 酒精性肝病 |
| Councilman 小体 | 肝细胞嗜酸性凋亡小体 | 病毒性肝炎 |

| Negri 小体 | 病毒包涵体 | 狂犬病 |
| 狼疮（LE）小体 | 抗核抗体攻击胞核，核呈均质一片，并被挤出胞体 | SLE |

## 酒精性肝炎

- 四联表现：灶状坏死、中性粒细胞浸润、脂肪变性、<font color="#ff0000">Mallory 小体</font>（记忆：早中芝麻）
- 「波斯猫爱喝酒」：玻璃样变、中间丝前角蛋白、Mallory 小体、酒精性肝炎
