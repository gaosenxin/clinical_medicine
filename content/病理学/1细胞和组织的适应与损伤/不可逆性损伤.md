# 概念
 细胞发生严重的代谢、结构和功能障碍，导致细胞的不可逆性损伤，既细胞死亡
# 类型
[[坏死]]
[[凋亡]]

## 坏死和凋亡的特征与比较
| 项目             | 坏死                 | 凋亡                           |
| ---------------- | -------------------- | ------------------------------ |
| 细胞             | 肿胀                 | 皱缩                           |
| DNA分解机制      | 随意性，弥漫性       | 核小体间分解（180–200 bp）|
| 细胞膜           | 破坏                 | 完整; 结构改变 lipids          |
| 细胞内容         | 漏出，酶消化         | 膜包绕，在凋亡小体内           |
| 周围组织炎反应   | 存在                 | 缺乏                           |
| 范围             | 多数细胞             | 单个细胞                       |
| 生化特点         | 非耗能的被动过程     | 耗能的主动过程                 |
| 诱因             | 病理性               | 生理性；病理性                 |
| 机制             | 他杀                 | 自杀                           |
| 电泳             | 通常不呈梯带状       | 琼脂凝胶电泳呈特征性梯带状      |
