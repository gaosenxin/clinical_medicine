# 一、概述
## （一）淋巴造血系统
造血干细胞分化，两个方向：
- 髓细胞：骨髓和血液系统中的各种血细胞成分，包括红细胞、白细胞（粒细胞、单核细胞）、血小板
- 淋巴细胞：胸腺、脾脏、<font color="#ff0000">淋巴结、淋巴组织</font>

## （二）肿瘤分类
- <font color="#ff0000">淋系肿瘤</font>→大多形成肿块。少量也可入血（淋系白血病）
- 髓系肿瘤→入血→白血病
- 组织/树突状细胞肿瘤

## （三）淋巴结结构
1. <font color="#ff0000">皮质区</font>：<font color="#ff0000">淋巴滤泡</font>；受抗原刺激后出现生发中心；此区内富含<font color="#ff0000">B细胞</font>和滤泡树突状细胞。
2. 皮质深层和滤泡间隙为<font color="#ff0000">副皮质区</font>，又称胸腺依赖区，有大量<font color="#ff0000">T细胞</font>和巨噬细胞分布在滤泡周围，是传递免疫信息的场所。
3. <font color="#ff0000">髓质区</font>：<font color="#ff0000">B细胞、浆细胞和网状细胞</font>集结成索状，称髓索；在髓索间为髓窦；此区是滤过淋巴液的场所。

# ❤ 二、淋巴组织肿瘤
| 项目                                 | 内容                                                                                          |
| ---------------------------------- | ------------------------------------------------------------------------------------------- |
| 定义                                 | 来源于<font color="#ff0000">淋巴细胞及其前体细胞的恶性肿瘤</font>，包括淋巴瘤、淋巴细胞白血病、毛细胞白血病（慢性克隆性B细胞增生性疾病）、浆细胞肿瘤等。 |
| <font color="#ff0000">恶性淋巴瘤</font> | <font color="#ff0000">原发于淋巴结和结外淋巴组织等处的淋巴细胞及其前体细胞的一类恶性肿瘤。</font>                             |
| 细胞来源                               | <font color="#ff0000">B（80%-85%）、T、NK及其前体细胞</font>                                          |
| 分级                                 | 惰性、侵袭性、局限侵袭性、高侵袭性                                                                           |
| 分类                                 | WHO（2008）根据起源分类：<font color="#ff0000">霍奇金淋巴瘤、非霍奇金淋巴瘤（80-90%）</font>                         |
| 临床表现                               | 无痛性、进行性淋巴结肿大；免疫功能异常；骨髓浸润（贫血、出血）；继发性肾脏损害                                                     |


## （一）淋巴瘤与白血病的概念

| 概念 | 定义 |
| --- | --- |
| 淋巴瘤（lymphoma） | 来源于淋巴细胞及其前体细胞，原发于淋巴结和结外淋巴组织 |
| 白血病（leukemia） | 骨髓造血干细胞克隆性增生，骨髓内异常的白血病细胞弥漫性增生，取代正常骨髓组织，并进入外周血和全身各组织／器官 |

> [!important] 要点
> 两者的本质区别在于首发部位与骨髓受累方式：淋巴瘤原发于淋巴结和结外淋巴组织；白血病自骨髓起病并进入外周血与全身。NHL 常累及骨髓，当血中肿瘤性淋巴细胞明显增多时，即表现为淋巴细胞白血病。
## （二）免疫标记

| 细胞          | 免疫表型标志                                                                                         |
| ----------- | ---------------------------------------------------------------------------------------------- |
| B 细胞及其肿瘤    | <font color="#ff0000">CD19、CD20、CD30、CD79a</font>、表面 Ig、PAX5：<font color="#ffff00">带0/9</font> |
| T 细胞及其肿瘤    | <font color="#ff0000">CD2、CD3、CD4、CD7 和 CD8</font>                                             |
| 前体 B 和 T 细胞 | <font color="#ff0000">TdT（末端脱氧核苷酸转移酶）</font>，区别于成熟的淋巴细胞肿瘤                                      |
| NK 细胞       | <font color="#ff0000">CD56</font>                                                              |
| 髓样细胞        | CD13、CD33、CD117 和 MPO，可用来区别髓样肿瘤还是淋巴样肿瘤                                                         |

> [!important] 要点
> TdT 阳性提示前体淋巴细胞肿瘤（如 ALL），成熟淋巴细胞肿瘤为 TdT 阴性；MPO 及 CD13、CD33、CD117 用于区分髓样与淋巴样肿瘤。

## ❤ （三）霍奇金淋巴瘤与非霍奇金淋巴瘤的全面对比

这是本章大纲明确要求掌握的区别点。一句话概括：<font color="#ff0000">HL 是「少数肿瘤细胞（RS 细胞）+ 大量反应性炎细胞」、沿淋巴引流连续扩散的淋巴瘤；NHL 是单一克隆肿瘤细胞弥漫生长、跳跃式扩散的淋巴瘤</font>。

| ⁣‍⁣​‌‌​‌‌​‌​‌‌​‌‌​‌​‌‌‌​‌‌‌​​‌‌​​​​​‌‌​​​‌​​‌‌​​‌​‌​‌‌‌‌​​​​​‌‌​‌​‌​‌‌‌​‌‌‌​​‌‌​​​‌​‌‌​‌‌‌​​‌‌‌‌​‌​​‌‌​‌‌‌​​​‌‌​​​‌​‌‌‌​​​​⁣‌⁣项目 | 霍奇金淋巴瘤（HL） | 非霍奇金淋巴瘤（NHL） |
| --- | --- | --- |
| 占淋巴瘤比例 | 10%～20% | 80%～90% |
| 肿瘤细胞来源 | <font color="#ff0000">滤泡生发中心 B 细胞</font>（RS 细胞） | 以 B 细胞为主（80%～85%），其次 T／NK 细胞，另有前体淋巴细胞 |
| 好发年龄 | 多见于年轻人（＜30 岁） | 随亚型而异：ALL、Burkitt 在儿童与青年；DLBCL、CLL／SLL 多在老年 |
| 首发部位 | <font color="#ff0000">淋巴结</font>（颈部淋巴结尤多见） | 2／3 原发淋巴结，1／3 原发结外器官或组织；部位有随机性、不确定性 |
| 扩散方式 | 由近及远、<font color="#ff0000">连续</font>扩散：淋巴结 → 脾 → 肝 → 骨髓 → 结外 | <font color="#ff0000">跳跃式、不连续</font>扩散，更易早期结外转移 |
| 镜下特点 | 肿瘤细胞数量少，<font color="#ff0000">背景为大量反应性炎细胞</font> | 单一克隆的肿瘤细胞弥漫散在浸润，<font color="#ff0000">无特殊肿瘤细胞</font>；病理类型复杂 |
| 特征性细胞 | <font color="#ff0000">RS 细胞</font>（含镜影细胞）；变异型：陷窝细胞、LP 细胞（爆米花细胞）、木乃伊细胞 | 无 RS 细胞；各亚型自有形态（Burkitt 的「满天星」、DLBCL 大细胞弥漫、滤泡性淋巴瘤的滤泡结构等） |
| 免疫表型 | 经典型：<font color="#ff0000">CD30、CD15、PAX5</font>；结节性淋巴细胞为主型：CD20、CD79a | B 细胞：CD19、CD20、CD79a；T 细胞：CD2、CD3、CD4、CD7、CD8；NK：CD56；前体：TdT |
| EB 病毒 | 混合细胞型常有、富于淋巴细胞型约 40%、淋巴细胞减少型近 100%；结节硬化型与 NLPHL 一般不伴 | 与地方性 Burkitt 淋巴瘤关系密切；MALT 淋巴瘤与慢性炎症（如 Hp）有关 |
| 骨髓受累与白血病转化 | 晚期可累及骨髓、脾、肝，<font color="#ff0000">不发生白血病转化</font> | <font color="#ff0000">常累及骨髓</font>；外周血肿瘤性淋巴细胞 > 25% 时即表现为淋巴细胞白血病 |
| 分级与预后 | 放化疗效果好，属临床可治愈疾病；经典型中淋巴细胞减少型预后最差 | 惰性（滤泡性、CLL／SLL、MALT）→ 侵袭性（DLBCL、外周 T、NK／T）→ 高度侵袭性（ALL、Burkitt） |
