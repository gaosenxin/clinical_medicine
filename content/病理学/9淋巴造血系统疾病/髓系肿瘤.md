# 四、髓系肿瘤

## （一）概念与分类

髓系肿瘤是骨髓内有多分化潜能的造血干细胞克隆性增生，向髓细胞方向克隆性增生（若向淋巴细胞方向克隆性增生则为淋巴组织肿瘤）。骨髓增殖性肿瘤与急性髓系白血病是其常见类别。

| 分类 | 内容 |
| ---- | ---- |
| 白血病 | <font color="#ff0000">是骨髓造血干细胞克隆性增生形成的恶性肿瘤</font>，其特征是骨髓内异常的白细胞弥漫性增生取代正常骨髓组织，并进入周围血和浸润脾、淋巴结等全身各组织和器官，造成贫血、出血和感染。 |
| WHO分类 | <font color="#ff0000">急性髓性白血病</font>及其相关的前体细胞肿瘤<br><font color="#ff0000">骨髓增殖性肿瘤（MPN）</font><br>骨髓增生异常综合症（MDS）<br>骨髓异常增生/骨髓增生性肿瘤（MDS/MPD）<br>伴有嗜酸性粒细胞增多和PDGFRA、PDGFRB或FGFR1基因异常的髓系和淋巴肿瘤<br>急性未名系列白血病 |
