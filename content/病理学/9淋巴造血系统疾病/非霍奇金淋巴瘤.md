# ❤ 三、非霍奇金淋巴瘤

> [!important] 大纲分级
> ❤ 掌握：霍奇金淋巴瘤与非霍奇金淋巴瘤的区别。大纲在「教学内容」中标非霍奇金淋巴瘤的临床病理特点及 WHO 分类原则为重点（*），本章重点与难点均在此。

【非霍奇金淋巴瘤】（non-Hodgkin lymphoma, NHL）：占所有淋巴瘤的 80%～90%，其中 2／3 原发于淋巴结，1／3 原发于结外器官或组织。

| 项目   | 内容                                                                                                                         |
| ---- | -------------------------------------------------------------------------------------------------------------------------- |
| 细胞来源 | <font color="#ff0000">B细胞(85%-90%)，单克隆起源</font>                                                                            |
| 发病率  | <font color="#ff0000">多见</font>，我国占淋巴瘤的89%-92%                                                                             |
| 好发年龄 | 各年龄阶段，随年龄增长而发病增多                                                                                                           |
| 好发性别 | 男性多于女性                                                                                                                     |
| 首发症状 | 无痛性淋巴结进行性肿大可发生在全身任何部位（<font color="#ff0000">正常淋巴结结构破坏</font>）                                                              |
| 原发病灶 | <font color="#ff0000">可结外淋巴组织</font>                                                                                       |
| 播散方式 | <font color="#ff0000">跳跃式，越过邻近淋巴结向远处淋巴结转移</font>                                                                           |
| 压迫浸润 | 常见，几乎可累及任何器官，胸部以<font color="#ff0000">肺门</font>及纵隔受累最多；CNS以累及<font color="#ff0000">脑膜、脊髓</font>为主；胃肠道以回肠最多见；骨骼损害以胸椎、腰椎最常见。 |
| 全身症状 | 少见，部分可伴发热(高热)，盗汗和原因不明的体重减轻，非特征性症状：乏力、皮肤瘙痒等，<font color="#ff0000">免疫功能缺陷。</font>                                            |
| 特有表现 | 无                                                                                                                          |
| 常见分型 | <font color="#ff0000">弥漫大B细胞性淋巴瘤(最常见</font>，占35%~40%)                                                                      |
| 确诊手段 | 通过淋巴结活检发现特征瘤细胞进行确诊分型                                                                                                       |
| 治疗方式 | 以化疗为主                                                                                                                      |
| 化疗方案 | <font color="#ff0000">CHOP方案</font>，CD20+者加利妥昔单抗疗效更好                                                                       |

## （一）三大类

根据肿瘤的起源和属性，NHL 分为三大类：前体淋巴细胞肿瘤（前体 B 细胞和 T 细胞肿瘤）、成熟 B 细胞肿瘤、成熟 T 细胞和 NK 细胞肿瘤。

### （一）前体淋巴细胞肿瘤（前体 B 细胞和 T 细胞肿瘤）<font color="#ff0000">母细胞来源</font>

| ------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------- |
| 好发年龄                                                                                                                           | <font color="#ff0000">儿童(高峰期为4岁)</font>                                                                                        | 青少年(高峰期为15-20岁)                                                                                     |
| 分级                                                                                                                             | 高度侵袭性                                                                                                                          | 高度侵袭性                                                                                               |
| 主要表现                                                                                                                           | <font color="#ff0000">白血病(广泛累及<font color="#ffff00">骨髓和外周血</font>)</font>                                                      | <font color="#ff0000">纵隔肿块(主要累及<font color="#ffff00">胸腺</font>)</font>                              |
| 普通表现                                                                                                                           | 贫血、粒细胞和血小板减少，淋巴结和肝脾大                                                                                                           | 贫血、粒细胞和血小板减少，淋巴结和肝脾大                                                                                |
| 病理变化                                                                                                                           | 淋巴结破坏，肿瘤性淋巴母细胞浸润被膜和结外组织，瘤细胞胞质稀少，核染色质均匀，核分裂象多见；巨噬细胞散在分布<font color="#ff0000">“星空”现象</font>。                                     |                                                                                                     |

| 核型分析                                                                                                                           | 细胞遗传学可有异常核型、染色体易位、重排                                                                                                           | 尚未发现特征性或重现性细胞遗传学异常                                                                                  |
| 治疗效果                                                                                                                           | 对化疗很敏感，95%患者可获完全缓解                                                                                                             | 对化疗很敏感，95%患者可获完全缓解                                                                                  |
| 预后                                                                                                                             | 差，易复发                                                                                                                          |                                                                                                     |

### （二）成熟 B 细胞肿瘤来源 

约 85% 的 NHL 是成熟 B 细胞肿瘤，最常见的两种类型是弥漫大 B 细胞淋巴瘤、滤泡性淋巴瘤。

## （六）总结

| ⁣‍⁣​‌‌​‌‌​‌​‌‌​‌‌​‌​‌‌‌​‌‌‌​​‌‌​​​​​‌‌​​‌‌​​‌‌​‌‌​​​​‌‌​​‌‌​​‌‌​​​‌​‌‌​‌‌​​​‌‌​‌​‌​​‌‌​‌‌‌‌​‌‌​​‌‌​​‌‌‌‌​​​​​‌‌​‌​‌​‌‌‌​​​‌⁣‌⁣分类 | 内容                                                                                                                                                                                                                                                                        |
| -------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| B细胞来源                                                                                                                            | 霍奇金淋巴瘤、弥漫大B细胞淋巴瘤、滤泡性淋巴瘤、结外边缘区粘膜相关淋巴组织淋巴瘤、Burkitt 淋巴瘤、多发性骨髓瘤、慢性淋巴细胞性白血病/小淋巴细胞淋巴瘤、套细胞淋巴瘤                                                                                                                                                                                    |
| T细胞来源                                                                                                                            | 外周T细胞淋巴瘤，非特殊类型<br>蕈样霉菌病 /Sezary综合征<br>血管免疫母细胞性T细胞淋巴瘤                                                                                                                                                                                                                      |
| 前体细胞来源                                                                                                                           | 急性淋巴母细胞性白血病/淋巴瘤                                                                                                                                                                                                                                                           |
| “满天星”“星空”现象                                                                                                                      | <font color="#ff0000">Burkitt淋巴瘤</font>、急性淋巴母细胞性白血病/淋巴瘤(ALL)、套细胞淋巴瘤                                                                                                                                                                                                       |
| 可转化为弥漫大B的类型                                                                                                                      | 滤泡性淋巴瘤、慢性淋巴细胞性白血病/小淋巴细胞淋巴瘤、结外边缘区黏膜相关淋巴组织淋巴瘤（MALT 淋巴瘤）、结节性淋巴细胞为主型霍奇金淋巴瘤                                                                                                                                                                                                    |

> [!important] 要点
> BL 的 t(8,14) 使 8 号染色体上的 MYC 与 14 号染色体上 Ig 重链基因并置，最常见的具体核型为 t(8;14)(q24;q32)；滤泡性淋巴瘤 t(14,18) 导致 Bcl-2 过度表达。
