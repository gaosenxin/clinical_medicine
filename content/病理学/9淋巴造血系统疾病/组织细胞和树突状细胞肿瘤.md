# 五、组织细胞和树突状细胞肿瘤

## （一）组织细胞肉瘤

组织细胞肉瘤很少见（9 版变动）。

## （二）Langerhans 细胞组织细胞增生症

- 是一种不成熟的树突状细胞（9 版变动）；
- 细胞表面有小的突起，胞质丰富，核形状不规则，常有核沟或呈分叶状。

## （三）类白血病反应

类白血病反应：外周血白细胞（WBC）明显升高并有幼稚细胞出现，随原发病治愈而消失，需与慢性髓系白血病鉴别。

![[组织细胞和树突状细胞肿瘤-类白血病反应与慢性髓系白血病.png|500]]

| 项目 | 类白血病反应 | 慢性髓系白血病 |
| --- | --- | --- |
| 原发病 | 感染、恶性肿瘤、中毒等 | 无 |
| 脾 | 不大或轻度肿大 | 明显（巨脾） |
| WBC | 很少＞50×10⁹／L | 可＞100×10⁹／L |
| 粒细胞特点 | 胞浆内常有中毒颗粒及空泡 | 无中毒性改变 |
| 嗜酸、嗜碱细胞 | 正常 | 增多 |
| 血小板 | 无明显减少 | 正常、增加或减少 |
| 贫血 | 没有 | 有 |
| NAP（中性粒细胞碱性磷酸酶） | <font color="#ff0000">强阳性</font> | 活性降低 |
| Ph¹ 染色体 | （－） | （＋） |
| 治疗 | 随原发病治愈而消失 | 需特殊治疗而缓解 |

> [!important] 要点
> 鉴别核心：类白血病反应有原发病、NAP 强阳性、无 Ph¹ 染色体、无贫血、脾不大；慢性髓系白血病无原发病、NAP 活性降低、Ph¹ 染色体阳性、伴贫血与巨脾。此处 Ph¹ 染色体即费城染色体，由 BCR::ABL1 融合基因形成，详见 [[髓系肿瘤]]。
