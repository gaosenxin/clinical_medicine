# 概念

瘢痕组织是[[肉芽组织]]成熟后形成的纤维结缔组织。

形态特点：
- 大量平行或交错排列的胶原纤维束，常呈玻璃样变
- 纤维细胞稀少，核细长深染
- 血管显著减少
- 大体：苍白/灰白半透明，质硬韧，缺乏弹性

# 对机体的双重影响

## 有利方面

1. 填补并连接缺损，维持组织器官的完整性
2. 抗拉力优于肉芽组织，维持组织器官的坚固性

> 胶原形成不足或长期承受较大张力时，瘢痕可因缺乏弹性而膨出，形成腹壁疝或室壁瘤。

## 不利方面

1. 瘢痕收缩
	- 关节附近瘢痕可致挛缩、活动受限
	- 举例：十二指肠溃疡瘢痕 → 幽门梗阻
	- 机制：水分丧失、含有肌成纤维细胞

2. 瘢痕性粘连
	- 器官之间或器官与体腔壁之间的纤维性粘连，影响功能
	- 器官内广泛损伤 → 广泛纤维化/玻璃样变 → 器官硬化

3. 瘢痕组织增生过度（肥大性瘢痕）
	- 突出皮肤表面并向周围不规则扩延 → 瘢痕疙瘩（keloid，蟹足肿）
	- 机制不清，可能与体质、瘢痕内缺血缺氧有关

# 瘢痕改建

胶原酶（来自成纤维细胞、中性粒细胞、巨噬细胞）可分解胶原，使瘢痕缩小、软化。

研究方向：调控肉芽组织中胶原的合成与分泌，加速瘢痕内胶原的分解与吸收。
