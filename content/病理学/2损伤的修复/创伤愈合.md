# 概念
创伤愈合（wound healing）：是指机体遭受外力作用，皮肤等组织出现离断或缺损后的愈复过程，<font color="#ff0000">是包括各种组织的再生和肉芽组织增生、瘢痕形成的复杂组合</font>。

# ❤ 基本过程
1. 细胞的迁移
2. 细胞外基质重构
3. 细胞增殖
# 皮肤创伤愈合
## 基本过程（以手术切口为例）

损伤发生后，固有组织细胞、血小板及嗜碱性粒细胞释放修复介质，启动细胞迁移。介质作用包括：调节血管通透性、抑制受损组织级联反应、启动修复级联反应。

### 1. 伤口早期变化

- 组织坏死、血管断裂出血
- 数小时内出现炎症反应：充血、浆液渗出、白细胞游出，局部红肿
- 早期中性粒细胞浸润为主，3天后转为巨噬细胞为主
- 血液及渗出液中纤维蛋白原凝固成凝块，表面干燥形成痂皮，起保护作用

### 2. 伤口收缩

- 时间：2～3天开始，持续至14天左右
- 机制：伤口边缘新生的肌成纤维细胞牵拉（与胶原无关）
- 意义：缩小创面
- 影响因素：伤口部位、大小、形状

### 3. 肉芽组织增生和瘢痕形成

- 第3天起：伤口底部及边缘长出肉芽组织填平伤口
- 毛细血管增长：0.1～0.6 mm/d，方向垂直于创面，呈袢状弯曲
- <font color="#ff0000">肉芽组织无神经，故无感觉</font>
- 第5～6天起：成纤维细胞产生胶原纤维，其后一周胶原形成活跃，之后渐缓
- 伤后约1个月：瘢痕完全形成；胶原纤维最终与皮肤表面平行（受局部张力影响）

### 4. 表皮及其他组织再生

- 24小时内：伤口边缘表皮干细胞向中心迁移，增生、分化为鳞状上皮
- <font color="#ff0000">健康肉芽组织为表皮再生提供营养及生长因子</font>
- 肉芽组织填平延迟或过度生长（exuberant granulation）均会阻碍上皮再生
- 伤口过大（直径>20 cm）常需植皮

> 皮肤附属器（毛囊、汗腺、皮脂腺）完全破坏后不能完全再生，呈瘢痕修复。肌腱断裂初期亦为瘢痕修复，经功能锻炼后胶原纤维可按原方向排列，达到完全再生。

## 愈合类型

### 一期愈合（healing by first intention）

条件：组织缺损少、创缘整齐、无感染、经黏合或缝合后创面对合严密

- 少量血凝块，炎症反应轻微
- 24～48小时：表皮再生覆盖伤口
- 第3天：肉芽组织从伤口边缘长出，很快填满
- 第5～7天：胶原纤维连接，可拆线，达临床愈合；切口鲜红，可略高出皮面
- 第2周末起：瘢痕开始"变白"，持续数月
- 1个月后：表皮结构基本正常，纤维结缔组织仍富含细胞
- <font color="#ff0000">3个月：抗拉强度达顶峰</font>
- 数月后：形成白色线状瘢痕

### 二期愈合（healing by second intention）

条件：组织缺损较大、创缘不整、哆开、无法整齐对合，或伴有感染

与一期愈合的不同：
- 坏死组织多或伴感染，炎症反应明显；需待感染控制、坏死组织清除后，再生才能开始
- 伤口大，收缩明显；肉芽组织从底部及边缘长出将伤口填平
- 愈合时间较长，形成的瘢痕较大

# 😊 骨折愈合

骨折通常可分为<font color="#ff0000">外伤性骨折</font>和<font color="#ff0000">病理性骨折</font>两大类；<font color="#ff0000">骨折愈合的再生能力很强</font>。骨折愈合过程可分为以下几个阶段：

1. 血肿形成：骨折的两端及周围伴有大量出血，形成血肿，数小时后血肿发生凝固，常出现轻度的炎症反应；局部骨组织和骨髓可坏死，小坏死灶被吸收，大坏死灶可形成死骨。
    
2.  #纤维性骨痂 形成：骨折后的<font color="#ff0000">2～3 天</font>，血肿开始由肉芽组织取代而机化，继而发生纤维化而形成纤维性骨痂（<font color="#ff0000">肉芽组织老化形成胶原纤维是镜下所见的关键成分</font>）；约1周后可进一步分化出透明软骨，多见于骨外膜骨痂区。
    
3.  #骨性骨痂 形成：纤维性骨痂中分化出成骨细胞，形成类骨组织，<font color="#ff0000">以类骨为主</font>；钙盐沉积后转变为编织骨，软骨经软骨化骨演变为骨组织，形成骨性骨痂。
    
4. 骨痂改建或再塑：紊乱的骨组织逐渐变成排列正常的骨组织；编织骨改建为成熟的板层骨，恢复皮质骨与髓腔的正常关系及骨小梁排列；改建由破骨细胞骨吸收和成骨细胞骨形成协调完成。

## 影响骨折愈合的因素
骨折断端及时、正确的复位
骨折断端及时、牢靠的固定
早日进行全身和局部功能锻炼，保持局部良好的血液供应
