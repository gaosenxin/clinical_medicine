# 六、垂体疾病（学长笔记）

## （一）垂体的内分泌细胞及分泌功能

| 部位 | 细胞 | 分泌功能 |
| --- | --- | --- |
| 垂体前叶 | 嗜酸性细胞 | 促生长素细胞 → 生长激素（growth hormone, GH）<br>催乳素细胞 → 催乳素（prolactin, PRL） |
| 垂体前叶 | 嗜碱性细胞 | 促甲状腺素细胞 → 促甲状腺素（thyroid stimulating hormone, TSH）<br>促性激素细胞 → 促卵泡素（follicle stimulating hormone, FSH）、促黄体素（luteinizing hormone, LH）<br>促肾上腺皮质激素细胞 → 促肾上腺皮质激素（adrenocorticotropin hormone, ACTH）、促脂解激素（lipotrophic hormone, LPH） |
| 垂体前叶 | 嫌色细胞 | 有少量分泌功能 → 可分泌上述某种激素；<br>无分泌功能 |
| 垂体后叶 | —— | 分泌加压素，即抗利尿激素（antidiuretic hormone, ADH）；<br>分泌催产素（oxytocin, OT） |

## （二）垂体功能亢进

垂体功能亢进：前叶的某一种或多种激素分泌增多，一般由前叶的功能性肿瘤引起，最常见的如性早熟症、垂体性巨人症、垂体性肢端肥大症、高催乳素血症、垂体性 Cushing 综合征。

| 类型 | 内容 |
| --- | --- |
| 性早熟症 | 中枢神经系统疾病（脑肿瘤、脑积水等）／遗传异常 → 下丘脑-垂体过早分泌、释放促性腺激素，表现为女孩 6～8 岁，男孩 8～10 岁出现性发育 |
| 垂体性巨人症及肢端肥大症 | 多由垂体生长激素细胞瘤分泌过多的生长激素所致；<br>青春期以前、骨骺未闭合 → 人体和骨骼、器官和组织按比例地过度生长 → 垂体性巨人症；<br>青春期后发生，骨骺已闭合 → 肢端肥大症 |
| 高催乳素血症 | 垂体催乳激素细胞腺瘤分泌过多的催乳素／下丘脑病变或药物所致；<br>表现为溢乳-闭经综合征：女性溢乳、闭经、不育 |

## （三）垂体功能低下

任何原因造成的垂体前叶多数组织的破坏都能引起，如肿瘤、血液循环障碍、外科手术、外伤等，常见的有 Sheehan 综合征、Simmond 综合征。

| 类型 | 内容 |
| --- | --- |
| 垂体性侏儒症 | 垂体前叶分泌生长激素部分或完全缺乏所致儿童期生长发育障碍性疾病 |
| Simmond 综合征（慢性） | 炎症、肿瘤、血液循环障碍、损伤等多种因素使前叶各种激素分泌障碍的一种综合征，导致相应的靶器官（如甲状腺、性腺、肾上腺等）萎缩，病程呈慢性经过，以出现恶病质、过早衰老、各种激素分泌低下和产生相应临床症状为特征 |
| Sheehan 综合征（急性） | 多由<font color="#ff0000">分娩时大出血或休克</font>引起，垂体缺血性萎缩、坏死 → 垂体前叶各种激素分泌减少的一种综合征，典型的临床表现为分娩后乳腺萎缩、乳汁分泌停止，相继出现生殖器官萎缩、闭经，甲状腺、肾上腺萎缩，功能低下，进而出现全身萎缩和老化 |

## （四）垂体腺瘤

【垂体腺瘤】：<font color="#ff0000">鞍内最常见的肿瘤</font>。

主要临床表现：

1. 分泌某种过多的激素，表现相应的功能亢进（功能性肿瘤）；
2. 肿瘤浸润、破坏、压迫垂体，使其激素分泌障碍，表现为功能低下；
3. 肿瘤压迫视神经，表现为视野缺失、视力下降或失明等。
