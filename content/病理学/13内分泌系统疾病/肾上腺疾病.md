# 七、肾上腺疾病（学长笔记）

肾上腺皮质分泌盐皮质激素、糖皮质激素和肾上腺雄激素或雌激素。每类激素异常分泌过多时可导致相应的临床综合征，常见的有皮质醇增多症（hypercortisolism），又称 Cushing 综合征，和醛固酮增多症（hyperaldosteronism）。

## （一）皮质醇增多症（Cushing 综合征）

【Cushing 综合征】：由于长期分泌过多的糖皮质激素，促进蛋白质异化、脂肪沉积，表现为<font color="#ff0000">满月脸、向心性肥胖</font>、高血压、皮肤紫纹、多毛、糖耐量降低、月经失调、性欲减退、骨质疏松、肌肉乏力等。

本症成人多于儿童，常见于 20～40 岁，女性多于男性。其病因和病变如下：

| 类型 | 病变 |
| --- | --- |
| 垂体性 | 垂体肿瘤／下丘脑功能紊乱 → 分泌过多的 ACTH／下丘脑释放的 CRF 过多 |
| 肾上腺性 | 肾上腺肿瘤／增生 → 分泌大量皮质醇，此时血中 ACTH 降低 |
| 异位性 | 异位分泌的 ACTH 引起，最常见的原因是<font color="#ff0000">肺小细胞癌</font>，其他有恶性胸腺瘤、胰岛细胞瘤等 |
| 医源性 | 长期大量使用糖皮质激素引起，此时垂体-肾上腺皮质轴受抑制，可致肾上腺萎缩 |

## （二）醛固酮增多症

分为原发性和继发性两种：

| 类型 | 内容 |
| --- | --- |
| 原发性 | 大多数由肾上腺肿瘤引起，少数为肾上腺皮质增生所致；临床表现主要为高钠血症、低钾血症、高血压；<font color="#ff0000">血清中肾素降低</font>（钠潴留 → 血容量升高 → 抑制肾素释放） |
| 继发性 | 各种疾病引起肾素-血管紧张素分泌增多，刺激球状带细胞增生而引起继发性醛固酮分泌增多的疾病 |

## （三）肾上腺皮质功能低下

分为急、慢性两类：

| 类型 | 内容 |
| --- | --- |
| 急性肾上腺皮质功能低下 | 主要原因为皮质大片出血或坏死、血栓形成或栓塞、重症感染或应激反应及长期使用皮质激素治疗后突然停药等；表现为血压下降、休克、昏迷等症状，严重者可致死 |
| 慢性肾上腺皮质功能低下 | 又称为 <font color="#ff0000">Addison 病</font>。主要病因：双肾上腺结核和特发性肾上腺萎缩，极少数为肿瘤转移和其他原因；双肾上腺皮质严重破坏，表现为皮肤和黏膜及瘢痕处<font color="#ff0000">黑色素沉着增多</font>、低血压、低血糖、食欲减退、肌力低下、易疲劳、体重减轻等 |

> [!note] 黑色素沉着的机制
> 肾上腺皮质激素减少，促使垂体分泌 ACTH 及 β-LPH 增多，促进黑色素细胞合成过多的黑色素所致。

### 特发性肾上腺萎缩（自身免疫性肾上腺炎）

一种自身免疫病，多见于青年女性，患者血中常有抗肾上腺皮质细胞线粒体和微粒体抗体；患者双肾上腺高度萎缩、皮质菲薄，内有大量淋巴细胞和浆细胞浸润。

## （四）嗜铬细胞瘤

【嗜铬细胞瘤】：髓质嗜铬细胞发生的一种肿瘤，又称为肾上腺内副神经节肿瘤。

| 项目 | 内容 |
| --- | --- |
| 好发年龄与临床表现 | 多见于 20～50 岁，临床上均可伴儿茶酚胺的异常分泌 → 间歇性／持续性高血压、头痛、出汗、心动过速、心悸、基础代谢率升高、高血糖等 |
| 肉眼 | 常为单侧单发，一般大小在 2～6 cm，平均重约 100 g，可有完整包膜，切面灰白或粉红色，常有出血、坏死、钙化及囊性变 |
| 光镜 | 瘤细胞为大多角形细胞，少数为梭形或柱状细胞，并有一定程度的多形性，可出现瘤巨细胞，胞质内可见大量嗜铬颗粒，瘤细胞呈索、团状排列，间质为血窦 |
| 电镜 | 胞质内含有神经内分泌颗粒 |
| 良恶性判断 | 良、恶性嗜铬细胞瘤在细胞形态学上很难鉴别，<font color="#ff0000">只有广泛浸润邻近脏器、组织或发生转移才能确诊为恶性</font> |
| 免疫组化 | 嗜铬细胞瘤表达 CgA、Syn |
