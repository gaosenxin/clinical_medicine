# 五、胰岛疾病（学长笔记）

## （一）糖尿病

【糖尿病】（diabetes mellitus）：一种因体内<font color="#ff0000">胰岛素绝对或相对不足</font>或靶细胞对胰岛素敏感性降低等引起的糖、脂肪、蛋白质代谢紊乱的一种慢性疾病。

### 1. 分类、病因、发病机制

| 分类 | 亚型 | 特点 |
| --- | --- | --- |
| 原发性糖尿病 | 胰岛素依赖型（Ⅰ型或幼年型） | 约占 10%，胰岛素分泌<font color="#ff0000">绝对不足</font>引起 |
| 原发性糖尿病 | 非胰岛素依赖型（Ⅱ型或成年型） | 约占 90%，胰岛素<font color="#ff0000">相对不足</font>，胰岛素抵抗引起 |
| 继发性糖尿病 | —— | 已知原因造成胰岛内分泌功能不足所致的糖尿病，如炎症、肿瘤、手术等 |

### 2. 病理变化

| 部位 | 病变 |
| --- | --- |
| 胰岛病变 | 胰岛 B 细胞颗粒脱失、变性、坏死；1 型胰岛玻璃样变，2 型后期常见胰岛淀粉样变性 |
| 血管病变 | 广泛动脉壁内皮细胞增生，血管壁增厚、玻璃样变、变硬 → 组织器官缺血、功能障碍、病变；大、中动脉有动脉粥样硬化或中层钙化 → 冠心病、心肌梗死、脑萎缩、四肢坏疽等 |
| 肾脏病变 | 早期，肾脏体积增大；<br>结节性肾小球硬化：肾小球系膜内出现圆形或卵圆形均质嗜伊红的玻璃样物质沉积结节，结节增大可使毛细血管腔阻塞；<br>毛细血管基底膜增厚；<br>弥漫性肾小球硬化：系膜基质弥漫性增多，基底膜弥漫性增厚 → 毛细血管腔变窄／闭塞，肾小球玻变 |
| 视网膜病变 | 早期表现为微小动脉瘤和视网膜小静脉扩张、渗出、水肿、微血栓形成、出血等病变；还可因血管病变引起缺氧，刺激纤维组织增生、新生血管形成等增生性视网膜性病变 |

## （二）胰岛细胞瘤

【胰岛细胞瘤】：胰腺的神经内分泌肿瘤。

| 项目 | 内容 |
| --- | --- |
| 类型 | 胰岛素瘤、胃泌素瘤、高血糖素瘤、生长抑素瘤、血管活性肠肽瘤、胰多肽瘤 |
| 性质 | 良、恶性均有 |
| 好发部位 | 胰腺 |
