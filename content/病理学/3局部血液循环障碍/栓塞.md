# ❤概念
1. 栓塞
	在循环血液中出现的不溶于血液的异常物质，随血流运行阻塞血管腔的现象称为 #栓塞
2. 栓子（embolus）
	阻塞血管的异常物质称为 #栓子

# 栓子的种类和来源

栓子可为固体、液体或气体。最常见的是脱落的血栓或其节段，其他有脂肪滴、空气、羊水、肿瘤细胞团等。

# 😊 栓子的运行途径

栓子随血流运行，最终停留在口径与其相当的血管并阻断血流。

| 来源                                         | 运行与栓塞部位                                                                          |
| ------------------------------------------ | -------------------------------------------------------------------------------- |
| <font color="#ff0000">体静脉</font>系统 / 右心腔   | 肺动脉主干及分支 → <font color="#ff0000">肺栓塞</font>；小而有弹性者（如脂肪栓子）可经肺泡壁毛细血管回左心 → 体循环动脉小分支 |
| <font color="#ff0000">主动脉</font>系统 / 左心腔   | 随动脉血流阻塞各器官小动脉，常见于<font color="#ff0000">脑、脾、肾、四肢指</font>（趾）                       |
| <font color="#ff0000">门静脉</font>系统（肠系膜静脉等） | <font color="#ff0000">肝</font>内门静脉分支                                             |
| 交叉性栓塞（反常性栓塞）                               | 右心腔 / 腔静脉栓子在右心压力升高时经房（室）间隔缺损或<font color="#ff0000">动脉导管未闭</font>入左心 → 体循环                                            |
| 逆行性栓塞                                      | 下腔静脉血栓在胸腹压骤升（咳嗽、深呼吸）时逆流至肝、肾、髂静脉分支                                                |

# ❤ 栓子的类型和对机体的影响

分血栓栓塞、脂肪栓塞、气体栓塞、羊水栓塞。

## （一）血栓栓塞

血栓或血栓的一部分脱落引起，占所有栓塞的 99% 以上。

### 1. 肺动脉栓塞

栓子 95% 以上来自膝以上下肢深部静脉（腘、股、髂总静脉），偶见盆腔静脉或右心附壁血栓。

对机体的影响取决于大小：
- 中小栓子：多栓塞肺动脉小分支。肺有双重血供（肺动脉 + 支气管动脉吻合支），一般<font color="#ff0000">不引起</font>严重后果，可溶解或机化；若栓塞前已有严重淤血，可引起出血性梗死
- 大栓子（少）：栓塞肺动脉主干或大分支，长者骑跨于分叉处称骑跨性栓塞，可突发呼吸困难、发绀、[[休克]]，严重者猝死
- 小栓子（多）：广泛栓塞肺动脉多数小分支，可致右心衰竭猝死

> [!important] 猝死机制
> - 肺动脉阻力骤增 → 急性右心衰竭；肺缺血缺氧、左心回心血量减少 → 冠状动脉灌流不足、心肌缺血
> - 刺激迷走神经反射性引起肺动脉、冠状动脉、支气管平滑肌痉挛 → 急性右心衰竭和窒息
> - 血小板释出 5-HT、血栓素 A₂ 引起肺血管痉挛（故新鲜血栓栓子危害更大）

![[栓塞-1789286446955.webp|344]]
### 2. 体循环动脉栓塞

约 80% 栓子来自左心腔：亚急性感染性<font color="#ff0000">心内膜炎的瓣膜赘生物</font>、二尖瓣狭窄的左心房<font color="#ff0000">附壁血栓</font>、心肌梗死区心内膜附壁血栓；其余为动脉粥样硬化溃疡或动脉瘤附壁血栓。

主要栓塞部位为下肢、脑、肠、肾、脾。后果取决于栓塞部位、侧支循环及组织对缺血的耐受性；无有效侧支循环时引起梗死。上肢动脉吻合支丰富、肝有双重供血，故很少梗死。

## （二）脂肪栓塞

循环血流中出现较大脂肪滴阻塞小血管。

- 来源：
	- <font color="#ff0000">创伤性</font>（长骨骨折、脂肪组织严重挫伤和烧伤、脂肪肝受挤压）→ 脂滴经骨髓血管窦状隙或静脉入血；
	- 非创伤性（糖尿病、慢性胰腺炎、酗酒等血脂过高）
- 部位：栓子经右心到肺，> 20μm 阻塞肺动脉分支/小动脉/毛细血管；< 20μm 经肺静脉入左心 → 体循环，最常阻塞脑血管（脑水肿、点状出血）
- 表现：损伤后 1～3 天突发呼吸急促、呼吸困难、心动过速；游离脂肪酸致内皮损伤、特征性瘀斑皮疹；脑栓塞可有兴奋、烦躁、谵妄、昏迷

> [!important] 脂肪栓塞与血栓栓塞的时间鉴别
> 一般认为脂肪栓塞较早发生呼吸困难；若受伤一两天后活动时突然出现呼吸困难，优先考虑<font color="#ff0000">血栓</font>栓塞。

- 后果：
	- 脂滴大小：小，体循环栓塞；大，肺栓塞
	- 脂肪数量：
		- 少量脂滴入血，可被巨噬细胞吞噬吸收，或由血中脂酶分解清除，无不良后果。
		- 大量脂滴（9～20g）短期内进入肺循环，使75%的肺循环面积受阻时，可引起窒息和因急性右心衰竭而死亡。

## （三）气体栓塞

空气迅速入血，或血内溶解气体迅速游离成气泡阻塞心血管。前者为空气栓塞，后者为减压病。

### 1. 空气栓塞

多因<font color="#ff0000">静脉损伤破裂</font>：头颈/胸壁/肺手术或创伤、正压静脉输液、人工气胸或气腹误伤静脉、分娩或流产时空气被挤入子宫壁破裂的静脉窦。

- 少量入血可溶解，无症状
- 大量（> 100ml）迅速入静脉：右心内搅拌成泡沫状血气泡，阻碍静脉回流及向肺动脉输出 → 呼吸困难、发绀、猝死；气泡可入肺动脉致肺小动脉栓塞，或经肺毛细血管入左心致体循环器官栓塞
- 气泡可激活血小板与第Ⅲ因子启动凝血 → [[弥散性血管内凝血|DIC]]，加重症状

### 2. 减压病（decompression sickness）

又称沉箱病、潜水员病、氮气栓塞。从高气压迅速转入常压/低气压，血、组织液、脂肪中溶解的气体游离成气泡；<font color="#ff0000">氧和二氧化碳</font>可再溶于体液内被吸收，<font color="#ff0000">氮气</font>溶解迟缓，最易形成气泡。
气血混合导致心输出量减少

- 皮下 → 皮下气肿
- 肌肉、肌腱、韧带 → 关节和肌肉疼痛
- 局部血管 → 局部缺血、梗死（股骨头、胫骨、髂骨无菌性坏死）
- 末梢血管（四肢、肠道）→ 痉挛性疼痛
- 短期内大量气泡阻塞多数血管（尤以冠状动脉）→ 严重循环障碍、迅速死亡

## （四）羊水栓塞

分娩过程中罕见而严重的并发症（1/50 000），病死率 > 80%。

- 机制：子宫强烈收缩、宫内压增高，羊水被压入子宫壁破裂的静脉窦 → 入肺动脉分支、小动脉、毛细血管；少量经肺静脉入左心致体循环栓塞
- 诊断依据：镜下见肺小动脉和毛细血管内有羊水成分（角化鳞状上皮、胎毛、胎脂、胎粪、黏液），母血中亦可找到
- 表现：分娩中或产后突发呼吸困难、发绀、抽搐、休克、昏迷，甚至死亡

> [!important] 猝死机制
> - 羊水胎儿代谢产物入血 → 过敏性休克
> - 羊水栓子阻塞肺动脉 + 血管活性物质 → 反射性血管痉挛
> - 羊水异源性物质入血 → <font color="#ff0000">血管广泛扩张</font>
> - 羊水具凝血致活酶作用 → [[弥散性血管内凝血|DIC]]

## （五）其他栓塞

- 细胞栓塞：肿瘤细胞、胎盘滋养叶细胞侵蚀血管，骨折时骨髓细胞入血
- 胆固醇结晶（动脉粥样硬化灶脱落）→ 动脉系统栓塞
- [[日本血吸虫|血吸虫]]及其虫卵 → 肝内门静脉小分支
- 细菌、真菌团、异物（子弹/弹片）偶尔入血
# 结局
阻塞血管、阻断血流
	静脉血管阻塞→淤血、水肿、出血
	动脉血管阻塞→[[梗死]]
		→代偿性侧支循环开放细菌或肿瘤栓塞→感染或肿瘤的扩散
