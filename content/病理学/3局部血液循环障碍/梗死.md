# ❤ 概念

器官或局部组织因血管阻塞、血流停滞而[[缺氧]]，所发生的坏死，称为 #梗死（infarction）。

# ❤ 形成的条件

任何引起血管腔阻塞，导致局部组织血液循环中断和缺血的原因，均可引起梗死。

## （一）梗死形成的原因
90%都是动脉阻塞引起的
1. 血栓形成 —— 最常见	- 动脉血栓形成致动脉血流中断或灌流不足
	- 常见于冠状动脉、脑动脉粥样硬化合并血栓形成 → 心肌梗死、脑梗死
	- 血栓闭塞性脉管炎累及足背动脉 → 足部梗死
	- 静脉血栓一般只引起淤血、水肿，但肠系膜静脉血栓形成可引起所属引流肠段的梗死
2. 动脉栓塞	- 多为动脉血栓栓塞，亦可为气体、羊水、脂肪栓塞
	- 常引起脾、肾、肺和脑的梗死
3. 动脉痉挛	- 在严重冠状动脉粥样硬化或硬化灶内出血的基础上，冠状动脉发生强烈而持续的痉挛 → 心肌梗死
4. 血管受压闭塞	- 血管外肿瘤压迫血管
	- 肠扭转、肠套叠、嵌顿疝时，肠系膜静脉和动脉受压或血流中断
	- 卵巢囊肿扭转、睾丸扭转致血流供应中断

## （二）梗死形成的影响因素

血管阻塞后是否造成梗死，与下列因素有关。

### 1. 器官血供特性
- 双重血液循环的器官 —— 一条动脉阻塞，另一条可维持供血，通常不易梗死
	- 肺：肺动脉 + 支气管动脉，肺动脉小分支血栓栓塞一般不引起梗死
	- 肝：肝动脉 + 门静脉双重供血，肝梗死很少见；门静脉阻塞一般不引起梗死，肝动脉血栓栓塞偶尔造成梗死
	- 前臂、手：桡动脉与尺动脉平行走行、吻合支丰富 → 绝少梗死
- 吻合支少的器官 —— 肾、脾、脑，动脉迅速阻塞时不易建立有效侧支循环，常易梗死

### 2. 局部组织对缺血的敏感程度
| 组织 | 对缺血的耐受 |
| --- | --- |
| 脑（少突胶质细胞、神经细胞） | 最敏感，缺血 3～4 分钟即引起梗死 |
| 心肌细胞 | 敏感，缺血 20～30 分钟即死亡 |
| 骨骼肌、纤维结缔组织 | 耐受性最强 |

> 严重贫血或[[心功能不全]]时血氧含量降低，可促进梗死的发生。

# ❤ 病理改变

## （一）梗死的形态特征

梗死是局部组织的坏死，其形态因组织器官不同而有所差异。

### 1. 梗死灶的形状 —— 取决于器官的血管分布方式

- 血管呈锥形分支的器官（脾、肾、肺）→ 梗死灶呈锥形，切面呈扇面形或三角形，尖端位于血管阻塞处，指向脾门、肾门、肺门，底部为器官表面
- 肠 → 肠系膜血管呈扇形分支并支配某一肠段，肠梗死灶呈节段形
- 心 → 冠状动脉分支不规则，心肌梗死灶呈地图状
![[梗死-1789718138187.webp|678]]![[梗死-1789718168145.webp|685]]
### 2. 梗死灶的质地 —— 取决于坏死的类型

- 实质器官（心、脾、肾）→ 凝固性坏死
	- 新鲜时组织崩解，局部[[血液生理概述|胶体渗透压]]升高而吸收水分 → 局部肿胀，表面和切面均微隆起；近浆膜面常有纤维蛋白性渗出物被覆
	- 陈旧性梗死含水分较少 → 略干燥，质地变硬，表面下陷
- 脑 → 液化性坏死：新鲜时质软疏松，日久逐渐液化成囊状
![[梗死-1789718150578.webp]]
### 3. 梗死灶的颜色 —— 取决于病灶内的含血量

- 含血量少 → 颜色灰白 →  #贫血性梗死 （anemic infarction）或白色梗死（white infarction）
- 含血量多 → 颜色暗红 → #出血性梗死 （hemorrhagic infarction）或红色梗死（red infarction）

# 😊 类型

|      | 贫血性梗死         | 出血性梗死       | 败血性梗死 |
| ---- | ------------- | ----------- | ----- |
| 组织结构 | 致密            | 疏松          |       |
| 血供情况 | 单循环/侧支循环不丰富   | 双循环/侧支循环丰富  |       |
| 原因   | 动脉阻塞，静脉回流未受影响 | 淤血＋动脉阻塞     |       |
| 器官   | 心、脑、肾、脾       | 肺、肠（卵巢）     |       |

## （一）贫血性梗死

发生于组织结构较致密、侧支循环不充分的实质器官，如脾、肾、心和脑组织。
### 😭形态学改变

- 形成机制：动脉分支阻塞 → 局部缺血缺氧 → 微血管通透性增高，病灶边缘侧血管内血液漏出于病灶周围，形成梗死灶周围的出血带
- 颜色：梗死灶组织致密，出血量反而不多；红细胞崩解、血红蛋白溶入组织液被吸收 → 梗死灶呈灰白色
- 形状：脾、肾梗死灶呈锥形，尖端向血管阻塞处，底部靠脏器表面，浆膜面常有纤维蛋白性渗出物被覆；心肌梗死灶呈不规则地图状
- 演变（早期）：梗死灶与正常组织交界处因炎症反应常见充血出血带；数日后红细胞被巨噬细胞吞噬转变为含铁血黄素 → 变成黄褐色
- 演变（晚期）：病灶表面下陷、质地坚实，黄褐色出血带消失，梗死灶发生机化，初由肉芽组织取代，以后形成瘢痕组织
- 镜下：呈[[坏死#凝固性坏死（coagulative necrosis）|凝固性坏死]]，早期细胞尚可见核固缩、核碎裂、核溶解，胞质嗜伊红、均匀一致，组织结构轮廓尚保存；随后肉芽组织长入，最终被瘢痕组织代替
- 脑梗死：一般为贫血性梗死，脑组织<font color="#ff0000">液化性坏死</font>，以后形成囊状，或被增生的星形胶质细胞和胶质纤维所代替，最后形成胶质瘢痕

## （二）出血性梗死

### 发生条件

1. <font color="#ff0000">严重淤血</font> —— 器官原有严重淤血时，血管阻塞引起的梗死为出血性，如肺淤血
	- 严重淤血是肺梗死形成的重要先决条件：肺淤血时肺静脉和毛细血管内压增高，影响肺动脉分支阻塞后建立有效的肺动脉、支气管动脉侧支循环 → 肺出血性梗死
2. 组织疏松 —— 肠和肺的组织较疏松，梗死初期疏松的组织间隙可容纳多量漏出的血液；组织坏死吸收水分膨胀时，也不能把漏出的血液挤出梗死灶外 → 梗死灶为出血性
	- 例外：肺有炎症而实变时，所发生的肺梗死一般为贫血性梗死

### 常见类型

#### 1. 肺出血性梗死

- 部位：常位于肺下叶及肺的边缘，尤其好发于肋膈缘，常多发，病灶大小不等
- 😭形态：呈锥形（楔形），尖端朝向肺门，底部紧靠肺膜，肺膜表面有纤维蛋白性渗出物
- 质地与颜色：质实，因弥漫性出血呈暗红色，略向表面隆起；时间久后红细胞崩解颜色变浅，肉芽组织长入逐渐机化 → 灰白色，瘢痕组织收缩使病灶表面局部下陷
- 镜下：呈凝固性坏死，可见肺泡轮廓，肺泡腔、小支气管腔及肺间质充满红细胞；早期（48 小时内）红细胞轮廓尚保存，以后崩解；梗死灶边缘与正常肺组织交界处肺组织充血、水肿及出血

![[梗死-1789286713944.webp|231]]![[梗死-1789718404796.webp|678]]![[梗死-1789718435633.webp|682]]

#### 2. 肠出血性梗死

- 多见于肠系膜动脉栓塞和静脉血栓形成，或在肠套叠、肠扭转、嵌顿疝、肿瘤压迫等情况下引起
- 😭肠梗死灶呈节段性暗红色，肠壁因淤血、水肿和出血呈明显增厚，随之肠壁坏死、质脆易破裂，肠浆膜面可有纤维蛋白性脓性渗出物被覆
![[梗死-1789286730448.webp|350]]![[梗死-1789718558253.webp]]
## （三）❤ 败血性梗死（septic infarction）

- 由含有细菌的栓子阻塞血管引起
- 常见于急性感染性心内膜炎：含细菌的栓子从心内膜脱落，顺血流运行引起相应组织器官动脉栓塞
- 梗死灶内可见细菌团及大量炎症细胞浸润；若有化脓性细菌感染，可形成脓肿
![[梗死-1789718603252.webp]]
# 对机体的影响

取决于发生梗死的器官、梗死灶的大小和部位，以及有无细菌感染等因素。

- 重要器官大面积梗死 → 器官严重功能障碍，甚至导致患者死亡
	- 大面积心肌梗死 → 心功能不全或死亡
	- 大面积脑梗死 → 瘫痪或死亡
- 脾、肾梗死 → 对机体影响较小，常仅引起局部症状
	- 肾梗死：腰痛、血尿，一般不影响肾功能
	- 肺梗死：胸痛、咳嗽、咯血
	- 肠梗死：剧烈腹痛、呕吐、血便、麻痹性肠梗阻和腹膜炎症状
- 肺、肠、四肢梗死若继发腐败菌感染 → 坏疽，后果严重

# ❤ 结局

梗死灶是组织的不可逆性病变。梗死组织可被溶解、吸收，或发生机化、包裹和钙化。

- 凝固性坏死灶（心、肾、脾等）：肉芽组织长入取代 → 机化 → 瘢痕组织；瘢痕收缩使病灶表面局部下陷
- 脑梗死（液化性坏死）：坏死组织液化成囊状，或被增生的星形胶质细胞和胶质纤维代替，最后形成胶质瘢痕

> [!note] 类型—结局对应（讲义提炼）
> - 贫血性梗死：实质器官凝固性坏死灶机化 → 瘢痕组织；脑梗死液化 → 囊状或胶质瘢痕
> - 出血性梗死：肺梗死灶红细胞崩解、颜色变浅，肉芽组织长入逐渐机化 → 灰白色，瘢痕收缩致表面下陷；肠梗死灶肠壁坏死、质脆易破裂
> - 败血性梗死：若为化脓性细菌感染，可形成脓肿
