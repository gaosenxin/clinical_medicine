# ❤ 概念
在活体的心脏和血管内，血液发生凝固或血液中某些有形成分凝集形成固体质块的过程，称为血栓形成（thrombosis）。
所形成的固体质块称为 #血栓 （thrombus）
# 血栓形成的❤条件和😊机制

> [!important] 形成基本条件
> - 心血管内皮细胞损伤
> - 血流状态异常
> - [[血液凝固|血液凝固]]性增加

---

## （一）心血管内皮细胞损伤

<font color="#ff0000">最重要、最常见</font>的原因。内皮细胞具有抗凝和促凝两种功能，生理情况下以抗凝为主。

### 1. 抗凝作用

- 屏障作用：分隔血小板、凝血因子与内皮下促凝基质
- 抗血小板黏集：合成 PGI₂、NO、ADP 酶
- 合成抗凝物质：
  - 凝血酶调节蛋白 → 激活蛋白 C → 灭活因子 Ⅴ、Ⅷ
  - 膜相关肝素样分子 → 与抗凝血酶 Ⅲ 结合 → 灭活凝血酶、因子 Ⅹ、Ⅸ
  - 蛋白 S → 协同蛋白 C 灭活因子
- 促纤溶：合成 t-PA

### 2. 促凝作用（损伤时被激活）

- 释放组织因子 → 激活外源性凝血
- 释放 vWF → 介导血小板与胶原黏附
- 分泌 PAI → 抑制纤溶

<font color="#ff0000">内源性凝血</font>：内皮损伤后暴露内皮下胶原 → 激活血小板和凝血因子 Ⅻ → 启动内源性凝血
外源性凝血：损伤的内皮细胞释放组织因子（因子 Ⅲ）→ 激活凝血因子 Ⅶ → 启动外源性凝血
![[血栓形成-1788784383914.webp]]
### 3. 血小板活化（三种连续反应）

- 黏附反应：vWF 介导血小板与内皮下胶原结合（整合素、糖蛋白 Ⅰb）
- 释放反应：释放 α 颗粒（纤维蛋白原、vWF、Ⅴ 因子等）和 δ 颗粒（ADP、ATP、Ca²⁺、5-HT 等）
  - ADP 是血小板间黏集的强有力介质
- 黏集反应：Ca²⁺、ADP、TXA₂ 作用下血小板不断黏集
  - 初期可逆 → 凝血酶产生 → 不可逆融合团块 → 纤维蛋白交织 → 血栓形成起始点
  - 凝血酶是核心成分，也是临床治疗靶点

### 常见情况

风湿性/感染性心内膜炎、心肌梗死区心内膜、粥样硬化斑块溃疡、创伤/炎症性血管损伤、[[缺氧]]、[[休克]]、败血症、细菌内毒素 → 可致 [[弥散性血管内凝血|DIC]]

## （二）血流状态异常

正常血流分层：红细胞、白细胞在中轴（轴流），其外是血小板，最外为一层血浆（<font color="#ff0000">边流</font>）。

- 血流<font color="#ff0000">减慢或产生漩涡</font> → 血小板进入边流 → 增加与内膜接触
- 凝血因子和凝血酶局部浓度升高

### 机理
破坏边流，增加血小板黏附
不能稀释活化的凝血因子
抗凝因子难以补充
内皮细胞损伤
- 涡流（turbulence）→ 主动脉和心腔内血栓形成
- 血流停滞（stasis）→ 静脉血栓形成
## （三）血液凝固性增加

高凝状态（hypercoagulability），分原发性和继发性。

- 原发性（遗传性）高凝状态：因子 Ⅴ 基因突变、凝血酶原基因突变、抗凝血酶 Ⅲ 缺陷、蛋白 C/蛋白 S 缺陷
- 继发性（获得性）高危因素：
	- 晚期恶性肿瘤可释放促凝因子；[[弥散性血管内凝血|DIC]]
	- 严重创伤、大面积烧伤、大手术后、产后大失血 → 血液浓缩，血小板和凝血因子增多
	- 妊娠期高血压、高脂血症、冠状动脉粥样硬化、吸烟、肥胖症等

# 😊 形成过程

## 起始阶段

- 血小板黏附于裸露胶原 → 激活 → 肿胀变形
- 释放颗粒内容物：ADP、TXA₂、5-HT、血小板第 Ⅳ 因子
- 血小板不断局部黏附 → 形成可逆血小板小堆

## 凝血途径启动

- 内源性 + 外源性凝血途径启动
- 可逆血小板小堆 → 不可逆血小板血栓（起始点）

## 血栓增大

- 凝血酶、ADP、TXA₂ 协同作用
- 血小板不断激活、黏附 → 血栓持续增大
- 血小板血栓阻碍血流 → 下游形成漩涡 → 新血小板小堆
- 反复进行 → 血小板黏附形成梁索状/珊瑚状突起（血小板小梁）

## 典型延续性血栓的形成链条

内膜损伤 → 胶原暴露 → 血小板黏附、释放、聚集 → 血小板小堆（可逆）→ 内、外源性凝血途径启动，纤维蛋白连接 → 不可逆血小板血栓（头）→ 血小板血栓下游血流变慢、形成漩涡 → 多个血小板小梁形成，小梁间纤维蛋白网充满红细胞（体）→ 血栓不断增大阻塞血管腔，下游血流停滞 → 血液凝固（尾）

> 尾部经常容易脱落，形成肺栓塞。

## 血栓结构

- 血小板小梁间：大量红细胞 + 纤维蛋白网填充
- 光镜：无结构淡红色，少量纤维蛋白
- 电镜：血小板轮廓可见，颗粒消失

> 血栓的发展、形态、组成和大小取决于发生部位和局部血流状态。

# 😊 血栓的类型与形态
![[血栓形成-1789718710637.webp]]
## 白色血栓（white thrombus）

> 概念：主要由血小板及少量纤维蛋白构成的灰白色固体质块，是血栓形成的起始部分。

- 好发部位：血流较快处——心瓣膜、心腔、动脉内；静脉延续性血栓的头部
- 肉眼：灰白色小结节或赘生物状，表面粗糙、质实，与血管壁紧密黏着不易脱落
- 镜下：血小板 + 少量纤维蛋白
- 别名：血小板血栓、析出性血栓
![[血栓形成-1789365931324.webp|302]]![[血栓形成-1789366057354.webp|388]]![[血栓形成-1789716281274.webp|347]]![[血栓形成-1789716295612.webp|344]]
## 混合血栓（mixed thrombus）

> 概念：由血小板小梁与纤维蛋白网及红细胞交替沉积、呈层状结构的血栓，多由白色血栓进一步发展而成。

- 好发部位：静脉延续性血栓的体部；心腔内、粥样硬化溃疡、动脉瘤内（<font color="#ff0000">附壁血栓</font> mural thrombus）；左心房内（球状）
- 肉眼：灰白色与红褐色层状交替（层状血栓），粗糙干燥圆柱状，与血管壁粘连
- 镜下：淡红色无结构的分支状/珊瑚状血小板小梁（肉眼灰白色）+ 小梁间纤维蛋白网及红细胞（肉眼红色）；小梁边缘可见中性粒细胞附着（纤维蛋白崩解趋化）
- 形成机制：血小板小梁与红细胞/纤维蛋白网交替沉积

❤附壁血栓（mural thrombus）
	发生于心腔内、动脉粥样硬化溃疡部位或动脉瘤内的混合血栓![[血栓形成-1789366431359.webp]]

## 红色血栓（red thrombus）

> 概念：血流极度缓慢或停滞时，血液发生凝固所形成的、以红细胞为主的暗红色固体质块，实质为凝固性血栓。

- 好发部位：静脉内，延续性血栓的尾部
- 肉眼：暗红色，新鲜时湿润有弹性，与血管壁无粘连（类似死后血凝块）；后期干燥、无弹性、质脆易碎
- 镜下：纤维蛋白网眼内充满血细胞，绝大多数为红细胞 + 少量白细胞
- 特点：与血管壁无粘连、质脆，<font color="#ff0000">最易脱落</font> → 脱落形成栓子 → 肺栓塞
![[血栓形成-1789702424123.webp]]
## 透明血栓（hyaline thrombus）

> 概念：发生于微循环毛细血管内、主要由嗜酸性同质性纤维蛋白构成的、仅镜下可见的微小血栓。

- 好发部位：微循环毛细血管（仅镜下可见）
- 镜下：嗜酸性、同质性纤维蛋白
- 别名：微血栓、<font color="#ff0000">纤维素性血栓</font>（fibrinous thrombus）
- 最常见于：[[弥散性血管内凝血|DIC]]
![[血栓形成-1789366727403.webp|700]]
# ❤ 结局

## 软化、溶解和吸收

- 纤溶酶激活 + 白细胞崩解释放溶蛋白酶 → 血栓软化溶解
- 取决于血栓大小和新旧程度：
  - 小的新鲜血栓：快速完全溶解
  - 大的血栓：部分软化 → 可碎裂或整体脱落 → 血栓栓塞

## 机化和再通

- 条件：纤溶酶系统活性不足，血栓存在时间较长
- [[坏死#机化与包裹|机化]]（organization）：
  - 血栓形成后 1–2 天开始
  - 内皮细胞、成纤维细胞、肌成纤维细胞从血管壁长入
  - 肉芽组织逐渐取代血栓
  - 较大血栓约 2 周完全机化 → 与血管壁紧密黏着不再脱落
- 再通（recanalization）：
  - 机化过程中水分被吸收 → 血栓干燥收缩或部分溶解出现裂隙
  - 新生血管内皮细胞长入被覆裂隙表面 → 相互吻合沟通
  - 被阻塞血管部分重建血流
  - 再通血管口径比原血管<font color="#ff0000">细</font>
![[血栓形成-1789366921920.webp|687]]![[血栓形成-1789702666849.webp|676]]![[血栓形成-1789716162214.webp|687]]
## 钙化

- 长时间存在的血栓 → 钙盐沉着
- 静脉石（phlebolith）/ 动脉石（arteriolith）
- 机化血栓的纤维组织玻璃样变基础上也可发生钙化
![[血栓形成-1789367033205.webp]]
# ❤ 对机体的影响

- 有利：破裂血管起止血作用（如慢性胃溃疡、[[结核分枝杆菌|肺结核空洞]] 壁血管）
- 不利：取决于血栓部位、大小、类型、阻塞程度及侧支循环建立情况

## 阻塞血管

- 动脉未完全阻塞 → 局部缺血，实质细胞萎缩
- 动脉完全阻塞 + 无有效侧支循环 → 梗死
  - 脑动脉 → 脑梗死
  - 心冠状动脉 → 心肌梗死
  - 血栓闭塞性脉管炎 → 患肢梗死，可合并坏疽
- 静脉浅表 → 侧支丰富，通常症状不明显
- 静脉深部 + 无有效侧支 → 淤血、水肿、出血、坏死（如肠出血性梗死）

## 栓塞

- 血栓与血管壁黏着不牢固 / 软化碎裂 → 整体或部分脱落成为栓子
- 最易脱落：深部静脉血栓、心室/心瓣膜血栓
- 深部静脉栓子 → 肺栓塞
- 左室、心瓣膜栓子 → 左心系统栓塞，如<font color="#ff0000">脾栓塞、肠系膜上动脉栓塞</font>
- 含细菌栓子 → 败血性梗死或脓肿形成

## 心瓣膜变形

白色血栓的主要结局：

- 风湿性/感染性心内膜炎 → 瓣膜上反复形成血栓（赘生物）→ 机化（肉芽组织取代、慢性炎症）
- 机化后瓣叶周边粘连、瓣膜增厚变硬 → 瓣膜口狭窄（二尖瓣早期狭窄；后期肉芽组织老化、挛缩、纤维化变硬）
- 瓣膜增厚卷缩、腱索增粗缩短 → 瓣膜关闭不全
- 持续的关闭不全呈<font color="#ff0000">鱼嘴样</font>二尖瓣 → 典型<font color="#ff0000">房颤</font>

## 广泛性出血

- [[弥散性血管内凝血|DIC]] → 微循环广泛纤维蛋白性血栓 → 广泛性出血
- 病因：严重创伤、大面积烧伤、羊水栓塞、癌肿、感染、缺氧、酸中毒等
- 机制：外源性/内源性凝血启动 → 微血管广泛纤维蛋白性血栓 → 凝血因子大量消耗 + 血浆素原激活 → 血液凝固障碍
- 受累器官：肺、肾、脑、肝、胃肠、肾上腺、胰腺等
- 后果：组织广泛坏死及出血、全身广泛性出血、休克
- 耗竭性凝血障碍病（consumption coagulopathy）
