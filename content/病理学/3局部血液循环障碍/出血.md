# ❤ 概念
血液从<font color="#ff0000">活体</font>血管或心腔溢出，称为出血（hemorrhage）

毛细血管出血常常发生于慢性淤血；大动脉、大静脉的破裂性出血则常由血管外伤引起，或由炎症和肿瘤侵蚀血管壁引起。

# 😭 病因和发病机制

病理性出血按机制分为破裂性出血和漏出性出血。

## 破裂性出血

心脏或血管壁破裂，出血量较多。

- 机械性损伤：割伤、刺伤
- 心血管病变：室壁瘤、主动脉瘤、粥样硬化破裂
- 周围病变侵蚀：恶性肿瘤、[[结核分枝杆菌|结核空洞]]、消化性溃疡
- 静脉破裂：食管下段静脉曲张（肝硬化）
- 毛细血管破裂：软组织损伤

## 漏出性出血

微循环的毛细血管和毛细血管后静脉通透性增高，血液通过扩大的内皮细胞间隙和受损的基底膜漏出血管外。

- 血管壁损害 → 微循环血管壁通透性增高：[[缺氧]]、感染、中毒、过敏性紫癜（IC 沉着于血管壁）
- <font color="#ff0000">血小板减少或功能障碍</font>：再生障碍性贫血、白血病等使血小板产生减少；DIC 时血小板消耗过多
- 凝血因子缺乏：先天性缺乏；肝实质疾患（肝炎、肝硬化、肝癌等）凝血因子合成减少；DIC 时凝血因子消耗过多

## 按有无疾病分类

- 生理性出血：月经期子宫内膜出血
- 病理性出血：创伤、血管病变、凝血机制障碍等引起的出血

# 😭 病理变化

按出血部位：

- 内出血：血液进入体腔或组织
  - 体腔积血：心包、胸腔、腹腔、关节腔
  - 血肿：硬膜下、皮下、腹膜后等
  - 瘀点：< 2mm；紫癜：3–5mm；瘀斑：> 5mm
  - 颜色演变：红蓝 → 胆红素 → 含铁血黄素（棕黄）
- 外出血：鼻出血、咯血、呕血、便血、尿血

# 😭 后果

- 少量出血：血管收缩、血小板黏集、凝血块形成 → 自行停止，吸收或机化
- 大量/快速出血：失血量达 20%–25% → [[休克|失血性休克]]
- 漏出性出血且出血广泛（如肝硬化门脉高压引起的胃肠道黏膜广泛漏出性出血）→ 也可导致出血性休克
- 重要器官出血：
  - 心脏压塞 → 急性[[心功能不全]]
  - 脑干出血 → 可致死
  - 内囊出血 → 对侧肢体偏瘫
  - 视网膜出血 → 视力下降或失明
- 慢性反复出血 → 缺铁性贫血（如 [[钩虫|钩虫病]] 成虫长期吸血、伤口渗血所致）
