# ❤ 概念

#水肿 （edema）是指组织间隙内的体液增多。体液积聚于体腔内则称为积液，如胸腔积液、心包积液、腹腔积液（腹水）。

- 按波及范围：全身性水肿、局部性水肿
- 按发病原因：肾性水肿、肝性水肿、心性水肿、营养不良性水肿、淋巴性水肿、炎性水肿
- 全身性水肿：除浆膜腔积液外，还伴有明显的皮下组织水肿

# 😊 发病机制

基本环节：毛细血管流体静压增高、[[血液生理概述|血浆胶体渗透压]]降低、血管通透性增高、淋巴回流障碍。

### 渗出液与漏出液的比较
| 项目 | 渗出液 | 漏出液 |
| ---- | ---- | ---- |
| 原因 | 炎症 | 心衰、低蛋白血症 |
| 血管通透性 | 增加 | 正常 |
| 蛋白质含量 | ＞30g/L | ＜30g/L |
| 蛋白质类型 | 多种（粘蛋白） | 白蛋白 |
| Rivalta试验（0.1%醋酸） | 阳性 | 阴性 |
| 纤维素 | 有 | 无 |
| 细胞数 | ＞500×10⁶/L | ＜100×10⁶/L |
| 比重 | 多数＞1.020 | ＜1.018 |
| 凝固 | 易自凝 | 不能自凝 |
| 透明度 | 浑浊 | 清亮 |

## （一）静脉流体静压增高
- 局部：常由静脉回流障碍引起
	- 肿瘤压迫局部静脉、静脉[[血栓形成]]
	- 妊娠子宫压迫髂总静脉 → 下肢水肿
- 全身：常由右心充血性[[心力衰竭的发生机制|心力衰竭]]引起
	- 静脉流体静压升高
	- 同时启动[[尿生成的调节|肾素-血管紧张素-醛固酮系统]]（renin-angiotensin-aldosterone system，RAAS）→ 肾脏水钠潴留 → 血管内血容量增加
	- 但心力衰竭并不能增加心排出量 → 静脉内积存过量液体、压力升高 → 进入组织间的液体增加 → 水肿
- [[心力衰竭的发生机制|左心衰竭]] → 肺淤血水肿（见 [[充血和淤血#肺淤血\|肺淤血]]）

## （二）血浆胶体渗透压降低
血浆胶体渗透压主要由血浆白蛋白维持。

- 白蛋白合成减少或大量丧失 → 血浆胶体渗透压下降 → 平均实际滤过压增大 → 组织液生成增加并进入组织间隙 → 血浆容量减少
- 肾灌注量随之减少 → 继发性醛固酮增多症（secondary aldosteronism）→ 水钠潴留
- 但水钠潴留并不能纠正血浆白蛋白含量，因而不能恢复血浆容量，反而加重水肿
- 血管外组织胶体渗透压增高同样造成水肿：炎症时局部组织细胞[[坏死]]崩解，局部胶体渗透压升高；毛细血管壁通透性增加，血浆蛋白渗出至组织内 → 局部水肿

## （三）淋巴回流障碍
- 淋巴道堵塞（如肿瘤压迫）→ 淋巴回流受阻或不能代偿性加强回流 → 含蛋白的水肿液在组织间隙聚积 → 淋巴性水肿
- 乳腺癌治疗时切除乳腺或腋下淋巴结、或进行放射治疗 → 患侧上肢严重水肿
- 乳腺癌癌细胞浸润阻塞乳腺皮肤表浅淋巴管 → 皮下组织水肿，呈 #橘皮 样外观
- [[丝虫|丝虫病]] → 腹股沟淋巴管和淋巴结纤维化 → 患侧下肢和阴囊水肿，严重时称 #象皮病（elephantiasis）

# 😭 病理变化

- 大体：水肿的组织肿胀，颜色苍白而质软，切面有时呈胶冻样
- 镜下：水肿液积聚于细胞和纤维结缔组织之间或腔隙内，HE 染色为透亮空白区，细胞外基质成分被水肿液分隔
	- 水肿液蛋白含量多（炎症性水肿）→ 同质性微粒状深红染
	- 蛋白含量少（心性、肾性水肿）→ 淡红染
- 最常见部位：皮下、肺、脑

## （一）皮下水肿

- 不同原因引起的皮下水肿，其部位分布各异，可呈弥漫性，也可呈局部性
- 右心衰竭性水肿：典型的体位性水肿，长期站立时下肢水肿，卧床时骶尾部水肿
- [[肾功能不全]]或肾病综合征：影响全身各部位，但早期首先影响疏松结缔组织，如眼睑水肿
- 皮肤水肿时表面紧张、苍白，用手指压时留下凹陷，称为 #凹陷性水肿（pitting edema）

## （二）肺水肿

- 最常见原因：左心室心力衰竭；其次为肾衰竭、成人呼吸窘迫综合征（adult respiratory distress syndrome，[[急性呼吸窘迫综合征|ARDS]]）、肺部感染和过敏反应
- 水肿液积聚于肺泡腔内
- 大体：肺肿胀、有弹性，质变实，重量比正常增加 2～3 倍，切面有淡红色泡沫状液体渗出

## （三）脑水肿

- 可位于局部受损伤的脑组织周围，如脓肿、肿瘤灶周围
- 也可为全脑性水肿，如脑炎、高血压危象和脑静脉流出通道阻塞
- 脑外伤可引起局部或全脑水肿，取决于损伤的性质和程度
- 大体：脑组织肿胀，脑回变扁平，脑沟变浅，重量增加
- 镜下：脑组织疏松，血管周隙加宽

# 😭 对机体的影响

取决于水肿的部位、程度、发生速度及持续时间。

- 全身性皮下水肿：常提示心力衰竭、肾衰竭或营养不良，对诊断有帮助
- 局部皮肤水肿：影响伤口的愈合和感染的清除
- 肺水肿：影响通气功能，甚至引起死亡。水肿液聚集在肺泡壁毛细血管周，阻碍氧气交换；聚集在肺泡腔内，形成有利于细菌感染的环境
- 脑水肿：颅内压增高、脑疝形成，或压迫脑干血管供应 → 患者快速死亡
- 喉头严重水肿：气管阻塞 → 患者窒息死亡
