# 充血与淤血的比较

| 比较项目   | 充血（动脉性充血）                                       | 淤血（静脉性充血）                                      |
| ------ | ----------------------------------------------- | ---------------------------------------------- |
| 概念     | 动脉输入血量增多，器官或组织血管内血液含量增加                         | 静脉血液回流受阻，血液淤积于细静脉和毛细血管内                        |
| 发生机制   | 小动脉和毛细血管扩张，血液<font color="#ff0000">输入量增加</font> | 细静脉和毛细血管扩张，血液<font color="#ff0000">输出受阻</font> |
| 过程性质   | <font color="#ff0000">主动</font>过程               | <font color="#ff0000">被动</font>过程              |
| 临床意义   | 多为<font color="#ff0000">生理性</font>              | 均为<font color="#ff0000">病理性</font>             |
| 调节因素   | 神经、体液因素                                         | 静脉受压、静脉腔阻塞、心力衰竭                                |
| 持续时间   | 快而短，多可迅速消退                                      | 可急性或慢性，持续时间长                                   |
| 局部颜色   | 鲜红色                                             | 暗红色、紫蓝色（发绀）                                    |
| 局部温度   | <font color="#ff0000">升高</font>（代谢增强）           | <font color="#ff0000">降低</font>                |
| 局部体积   | 轻度增大                                            | 增大                                             |
| 实质细胞变化 | 无明显变化，功能增强                                      | 萎缩、变性、坏死                                       |
| 间质变化   | 无                                               | 水肿、纤维组织增生（淤血性硬化）                               |
| 常见后果   | 生理性代谢增强；炎症性充血                                   | 淤血性水肿、淤血性出血、淤血性硬化                              |
| 举例     | 进食后胃肠道黏膜充血、运动时骨骼肌充血                             | 左心衰→肺淤血；右心衰→肝淤血（槟榔肝）                           |

# 充血（hyperemia）
## ❤ 概念
动脉输入血量增多，使器官或组织血管内血液含量增加，称为动脉性充血（arterial hyperemia），一般简称充血，是一种主动过程，表现为局部组织或器官小动脉和毛细血管扩张，血液输入量增加

- 特点
	- 主动性
	- 多为生理性
	- 神经、体液因素
	- 快而短
## 类型
### 生理性充血
指局部组织或器官因生理需要和代谢增强而发生的充血
例如进食后的胃肠道黏膜充血，运动时骨骼肌组织充血，妊娠时子宫充血等
### 病理性充血
指各种病理状态下局部组织或器官发生的充血。
<font color="#ff0000">炎症性充血</font>是较为常见的病理性充血：致炎因子释放细胞因子、组胺、缓激肽等 → 血管扩张，如化脓性脑膜炎、扁桃体炎
### 减压性充血
局部组织较长时间受压后突然解除压力，细动脉发生反射性扩张而引起的充血。
例如一次性大量抽取腹水、突然解开绷带

# 淤血
## ❤ 概念
器官或局部组织静脉血液回流受阻，血液淤积于细静脉和毛细血管内，导致血量增加，称静脉性充血（venous hyperemia），一般简称淤血。淤血是一种被动过程，可发生于局部或全身。

- 特点
	- 被动性
	- 病理性
	- 静脉受压
## 😊 原因
1. 静脉受压：狭窄、闭塞，回流障碍
	- 肿瘤压迫局部静脉 → 相应组织淤血
	- 肠疝嵌顿、肠扭转、肠套叠 → 压迫肠系膜静脉 → 肠管淤血
	- 肝硬化 → 假小叶形成、假小叶内纤维组织增生 → 压迫肝血窦、小叶下静脉 → 门静脉压升高 → 胃肠道、脾脏淤血
2. 静脉腔阻塞：瘤栓等血栓（如下肢深静脉血栓形成后患肢淤血、水肿、疼痛）
3. 心力衰竭：瓣膜病，高血压，肺心病
	- 二尖瓣或主动脉瓣狭窄和关闭不全、高血压病后期、心肌梗死 → 左心衰 → 肺静脉压升高 → 肺淤血
	- 慢支、支扩、硅沉着病 → 肺心病 → 右心衰 → 中心静脉压升高 → <font color="#ff0000">体循环淤血</font>

> [!note] 淤血的四联后果
> - 发绀（cyanosis）：微循环动脉血灌注量减少，血液内氧合血红蛋白减少而还原血红蛋白增加，局部皮肤呈蓝紫色
> - 淤血性水肿（congestive edema）：毛细血管淤血 → 流体静压升高，缺氧致通透性升高 → 水、盐、少量蛋白质漏出，漏出液潴留于组织内；积聚在浆膜腔时称积液
> - 淤血性出血（congestive hemorrhage）：毛细血管通透性进一步增高或破裂 → 红细胞漏出，形成小灶性出血
> - 淤血性硬化（congestive sclerosis）：长期淤血，组织缺氧、营养物质供应不足和代谢中间产物堆积刺激 → 实质细胞萎缩、变性甚至死亡，间质纤维组织增生，网状纤维胶原化 → 器官逐渐变硬
## 重要器官的淤血

### 肺淤血

由左心衰竭引起，左心腔内压力升高，阻碍肺静脉回流。

#### 急性肺淤血

- 大体：肺体积增大，暗红色，切面流出泡沫状红色血性液体
- 镜下：
  - 肺泡壁毛细血管扩张、充血
  - 肺泡壁增厚，伴肺泡间隔水肿
  - 部分肺泡腔内充满水肿液，可见[[出血]]
![[充血和淤血-1789121068988.webp|688]]![[充血和淤血-1789121078115.webp|681]]![[充血和淤血-1789121087606.webp]]
#### 慢性肺淤血

- 镜下：
  - 肺泡壁毛细血管扩张、充血更明显
  - 肺泡间隔增厚、纤维化
  - 肺泡腔内除水肿液及[[出血]]外，可见大量吞噬 #含铁血黄素颗粒 （普鲁士蓝染色深蓝）的巨噬细胞——即 #心衰细胞 （heart failure cell）
- 结局：肺淤血性硬化 → 质地变硬、呈棕褐色，称 #肺褐色硬化 （brown induration）
#### 临床

- 一般表现：气促、发绀
- 急性肺淤血可致<font color="#ff0000">心源性哮喘</font>
- 急性严重肺水肿：咯大量粉红色泡沫痰、面色如土、呼吸困难、濒死感，可致心肺功能衰竭

### 肝淤血

常由右心衰竭引起，肝静脉回流受阻，血液淤积于肝小叶循环静脉端，致肝小叶中央静脉及肝窦扩张淤血。

#### 急性肝淤血

- 大体：肝脏体积增大，呈暗红色
- 镜下：
  - 肝小叶中央静脉和肝窦扩张，充满红细胞
  - 小叶中央区肝细胞[[萎缩]]、[[坏死]]
  - 小叶周边部肝细胞因靠近肝小动脉、缺氧较轻，可仅出现[[可逆性损伤#脂肪变 fatty change|脂肪变]]性

#### 慢性肝淤血

- 大体：
  - 肝小叶中央区淤血呈暗红色，多个中央淤血区可相连
  - 小叶周边部肝细胞脂肪变性呈黄色
  - 切面红黄相间，状似槟榔切面—— #槟榔肝 （nutmeg liver）
- 镜下：
  - 中央肝窦高度扩张淤血、[[出血]]
  - 中央肝细胞[[萎缩]]，甚至消失
  - 小叶周边部肝细胞[[可逆性损伤#脂肪变 fatty change|脂肪变性]]
- 结局：
  - 长期严重淤血 → 中央区网状纤维塌陷、胶原化
  - Disse间隙肝星状细胞[[增生]]，合成胶原纤维增多
  - 门管区纤维结缔组织[[增生]]
  - 肝脏间质纤维组织广泛增多 → 淤血性肝硬化（congestive liver cirrhosis）
  - 患者出现肝功能损害表现
![[充血和淤血-1789096814508.webp|678]]![[充血和淤血-1789096833536.webp]]![[充血和淤血-1788784331900.webp]]

> [!note] 对比门脉性肝硬化
> 淤血性肝硬化：右心衰→静脉淤血→肝细胞萎缩坏死→肝小叶结构无明显改变
> 门静脉性肝硬化：肝细胞广泛变性坏死→肝内纤维组织增生由肝小叶结构明显改变
