乳腺最常见的良性肿瘤，由纤维间质与腺体增生构成。

## （四）乳腺癌

### 1. 分类

乳腺癌大致分为非浸润性癌和浸润性癌两大类：

| 大类 | 定义 |
| --- | --- |
| 非浸润性癌（原位癌） | 局限于<font color="#ff0000">基底膜以内</font>，未向间质或淋巴管、血管浸润 |
| 浸润性癌 | 突破基底膜向间质浸润 |

> [!important] 浸润的意义
> 一旦向间质浸润，血道转移和淋巴道转移的发生率会明显上升，预后明显变差；原位癌的预后明显更好。

- 导管原位癌 DCIS 和小叶原位癌均来自终末导管-小叶单位上皮细胞；
- 浸润性导管癌是乳腺癌<font color="#ff0000">最常见的类型（70%）</font>；
- 髓样癌、小管癌、黏液癌的预后好于浸润性导管癌。

![[乳腺疾病-乳腺癌分类树.png|500]]

> [!note] 乳腺癌分类树
> - 非浸润性癌：导管原位癌（粉刺癌、非粉刺导管内癌、乳头 Paget 病伴导管原位癌）、小叶原位癌
> - 浸润性癌：浸润性导管癌（70%）、浸润性小叶癌、特殊类型癌（乳头 Paget 病伴导管浸润癌、髓样癌、小管癌、黏液癌）

### 2. 发病机制

![[乳腺疾病-乳腺癌发生三条分子通路.png|500]]

> [!note] 图 19.27 乳腺癌发生的主要分子通路
> - 最常见途径（黄箭头）：正常乳腺 → 平坦上皮不典型性 → 不典型导管增生 → DCIS → 浸润性癌（ER 阳性、HER2 阴性，管腔型），伴胚系 BRCA2 突变、1q 扩增、16q 缺失、PIK3CA 突变
> - 第二条途径（绿箭头）：正常乳腺 → 不典型顶浆分泌腺病 → DCIS → 浸润性癌（HER2 过表达型），伴胚系 TP53 突变、HER2 扩增
> - 第三条途径（蓝箭头）：正常乳腺 →（中间病变不明）→ DCIS → 浸润性癌（基底样型，三阴性），伴胚系 BRCA1 突变、TP53 突变、BRCA1 失活

### 3. 分子亚型

![[乳腺疾病-乳腺癌分子亚型与标志.png|500]]

| 分子亚型 | 分子标志 |
| --- | --- |
| Luminal A（管腔 A 型） | ER+／PR+，HER2− |
| Luminal B（管腔 B 型） | ER+／PR+，HER2+ |
| HER2 过表达型 | ER−，PR−，HER2+ |
| basal-like 型（基底样型） | ER−，PR−，HER2−，CK5/6+ 或 EGFR+ |

免疫组化标志的意义（源笔记原文）：

| 标志 | 意义 |
| --- | --- |
| ER（雌二醇／雌激素受体）、PR（孕酮／孕激素受体） | 阻断 ER 和 PR 的作用环节可抑制乳腺癌生长；受体阳性者，尤其两种受体均阳性者，可应用内分泌治疗作为辅助手段；ER 和 PR 与预后有关，阳性者转移率低、存活时间长 |
| HER2 | 原癌基因；过表达者，预后好 |
| EGFR（表皮生长因子受体） | CK5/6 阳性者预后可能较差 |

> [!warning] 待核对
> 源笔记此处写「HER2 过表达者，预后好」，与本篇上文分子亚型表（HER2 过表达型多为侵袭性强）及教材通行说法相反，疑为转录或原文笔误，复习时以教材为准。

### 4. 病理变化

| 类型 | 肉眼 | 镜下 |
| --- | --- | --- |
| 非浸润性癌－导管原位癌 DCIS（高级别，粉刺癌） | 乳腺中央部位常见；切面可见扩张的导管，管腔内含灰黄色膏样坏死物质，挤压时可从导管溢出，如皮肤粉刺 | 癌细胞体积大、多形，核仁明显，核分裂象多见，细胞排列常紧密；中央有大片坏死 |
| 非浸润性癌－DCIS（中级别） | 无明显特征 | 结构表现多样，细胞异型性位于高级别和低级别之间 |
| 非浸润性癌－DCIS（低级别） | 无明显特征 | 癌细胞较小、单形，核仁不明显，核分裂象少见，一般无坏死或仅有轻微坏死 |
| 非浸润性癌－小叶原位癌 LCIS | 无明显特征 | 癌细胞局限于基底膜内，充满轻度扩张的小叶腺泡和小叶末梢导管，小叶结构尚存 |
| 浸润性癌－浸润性导管癌 | 外上象限常见；灰白色、质硬，无包膜，界限不清；切面有沙砾感，星状或蟹足状；可导致乳头下陷或呈橘皮样外观 | 癌细胞排列成巢状、团索状；肿瘤间质有纤维组织增生，癌细胞在纤维间质内浸润生长 |
| 浸润性癌－浸润性小叶癌 | 双侧多发；切面呈橡皮样，色灰白柔韧，与周围组织无明确界限 | 癌细胞呈单行串珠状或细条索状（列兵状），浸润于纤维间质之间，或环形排列在正常导管周围 |

> [!note] 补充
> - 高级别 DCIS 转变为浸润癌的几率远远高于低级别；
> - 小叶癌共有的特点：容易双侧乳房发病，多中心受累，血道转移多见。

### 5. 两个肉眼体征的机制

| 体征 | 机制 |
| --- | --- |
| 乳头下陷 | 癌肿侵及乳头，且伴大量纤维组织增生，癌周增生的纤维组织收缩所致 |
| 橘皮样外观 | 癌组织阻塞真皮内淋巴管，致皮肤水肿，而毛囊汗腺处皮肤相对下陷 |

### 6. 扩散

| 途径 | 内容 |
| --- | --- |
| 直接蔓延 | 沿乳腺导管直接蔓延，可累及相应的乳腺腺泡；沿导管周围组织间隙向周围扩散到脂肪组织；癌组织不断扩大，甚至可侵及胸大肌和胸壁 |
| 淋巴道转移 | 最常见的转移途径：①同侧腋窝淋巴结；②锁骨下淋巴结、逆行转移至锁骨上淋巴结；③纵隔淋巴结；④对侧腋窝淋巴结 |
| 血道转移 | 晚期可经血道转移至肺、骨、肝、脑等组织和器官 |
