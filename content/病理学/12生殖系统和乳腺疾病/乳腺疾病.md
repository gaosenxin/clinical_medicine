## （四）乳腺癌

### 1. 分类

乳腺癌大致分为非浸润性癌和浸润性癌两大类：

| 大类 | 定义 |
| --- | --- |
| 非浸润性癌（原位癌） | 局限于<font color="#ff0000">基底膜以内</font>，未向间质或淋巴管、血管浸润 |
| 浸润性癌 | 突破基底膜向间质浸润 |

> [!important] 浸润的意义
> 一旦向间质浸润，血道转移和淋巴道转移的发生率会明显上升，预后明显变差；原位癌的预后明显更好。

- 导管原位癌 DCIS 和小叶原位癌均来自终末导管-小叶单位上皮细胞；
- 浸润性导管癌是乳腺癌<font color="#ff0000">最常见的类型（70%）</font>；
- 髓样癌、小管癌、黏液癌的预后好于浸润性导管癌。

### 2. 发病机制

![[乳腺疾病-乳腺癌发生三条分子通路.png|500]]

> [!note] 图 19.27 乳腺癌发生的主要分子通路
> - 最常见途径（黄箭头）：正常乳腺 → 平坦上皮不典型性 → 不典型导管增生 → DCIS → 浸润性癌（ER 阳性、HER2 阴性，管腔型），伴胚系 BRCA2 突变、1q 扩增、16q 缺失、PIK3CA 突变
> - 第二条途径（绿箭头）：正常乳腺 → 不典型顶浆分泌腺病 → DCIS → 浸润性癌（HER2 过表达型），伴胚系 TP53 突变、HER2 扩增
> - 第三条途径（蓝箭头）：正常乳腺 →（中间病变不明）→ DCIS → 浸润性癌（基底样型，三阴性），伴胚系 BRCA1 突变、TP53 突变、BRCA1 失活

### 3. 分子亚型
| 分子亚型         | 分子标志                                                      | 意义                     |
| ------------ | --------------------------------------------------------- | ---------------------- |
| 管腔A型         | <font color="#ff0000">ER+/PR+</font>，HER2-                | 分化较好，对激素治疗敏感，预后较好      |
| 管腔B型         | <font color="#ff0000">ER+/PR+</font>，HER2+                |                        |
| HER2过表达型     | ER-，PR-，<font color="#ff0000">HER2+</font>                | 分化较差，对激素治疗不敏感，靶向治疗反应好  |
| 三阴性乳腺癌（基底样型） | <font color="#ff0000">ER-，PR-，HER2-</font>，CK5/6+ 或 EGFR+ | 三阴性乳腺癌分化差，15%～20%化疗敏感。 |

免疫组化标志的意义：

| 标志                         | 意义                                                                                   |
| -------------------------- | ------------------------------------------------------------------------------------ |
| ER（雌二醇／雌激素受体）、PR（孕酮／孕激素受体） | 阻断 ER 和 PR 的作用环节可抑制乳腺癌生长；受体阳性者，尤其两种受体均阳性者，可应用内分泌治疗作为辅助手段；ER 和 PR 与预后有关，阳性者转移率低、存活时间长 |
| HER2                       | 原癌基因；过表达者，预后好                                                                        |
| EGFR（表皮生长因子受体）             | CK5/6 阳性者预后可能较差                                                                      |


### 4. 病理变化

| ⁣‍⁣​‌‌​‌‌​‌​‌‌​‌‌​‌​‌‌‌​‌‌‌​‌‌​‌​‌‌​‌‌​​​​‌​‌‌​‌‌​‌​​‌‌​‌​‌​‌‌‌​​​​​‌‌‌​​​​​​‌‌‌​​​​‌‌‌​​‌​​‌‌​​‌​‌​‌‌‌​‌‌‌​‌‌​‌​‌​​‌‌​‌‌​​⁣‌⁣类型 |                                       | 肉眼                                                                                                                                                                                      | 镜下                                                                                                         |
| -------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| **导管原位癌**                                                                                                                        | <font color="#ff0000">高级别（粉刺癌）</font> | 乳腺中央部位常见，切面可见扩张导管，内含灰黄色软膏样坏死物质，如皮肤粉刺                                                                                                                                                    | 癌细胞<font color="#ff0000">体积大，多形，核分裂象常见，</font>细胞排列常呈实心团块；<font color="#ff0000">导管中央有大的坏死灶</font>，且容易转化为浸润癌 |
|                                                                                                                                  | 中级别                                   | 结构表现多样                                                                                                                                                                                  | 细胞异型性介于高级别和低级别导管原位癌之间                                                                                      |
|                                                                                                                                  | 低级别（非粉刺型）                             | 病变范围<font color="#ff0000">≥2mm（十版）</font>                                                                                                                                               | 癌细胞<font color="#ff0000">小，大小一致，核分裂像少见</font>，一般无坏死或仅有轻微坏死                                                 |
| **小叶原位癌**                                                                                                                        |                                       | 常为<font color="#ff0000">多中心性</font>，累及<font color="#ff0000">双侧</font>乳腺                                                                                                                 | 癌细胞局限于基底膜内，充满轻度扩张的小叶腺泡，小叶结构存在                                                                              |
| <font color="#ff0000">**浸润性导管癌**</font>                                                                                          |                                       | <font color="#ff0000">外上象限</font>常见，界限不清，切面<font color="#ff0000">沙砾感</font>，<font color="#ff0000">星状或蟹足状</font>，可导致<font color="#ff0000">乳头下陷</font>或<font color="#ff0000">橘皮样</font>外观 | <font color="#ff0000">癌细胞排列成巢状、团索状；肿瘤间质有纤维组织增生，癌细胞在纤维间质内浸润生长</font>                                        |
| **浸润性小叶癌**                                                                                                                       |                                       | 双侧多发，切面呈橡皮样，色灰白柔韧，与周围组织<font color="#ff0000">无明确界限</font>                                                                                                                               | 癌细胞<font color="#ff0000">呈单行串珠状或细条索状浸润于纤维间质之间</font>或环形排列在正常导管周围，呈“列兵样”排列                                  |
| **Paget病（湿疹样癌）**                                                                                                                 |                                       | 乳头和乳晕渗出和浅表溃疡，呈<font color="#ff0000">湿疹样改变</font>                                                                                                                                        | 导管内癌（伴或不伴间质浸润）同时伴有胞内大并异形、胞质透明的肿瘤细胞                                                                         |

> [!note] 补充
> - 高级别 DCIS 转变为浸润癌的几率远远高于低级别；
> - 小叶癌共有的特点：容易双侧乳房发病，多中心受累，血道转移多见。

| 类型           | 病理特点                                                                                                                                   | 预后  |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------- | --- |
| 髓样癌          | 癌灰白、质软，<font color="#ff0000">边界清楚。癌细胞大而密集(由大细胞组成)，相互融合成片(大量癌细胞巢)</font>，癌细胞巢之间间质少(纤维组织少)癌巢周围有<font color="#ff0000">明显的厚层淋巴细胞浸润</font>。 | 较好  |
| 小管癌          | 为高分化腺癌(分化好)，癌组织主要由形态规则的腺管样结构组成(大量腺体形成)，浸润于基质中，腺管上皮细胞为单层，细胞小，轻度异型，<font color="#ff0000">恶性程度低</font>。                                   | 较好  |
| 黏液(腺)癌       | 癌细胞分泌大量黏液释放到间质中，黏液中漂浮癌细胞团，偶在细胞内呈<font color="#ff0000">印戒样</font>。                                                                      | 较好  |
| 佩吉特病（Paget病） | 癌细胞沿乳腺导管向上扩散，累及乳头和乳晕，在表皮内可见大而异型，胞质透明的癌细胞。乳头和乳晕可见渗出和浅表溃疡，呈<font color="#ff0000">湿疹样改变(又称湿疹样癌)</font>。                                   | 较好  |

### 5. 两个肉眼体征的机制

| 体征 | 机制 |
| --- | --- |
| 乳头下陷 | 癌肿侵及乳头，且伴大量纤维组织增生，癌周增生的纤维组织收缩所致 |
| 橘皮样外观 | 癌组织阻塞真皮内淋巴管，致皮肤水肿，而毛囊汗腺处皮肤相对下陷 |

### 6. 扩散

| 途径    | 内容                                                                                 |
| ----- | ---------------------------------------------------------------------------------- |
| 直接蔓延  | 沿乳腺导管直接蔓延，可累及相应的乳腺腺泡；沿导管周围组织间隙向周围扩散到脂肪组织；癌组织不断扩大，甚至可侵及胸大肌和胸壁                       |
| 淋巴道转移 | <font color="#ff0000">最常见的转移途径</font>：①同侧腋窝淋巴结；②锁骨下淋巴结、逆行转移至锁骨上淋巴结；③纵隔淋巴结；④对侧腋窝淋巴结 |
| 血道转移  | 晚期可经血道转移至肺、骨、肝、脑等组织和器官                                                             |
