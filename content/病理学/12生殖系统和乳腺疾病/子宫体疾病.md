# 二、子宫体疾病

## （一）子宫内膜异位症

【子宫内膜异位症】：子宫内膜腺体与间质出现于子宫内膜以外的部位。

| ⁣‍⁣​‌‌​‌‌​‌​‌‌​‌‌​‌​‌‌‌​‌‌‌​‌‌​‌​​‌​‌‌‌​‌‌​​‌‌‌‌​‌​​‌‌​‌‌‌‌​‌‌​‌​​‌​‌‌​‌​​‌​‌‌​‌‌​‌​​‌‌‌​​‌​‌‌​‌‌​​​‌‌‌​‌‌‌​‌‌‌​​​​​‌‌‌‌​​‌⁣‌⁣项目   | 内容                                                                |
| ---- | ----------------------------------------------------------------- |
| 部位   | <font color="#ff0000">常见于卵巢（80%）</font>、子宫阔韧带、直肠阴道陷凹、盆腔腹膜、腹部手术瘢痕等 |
| 肉眼   | 点灶状紫红或棕黄结节                                                        |
| 镜下   | 正常的子宫内膜腺体、子宫内膜间质、含铁血黄素                                            |
| 临床表现 | 痛经、月经不调、不孕                                                        |

两种特殊类型：

| 类型                                 | 定义                                                                    |
| ---------------------------------- | --------------------------------------------------------------------- |
| 子宫腺肌病（adenomyosis）                 | 子宫内膜异位于子宫肌层中，至少距子宫内膜基底层 2mm 以上                                        |
| <font color="#ff0000">巧克力囊肿</font> | 子宫内膜异位于卵巢，反复周期性出血致卵巢体积增大，形成囊腔，内含<font color="#ff0000">黏稠的咖啡色液体</font> |

## （二）子宫内膜增生症

| 项目     | 内容                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 概念     | 由内源性或外源性雌激素增高引起的子宫内膜腺体或间质增生，子宫内膜增生、不典型增生和子宫内膜癌，无论是形态学还是生物学，都为一连续的演变过程。                                                                                                                                                                                                                                                                                                                                                                                        |
| 分型（十版） | 1.增生不<font color="#ff0000">伴不典型性：</font>腺体与子宫内膜间质的比例大于1 : 1；可拥挤呈<font color="#ff0000">背靠背图像</font>。衬覆腺体的上皮一般呈复层柱状，<font color="#ff0000">无异型性</font>，细胞形态和排列与增殖期子宫内膜相似。<font color="#ff0000">1% ~ 3%可进展</font>为高分化子宫内膜样腺癌。<br>2.子宫内膜<font color="#ff0000">不典型增生</font>：<font color="#ff0000">子宫内膜样癌前驱病变</font>，腺上皮排列拥挤，腺上皮细胞<font color="#ff0000">具有异型性</font>，细胞极性紊乱，体积增大，核质比例增加，核染色质浓聚，核仁醒目，常伴有鳞状细胞化生。<font color="#ff0000">约1/3的诊断时伴有癌或在1年内发展为子宫内膜癌</font>。 |


## （三）子宫内膜腺癌

【子宫内膜腺癌】：来源于子宫内膜上皮细胞的恶性肿瘤。

| 项目  | 内容                                                                                                                     |
| --- | ---------------------------------------------------------------------------------------------------------------------- |
| 病因  | 多见于绝经期或绝经期后；绝大多数为子宫内膜样腺癌，与子宫内膜增生和雌激素长期持续作用有关；不科学使用雌孕激素替代疗法使发病率上升；肥胖、糖尿病、吸烟也是高危因素，常有<font color="#ff0000">TP53突变</font> |

### 1. 肉眼

| 类型  | 特点                                                                                                        |
| --- | --------------------------------------------------------------------------------------------------------- |
| 弥漫型 | 子宫内膜弥漫性增厚，表面粗糙不平，常有出血坏死，并不同程度浸润子宫肌层                                                                       |
| 局限型 | 多位于<font color="#ff0000">子宫底</font>或<font color="#ff0000">子宫角</font>，呈息肉或乳头状突向宫腔；若癌组织小而浅，诊断性刮宫时可全部刮出，预后较好 |

### 2. 镜下

根据癌组织内子宫内膜腺体所占比例和细胞分化程度分类：

| 分化    | <font color="#ff0000">腺体占比</font> | 特点                                        |
| ----- | --------------------------------- | ----------------------------------------- |
| 高分化腺癌 | ≥95%（此型居多）                        | 轻至中度异型性，形似增生期子宫内膜腺体                       |
| 中分化腺癌 | 50%～94%                           | 腺体不规则、排列紊乱，细胞向腺腔内生长形成乳头或筛状结构；异型性明显，核分裂象易见 |
| 低分化腺癌 | ＜50%                              | 癌细胞分化差，多呈实体片状排列，异型性明显，核分裂象多见              |

### 3. 扩散

直接蔓延最常见、最重要；晚期可经淋巴道转移；血道转移少见。

> [!note] 其他组织学类型
> 除子宫内膜样腺癌（最经典）外，还有子宫内膜浆液性癌（常有 p53 突变）、子宫内膜透明细胞癌；两者预后均较子宫内膜样腺癌差。

## （四）子宫平滑肌瘤

女性生殖系统最常见的肿瘤。

### 1. 病理变化

| 项目   | 内容                                                                                                                                                                                                                      |
| ---- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 肉眼   | 多数肿瘤发生于<font color="#ff0000">子宫肌层</font>，也可位于<font color="#ff0000">黏膜下或浆膜下</font>。<br>肿瘤边界清，无包膜。切面灰白，质韧，<font color="#ff0000">编织状或旋涡状</font>。<br>当肌瘤间质血管内有血栓形成时，肿瘤局部可发生梗死伴出血，肉眼呈暗红色，称<font color="#ff0000">红色变性</font>。 |
| 红色变性 | 间质血管内有血栓生成时，肿瘤局部发生梗死伴出血，肉眼呈暗红色                                                                                                                                                                                          |
| 镜下   | <font color="#ff0000">瘤细胞与正常子宫平滑肌细胞相似，梭形、束状或旋涡状排列</font>，胞浆红染，核呈长杆状、两端钝圆；<font color="#ff0000">核分裂少见，缺乏异型性</font>，与周围正常组织界限清楚<br>如肿瘤组织出现坏死，边界不清，细胞显著异型，核分裂象增多，应诊断<font color="#ff0000">平滑肌肉瘤</font>。<br>                |

### 2. 预后与平滑肌肉瘤

- 子宫平滑肌瘤<font color="#ff0000">极少恶变</font>，多数平滑肌肉瘤从开始即为恶性；
- 若肿瘤组织出现坏死、边界不清、细胞异型、核分裂象增多，应考虑平滑肌肉瘤；
- 平滑肌肉瘤有很高的复发倾向，常血行转移，也可在腹腔播散。

### 3. 临床病理联系

- 最主要的症状：黏膜下平滑肌瘤引起出血，或压迫膀胱引起尿频；
- 血流阻断可引起突发性疼痛；
- 可导致自然流产、胎儿先露异常、绝经后流血。
