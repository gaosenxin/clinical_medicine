# 三、滋养层细胞疾病

包括葡萄胎、侵袭性葡萄胎、绒毛膜癌、胎盘部位滋养细胞肿瘤，共同特征为<font color="#ff0000">滋养层细胞增生</font>；患者血清和尿液中人绒毛膜促性腺激素（hCG）含量高于正常妊娠。

|                                     | 完全性葡萄胎(多见)                                                                                                                               | 不完全性葡萄胎                                                                                                                                                  |
| ----------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 病理形态                                | 所有绒毛均呈葡萄状<br>(<font color="#ff0000">缺乏</font>胚胎或胎儿组织)                                                                                    | 部分绒毛呈葡萄状，部分正常绒毛<br>(<font color="#ff0000">可</font>伴胚胎或胎儿组织)                                                                                              |
| 染色体核型                               | <font color="#ff0000">二倍体</font>（2024N151X）：<br>①主要:46XX(23X精子在空卵中自我复制形成)<br>②少数:46XY(两个精子23X和23Y+一个<font color="#ff0000">空卵</font>结合形成) | <font color="#ff0000">三倍体或四倍体</font>:<br>①大部分:69XXX或69XXY<br><font color="#ff0000">正常23X卵子</font>+一个没有发生减数分裂的双倍体精子(46XY)或两个单倍体精子(23X或23Y)<br>②极少数:92XXXY |
| 起源                                  | 均为<font color="#ff0000">男性遗传起源</font><br>缺乏卵子染色体→胚胎不能发育                                                                                  | 男性和女性共同起源<br>有精子+卵子染色体→可伴胚胎组织                                                                                                                            |
| <font color="#ff0000">p57核染色</font> | 阴性（十版新增）                                                                                                                                 | 阳性（十版新增）                                                                                                                                                 |

## （一）葡萄胎、侵袭性葡萄胎与绒毛膜癌
| 类型  | 葡萄胎                                                         | 侵袭性葡萄胎                                                                                                        | 绒毛膜癌                                                                                                                |
| --- | ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| 性质  | 良性肿瘤                                                        | 交界性肿瘤                                                                                                         | <font color="#ff0000">高度侵袭性</font>恶性肿瘤                                                                              |
| 肉眼  | 绒毛<font color="#ff0000">水肿</font>，形成透明或半透明的薄壁水泡，似葡萄状        | <font color="#ff0000">水泡状绒毛侵入子宫肌层</font>，紫蓝色的出血坏死结节                                                           | 子宫壁内出血坏死性结节，广泛出血与坏死                                                                                                 |
| 镜下  | 绒毛间质高度疏松水肿而增大<br>绒毛间质一般无血管，或有少数无功能血管<br>滋养层细胞有不同程度的增生，可轻度异型 | 子宫肌层内见水泡状绒毛<br>滋养层细胞增生明显和<font color="#ff0000">异型性</font><br><font color="#ff0000">与葡萄胎的区别</font>：水泡状绒毛侵入子宫肌层 | <font color="#ff0000">三无：无绒毛结构、无间质、无血管</font><br>广泛出血坏死<br>异型滋养层细胞<br><font color="#ff0000">与侵袭性葡萄胎的区别：无绒毛结构</font> |
| 预后  | 清宫后80～90%痊愈；<br>10%发展为侵袭性葡萄胎；<br>2%恶变（绒毛膜癌）                 | 对化疗敏感，预后良好                                                                                                    | <font color="#ff0000">血道转移（肺转移）</font>是绒毛膜癌的显著特点；化疗效果好                                                              |

> [!note] 正常绒毛的变化
> 正常绒毛在妊娠 3 个月后，滋养层细胞仅剩合体滋养层细胞；但葡萄胎中两种细胞持续存在并活跃增生，失去正常排列。

## （二）三种滋养层细胞疾病的区别

| 疾病     | 绒毛                             | 滋养层细胞增生 | 侵袭                                                                     |
| ------ | ------------------------------ | ------- | ---------------------------------------------------------------------- |
| 葡萄胎    | 有                              | 有，轻度异型性 | 无                                                                      |
| 侵袭性葡萄胎 | 有                              | 有，中度异型性 | <font color="#ff0000">侵入子宫肌层</font>，可伴有出血坏死                            |
| 绒毛膜癌   | <font color="#ff0000">无</font> | 有，重度异型性 | 位于子宫不同部位，大者可突入宫腔，常侵入深肌层，甚至穿透宫壁达浆膜外；<font color="#ff0000">广泛出血坏死</font> |

## （三）胎盘部位滋养细胞肿瘤与上皮样滋养细胞肿瘤

- 与绒毛膜癌不同之处：由单一增生的胎盘中间型滋养细胞组成；
- 免疫组化：大多数中间型滋养细胞——胎盘部位滋养细胞肿瘤胎盘催乳素（hPL）弥漫性阳性，上皮样滋养细胞肿瘤胎盘催乳素（hPL）散在性阳性。
