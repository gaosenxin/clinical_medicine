# 一、子宫颈疾病（学长笔记）

## （一）慢性子宫颈炎

子宫颈自外口向内依次为鳞状上皮、鳞-柱状上皮交界、柱状上皮。

| 项目 | 内容 |
| --- | --- |
| 病因 | 链球菌、肠球菌、葡萄球菌、沙眼衣原体、淋病奈瑟菌、乳头状瘤病毒、单纯疱疹病毒 |
| 危险因素 | 分娩、机械损伤 |
| 临床表现 | 白带增多、阴道出血 |
| 镜下 | 子宫黏膜充血水肿；间质有淋巴细胞、单核细胞、浆细胞浸润；腺上皮增生或鳞状上皮化生 |

慢性子宫颈炎的常见继发改变：

| 改变 | 形成机制与形态 |
| --- | --- |
| 纳博特囊肿（子宫颈囊肿） | 鳞状上皮增生覆盖，阻塞子宫颈腺体开口，黏液潴留，腺体扩大呈囊 |
| 子宫颈息肉 | 黏膜增生、充血水肿，向表面突起 |
| 子宫颈假性糜烂 | 柱状上皮（薄）在雌激素作用下下移取代鳞状上皮，上皮下血管易显露，呈红色；真性糜烂很少见 |

## （二）子宫颈上皮内瘤变与子宫颈癌

### 1. 子宫颈癌的病因

- 多发生于 30～60 岁女性，近年有年轻化趋势；
- 与性生活过早、性生活紊乱、早婚、多产、宫颈裂伤、局部卫生不良、包皮垢刺激等多种因素有关；
- 人乳头状瘤病毒 HPV 感染可能是子宫颈癌发病的最主要原因，尤其是 <font color="#ff0000">HPV-16、18、31、33</font> 为高风险亚型；
- 病毒癌基因 E6、E7 与宫颈上皮细胞基因组整合后，编码使 TP53、RB 失活的蛋白；
- p16 蛋白是高危型 HPV 基因表达的指标，阳性可辅助诊断。

### 2. 子宫颈上皮内瘤变（CIN）

【子宫颈上皮内瘤变】（cervical intraepithelial neoplasia, CIN）：宫颈鳞癌的癌前病变。子宫颈上皮被不同程度异型性的细胞取代，表现为细胞大小、形态不一，核大而深染，核质比增高，核分裂象增多，出现病理性核分裂象，细胞极性紊乱；可见挖空细胞或鳞状上皮异型增生。

好发部位：子宫颈鳞状上皮与柱状上皮交界处（<font color="#ff0000">移行带</font>）；病变由基底层逐渐向表层发展，分三级。

| 分级 | 累及范围 | 鳞状上皮内病变 | 免疫组化 |
| --- | --- | --- | --- |
| 子宫颈上皮内瘤变Ⅰ级（CINⅠ） | 局限于上皮的下 1/3 | LSIL | —— |
| 子宫颈上皮内瘤变Ⅱ级（CINⅡ） | 累及上皮层的下 1/3～2/3 | HSIL | p16 细胞核和（或）细胞质阳性；Ki-67 细胞核阳性 |
| 子宫颈上皮内瘤变Ⅲ级（CINⅢ） | 超过全层的 2/3，包含重度不典型增生与原位癌 | HSIL | p16 细胞核和（或）细胞质阳性；Ki-67 细胞核阳性 |

![[子宫颈疾病-正常LSIL与HSIL鳞状上皮病变谱.png|500]]

> [!note] 图解
> 正常鳞状上皮、LSIL、HSIL 的对比：LSIL 可见挖空细胞性异型；HSIL 上皮全层渐进性异型；最右为全层弥漫异型伴成熟丧失（原位癌）。

> [!important] 原位癌（carcinoma in situ, CIS）
> 异型增生的细胞累及子宫颈黏膜上皮全层，但病变局限于上皮层内，<font color="#ff0000">未突破基底膜</font>。

### 3. CIN 的预后

- CINⅠ 不一定都发展为 CINⅡ、CINⅢ 乃至浸润癌，经适当治疗，多数可逆转或治愈；
- 发展为 CINⅢ 乃至浸润癌的几率和所需时间与上皮内瘤变的程度有关：病变级别越高，转化概率越高，所需时间越短；
- LSIL 癌变概率小，预后好；HSIL 与之相反。

### 4. 辅助检查

| 试验 | 原理与表现 |
| --- | --- |
| 碘液染色（碘试验） | 正常子宫颈鳞状上皮富含糖原，对碘着色；患处不着色，提示有病变 |
| 醋酸试验 | 醋酸可使子宫颈有 CIN 改变的区域呈白色斑片状 |

## （三）子宫颈浸润癌

好发部位：子宫颈鳞状上皮与柱状上皮交界处（移行带）。

### 1. 肉眼类型

| 类型 | 特点 |
| --- | --- |
| 糜烂型 | 病变处黏膜潮红、呈颗粒状，质脆，触之易出血；病变深度非常浅，浸润表现轻，预后好，多属于原位癌和早期浸润癌 |
| 外生菜花型 | 癌组织主要向子宫颈表面生长，形成乳头状或菜花状突起，表面常有坏死和浅表溃疡形成 |
| 内生浸润型 | 癌组织主要向子宫颈深部浸润生长，使宫颈前后唇增厚变硬，表面常较光滑 |
| 溃疡型 | 癌组织除向深部浸润外，表面同时有大块坏死脱落，形成溃疡，似火山口状 |

### 2. 镜下类型

| 类型 | 比例与特点 |
| --- | --- |
| 鳞状细胞癌 | <font color="#ff0000">80%</font>；早期浸润癌浸润深度不超过基底膜下 <font color="#ff0000">5mm</font>；浸润深度超过 5mm 者为浸润癌，按分化程度分角化型鳞癌（高分化，可见角化珠形成）与非角化型鳞癌（低分化） |
| 腺癌 | 20%；常与 HPV 感染有关，分高分化、中分化、低分化三型；对放疗、化疗均不敏感，预后较差 |

### 3. 扩散

| 途径 | 内容 |
| --- | --- |
| 直接蔓延 | 向上浸润破坏整段子宫颈，很少侵犯子宫体；向下累及阴道穹窿、阴道壁；向两侧累及宫旁及盆壁组织；晚期可向前累及膀胱、向后累及直肠。临床分期时参照蔓延部位 |
| 淋巴道转移 | 最常见、最重要的转移途径；首先转移至子宫旁淋巴结，依次至闭孔、髂内、髂外、髂总、腹股沟与骶前、腹主动脉旁淋巴结，晚期可至锁骨上淋巴结 |
| 血道转移 | 较少见；晚期可经血道转移至肺、骨、肝 |

### 4. 临床分期

| 分期 | 范围 |
| --- | --- |
| 0 期 | 原位癌（CINⅢ级） |
| Ⅰ期 | 癌局限于子宫颈以内 |
| Ⅱ期 | 肿瘤超出子宫颈进入盆腔，但未累及盆侧壁；癌肿侵及阴道，但未累及阴道下 1/3 |
| Ⅲ期 | 癌扩展至骨盆壁及阴道下 1/3 |
| Ⅳ期 | 癌组织已超越骨盆，或累及膀胱黏膜（向前）或直肠（向后） |
